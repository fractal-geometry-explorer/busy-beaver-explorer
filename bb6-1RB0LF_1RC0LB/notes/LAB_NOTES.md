# Lab notes: 1RB0LF_1RC0LB_1RD1RB_1RE1RF_1LA---_0RC1LA

## 2 November 2026: setup and first look

Set up on the shared tools (`../../tools`): `lean/Machine.lean` generated by `bbtools.leangen` (namespace `BB6e`),
bounded runs in `lean/Blank.lean`, the reference simulator wrapped in `py/blank.py`, both pages built from
`status.json`.

The table, with the halting transition E1:

| state | on 0 | on 1 |
|---|---|---|
| A | 1RB | 0LF |
| B | 1RC | 0LB |
| C | 1RD | 1RB |
| D | 1RE | 1RF |
| E | 1LA | halt |
| F | 0RC | 1LA |

**Where a halt comes from.** E is entered only by D0 (write 1, move right), and D only by C0 (write 1, move
right). So the machine halts exactly when D reads a 0 whose right neighbour is 1 (`halt_shape`, kernel). B sweeps
left over 1s erasing them (B1 = 0LB).

**Bounded runs.** No halt in 20,000 steps (kernel), 10⁷ (`native_decide`), 10¹⁰ (C `tmrun`: 313 ones, 642 cells
visited; the last new cell before that was reached at step 9,311,800,524, on the left).

**No linear invariant.** `bbtools.invariants` finds no conserved a·ones + b·pos + W[state] modulo 2 to 12.

**No small closed tape language.** `bbtools.ctl` with windows of K = 3 to 6 cells closes, but every one of them still
allows a halt (`E` on a 1 with `1 1 0 …` to the left), so window CTLs of this size do not decide the machine.

**D reading a 0.** In the first 3·10⁶ steps D reads a 0 103,296 times, always with a 0 to its right (57 of them at
the right end of the visited tape). `python3 py/blank.py dzero STEPS` lists them.

**Growth.** The width is 128 cells after 10⁵ steps, 199 after 10⁶ and 642 after 10¹⁰: much slower than the other
machines here, so the time per new cell grows quickly and a pass over the tape is probably nested inside a counter.
The records (`python3 py/blank.py records 100000 60`) alternate between right-end visits `… 0 1^b B>0` followed by
`C>0`, `D>0`, `E>0` one step apart, and left-end visits `F>0 0 1 0 1 0^2 1 0 1 0 1 …`. At the right ends the tape is
blocks of 1s of even length separated by single 0s.
