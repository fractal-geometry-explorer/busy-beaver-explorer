Busy Beaver Explorer

Interactive pages on six-state Turing machines: three BB(6) holdouts and the current BB(6) champion.

The holdout

1RB0RE_1LC0RA_1LA1LD_1LA---_0RF0LB_0LD1RE

Proof status What is proved in Lean about a halt from blank tape, what is still open, and how to check it yourself. Closing-gap rule map A summary of the research: what each rule does, the mark model, the loop and how it ends, and what is established and how firmly. Mark-rule stepper Steps the mark rules one round at a time from a tape you choose. On small tapes each round is also run on the bare machine and compared.

The holdout 1RB1RA_1RC1LB

1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB

Proof status What is proved in Lean, what is computed and what is only observed about this machine, kept apart. The reduction How the run comes down to one number N that must be a power of two for a halt, link by link, with what each link rests on. The top blocks Where halting is decided: the number d1 at each return to the left end, the proof that N only grows, the corrected odds and tests of the random model. Level by level Runs the machine in the browser at five levels: raw steps, block rules, the macro step, the halving wave and the number N.
