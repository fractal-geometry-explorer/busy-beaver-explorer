Busy Beaver Explorer / 1RB1RA_1RC1LB

What is known about 1RB1RA_1RC1LB, and what is open

1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape. This page tracks what has been established about it, sorted by what each result rests on.

The run's structure is now proved in two layers. Lean has the machine as an explicit map on lists of block lengths, and a theorem that the machine halts exactly when that map's run reaches one specific shape. Read four macro steps at a time, that map is a carry wave running left through the blocks, and Lean now also proves that the halting shape is one arithmetic event: a single number built from the blocks being a power of two. What is open is whether it ever is.

The reduction walks through this link by link; level by level runs the machine in the browser at each level.

Status as of 30 October 2026.

In short

The question is open, and it is now a question about a list map. Lean proves that one macro step of the machine (a phase of transfers, then a sweep to the right or a carry to the left) is an explicit function next on the lists of block lengths, step counts included, and that the machine halts from blank tape iff the macro run reaches a halt. A macro step halts exactly when the head's block is odd and, after the transfers, every block to the left of the head is 2.

Running that map, Lean's kernel proves no halt in the first 2·1010 steps. Lean now also proves the exact machine-step count of each super step (below), so following the super orbit gives longer runs: no halt in the first 1.4·1016 steps checked by the kernel alone, and, with native_decide, no halt in the first 1024 steps by the plain orbit. Skipping over the cycles of the last 30 blocks, the kernel alone checks no halt in the first 1.2·1032 steps (below). In those runs the blocks reach the billions, far from all 2s. What is missing is an argument that the map never produces that shape.

The halting condition in one number, proved. Every fourth time A stands on the blank right of the tape, the tape is blocks p1, …, pm followed by 5, 0, and the next such tape follows from an explicit formula: with dm+1 = 20 and dl = pl + dl+1/2, a wave of halvings runs left while d is even and turns at the first odd d. Lean proves this super step from the macro map for every list, and proves that the machine halts from blank tape iff N = 10 + Σ pl·2m−l (the blocks read as binary digits) is a power of two at some super step of the orbit from (1, 6). The wave reaches the left end when 2m−1 divides N, which explains why the head gets there so rarely (computed, not part of the proof). Read from the right end, the super step is a cascade in which each block only passes something to the block on its left, so the last k blocks evolve on their own and fall into exact cycles (the last 44 repeat every 1.8·1021 super steps). A search that tabulates those cycles and skips over them finds no halt in the first 6·1023 super steps, 2.7·1049 machine steps (computed, not proved). Lean proves that the last blocks run on their own and that the tables are sound, and with native_decide the same tables give no halt in the first 4.4·1037 steps.

Prior work

The machine is an open BB(6) holdout on @mxdys's lists (623 machines up to equivalence, 24 October 2026) and sits unannotated in the community ledger's "Cubic Mess" class. It is not a named cryptid and has no page on the bbchallenge wiki.

Google DeepMind's cryptids repository lists it as an open acceleration problem (PR #18, 27 October 2026), with a Lean proof that it halts iff a map on two stacks of block lengths halts: the level of the macro step here. Nothing found reduces it further; the super step and the criterion on N appear to be new.

The machine 1RB1RA_1RC1LB_1LD0RA_1RA0LE_---0LF_0RD0LB, which the ledger says was merged into another equivalence class in April 2026, runs through the same tapes and halts from the same configurations (py/sibling.py), so these results should apply to it too. Its Collatz-like map is not Antihydra's or Hydra's: those iterate one integer under n → ⌊3n/2⌋, while here the state is a growing list and N does not determine the next N. Sources and details: notes/PRIOR_WORK.md.

kernel Proved in Lean, kernel-checked

The machine halts iff N is ever a power of two

Let the super orbit start at P = (1, 6) (the tape [1, 6, 5, 0] at step 136) and go on by superstep. The machine halts from blank tape iff some P = (p1, …, pm) of the orbit has N = 10 + Σ pl·2m−l a power of two. Built on halts_iff: the proof follows the macro run, without step counts, from one super step to the next.

halts_iff_pow2' (the order of waves.py), halts_iff_pow2, run_halts_iff, lean/Wave.lean

The super step

From the tape [p1, …, pm, 5, 0] (A on the blank right of the last block), the macro run reaches [P′, 5, 0] with P′ = superstep P, or halts. With dm+1 = 20 and dl = pl + dl+1/2, the wave leaves d/2 at each block with d even; at the first odd di the block becomes (di + 5)/2 and the one to its left gains (di − 1)/2. At the left end it goes on halving, and halts when d reaches 1. Proved for every list and every block length, and every tape of the orbit is reached by the machine from blank tape (orbit_tape).

super_run, carry_wave, carry_left, orbit_tape, lean/Wave.lean

The step count of a super step

From the tape [p1, …, pm, 5, 0] the machine reaches the next super-step tape in exactly superT steps, or halts right after that many: 200 steps to the first carry of the wave, then 2q2 + q − 5 for each block the wave passes with even d = 2q, then 2q2 + 4q + 17 + A where it turns at an odd d = 2q + 1, with A = 3 plus q + 1 for each block passed. At the left end the wave goes on with p = 0, and a halt there costs 11 steps. Proved for every list by following the timed macro steps of next_sound through the wave. It equals the sum of the four step counts of py/waves.py on 150,000 super steps (a test).

super_steps, carry_wave_t, superT, lean/WaveTime.lean

When a super step halts

A super step halts iff N is a power of two. The wave passes a block exactly when d is even, so if it reaches the left end, 2m−1·d1 = N, and it halts there exactly when d1 is a power of two; if it turns at an odd di, N is an odd number of at least 3 times a power of two.

superL_none_iff, wave_none_iff, lean/Wave.lean

The machine halts iff the macro run does

With X(ls, n, cs) = 0∞ 1lr 0 … 0 1l1 0 A> 1n 000 1c1 00 … 00 1cs 0∞, the run from blank tape is at X([1], 2, []) after 15 steps, and from every X the machine goes where the list function next says, in exactly the steps it says (next_sound). Every reachable X is well formed, so the machine halts from blank tape iff the macro run runM reaches a halt (halts_iff).

halts_iff, next_sound, runM_sound, lean/Macro.lean

When a macro step halts

A macro step from X(k :: ls, n, cs) halts iff n is odd and every block of (k + ⌊n/2⌋) :: ls equals 2: the carry to the left eats every block of 2 and reaches the left end.

next_halt_iff, lean/Macro.lean

Seven block rules

Transfer (two cells of the head's block move, one left, one right, 2n + 11 steps), the start and each block of the sweep to the right, and the four stages of the carry to the left; each for every block length and any surrounding tape.

Two shift rules

State A runs right over a block of n ones in n steps; state B runs left over a block of n ones to the 0 before it in n + 1 steps; for every n and any surrounding tape.

a_sweep, b_sweep, lean/Rules.lean

The last blocks run on their own; the skip tables are sound

Split the list (nearest first) as B ++ U: the super step of B ++ U is B's own step followed by what B passes on (nothing, an add, or a wave) applied to U, and its step count superT splits the same way. A table that is one period of B can stand in for B: running U on it follows the timed orbit over whole periods. A table for one more level, built over L passes, is a period as soon as the level comes back to its block, which the builder checks. Every list, every k.

superL_split, superT_split, pass_sound, build_rep, drive_sound, runs_of_drive, lean/Cascade.lean

Each level cycles, or the machine never halts

From any state, the last k blocks on their own either come back to themselves after some point (and then have a table of one period) or never again pass anything to the left. The proof is by induction on k: a level fed by a cycle that sends it a wave each period stays below a bound (a wave halves it), so it repeats; fed by one that sends no wave, it passes nothing on. A silent bottom on the orbit from blank tape means the wave never reaches the left end again, so the machine never halts. So once the orbit has k blocks, either it halts soon after, or the last k blocks cycle, or it never halts. Which case holds is not decided. On the orbit, the last 1 to 30 blocks are checked to cycle, each with its least period (4, 8, 32, 128, 256, 1,024, …, 1.7·1014 super steps for the last 30): the table of each level is written out and checked in pieces, the next block comes back after L passes of it and not before, and then L times the least period below is the least period (least_append). The last six are also checked by decide directly.

cycles_or_silent, rep_of_cycles, never_halts_of_silent, cycles_or_never_halts, cycle₁–cycle₆, lean/Cycles.lean; cycle1–cycle30, lean/CycleRun.lean

The period factors are 1, 2, 4 or 5

Each block added to the cycling bottom multiplies its period by a factor L. Mod 5 a wave acts on a block as p → 3(p + h), whether the wave turns there or passes ((d + 5)/2 and d/2 are both 3d mod 5), and an add as p → p + v. So over a period the next block moves mod 5 by r → 3Wr + b, W the waves it receives per period. Lean proves that the blocks of a cycle are distinct mod 5, so L is the period of the residue under that affine map: L is 1, 2, 4 or 5, never 3; 1 or 4 if W is odd, 1 or 2 if W ≡ 2 mod 4, and if W ≡ 0 mod 4, 5 when b ≠ 0 and 1 when b = 0. This is why every period is 2a·5b.

The last blocks are periodic

Numbering the blocks from the right, block k only receives an add or a wave from block k−1 and passes one on, so the last k blocks are a closed system. Each wave halves a block, and they fall into exact cycles: the last block 11 → 13 → 14 → 12, the last two with period 8, the last 20 with period 1.7·1010, the last 44 with period 1.8·1021 super steps (each a 2a·5b). The search checks each cycle before using it. That every level either cycles or goes silent is now proved in Lean (above), and so is the rule for the factors; the periods of the last 1 to 30 blocks are kernel-checked (above), and beyond those they are computed. Every one of the 44 factors is the one the mod-5 rule predicts, and from the fourth block on a settled block remembers only its residue mod 5 from one period to the next.

Far from the halting shape

In 107 macro steps the left list of blocks holds blocks in the hundreds of thousands; halting needs every block to the left of the head to be 2.

notes/LAB_NOTES.md

Why the returns to the left end are rare

The wave is a binary carry: reaching the left end needs v2(N) ≥ m − 1, about once in 2m−1 super steps if N's low bits behave like coin flips, and each return adds blocks. They do not quite: from the periodic tables, a wave passes the last k blocks at the rate 1.2764·2−k per super step (computed, converged to four digits by k = 40), so the low bits of N lean towards 0 by a constant factor. The observed gaps are somewhat shorter still. The returns do not stop; they thin out.

notes/LAB_NOTES.md

Almost certainly no halt

At a return the deciding number d1 is now about 1.9·1027 and has grown by about 2.4 bits per return; if it behaved like a random integer, the chance of ever hitting a power of two from here would be about 10−27. The rule for the periods explains the last blocks completely but gives no obstruction: halting is decided at the top, where the blocks are young. N shows no modular obstruction (see below).

notes/LAB_NOTES.md

No invariant keeps N off the powers of two

Searched for a property of the orbit that every power of two lacks; none found. For every odd q ≤ 127, N takes every residue a power of two takes mod q, also jointly with N's bit length (2a has a + 1 bits). N's popcount and leading bits look like a random number's (it comes within 15 zeros of a power of two). Lower bounds on the blocks cannot help, since halting depends only on the sum N. And the super step started from 3,600 small tapes halts 217 times against about 239 expected if the deciding number were random: the map has no invariant of its own that forbids halting. The one exact pattern found, a four-step cycle 11 → 13 → 14 → 12 of the last block (proved by hand from the super-step formula), only fixes N's parity pattern.

Whether it halts

Whether N = 10 + Σ pl·2m−l is ever a power of two along the super orbit from (1, 6). By the proved halts_iff_pow2' this is exactly the question whether the machine halts: a Collatz-like question about one orbit.
