1RB1RA_1RC1LB, level by level

1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB

This machine's run from blank tape can be read at five levels. At the bottom it is one cell at a time. Watch long enough and the cells form blocks, the blocks follow seven rules, the rules group into a macro step on lists of numbers, the macro steps are a wave of halvings running left, and four waves together are one step on a single number N. The machine halts exactly when that number is a power of two.

Each level below runs the same machine from blank tape and can be stepped on its own. Where a level's moment is small enough, Show in the machine runs the bare machine to the same step so you can compare. The write-up states each level precisely and says what is proved about it; the tags here say the same in short.

Level 0

The machine, one cell at a time

Six states, two symbols, one halting transition. The machine starts in state A on a blank tape (all 0). At each step it reads the cell under the head, looks up the state and symbol in the table, writes, moves one cell and changes state. Only D reading 0 halts, and D is entered only from C reading 0, so a halt needs C to read a 0 with another 0 to its left.

The diagram under the tape is a space-time picture of the last 200 steps, newest at the bottom: dark cells are 1s and the orange mark is the head. Run it for a few thousand steps and the head settles into long sweeps across a tape of blocks, with short back-and-forth loops where it moves cells from one block to another.

Level 1

Blocks, and seven rules that move them

kernel

From step 15 on, the tape is blocks of ones separated by one, two or three 0s, and everything the head does is one of a few moves on those blocks. Below, the tape is drawn as blocks (a pill is a block of ones, labelled with its length; a dot is a 0; the outlined cell is the head) and the run advances one move at a time:

  • transfer: A runs over the block under it and back; the block loses two cells, one going to the block on its left and one to the first block past its 000.
  • empty_start, sweep_step: when the block is used up, A sweeps right, turning every 00 into 0 and adding two cells to each block it passes.
  • carry_start, carry_two, carry_exit, carry_one: when one cell is left, F carries left. Each block of exactly 2 it meets disappears into a 001 on the right; the first other block stops it.

Lean proves each move for every block length and any surrounding tape, with its exact step count (lean/Rules.lean). Here every move is also checked against the bare machine run to the same step.

Level 2

The macro step: the machine as a map on lists

kernel

Group the moves between two transfer phases and the tape only needs three things: the blocks to the left of the head (ls, nearest first), the block under it (n) and the blocks to the right (cs). Write the configuration as X(ls, n, cs). One macro step does ⌊n/2⌋ transfers, then a sweep right if n is even or a carry left if n is odd, and lands on the next X.

Lean proves that the machine does exactly this, step counts included (next_sound), and that the machine halts from blank tape iff this map's run reaches a halt (halts_iff). A macro step halts exactly when n is odd and, after the transfers, every block to the left of the head is 2 (next_halt_iff): the carry then eats every block and reaches the left end. The panel Distance from halting shows how far each configuration is from that shape. To see a halt, start from X([2, 2, 2], 1, [3]).

    Level 3

    The halving wave

    computed

    Cut the same run at a different moment: each time A stands on the blank just right of the last block. Call that an event. At an event the tape is blocks separated by single 0s, 1b1 0 … 0 1bn A>0, and the next event follows from the list b alone.

    In between, a wave runs left from the right end. At a block it carries a value c (the first one is the last block minus 1). It halves the block: ⌊c/2⌋ cycles, which are level 2's transfers. If c is odd the wave turns and A sweeps back to the right end. If c is even it moves on to the next block left, of length y, with c' = y + c/2 − 2. At the left end there is no block (y = 0), so the wave keeps halving into new tape, c → c/2 − 2. It halts if it reaches c = 0, that is, if it arrives with c + 4 a power of two. (When the last block is empty there is no wave: the tape just gains a block of 2 at the end, in 17 steps.)

    The table under the tape shows the wave that runs from the current event: the value c at each block it reaches, and where it turns.

    Level 4

    One number: N = 10 + Σ pl·2m−l

    computed

    From event 3 on (step 136), every fourth event ends the same way: the tape is [p1, …, pm, 5, 0]. Four waves later it is again of that form, and the new list P' follows from P by one formula, the super step. Put dm+1 = 20 and, going left, dl = pl + dl+1/2. The wave turns at the last odd di; if d2, …, dm are all even it reaches the left end, and it halts there if d1 is a power of two.

    All of that is one number. Read the blocks as binary digits, pm the units: N = 10 + Σ pl·2m−l. As long as the values to its right are even, dl·2m−l = 10 + Σk≥l pk·2m−k, the part of N from block l on, so the wave goes v2(N) + 1 blocks deep (one more than the number of trailing zeros of N), reaches the left end exactly when 2m−1 divides N, and the machine halts iff N is a power of two. The chart shows how rarely the wave gets deep: it has to reach the line m.
