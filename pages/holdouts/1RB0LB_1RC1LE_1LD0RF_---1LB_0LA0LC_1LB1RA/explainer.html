The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in D reading 0. D is entered only from C0 (writes 1, moves L): 0 C>0. So a halt is the moment this pattern appears, with the head on the cell after >.

Local structure

An alternating background

Most of the tape reads 1 0 1 0 …. Sweeping right, A with a 1 behind it shifts the pattern by one cell as it passes, eight steps per pair:

1 A> 0 1 0 1 0 1      
1 0 1 0 1 0 1 A> 0    (24 steps later)

(Lean: walk_A.) Sweeping left, B with 1 1 ahead turns each 0101 into 1010 (walk_B). Where the alternation breaks, at a 00 or 11, the head does something else, and these defects are what changes from sweep to sweep.

The halting condition

D must read a 0

Only D reading a 0 halts, and D is entered from C reading a 0 and moving left. So two 0s in a row under C halt the machine:

0 C> 0      
D> 0 1      (D on a 0: halt)

D is entered 7.1 million times in the first 2·108 steps, always on a 1.

Kernel
halt_route, lean/Route.lean (written by py/route.py)
Where a halt can come from

If the machine halts on its third step from a configuration, that configuration is one of: E with 0 two left, 0 left, 1 under the head. So a run can reach a halt only through one of these patterns, and a proof that the machine never halts only has to rule them out. The proof splits on the state and the five cells around the head.

In the first 2·108 steps the machine is in state D 7,101,514 times, every time on a 1: the halting transition D0 is never close to firing in a way the run shows.

Computed
sweeps of 13 November 2026 (family F11); the tagged and run-length deciders are not in the repository yet
Regular-language deciders tried (F11)

None of these closes: each reaches a halting configuration in its abstraction, which says nothing about whether the machine halts. n-gram CPS (tools/c/ngramcps.c), equal widths on both sides: a halting local configuration is reached with plain up to width 24, history 1 up to width 24, history 2 up to width 24, history 3 up to width 24, LRU history up to width 8 (larger widths ran out of the 150 s or 60 million configuration budget). n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 20, p = 3 up to width 20, p = 4 up to width 20, p = 6 up to width 20. n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets. Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4). Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..8; n = 9 not finished in 150 s.

Open
Does it halt from blank tape?

Not known. The defects behave chaotically; NGramCPS with n ≤ 10 and window CTL with K ≤ 7 leave it open.
