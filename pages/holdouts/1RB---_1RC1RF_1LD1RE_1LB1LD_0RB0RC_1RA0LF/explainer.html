Does this machine ever halt?

1RB---_1RC1RF_1LD1RE_1LB1LD_0RB0RC_1RA0LF

Nobody knows whether it halts. Started on a blank tape, this machine runs a clock at the right end of its tape: a block of 1s grows by four cells per tick and tick k applies one map P to the word beside it 2k times. The clock is proved in Lean for every tick whose 2k trips all return; an exact accelerated run follows it to 2.39·10248 steps.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in A reading 1. A is entered only from F0 (writes 1, moves R): F>0 1. So a halt is the moment this pattern appears, with the head on the cell after >.

Structure

What the tape looks like

Seen at the moments the head, in state E, reaches a new cell on the right, the tape is a row of digits: 1^a 0 1^(4m1+1) 0 1^(4m2+1) 0 … 1^(4mk+1) 0 1^b E>0, blocks of 1s one more than a multiple of four, each followed by a single 0 (and a last run of b ones, b = 1 since step 877,024,800). In the 1011-step run 73 of the 82 such moments have exactly this form. Most digits are 0 or 1. The last digit grows by one at each new right cell (its block by four ones), and the time to the next new right cell doubles; meanwhile a 1 or a 2 walks left through the 0s, one digit per record. When it reaches the left part of the tape, the head visits the left end, the digits are rewritten and a new phase starts, with a new last digit.

Halting

The one way to stop

The halting transition is A reading a 1. A is entered only from F reading a 0 (F writes 1 and moves right), so the machine halts exactly when F has 0 1 under and after it. F is entered from B reading a 1 (moving right) or from F reading a 1 (moving left, and erasing it), so the only way in is B> 1 0 1. So the machine halts exactly when it produces B> 1 0 1; Lean proves both directions (halt_ctx: the steps from there to the halt; halt_iff_2: nothing else halts two steps later).

How close does it come? What F has ahead of it, counted at every step of the first 1010 steps:

What is left

What a proof would need

A proof of the second clock's tick would let the accelerated run jump through it too. What decides halting is what a phase end does to the word: the halting context B> 1 0 1 would have to be built there.

The clock

A block that grows by four, a word that is run 2k times

Watch the tape at the moments the head, in state C, stands on a 0 just right of 1^L 0 at the right end. Along a phase L grows by four per visit and each visit takes twice as long as the previous one. Seen in the mirror (left and right swapped), the step from one visit to the next is a tick: the head sweeps the block into 0s, makes 2k trips through the word (each one application of a map P), and merges the block back four cells longer. That tick is proved in Lean for every k and every word, then carried to the machine itself by a mirror lemma.

The halting context

From B> 1 0 1 the machine reaches its halting transition (proved step by step, then step_none_iff). The halting transition is A reading a 1. A is entered only from F reading a 0 (F writes 1 and moves right), so the machine halts exactly when F has 0 1 under and after it. F is entered from B reading a 1 (moving right) or from F reading a 1 (moving left, and erasing it), so the only way in is B> 1 0 1. The converse is proved too: a configuration halts after exactly two more steps if and only if it is B> 1 0 1 (halt_iff_2), so a halting run from blank passes through it (halts_blank_pred_2).

Kernel
tick, tick_left_end, lean/MirrorClock.lean
The clock, for every k (mirror image)

tick: for every j, every word W and all tapes L, if W reaches W' by 2j P-steps (each one a trip L 0^6 F> 0 W → L E> 1^6 0 W', for every L) of total cost E, then L 0^4 E> 1^(6+4j) 0 W reaches L E> 1^(6+4j+4) 0 W' in exactly E + 28·2j − 4 steps. Strong induction on j: sweep, one P-step, ticks 0, …, j−1, merge.

A mirror lemma (step_mir, steps_mir: one step of the mirror image is one step of the machine on the mirrored configuration) carries the tick over: tick_right_end and tick state the same clock for the machine itself, at the right end of the tape.

The second regime

Between the clock phases the end of the tape is 1^N 0 1 0 C>0: the block N one further in grows by 4 per visit while the time between visits doubles (from 3.8·1013 to 2.0·1022, from 1.67·1057 to 8.1·10140, and from 7.98·10245 to the end of the run, 814 visits). This is a clock one block further in; its tick is not covered by the theorem, so the accelerated run does these visits one at a time.

Open
Does it halt from blank tape?

A normal tick cannot halt (the clock theorem). Halting needs B> 1 0 1, which would have to be built at the end of a phase or inside the second regime. Open: a proof of the second-regime tick, a closed form for P, and what a phase end does to the word.
