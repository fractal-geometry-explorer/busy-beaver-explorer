What is known about 1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---

1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

It is one of a pair, 1RB0RD_1LC0RA_1LA0LB_1RE0LC_1L?1RF_0RB---, that differ only in E0 (here 1LC, there 1LD). The outer sweeps never read E0, so the two machines share them; the inner phases differ.

Status as of 8 November 2026.

In short

The question is open. The outer sweeps are proved in Lean, but the inner phases, which decide how the blocks grow, are only observed; no invariant that would exclude a halt is known.

Where a halt would have to come from. The machine halts only in F reading a 1. F is entered only from E reading a 1, and E only from D reading a 0; so a halt needs the head in D on 0 1 1 (and as D is entered only from A reading a 1, the head in A on 1 0 1 1). F is entered constantly (in the regular sweeps), 343,472,060 times in 2·1010 steps, and always reads a 0: the cell after …0011 is always the start of 0101….

F always reads 0

In 2·1010 steps state F is entered 343,472,060 times, always on a 0; no halt. The context is always …0011 F>0, followed by 101… or by cells not yet visited.

Why it is hard

The inner phase is a smaller machine of the same kind working on the right end of the tape: short sweeps move one a at a time from one block into a longer one, so blocks get multiplied rather than added. Each outer phase takes time about quadratic in the tape length, and each inner phase produces a much longer last block, so the phases grow quickly and nothing in sight closes the loop.

open Open

Does it halt from blank tape?

Not known. It halts only if the head is ever in D on 0 1 1; it never was in 2·1010 steps.
