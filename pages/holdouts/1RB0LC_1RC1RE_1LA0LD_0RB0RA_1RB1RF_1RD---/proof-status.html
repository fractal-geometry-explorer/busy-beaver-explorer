OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open. The run is a sequence of phases: a counter n becomes 8·(n div 3) + d, where the residue of n mod 3 and a word P of blocks to its left decide d and the next word. Lean proves the rounds of a phase for all lengths, and the residue-0 phase end: (L 0 1a+1 0, 3m + 3) → (L 0, a + 8m + 11). No halting transition was found in the word dynamics (trusted, by simulation), so the machine may well run forever, but the word dynamics is unbounded and not understood. Update, 13 November 2026: a search of all tails of at most 26 cells with the generic class map finds halting classes; the nearest needs 107 prescribed residues mod 3 in a row from the start of the run (observed, not proved). The machine is a cryptid.

Rounds between end events, by remainder class

Sample the run whenever the head is in state D reading 0 with only 0s to its right. Read leftwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m mod 3) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (10 events) the class map predicts the next event in all 6 rounds it applies to. This is an extrapolation checked by computation, not a proof.

heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.499).

tools/py/bbtools/triage.py

Probably nonhalting, for a structural reason not yet proved

Unlike Antihydra-type machines, no halting word is known here, so there is no coin-flip argument for a halt. The word behaves like a stack of nested counters (a residue-0 phase absorbs its last block into the counter, the others push or edit blocks), and the explored part of it never halts; a proof would need an invariant on all reachable words.

No halting class among 5,000 contexts

Breadth first from the starting context, with every remainder at every context (whether or not the numbers can really produce that sequence of remainders, and only for m large compared with the contexts): 5,000 contexts expanded, 5,451 found, to depth 43. None of them halts; the search is not complete (the set of contexts keeps growing), and it says nothing about a halt that needs a context as long as the block itself.

A halting class is reachable, 107 rounds away

The same search restricted to contexts of at most 26 cells runs to the end: 3,089 contexts (488 longer ones are reached but not expanded), and 2 of their classes halt. The nearest is 107 rounds from the starting context: after the remainders 22 03 23 0 23 03 23 04 23 03 24 05 24 04 24 03 23 03 23 04 23 03 24 05 24 05 24 04 24 05 (mod 3) the tail is 01011011, and with m ≡ 2 (mod 3) the machine halts before the next event (all six simulated values of m halt). So, granted the class map, a halt is possible, but only through one prescribed sequence of 107 remainders or a longer one; with remainders like fair dice that is one chance in 3107 per try. The orbit computed has not come near it.

Does it halt from blank tape?

Not known. Granted the class map (observed, not proved), it halts exactly if the orbit ever reaches a halting class; the nearest known one needs 107 prescribed remainders mod 3 in a row. A Collatz-like question about one orbit: a cryptid.
