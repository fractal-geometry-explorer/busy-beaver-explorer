What is known about 1RB---_1RC1LE_0RD0RF_0RE0LA_1LF0LB_1LA1LD

1RB---_1RC1LE_0RD0RF_0RE0LA_1LF0LB_1LA1LD

Nobody knows whether this machine halts from blank tape, and it may be hard to ever know: its run is a Collatz-like iteration. Each time the head, in state C, stands at the right end of the tape, the tape is 1^4 0 (10)^x 1^m with the head on a cell s; a six-case map sends (x, m, s) to the next such moment, and one case of the map is the halt. Lean proves that this map describes the machine exactly: the machine halts from blank tape if and only if the orbit of (7, 1, 0) under the map reaches the halting case. This page explains the map and why the halting question becomes a question about powers of two.

Status as of 8 November 2026.

In short

The question is open, and Collatz-like. The run follows a map on (x, m, s), and Lean proves it: the machine halts from blank tape if and only if the map's orbit from (7, 1, 0) reaches the halting case. That happens exactly when, during a chain of doubling steps, x lands on one particular value; iterating the map shows no such landing in the first 10,000 rounds, which is far beyond 10100 machine steps, but nothing rules it out in general.

Rules B and R of the map

For all n, x: from K(x+1, 2n, s) the machine reaches K(x, 2n+4, 1−s) (rule B, 6n+12 or 6n+10 steps), and from K(0, 2n, s) it reaches K(n+3, 1, 0) for s = 0 and K(n+3, 3, 0) for s = 1 (rule R). Here K(x, m, s) is 1^4 0 (10)^x 1^m with the head in C on s at the right end, blank beyond.

ruleB0, ruleB1, ruleR0, ruleR1, lean/Rules.lean

Rules A, A' and C of the map, for all parameters

For all parameters: rule C, K(i+n+3, 2n+1, 0) reaches K(i, 4n+9, 0) and K(i+n+3, 2n+1, 1) reaches K(i, 4n+8, 1); rule A, K(j+2, 2(j+1+k)+1, s) reaches K(2j+5, 2k+3, 1−s), and K(j+2, 2j+1, 1) reaches K(2j+5, 1, 0); rule A′, K(j+2, 2j+1, 0) reaches K(2j+7, 1, 0); and A for x = 1. Rules A and C share their first two parts: a start piece, then one inner cycle per 10 pair moved (chained by an induction written by hand); each ends with its own end piece. Every piece is proved by bbtools.symtm.

ruleC0, ruleC1, cycN0, cycN1, lean/CRule.lean; ruleA0, ruleA1, ruleA1z, ruleAp, lean/MapThm.lean; pieces in lean/Rules.lean

Halting is equivalent to the orbit reaching H

step_ok: from every sample K(x, m, s) the machine reaches the sample the map gives, in at least one step, or (case H) halts. start: from blank tape it reaches K(7, 1, 0) after 216 steps. halts_iff: the machine halts from blank tape if and only if the orbit of (7, 1, 0) under the map (mstep, orbit) reaches the case H. nonhalt_of_orbit: if the orbit never reaches H, the machine never halts. Axioms: propext, Classical.choice, Quot.sound only.

halts_iff, nonhalt_of_orbit, step_ok, start, lean/MapThm.lean

The halting case

From K(0, 2n+1, s), for every n, the machine runs into its halting transition (A reads a 1) after 2n+11 (s = 0) or 2n+9 (s = 1) steps.

The halting condition is a near-power-of-2 condition

Only rule C with s = 0 can lead to the halting case: it leaves m odd, and it reaches x = 0 exactly when x = (m+5)/2. Along a chain of such C steps m runs through (m+7)2i − 7, so a chain from (x, m, 0) halts exactly when x + k + 1 = (m+7)(2k+1−1)/2 for some k ≥ 0 (after an R step with m = 1: x = 2k+3 − k − 5). Elementary algebra on the map (not in Lean), checked by brute force for every x < 3000 and odd m < 200.

README, section When it would halt

No halt of the map in 10,000 rounds

Iterating the map from K(7, 1, 0) (the sample at step 216), with whole B phases applied at once, gives 10,000 R steps, 29,225,208 C steps and 25,330 A steps without reaching the halting case; x then has thousands of bits, so this is far beyond any number of machine steps one could simulate. Since the map is a theorem, this shows that the machine does not halt in its first 10,000 rounds (the iteration itself is a Python computation).

Why a halt looks very unlikely

If the remainder at the end of each doubling chain were spread evenly, a chain whose last step has h = (m+5)/2 would halt with chance about 1/h. Summed over the orbit this gives 0.3187 in all, but almost all of it in the first 20 rounds (which are checked exactly); rounds 21 to 1,000 add less than 10−4, and x gains about 0.58 bits per round (583 bits at round 1,000), so the rest is negligible. The remainders look spread over all of [0, h), somewhat more often near 0 (in 1,000 rounds the 1,409 chain ends fall 192 into the lowest tenth and 88 into the highest), so nothing rules a hit out either: this is evidence, not proof.

open Open

Does it halt from blank tape?

Not known. Lean reduces the question exactly to the map: the machine halts iff the orbit of (7, 1, 0) reaches H. What is missing is a proof that the orbit never meets the halting condition (x + k + 1 = (m+7)(2k+1−1)/2 at the start of a doubling chain), a Collatz-type problem; heuristically a halt is very unlikely but nothing excludes it.
