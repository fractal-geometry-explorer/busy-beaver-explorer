What is known about 1RB0RB_1LC1RE_1LF0LD_1RA1LD_1RC1RB_---1LC

1RB0RB_1LC1RE_1LF0LD_1RA1LD_1RC1RB_---1LC

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open, and reduced in Lean to a Collatz-like map. Sampled with the head in D at the left end, the tape is a run of ones with one hole: p ones, the hole, r ones. Lean proves, for all p, r ≥ 1, that one sample leads to the next by an explicit map f (the hole's position roughly halved when it is odd, a jump of the hole to the right end when it is even) in an explicit number of steps, or halts (p = 1), and that the machine halts from blank tape if and only if the orbit of (2, 2) under f reaches p = 1. Following the proved map, the kernel shows no halt in the first 103669 steps. Whether the orbit ever reaches p = 1 is a Collatz-like question; heuristically the chance is a few in 104.

Hole at position 1 halts

From D> 1 0 R with blank tape to the left, the machine reaches F on a 0 in 7 steps and halts, for every tape R.

The hole map, for all p and r

Write S(p, r) for the head in state D on the leftmost cell of 1^p 0 1^r, blank tape around. For all p, r ≥ 1: S(1, r) halts; S(3, r) → S(r+5, 2) for r odd and S(r+5, 1) for r even; S(2k+2, r) → S(3k+r+4, 1); S(2m+1, r) → S(m−1, m+r+3) for m ≥ 2, each in an exact number of steps cost p r (quadratic in k or m). Built from 12 symbolic rules found and proved by bbtools.symtm, chained by induction over the drift of a block across the ones, its consumption 11 by 11 at the right end, and the halving rounds.

sample_step, lean/Map.lean; rules in lean/Steps.lean (from py/steps.py)

The reduction

From blank tape the machine reaches S(2, 2) in 11 steps, and it halts if and only if the orbit of (2, 2) under the map reaches p = 1.

The hole map, checked

From each sample (D on the leftmost cell, reading 1; N cells, a single 0 at position p): p even: N' = N + p/2 + 2, p' = N' − 2; p odd, p ≥ 5: N' = N + 1, p' = (p−3)/2; p = 3: N' = N + 4, p' = N' − 3 (N odd) or N' = N + 3, p' = N' − 2 (N even); p = 1: halt. The machine follows this from every sample with N < 120 and 1 ≤ p ≤ N−2 (exhaustive), along the first 3·107 steps (31 samples) and at all 52 samples of the run to 2.9·109 steps. (Now proved for all N: see above; the check also confirms the step counts.)

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.07). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.471).

tools/py/bbtools/triage.py

Why it probably never halts

A halving chain p → (p−3)/2 → … ends at 1 only if it starts at p = 2j − 3; chains start at N − 2 (or N − 3 after p = 3), with N growing by a factor about 3/2 per even step. So the run must land exactly on a length like 2j − 1. Treating N as random at its scale, the expected number of hits beyond N ≈ 3·104 is about Σj≥15 2/(2j ln 1.5) ≈ 3·10-4. The community lists the machine as Space Needle-like, probviously non-halting (bbchallenge wiki).

Does it halt?

Not proved either way. By the kernel claims above, the question is exactly whether the orbit of (2, 2) under the hole map ever reaches p = 1 (a halving chain p → (p−3)/2 → … starting at 2j − 3), a Collatz-like question with no visible invariant that rules it out.
