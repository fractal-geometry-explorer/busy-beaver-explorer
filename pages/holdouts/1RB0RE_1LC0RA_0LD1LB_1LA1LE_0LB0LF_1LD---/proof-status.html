OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open; the phase map is now proved far beyond the first m ≡ 2 case. The tape at a phase start is A> 1110 10 1m followed by a list of remnants 0 (10)k 1c. Lean proves a phase map on (m, remnant list) with exact step counts that covers every case except m ≡ 2 (mod 3) in front of a remnant with c = 2 (or in front of a non-final remnant with c ≤ 1). In particular the m ≡ 2 case of a clean phase is S(3j+2) → S(10j−2) followed by the remnant 0 (10)6 1111 (j ≥ 2). From blank tape the proved map carries the run through 61,963 phases (m of 107,632 bits), so if the machine halts it does so after more than 26953 steps (kernel) / 2215260 steps (compiled evaluation). Phase 61,964 is the first uncovered case: m ≡ 2 in front of the remnant 0 (10)75 11.

The round, and the end of a phase

The case m ≡ 2 (mod 3), and phases in front of remnants

With the remnant G(k, c) = 0 (10)k 1c and P(m, W) = A> 1110 10 1m followed by the remnants W: after the rounds (x' = x + 5⌊m/3⌋), m ≡ 0 sends G(k+1, c) to P(2x'+11, G(k, c)…) and G(0, c) to P(2x'+10+c, …); m ≡ 1 joins the first remnant to the phase (the tape is T(x'+k+1, c)); m ≡ 2 with x' ≥ 8 gives P(2x'−4, [G(6, 4)]) on blank tape, P(2x', G(k+7, c)…) before G(k, c+3), and P(2x'−4, [G(6, 2k+4)]) / P(2x'−4, [G(6, 2k+6)]) before a last G(k, 0) / G(k, 1). Each case is a run of the machine with its exact step count. For a clean phase: S(3j+2) → P(10j−2, [G(6, 4)]) for j ≥ 2.

The uncovered case: m ≡ 2 before a remnant with c = 2

There the leftover pair of 1s meets the remnant's pair, and small runs show a nested process whose outcome depends on k (from T(10, 2) before G(k, 2): k = 0 → P(26, [G(1, 7)]), k = 1 → P(18, [G(9, 1)]), k = 2 → a phase T(17, 4) with no remnant, k = 3 → P(26, [G(0, 2), G(4, 4)]), k = 4 → P(16, [G(13, 1)])). Its rule was not worked out. Before the remnant rules: direct runs S(2) → S(28), S(5) → S(112), S(8) → S(276), S(11) → S(128), S(20) → S(228), S(29) → S(328).

py/remnant.py, py/phase_m2.py

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.487). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.032).

Does it halt from blank tape?

Not known. The proved map covers the run through 61,963 phases; whether the machine halts depends on the nested case (m ≡ 2 before a remnant with c = 2) and on the cases after it. The machine can stop only on 1 E> 1, which none of the proved cases produce.
