The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in D reading 1. D is entered only from C0 (writes 1, moves R): C>0 1. So a halt is the moment this pattern appears, with the head on the cell after >.

The run at a glance

Space-time diagram and records

The diagram stacks the tape at many moments. Sampling at each new cell shows the shape of the run as the visited region grows; sampling evenly in time shows where the head spends its time. The records list every step at which the head reaches a cell no earlier step reached, with the side, the width so far and the whole tape: the first place to look for a repeating macro structure.

Macro structure

Regions that feed each other

Stop the simulator at the turns at the left end and write c = 110, q = 010110101101010110101101 (24 cells) and s = 101010110110110 (15 cells). At step 7,087,597 the tape starts

B>c2 0 c2 1 0 c 1 0 c 1 q40 0 1 0 c 1 0 c 1 0 1 0 c 1 0 1 0 1 0 c2 1 0 c 1 0 s36 1 0 c6 1 0 s c (10)5 s c (10)16 s c (10)38 c 1 0 c (10)78 c2 0 c2 (10)157 ...

and continues with a long run of 101110110110, and an irregular stretch at the right end. So the tape is a row of periodic regions with short joints between them; the runs of 10 have lengths 5, 16, 38, 78, 157, roughly doubling, as if each held one level of a counter.

Counting copies at the left-end turns shows how they feed each other. The q-run grows from 3 copies (step 561,704) to 111 (step 4,263,440) while the s-run shrinks from 50 copies to 7; by step 4.7·106 both are gone and the q-run starts again from a few copies. After that an s-run of 36 copies sits still while q grows again and the region further right shrinks. It looks like a counter whose digits are whole regions.

The passes are fast rewrites one copy at a time. Moving right, A rewrites each copy of q as 100111001111100111001111 in 32 steps; moving left, C restores it in 68 steps. For example A>011 011 011 becomes 100 100 100 A> in 15 steps (pass_right_c).

The only halt is C>0 1 (halt_C): C writes a 1 and steps right onto a 1 in state D, which has no transition for 1. Finding the exact round-trip rule of the regions, and an invariant from it that keeps D off a 1, is the open step.

The shape of the run

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.539). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.379).

After 109 steps the tape spans 42,923 cells (27,961 left of the start, 4,780 right), with a density of 1s of 0.653.
