The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 1. F is entered only from E1 (writes 0, moves R): E>1 1. So a halt is the moment this pattern appears, with the head on the cell after >.

The run at a glance

Space-time diagram and records

The diagram stacks the tape at many moments. Sampling at each new cell shows the shape of the run as the visited region grows; sampling evenly in time shows where the head spends its time. The records list every step at which the head reaches a cell no earlier step reached, with the side, the width so far and the whole tape: the first place to look for a repeating macro structure.

Macro structure

A word in three letters

Read the tape in pieces a = 10, b = 100, c = 1000: a 1 followed by one, two or three 0s. Apart from a rare 11 next to the head, that is all the tape ever holds. The head sweeps to the right end of the tape and back again and again; every time it reaches the right end in state D, the tape has grown by 3 cells. We call these moments visits.

On most visits the head does not go back to the left end. It turns around at some point inside the tape, does a small local change there, and comes back. Where it turns, and what it changes, is the whole story.

Exact doubling

Epochs: the same pattern, twice as big each time

Every so often the tape ends in exactly the same shape:

… M (aaacacac)^T aaa cacb (aacaacac)^3 aacaac (baccaaa)^X bab aaa caacaac 1 D>

with X = 6T + 17. This is the start of an epoch. The run from blank tape reaches it after 638,914 steps with T = 7, and then again with T = 19, 43, 91, 187, 379, 763, 1531, 3067: each time T′ = 2T + 5, exactly. An epoch takes exactly 72T + 290 visits, and (from T = 91 on) exactly 16416T² + 151769T + 288000 steps, so each epoch is about four times longer than the one before. That is why the tape grows like the square root of the time.

Each epoch leaves a block behind that never changes again, (acacaaac)^(T−10) (ac)^36 (bac)^(6T−3) cc … U^((T−43)/6) (c)^13, where U is a fixed word of 168 cells, and it adds one copy of U to the block of the epoch before. Machines like this are called exponential bouncers: a regular pattern whose size doubles. Nothing in an epoch comes close to the one way the machine can halt (state D reading three 1s in a row).

Inside an epoch

Five phases: three proved, two exact cycles

  1. Phase 1 (X visits). Each visit the head walks left to the block (baccaaa)^X, turns one copy into aaaaca + caa, and walks back. Proved in Lean for every size (phase1): from … (baccaaa)^n ba 1 00 aaa (caa)^2 c 1 the machine reaches … ba 1 00 (aaaaca)^n aaa (caa)^(n+2) c 1, for every n and every tape on the left.
  2. Phase 2 (about X visits). Each visit turns one copy of aaaaac into one more bac on its left and one more caa on its right; this builds the block (bac)^(6T−3). Proved in Lean for every size (phase2).
  3. Phases 3 and 4. At the right end, aac is turned into aaacac (one copy every two visits), and then aaacac into aaaac (two copies every four visits). Meanwhile every second visit runs deep into the tape, to a region of irregular words just right of the block (bac)^(6T−3). That region works like a counter: how deep each of these visits goes follows a ruler-like pattern, as when a number is incremented and the carry runs further every now and then. When it is done, the old (aaacacac)^T has become part of the frozen block and a new (aaacacac)^(2T+5) stands in its place. After a start-up stretch both phases are exact cycles: in phase 3, every 144 visits add one copy of U and move the counts at the right end by fixed amounts; in phase 4 the same with 288 visits. A computer check (exact symbolic simulation) confirms these cycles for every value of the counts, but they are not yet proved in Lean.
  4. Phase 5 (two visits per copy). The block (aaaac)^j is turned back into (baccaaa), one copy every two visits, until there are 6(2T+5) + 17 of them: the next epoch starts. Proved in Lean for every size (phase5).

So what is left for a proof of non-halting: the two cycles in Lean, the short transitions between the phases, and an induction over the epochs. Each piece is a finite, mechanical check; none of it looks like an open mathematical problem.

First look

The shape of the run

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.499).

After 109 steps the tape spans 97,518 cells (37 left of the start, 62,618 right), with a density of 1s of 0.412.

Kernel
lean/Shifts.lean (written by bbtools.symtm.prove)
Shift rules

For every length n of the run and any tape around it: L (10)^n B> 1 R reaches L B> 1 (10)^n R; L A> (01)^n R reaches L (01)^n A> R; L (01)^n D> 0 R reaches L D> 0 (01)^n R. These are the moves the head makes across the long uniform stretches of the tape.

Computed
the transition table
Halting needs D on 1 1 1

Read off the table: F is entered only by E reading 1 (moving right), and E only by C reading 0 (moving left, so F then reads the 0 that C wrote) or by D reading 1 (moving right). So a halt happens exactly when D reads a 1 that is followed by two more 1s. Three 1s in a row do appear next to the head (171,801,958 times in the first 109 steps), which is why simple local invariants fail.

Computed
py/cycles.py
Phases 3 and 4 are exact cycles of 144 and 288 visits

With U = (c)^7 (bac)^5 acacbacb (ac)^3 (bac)^5 aca: in phase 3, 144 visits add one U, 12 copies of acacaaac and 72 of acaaac and use up 144 of aac; in phase 4, 288 visits add one U, 12 acaaacac and 144 acaaa and use up 72 acaaac. Checked by exact symbolic simulation (bbtools.symtm with shift rules) from a tape of the run with every long count a variable and the far left an unknown context: the rule holds for every value of the counts. Not in Lean: written by symtm, the proofs would run to hundreds of megabytes.

The whole question

To prove non-halting along these lines: the phase 3 and 4 cycles in Lean (with the untouched part of the tape as a context in each visit, or with a verified symbolic executor), the short transitions between the phases as symbolic runs in T, and the induction over epochs (two kinds, as T alternates between 1 and 7 modulo 9).
