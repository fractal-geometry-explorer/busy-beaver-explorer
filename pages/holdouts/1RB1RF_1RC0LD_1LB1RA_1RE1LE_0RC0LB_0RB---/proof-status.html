What is known about 1RB1RF_1RC0LD_1LB1RA_1RE1LE_0RC0LB_0RB---

1RB1RF_1RC0LD_1LB1RA_1RE1LE_0RC0LB_0RB---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. The run is understood at the level of passes: the tape is a run of 1s with a few 0s; one 0 (the marker) moves right by 4 cells per bounce while the right end moves by 1, so a marker that starts g cells from the end catches it after about g/3 bounces and the pass ends with the tape g/3 cells wider. New markers start near the left end, so the width is multiplied by about 4/3 per pass (checked for the 21 passes to 1.6·1010 steps). Which marker comes next is decided by a short prefix at the left end and by residues of the width mod 3; whether that Collatz-like process ever lines up to halt is not known.

Shift rules of the sweeps

The two sweeps are shift rules: to the right the head turns each triple 100, 001 or 010 (by its phase) into 111, to the left it turns 111 back into 001, 100 or 010; and one bounce of the marker zig-zag, L 0 1 1 (111)^(m+1) D>1 0^∞ → L 1111 0 11 (111)^m 1 B>1 1 0^∞ (the marker 4 cells to the right, the gap to the end 2 shorter), for every m and every tape L.

lean/Rules.lean (generated by py/rules.py)

The marker zig-zag

Between passes the head bounces between the marker (a single 0 in a run of 1s) and the right end. Two bounces take L 0 (111)^(m+2) B>1 0^∞ to L 1^8 0 (111)^m B>1 0^∞; by induction 2j bounces take gap 3(m+2j) to 3m, leaving 1^(8j) behind the marker, for every m, j and every tape L. With the first bounce after a launch at gap ≡ 1 (mod 3), and the launches from the left end with no marker (width ≡ 0 or 2), a pass from gap 3(e+2j+1)+1 reaches gap 3e with the tape 2j cells wider.

Growth shape: power/sqrt

Left of the start, the visited part of the tape grows like a power of the step count other than 1/2 (fitted exponent 0.151). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.516).

Does it halt from blank tape?

Not known. The run is a Collatz-like process: each pass multiplies the width by about 4/3, and the prefix at the left end, which decides where the next marker starts, changes with the width mod 3 (the leftward sweep converts the tape in triples counted from the right end). The halting transition F1 needs A to read 1 followed by another 1, which happens only if a rightward sweep meets triples that are not in the phase it expects; nobody has shown that the residues never produce that.
