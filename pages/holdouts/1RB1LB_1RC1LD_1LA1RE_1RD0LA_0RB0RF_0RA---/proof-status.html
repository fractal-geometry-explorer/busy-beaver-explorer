OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open. At the visits of the head (state A) to the left end the tape is A>0 P (110)^N 1 with a short word P; N grows by about 3/2 per visit (…, 1080, 2457, 3690, 8325, 12492, 28122). Lean proves the eleven shift rules of the sweeps; the map is only observed.

In the community's BB(6) tracker the machine's class is Bell-like. These are labels read off the run by others, not results.

Rounds between end events, by remainder class

Sample the run whenever the head is in state C reading 1 with only 0s to its right. Read leftwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m modulo 1 or 2 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (39 events) the class map predicts the next event in all 27 rounds it applies to. This is an extrapolation checked by computation, not a proof.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.049). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.496).

325,831 rounds of the class map without a halt

Iterated with exact integers from the event at step 33,625 of the run (A = (empty), U = 110, m = 85, B = 13): 325,831 rounds without meeting a halting class; m then has 95,306 bits (about 1057,380 steps of the machine). 226 distinct contexts occur, the longest of 4,246 cells. The iteration stops there, at a context too large for the six simulations (a second long block has formed); this is a limit of the tool, not an event of the machine.

No halting class among 530 contexts

Breadth first from the starting context, with every remainder at every context (whether or not the numbers can really produce that sequence of remainders, and only for m large compared with the contexts): 530 contexts expanded, 530 found, to depth 186. None of them halts; the search is not complete (the set of contexts keeps growing), and it says nothing about a halt that needs a context as long as the block itself. 36 contexts longer than 300 cells were not expanded.
