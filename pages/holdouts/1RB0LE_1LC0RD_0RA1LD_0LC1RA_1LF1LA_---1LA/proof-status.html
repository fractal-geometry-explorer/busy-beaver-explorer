What is known about 1RB0LE_1LC0RD_0RA1LD_0LC1RA_1LF1LA_---1LA

1RB0LE_1LC0RD_0RA1LD_0LC1RA_1LF1LA_---1LA

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

Open; the whole map is now known and no halt is in sight. Sample the run when the head is in state E at the left end reading 1: the tape is EL(m, T) = E> 1 00 1^m T where T is a short list of runs 0 1^a1 0 1^a2 …. One round sends m to (4m + c)/3 and T to T′, where c and T′ depend only on m mod 3 and T (once m is large compared with T). This exact round map matches every EL event of the direct run up to 5·109 steps and was iterated 100,000 rounds (past 1024990 steps) without a halt. The tail is mostly a single growing run that is absorbed into m whenever m ≡ 1 (mod 3); none of the 4,545 rounds tried, including synthetic tails, halts.

Third pass. The halting condition is found: with the list T = [a, …], the first run a is swallowed when m = 1 mod 3 and otherwise grows by 4/3 while the main run pays, m′ = (4m − a)/3; the machine halts when a reaches 4m (+14). That needs about 4m/a rounds in a row without m = 1 mod 3, so it is probviously non-halting; and because a regular language cannot compare a with m, no closed tape language can prove it (the pushdown reduction fails with every DFA tried). No halt in 1018 steps by macro simulation.

The halting condition: the first run of the list reaches four times the main run

EL(m, [a, …]) halts before the next event when m is not 1 mod 3 and a ≥ 4m + 14 (m = 0 mod 3) or a ≥ 4m (m = 2 mod 3), up to 12 less when more runs follow; for m = 1 mod 3 it never halts (a is swallowed). Every m < 30, a < 200, suffixes [], [2], [7, 2].

py/drain.py halt 30 200

The drain law

While the first run a survives a round (r = 0 or 2 and a outside three residues of twelve), a′ = 4a/3 + O(1) and m′ = (4m − a)/3 + O(1), so 1/x′ = 1/x − 1/4 for x = a/m; for r = 1, m′ = (4m + 3a + 8)/3 and the run is gone.

py/drain.py law 110

Rounds between end events, by remainder class

Sample the run whenever the head is in state D reading 1 with only 0s to its left. Read rightwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m mod 3) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (31 events) the class map predicts the next event in all 22 rounds it applies to. This is an extrapolation checked by computation, not a proof.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.508). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.045).

tools/py/bbtools/triage.py

No halting round is known

The tail is essentially one run of length a: while m ≡ 0 or 2 (mod 3) it grows by about 4/3 (sometimes with a short run 2 or 7 behind it), and when m ≡ 1 (mod 3) it is absorbed into m (m′ = (4m + 3a + 8)/3). Every round with tail [a] + suffix, a < 300, suffix in {[], [2], [7,2], [17,2], [17,7,2]}, all residues (4,485 rounds), and every tail reachable within 400 cells, comes back to the EL form without halting.

py/roundmap.py bfs 3000 400

No regular invariant can exclude the halt

The first run of the list is unbounded along the run unless the residues m mod 3 conspire; a regular set that contains the run then contains, by pumping, configurations with a ≥ 4m + 14, which halt. The pushdown reduction also fails with windows of up to 4 cells with counters mod 3 and with DFAs learned from the run (up to 16,638 states).

py/pdsx.py; README

Probviously non-halting

A halt needs a first run to survive about 4m/a rounds in a row, each with probability about 1/2; with m > 2·106 from round 40 on and growing by 4/3 per round, the total chance is below 2−100,000.
