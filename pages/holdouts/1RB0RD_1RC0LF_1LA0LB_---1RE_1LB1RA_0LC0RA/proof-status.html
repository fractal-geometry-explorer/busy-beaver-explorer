What is known about 1RB0RD_1RC0LF_1LA0LB_---1RE_1LB1RA_0LC0RA

1RB0RD_1RC0LF_1LA0LB_---1RE_1LB1RA_0LC0RA

This six-state, two-symbol Turing machine is one of the holdouts left open by the bbchallenge project. It does not halt when started on a blank tape; the proof is in Lean, with its long computations evaluated by compiled code. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

It does not halt (Lean theorem nonhalt, level native). The run is a sequence of rounds. At the end of a round the tape is 01001000 (01)^B T with a big block of B pairs and a short tail T. There are 1,144 classes of such tapes (one of 62 tails, B = r0 + m·x with m = 27, 45, 48 or 66 and r0 ≥ 20,000) such that every tape of a class ends its next round in a class again; the real run enters the set at B = 28,531.

In Lean, a symbolic executor whose every move is proved to be a run of the machine (kernel) runs one round for each class with x free, and the arrival from blank tape; a second proved test shows that every round end announced lies in a class. The 1,144 rounds (133 million executor moves), the arrival and the six cycle rules are evaluated by native_decide, so the result rests on the Lean kernel and the Lean compiler. Step counts are computed by the simulators (trusted), not part of the Lean statement. Tapes of the same shape with a slightly different tail do halt, so the set cannot be widened to all tails.

Sweeps over the long blocks

Eight shift rules, for every number n of words and every surrounding tape. The five sweeps of one visit of the left end, three pairs at a time: 1 C>(010101)^n → (011001)^n 1 C> (14n steps); (011001)^n A>110 → A>110 (010101)^n (22n); 1 B>(010101)^n → (010110)^n 1 B> (14n); (010110)^n B>000 → B>000 (010101)^n (22n); (011001)^n F>0 → F>0 (010101)^n (22n). And three earlier ones (f_left, b_right, e_right).

The machine does not halt: a second proof, in Coq (busycoq)

A closed set of round ends implies that it never halts

If the run from blank tape reaches a round end A> 01001000 (01)^B T that belongs to a set S, and every round end in S reaches a round end in S after at least one step, then the machine does not halt. Its two hypotheses are proved by the replay below.

nonhalting_of_closed_set, lean/Closed.lean

A symbolic executor and the two class tests, proved sound

The executor of 1RB0RC_0RC1RC_0LD0RA_1LE0LF_0LA1LC_---1LA, adapted: tapes of cells and blocks (w)^n with n = c + a·x; shift rules with a carried word, one to three copies at a time; one machine step; at each arrival of state A at the left end a re-bracketing and a cycle rule applied N times, where N may itself be a count N0 + q·x (the subtraction is checked coefficient by coefficient). Any step that would depend on x fails. Theorems: whatever the executor does, the machine does, for every x (run_sound); a class whose run ends at the announced round end does so for every x, in at least one step (clsRun_sound); the coverage test, a finite check over one period of the remainders, implies that every announced B lies in a listed class (covers_sound); a list that passes both is closed (closed_of_checks). The 15 shift rules are proved by evaluation in the kernel.

lean/Exec.lean, lean/Classes.lean; shRTbl_ok, shLTbl_ok in lean/ExecData.lean

The 1,144 classes are closed under one round

For each class (tail T, B = r0 + m·x) the executor runs one round with x free (60,000 to 231,000 moves, 132,636,430 in all) and ends at the round end with tail T' and B' = k + c·x of the certificate; every such B' lies in a listed class. So every round end of the set reaches a round end of the set in at least one step. Eight native_decide evaluations of 143 classes each, 35 to 56 s each.

The tail cycles

Within a round the tape is 010 (01)^a 000 (01)^b T. After a start-up the tail T repeats with a fixed period: 15 visits of the left end (a − 45, b + 99; three different tails), 16 visits (a − 48, b + 99), 22 visits (a − 66, b + 141) or 9 visits (a − 27, b + 57). Each cycle is established by one symbolic run with a and b free (steps affine in both) and re-checked on numbers.

py/closure/accel.py (verify, selftest)

The closed set: how it was found, step counts

A class is a tail T (62 of them) and a remainder of B (modulo 66: 682 classes; 45: 300; 48: 144; 27: 18), with B ≥ 20,000. For each class one symbolic round with B = r + m·x, x free, ends at 01001000 (01)^B' T' with B' = k + c·x (c = 141, 99 or 57, k ≥ 41,224); every remainder B' can have lies in a class again. The simulator refuses any step whose outcome depends on x. closure.py check re-runs all classes and tests the coverage independently of the search (5 minutes). That the set is closed is now a Lean theorem (above); this tool found it and supplies the step polynomials.

py/closure/closure.py, py/closure/cert.json

The real run enters the closed set: step count, later rounds

That blank tape reaches the round end with B = 28,531 is a Lean theorem (above). Computed: from blank tape the run is at the round end with B = 28,531 after 2,340,515,329 steps (the plain C simulator gives the same step), in the class B = 19 mod 66 of its tail. The next 1,302 rounds (B up to 437 digits), computed with numbers, agree with their classes: next tail, next B and the number of steps, all exact; 684 of the classes and all 62 tails occur.

Nearby tapes that halt

The same shape with another tail can halt: of the tails that differ from one of the 62 by one pair 10 in one block (a sample, 1,141 classes), 5 classes halt for every B, for example tail 000010101010101010101010000101010100001010101010101010101010101110000101 with B = 20,002 + 3x halts after 815,565 + 122x steps (confirmed bit by bit at three values). The other 1,136 fall into the closed set after one round. Other remainders of B for the 62 tails (a sample, 1,722 classes) all fall into the closed set; none halts.

Independent check of the closed set

A second accelerated simulator written from scratch, without the first tool's engine (verify/accel.cpp, validated against plain simulation up to 4.4·109 steps), confirms the arrival from blank tape at step 2,340,515,329 and, for every one of the 1,144 classes, four members (the two smallest, one B near 106, one near 1011) plus 7,000 random members: no halt, the next round end is exactly the predicted tail, B and step count, and lies in a listed class. 0 mismatches; the five neighbouring tails said to halt do halt. It samples B; that every B of a class behaves so is the Lean theorem closed_set.

Growth shape: sqrt/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.498).
