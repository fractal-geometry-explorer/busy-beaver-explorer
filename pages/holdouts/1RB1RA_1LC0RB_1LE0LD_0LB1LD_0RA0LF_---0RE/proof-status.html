What is known about 1RB1RA_1LC0RB_1LE0LD_0LB1LD_0RA0LF_---0RE

1RB1RA_1LC0RB_1LE0LD_0LB1LD_0RA0LF_---0RE

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open. The run is a sequence of levels (b, tail); the level map is known symbolically for twelve of the fourteen level types met (trusted code, no halting case), the four cycles it uses are proved in Lean, and the run from blank tape passes nine levels in 1.6 × 1015 steps without halting. Two level types contain a counter, and there the next level depends on the digits of a block length.

Other proofs and outside reports

In the community's BB(6) tracker the machine's class is Bell-like. These are labels read off the run by others, not results.

The drain cycle

0^∞ E>(011)^4 (010)^(a+6) 1 1 1 (01011)^(b+1) 0 1 0^∞ reaches 0^∞ E>(011)^4 (010)^(a+2) 1 1 1 (01011)^(b+15) 0 1 0^∞ in 168a + 224b + 2978 steps, for every a and b.

drain, lean/Rules.lean

The split cycle

0^∞ B>0 0 (110101)^c 1 1 0 1 (100)^(d+3) 1 0 1 1 1 (01011)^(b+1) 0 1 0^∞ reaches the same with c+1, d+1, b+3 in 32b + 50c + 24d + 228 steps, for every b, c, d.

split, lean/Rules.lean

The copy cycle

One visit of the right end in the copy phase: L (01111)^(n+2) (010)^(m+1) 0 1111 (00111)^(m+1) B> 0^∞ takes 28m+55 steps and moves one word of the old final block into a new (010) block and a new final block (00111), for every n, m and every tape L on the left.

copy, lean/Rules.lean

The pour cycle, visit by visit

Twenty one-visit theorems: 0^∞ 1 (100111)^3 (001)^(d+4) 1 1 1 0 (01110)^(a+2) 0 1 1 1 B> 0^∞ returns after 20 visits of the right end with d − 2 and a + 10, for every a and d.

pour1..pour20, lean/Visits.lean

No halt in the first 1015 steps

c/hsim2.cpp, a block macro simulator that takes a linear jump over k cycles only after checking the cycle symbolically for every larger count (step count summed exactly), runs to 1.05·1015 steps without a halt. At 5·1010 steps its state and every cell agree with plain simulation (py/cmpc.py).

c/hsim2.cpp, py/cmpc.py

The feed round

A fourth phase feeds the block (110101)^c back into the final block at about 5.08 words per word, through a small counter of 3-cell digits. One round, for every c, d, b, is a symbolic trace of 32b+34c+24d+3813 steps found by bbtools.symtm; it is too long for the Lean kernel to check in reasonable time and memory, so it is not in Rules.lean.

py/rules.py (history)

The level map for twelve of fourteen level types; no halting case

A level starts when the final block has just been rewritten as (01111)^b. A symbolic run with b and the other block counts free (residue splits on demand, every assumption recorded) gives the next level for 89 cases of 14 types, e.g. b = 4k+r → 18k + const on the short tails; no case halts. Two cases fail: the levels with a long block (011110)^m or (110011)^m, where a counter runs between the blocks.

heuristic Evidence only

Growth shape: sqrt/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.638). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.46).

tools/py/bbtools/triage.py

The level sequence

Final-block size at each copy, from the accelerated simulator: 13 (5.4·103 steps), 108 (2.8·105), 907 (2.0·107), 7,265 (1.26·109), 14,531 after a split (6.1·109), 33,000 (1.67·1010), 83,545 (1.66·1011), 375,963 (3.37·1012), about 3.0·106 (2.15·1014), about 6.0·106 after a split (5.4·1014), 6,015,471 (1.05·1015). The ratios (about 8, 4.5, 2 at a split) depend on which phase starts, so the level map looks like a Collatz-style map on residues; its exact form is not derived.

C run, c/ev.c

No exact growth cycle; counter levels depend on digits

The second round of levels repeats the types of the first, but growth is multiplicative and the next type depends on b mod 4 and, after a counter level, on the digits of the counter length m: with b = 400 and m = 1..48 every level reaches a next one without halting, but the new b is not monotone in m.

Does it halt from blank tape?

Not known. The level structure is exact for twelve level types and none of their cases halts, but two level types contain a counter whose outcome depends on the digits of a block length, so the set of level types does not close; the machine is Collatz-like with a counter inside.
