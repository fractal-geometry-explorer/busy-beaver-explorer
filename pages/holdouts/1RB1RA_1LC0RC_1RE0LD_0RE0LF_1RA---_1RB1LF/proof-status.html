What is known about 1RB1RA_1LC0RC_1RE0LD_0RE0LF_1RA---_1RB1LF

1RB1RA_1LC0RC_1RE0LD_0RE0LF_1RA---_1RB1LF

OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open, but reduced to arithmetic. Lean proves (kernel) that the machine halts from blank tape exactly when an explicit map on lists of numbers reaches none: when a carry wave arrives at the left end of the tape with the value 1, i.e. when the value carried onto the leftmost digit is of the form 2t−1. Iterating the map exactly shows no halt for the first 9·1052 steps; heuristically the chance of a halt is negligible.

Shift rules

For every length n of the run and any tape around it: L A> 1^n R reaches L 1^n A> R; L 1^n F> 1 R reaches L F> 1 1^n R. These are the moves the head makes across the long uniform stretches of the tape.

lean/Shifts.lean (written by bbtools.symtm.prove)

Halting is equivalent to an arithmetic iteration

HaltsFromBlank ↔ ∃ k, iter k = none, where iter iterates the digit map next from the digits [26, 13, 9, 6] of the first cycle start (step 6,517). One cycle (5,369 steps) starts a wave on the last digit plus 61; on an odd value a the wave leaves a/2+1 behind and adds a/2 to the next digit; on an even value it stops (the digit becomes a/2+3, the next digit grows by a/2); at the left end of the tape the value 1 halts (E reads a 1 eleven steps later). Every piece is a symbolic trace checked by Lean; the composition is by induction.

The digit map iterated exactly (Python integers, with the step count of every piece), accelerated by memoizing the effect of the lowest digits until a wave leaves them: 29 visits of the left end, none with the value 1. heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.531).

tools/py/bbtools/triage.py

Almost surely it never halts

A halt needs the value carried onto the leftmost digit to be 2t−1, all ones in binary. These values grow by a few bits per visit of the left end (85 bits by 1052 steps) and most of them are even; if their bits were random the chance of ever seeing all ones from here on would be below 2-80.
