What is known about 1RB1LC_1RC0LF_0LD0RC_1RA1LE_---1LA_0LC1LF

1RB1LC_1RC0LF_0LD0RC_1RA1LE_---1LA_0LC1LF

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. Lean proves no halt in the first 107 steps; the C simulator finds none in 1011.

Reduced to one machine. Lean proves this is 1RB1LE_1RC1LD_1RD0LF_0LA0RD_---1LB_0LD1LF with renamed states, started in state B. See that machine for the mechanism.

M3 is T with its states renamed

1RB1LC_1RC0LF_0LD0RC_1RA1LE_---1LA_0LC1LF is 1RB1LE_1RC1LD_1RD0LF_0LA0RD_---1LB_0LD1LF with the states renamed A→D, B→A, C→B, D→C (every transition, halts included), so its run from blank tape is the run of 1RB1LE_1RC1LD_1RD0LF_0LA0RD_---1LB_0LD1LF started in state B on blank tape: one 1 fewer at the left than T's own run after its first step. m3_iff.

lean/Family.lean

T and M1 make the same run until a 0 sits within two cells left of A reading a 1

The two machines differ only in the 1-transitions of A, B and E, which all write 1 and move left. The seven-state machine S = 1RB1LE_1RC---_1RD0LF_0LA0RD_---1LG_0LD1LF_---1LD is the part they share (B split into B entered from A0 and E entered from A1). Every step S makes, both make on the same tape (shadow); in S, B entered from A0 always reads a 0, because A is entered only by D0 = 0LA (star_good); so S stops only where A has read a 1 and then meets a 0 one cell (S's E0) or two cells (S's G0) further left, and there exactly one of T and M1 halts and the other goes on with B0 = 1RC (deviation). Hence S halts iff T or M1 halts (star_halts_iff), and if neither halts they make the same run step for step (same_run).

Does it halt from blank tape?

Not known. It halts iff T started in state B halts (proved); the rules of T's higher counter levels are not known, so there is no argument either way.
