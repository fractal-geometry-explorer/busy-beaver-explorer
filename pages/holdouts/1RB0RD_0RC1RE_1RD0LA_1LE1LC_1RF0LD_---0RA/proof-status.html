What is known about 1RB0RD_0RC1RE_1RD0LA_1LE1LC_1RF0LD_---0RA

1RB0RD_0RC1RE_1RD0LA_1LE1LC_1RF0LD_---0RA

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Its whole run is now known to be the orbit of an explicit map on two numbers, proved in Lean: a stack of m words 1011 and a block of n ones. The block grows like 8n/3 each phase while the stack loses one or two words; when the stack runs out the machine either halts or rebuilds a much larger stack and starts again. Whether it halts is a question about the residues mod 3 of a Collatz-like sequence, of the same kind as the famous cryptid Antihydra.

Status as of 8 November 2026.

In short

The question is open, and reduced to a Collatz-like map (kernel). Lean proves that the machine halts from blank tape if and only if the orbit of (14, 5) under the map next below reaches a point (1, n) with n % 3 = 1 (halts_iff, lean/Map.lean).

The first two cycles do not halt. The orbit resets at phases 8 and 6,819; at phase 6,819 the stack has more than 102900 words, so the machine runs at least 102899 steps without halting (runs_long, lean/Orbit.lean, by native_decide). Deciding the third cycle needs about 5·102901 phases of the map: out of reach by simulation.

Heuristically it halts, absurdly late. If the residues mod 3 behave like coin flips, each cycle ends in a halt with probability 1/5 (simulated: 0.19 to 0.20 over 4,000 random cycles from large random starts), so the machine halts with probability 1, but each cycle is exponentially longer than the one before: a halt would come after a tower of exponentials of steps.

The phase start and the map

A phase start is P m n = 0^inf (1011)^m 1^n (10)^3 A> 1 0^inf. Writing n = 3k + 3 + r with r < 3, from P m n the machine reaches: for r = 0, P (m-1) (8k+19) if m ≥ 1 and P (2k+4) 5 if m = 0; for r = 1, P (m-2) (8k+29) if m ≥ 2, a halt if m = 1, P 0 (8k+18) if m = 0; for r = 2, P (m-2) (8k+35) if m ≥ 2, P (2k+8) 5 if m = 1, P 0 (8k+18) if m = 0. Each case is a chain of symbolic runs proved step by step plus an induction over the inner bouncer.

The map against the machine

Simulating the machine from P m n for 598 pairs (all m ≤ 7 with 3 ≤ n < 59, and 150 random pairs up to m = 60, n = 400) gives the next phase start the map predicts, or a halt exactly at m = 1, n ≡ 1 (mod 3); the run from blank tape passes through the phase starts the map predicts up to step 3.6·109. (Lean proves the map for all values; this is an independent check.)

heuristic Evidence only

Halting probability 1/5 per cycle

Within a cycle the stack drops by 2 (when r ≠ 0) or 1 (r = 0); if the residues are like fair dice the stack lands on 1 with probability 3/5, and then halts with probability 1/3: 1/5 per cycle. Simulating 4,000 cycles of the map from random large starts gives 0.19 to 0.20. The machine would then halt with probability 1, but cycle c+1 is about (8/3)^(m_c/1.8) times longer than cycle c.
