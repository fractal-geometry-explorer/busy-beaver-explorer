OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state machine halts from blank tape. It belongs to a family of six holdouts with almost the same table (F0 = 0LB, E1 = 0RA). Their tapes are made of the words 10 and 110, grouped in sections split by 000, and they grow slowly to the left. This page lists what has been established, sorted by what each result rests on.

Status as of 22 November 2026.

In short

The question is open. The engine is decoded and proved in Lean for every size and every layout. At an event the tape is a base-3 counter N, then a binary counter Z, then a chain of binary words; N and Z get 1 per event, and every word is a counter that, when it wraps, sends 3 to the next word (so a carry is multiplied by 3 at every separator, and an empty word passes 3 times what it got). This chain law covers every layout the run has shown (the plain cascade, the X layer and all later eras are special cases) and is proved in lean/Layers.lean for any number of words of any widths. Inside a layout the whole right side is one number that grows by 1 per event, so an era change happens only when a carry runs off the last word. Using this, a simulator that jumps from one era change to the next and runs each change cell by cell has followed the run through 510 changes of era, 2.4·10297 events (so at least that many steps), with no halt. At an era change N becomes ⌊N/3d⌋ + 1, where d > 0 is fixed by N's lowest digits and whether d = 0 is decided by the state in which the head gets back to the left end; a closed form for that state and for the new words is the open part. C never runs out of digits: instead the chain keeps gaining words.

What a change of era hands on

The change of era is one event whose carry runs off the last word; the head then sweeps back to the left end. Let d be the number of base-3 digits N loses. R1: N' = ⌊N/3d⌋ + 1. R2: if d > 0, d is fixed by N: read from its lowest digit, N starts with a zeros, one digit 1 or 2, b twos and one more digit, and the change eats exactly that block, so d = a + b + 2. R3: d = 0 exactly when the sweep back reaches the head cell of the last event in state C (otherwise it arrives in A). Every word wraps and the words are read again with each separator moved by half a digit. In 1,000 changes of era of this machine (no halt) every change follows them except 6 of the first 9, while N has at most 5 digits.
