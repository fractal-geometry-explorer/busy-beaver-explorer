1RB---_1LC0RB_0LD0LC_1RE1RB_1RD1LF_1LA0LE

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open, and it is a Collatz-type question. The run is a sequence of phases: a counter n becomes about 3n/2 each phase, and the parity of n edits a short word P on the tape. One word, reached after a particular run of 42 parities, halts. Lean proves the phase rounds for all lengths; the word dynamics is measured by simulation and checked against the real run.

Rounds between end events, by remainder class

Sample the run whenever the head is in state E reading 0 with only 0s to its left. Read rightwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m modulo 2 or 4 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (20 events) the class map predicts the next event in all 14 rounds it applies to. This is an extrapolation checked by computation, not a proof.

heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.484). Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).

tools/py/bbtools/triage.py

Halts with probability 1, at an absurd time

With random parities the word stays short and keeps returning to the empty word (200 random walks of 2,000 phases: no halt in 400,000 phases). Reaching the halting word needs a specific run of about 42 parities, about one chance in 240 per return, so with coin-flip parities the machine halts with probability 1, but after about 240 phases, when n has about 1011 digits.

python3 py/phases.py walk 200 2000
