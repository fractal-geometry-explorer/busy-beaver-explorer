OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape. Its tape is an irregular word followed by a run of ones that counts the head's visits to the right end; it can only halt if the word eats the whole run.

Status as of 8 November 2026.

In short

The question is open. Lean proves that a halt needs E at the right edge, and that each trip over the run of ones adds one to it; only A crosses the run to the right, so a halt needs the word W on its left to eat the whole run. In 2·1010 steps the run has grown to 137,905 cells while W eats about one cell per fifteen visits; W's own dynamics are not decoded.

Halts only at the right edge

A closed tape language from windows of 3 cells (338 abstract configurations, found by bbtools.ctl, checked by decide in the kernel) covers every configuration of the run from blank tape; in all of them where E0 can fire, the tape after the head is blank. So every halt happens in state E with blank tape from the head on, and the machine halts iff that ever happens.

Only A crosses the run

A is the only state that moves right over a 1 and stays the same (B and F erase the 1 they step on and D turns back), so E can reach the right edge only once W has eaten the whole run. The run grows by one per visit and W eats about one cell in fifteen: the run outgrows W, as long as W's appetite stays bounded.
