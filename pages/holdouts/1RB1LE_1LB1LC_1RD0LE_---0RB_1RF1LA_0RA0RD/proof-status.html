What is known about 1RB1LE_1LB1LC_1RD0LE_---0RB_1RF1LA_0RA0RD

1RB1LE_1LB1LC_1RD0LE_---0RB_1RF1LA_0RA0RD

Nobody knows whether this six-state machine halts from blank tape. This page records what is established about it, sorted by what each result rests on.

The tape is a few long blocks of 1s separated by single 0s. The head keeps returning to the right end in state B with a single block on the tape, Y(n) = 0^∞ 1^n 0 B>0 0^∞. From one such visit to the next, n follows a Collatz-like map: odd n go to 3n − 7, even n go through a nested computation on two blocks whose outcome is piecewise linear on residue classes modulo powers of 2, and which halts for a sparse set of even n.

Status as of 8 November 2026.

In short

The question is open. The run from blank tape has been followed exactly, on a run-length simulator tested against the plain one, to step 1.88·1018 and through the visits Y(n) for n = 2, 5, 8, 14, 39, 110, 232, 357, 1064, 1614, 4539, 13610, 23544, 67275, 201818, 576606, 1243308, 1864956, 2797428, 4196136, 8162799, 24488390, 37736994, 129867393, 389602172, 584403252, 876604872, 1397089014 without a halt.

Why it is hard. An even n halts with a probability that falls slowly with n (13% of even n below 64, 1% around 2,000, 0.1% around 100,000), so the run has survived real risks; along the orbit the chance of a future halt is small (heuristically of order 10−4), but the map is a Collatz-like map with infinitely many residue classes and no proof method is known.

The halting configurations

The machine stops exactly when D reads a 0.

step_none_iff, lean/Blank.lean

How a halt happens

E standing on a 0 before a block of exactly one 1, followed by a 0, makes D read a 0 two steps later (L 1 E>0 1 0 R). D is entered only from C (which always leaves a 1 for D) and from F, so this is the only way.

r_halt, lean/Rules.lean

Shift rules

For all lengths and any surrounding tape: E before a block of m + 3 slides a 0 through it (L E>0 1^(m+3) 0 R to L 1 0 1^(m+1) 0 B>0 R); E before a block of 2 merges it with the next; B on a double gap after an even block of 2j + 4 takes 4 from it, giving 1 to the left block and 3 to the right (r_g4); Y(2k + 5) turns into 0^∞ A>0 1^(2k+3) 0 1^3; and 0^∞ A>0 1^3 0 1^b into Y(b + 5).

An exact accelerated simulator

c/rle.h runs the machine on a run-length tape and crosses a run in one move when the machine provably does the same thing on every cell of it (a sweep whose states cycle, or a 0 sliding through 1s); c/rle_test.c checks it against tools/c/tm.h after every move (state, head position) and on 3,000 cells each side every 1,000 moves, here over 2.3·108 steps.

c/orbit.c

The odd rule

For every odd n from 5 to 19,999, Y(n) leads to Y(3n − 7); Y(3) halts. (Lean proves the first and last phases, r_y_odd and r_w_end; the shifts between them are not yet proved.)

c/ymap.c

The even map

For every even n ≤ 20,000 (and 100,000 to 104,000) the next visit, or the halt, was computed. The map is linear on residue classes modulo powers of two: n ≡ 4 (mod 8) gives 3n/2 − 6, n ≡ 16 (mod 32) gives 9n/8 − 5, n ≡ 22 (mod 32) gives 15n/8 − 9/4, n ≡ 2 (mod 64) gives 27n/16 − 99/8, n ≡ 14 (mod 64) gives 45n/16 − 3/8 (each checked on every n of its class between 4 times the modulus and 20,000), and finer classes for the rest. 57 even n below 20,000 halt: 10, 12, 34, 48, 122, 138, 178, 186, 192, 230, 294, ..., including every 3·4k (12, 48, 192, 768, 3072, 12288).

c/ymap.c, c/zmap.c

Where a halt can be

A closed tape language of windows of 4 cells (tools/py/bbtools/ctl.py, closure checked) allows a halt only with 0^∞ 1 1 0 D>0: the halting block of one 1 must be the leftmost block, next to a block of one 1.

heuristic Evidence only

Probviously non-halting

The fraction of even n whose step halts falls from 13% (n < 64) to 4% (64 to 512), 1.1% (512 to 4,096), 0.3% (4,096 to 20,000) and 0.1% (around 100,000), roughly like n−0.5. Along the orbit n grows by a factor of about 2 per visit, so if the even values behave like typical ones the chance of a halt after n = 1.4·109 is of order 10−4.
