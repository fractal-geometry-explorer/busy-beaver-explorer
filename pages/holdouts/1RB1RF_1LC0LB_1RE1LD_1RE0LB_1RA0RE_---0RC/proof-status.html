What is known about 1RB1RF_1LC0LB_1RE1LD_1RE0LB_1RA0RE_---0RC

1RB1RF_1LC0LB_1RE1LD_1RE0LB_1RA0RE_---0RC

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 9 November 2026.

In short

The question is open, but reduced to one lemma. The machine is a binary counter that gains 39 or 42 every 8 sweeps. Lean proves that every sweep keeps the counter in its steady form except at a B-overflow (once every second doubling), so a halt would have to happen in a B-overflow transient; the run through the first one is evaluated too. Proving that every B-overflow transient ends well (its long exit sweep, about 140·2w steps with two nested counters) would prove non-halting.

Where a halt can come from

If the machine halts on its third step from a configuration, that configuration is one of: E with 0 under the head, 1 right, 0 two right. So a run can reach a halt only through one of these patterns, and a proof that the machine never halts only has to rule them out. The proof splits on the state and the five cells around the head.

Every sweep that does not overflow the counter

The middle part of each visit (between the two block crossings) is proved for all 7 shallow cases (inner counter i < 7, i → i+1) and all 162 deep cases (i = 7: V → V + 39 or 42, t flips), for every value of the five low digits, digit 5 when it matters, and a carry crossing any number of 1-digits, for every tape left of the digit that stops the carry. The A-overflows

A deep visit in phase A whose carry runs through all digits to the blank tape (0^inf (U(1))^(k+1) [U(b5)] low M(t) I(7)) ends as phase B with the same width and a lone 1 in front (0^inf 1 (U(0))^(k+1) [U(b5)] low' M(1-t) I(0)), for all 81 cases and every k.

Every steady visit that is not a B-overflow leads to a steady visit

The visit configurations are written with the digits of V as a list of bits; Steady says the tape has the steady layout (phase A or B, at least 7 digits, block at least as long as the counter is wide). For every such configuration that is not a B-overflow, the run reaches another steady configuration: shallow visits, deep visits with a carry through any number of 1-digits, and A-overflows, for every counter value, width and block length.

A halt can only come in a B-overflow transient, and not in the first one

The run from blank tape reaches a steady visit (visit 280, step 1,882,602, evaluated), so with steady_step a halt needs the run to reach a steady B-overflow visit first; the run through the first B-overflow transient to visit 2688 (step 31,879,658) is evaluated too, so that B-overflow must come at step 31,879,658 or later.

Non-halting follows from one lemma about the B-overflows

If every steady B-overflow visit is followed by a steady visit, the machine never halts from blank tape.

heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.514).

Tape structure

At 108 steps the tape ends in (0111)^3998 011 A>1 (1001)^907 1, at 109 in (1011)^1088 10 B>1 (0110)^14656 011: two long periodic blocks meet at the head and trade length, with an irregular region of short words to their left that changes slowly.

The exit sweep

In the four B-overflows of the run (w = 13 to 16) the exit sweep takes about 140.5·2w extra steps. It is a loop of rounds of about 140 steps: each round adds 3 to a binary counter in the digit cells (at w = 13: from 14 to 213 in 2,726 rounds, then, one bit wider, from 0 to 214 − 1 in 5,461 more), while a second counter (base-3 digits in M, continued on the first copies of the block) counts the rounds. After a final loop and a clean-up it ends at a steady phase-A visit with one more digit and V = 2w + 203, 323, 203, 242. The round counter, the final loop and the clean-up are decoded only roughly.

README (The B-overflow transient)

It never halts

A halt can only happen in a B-overflow exit sweep. That sweep is a fixed program run on counters whose lengths grow with the width, the four seen behave alike, the symbolic runs reach it in all 81 cases, and 2·1010 steps follow the model with no exception, so a halt is very unlikely.
