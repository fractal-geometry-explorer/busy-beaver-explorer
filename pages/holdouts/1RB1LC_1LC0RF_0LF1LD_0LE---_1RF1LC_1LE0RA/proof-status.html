OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open, and looks hard. The run is a sequence of phases. A phase starts with a block of l cells, mostly ones, followed by a short tail; rounds turn the ones into words 110, four ones for two words (proved in Lean for any size), and at the end of the phase the block is about 3l/2 long. Jumping over the rounds with the Lean rule, the run is followed exactly through 47 phases, to about 3.4·1018 steps and a block of 2.39·109 cells, without a halt; the tail is always one of five, and on them the phase map is an exact 3/2 map whose parities steer the tail. The tail's own block of ones is processed like a small copy of the main run, so the tails that can arise are not a finite family: a reduction to a halting condition on the map stops there.

The phase map with an empty tail

A phase starts with the head in C on a new cell at the left end and l cells (1^l or 10 1^(l-2)) before the tail. On the run from blank tape and on constructed tapes: with an empty tail, an even l goes to 3l/2 + 4 with an empty tail and an odd l to (3l+5)/2 with the tail 011; with the tail (011)^c an even l goes to 3l/2 + 4 + 3c with an empty tail.

Rounds between end events, by remainder class

Sample the run whenever the head is in state A reading 0 with only 0s to its right. Read leftwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m mod 4) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (23 events) the class map predicts the next event in all 14 rounds it applies to. This is an extrapolation checked by computation, not a proof.

Why it is hard

The lengths grow by a factor 3/2 a phase and their parities behave like coin flips, as in Mahler's 3/2 problem and the Antihydra cryptid. Which tails can arise, and whether one of them leads the head to D reading 1 (the only halting transition), depends on these parities.

189 rounds of the class map without a halt

Iterated with exact integers from the event at step 57,486 of the run (A = 0, U = 001, m = 104, B = (empty)): 189 rounds without meeting a halting class; m then has 77 bits (about 1047 steps of the machine). 38 distinct contexts occur, the longest of 6,270 cells. The iteration stops there, at a context too large for the six simulations (a second long block has formed); this is a limit of the tool, not an event of the machine.

No halting class among 22 contexts

Breadth first from the starting context, with every remainder at every context (whether or not the numbers can really produce that sequence of remainders, and only for m large compared with the contexts): 22 contexts expanded, 22 found, to depth 10. None of them halts; the search is not complete (the set of contexts keeps growing), and it says nothing about a halt that needs a context as long as the block itself. 8 contexts longer than 300 cells were not expanded.

Does it halt from blank tape?

Equivalent to: does the phase map, with its tail of digits, ever reach a phase end in which D reads 1? A reduction to a closed system (a halts-iff statement about the map) is not reached: on the five tails of the run the map is the table above, but an odd l on [359,2] leads to [1232,2] and then to an unbounded chain of tails whose blocks follow their own 3/2 dynamics, and the phase ends for general tails are not decoded or proved. No halting tail has been found.
