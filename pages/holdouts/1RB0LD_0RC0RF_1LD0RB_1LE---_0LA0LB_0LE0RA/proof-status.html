OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open; the machine is a probable cryptid. Lean proves the two conversions the sweeps make and the situations that lead to a halt (kernel). A symbolic class search (programs, not Lean) ends with 7,030 tape shapes of which exactly one halts, and that shape is reached when two block counts M and Q satisfy Q = 3M − 1. The run from blank tape has not hit the line in about 1095 steps (accelerated, exact); whether it ever does is not known.

A closed set of 7,030 node classes with one halting shape

Seen in a mirror, a node is the tape F> 00001101 (1000)^P 101… at the near end; a class is a node shape with every count of at least 20 free, with its parity. Each class is run symbolically to the next node and split into pieces when the outcome depends on the counts. The search ends: 7,030 classes, 8,015 pieces, none undecided; every piece reaches a node of a class in the set except one, H(P) = F> 00001101 (1000)^P 101110110100001101 (P odd), which halts. So, as far as the programs are right, the run from blank tape halts if and only if it visits H. A plain simulator agrees on 15,499 piece runs and 14,060 class points.

H is reached on the line Q = 3M − 1

A backward search in the certificate finds a ladder: in the shape Y(P,M,Q) = F> 00001101 (1000)^P 1011 (1000)^M 1010100001 (1000)^Q 101000000101 (and three more shapes of the same cycle) each turn takes one block from M and three from Q, and the ladder ends in H exactly when Q = 3M − 1, whatever P is. Plain runs confirm it on examples: Y(21,3,8), Y(21,8,23), Y(23,8,23), Y(33,12,35) and Y(21,22,65) halt, and with Q one or two off the line they do not halt in 3·106 steps. The backward search does not terminate, so the complete set of tapes that lead to H is not written down.

Growth shape: sqrt/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.476). Counters and epochs

At every left-end visit with A in front of 000 in the first 107 steps, the tape is a short list of blocks of 1s; within an epoch the counts change by the same amounts every round trip (for example x − 8, y − 8, z + 32, or x − 12, y − 4, z + 32), and an epoch ends when one of them runs out.

How close the run comes to the line (observed)

In that run Y is visited 972 times; the closest to the line is |Q − 3M + 1| = 101, and Q − 3M + 1 takes every residue mod 2, 3 and 4, so no simple congruence keeps the run off the line.
