OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. The run is understood as a process on a list of blocks: each round halves the number of blocks of every size and moves them up one size. That description comes from simulation; Lean proves only the sweep rules the rounds are built from. The sister machine 1RB1RA_1LC0RD_1LD1LB_1LE0LF_0RA---_0LB0LE behaves the same way.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Chaotic Bell Class 1. These are labels read off the run by others, not results.

Rounds and block lists

A C run of 109 steps reaches the left end in state E 29 times (counting only events at least 106 steps apart). Each time the tape is a list of blocks of 1s separated by 00; almost all blocks have length 6m + 1 and stand in runs of equal blocks, longest blocks on the left.

c/blocks.c

Counts halve each round

From one round end to the next, the number of blocks of length 6m + 1 becomes about half (within a few blocks) the number of blocks of length 6(m − 1) + 1 before; a new run of blocks 1 appears on the right, alternately about 2,000 to 4,000 and about 200 to 450 long in the last rounds. A few irregular blocks sit at the boundaries of the runs.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.115). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.503).

tools/py/bbtools/triage.py

A marker sweeping left

Between round ends the head goes back and forth across most of the tape; the point where it turns moves left a few cells per trip while each trip adds a few cells on the right. This is why the right side grows like the square root of the step count and the left side, which only grows at round ends, like its logarithm.

Does it halt from blank tape?

Not known. A proof would need the round map on block lists in closed form, including the irregular blocks at the run boundaries, and then an argument that the halting landing never happens.
