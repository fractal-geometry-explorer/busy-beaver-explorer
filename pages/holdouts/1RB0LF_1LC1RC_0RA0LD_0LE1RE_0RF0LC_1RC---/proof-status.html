OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Both ends of the tape grow logarithmically. The left end is a long run of 10 after a few 0s (24 copies at step 556,283,168, 25 at step 1,678,517,170). The right end is a run of 110 (15 copies at step 1.8·109). In between lies a word of short digits (10, 110, 1110) in no fixed order that changes at each pass, like the digits of a counter, and decides when the head next reaches the left end. It is the same kind of machine as 1RB---_1LC1RF_0LE0RD_0RB0LC_1RD0LD_0RC0RA. No exact rule for the middle has been found.

Status as of 26 November 2026.

In short

The question is open. The machine can halt only from 1 C> 1 1 (both directions proved in Lean); in 20,000,000,000 steps that never happens. In the first 109 steps C had 1 C> 1 0 about 2.9·107 times and 0 C> 1 1 about 8.8·107 times, but never 1 C> 1 1: two of the three cells match all the time, the third never.

New, 14 November 2026. The whole run is now one rule: the tape is a binary counter with doublers (words 1010, 000, 100), and each round sends one defect through it. A tape with one defect cannot halt; a halt needs two defects to meet. In 100,000 rounds there was no halt, and in the 4,500 rounds followed word by word every defect disappeared long before the next one started. Whether that is always so is the open question.

New, 22 November 2026. For the shared rounds Lean now proves that a tape with at most one defect cannot halt, and a new engine followed the defect through 500,000 rounds (more than 2944,371 steps of the twin) without one surviving its round. Open: that this always holds, and the correspondence of the two runs.

Later on 22 November 2026. The correspondence with the twin holds on random tapes, not only along the run, and this machine's visits close up on the same token words. On the twin Lean now proves everything except that each round's defect dies; for this machine the correspondence itself is still to be put in Lean.

Latest, 22 November 2026. The correspondence is now a theorem: Lean proves, on this machine's own transition table, that every token rule of the twin is a run of this machine and that its rounds are the twin's rounds (lean/Link.lean). From blank tape it reaches round 9 at step 7,834, and it never halts if from round 9 on every round's defect needs at most one visit, exactly the twin's remaining assumption. Correction (evening): the first version assumed every defect dies counted from round 0, which is false (round 2's defect survives), so it proved nothing; it is replaced by the round-9 reduction.

26 November 2026. A worst-case test of the far end. An adversary rewrote every digit above the exact layers before every round, from round 100 to 1,500 (all 000, all 100 100, or random), so that nothing there can stop a defect. The defect then reached the floor of exact digits in only 11 or 12 rounds, at least 19 rounds apart and never deeper than height 2m − 27, and the floor was whole again within 7 rounds each time; the defect still needed 3 or 4 visits against 2m. So the digits of the far end cannot be where a halt comes from. What is left to prove concerns the doubler-rich part of the tape: that its heights stay up, and that it stops the defect in most rounds.

The halting context

From 1 C> 1 1 the machine reaches its halting transition (proved step by step, then step_none_iff). The halting transition is F reading a 1. F is entered from A reading a 1 (moving left) or E reading a 0 (moving right). A is entered only from C reading a 0, which writes a 0 to A's left, so the first way is impossible. E is entered from D reading a 0 (moving left, and then F reads the 0 D wrote) or a 1 (moving right), so the halt needs D> 1 0 1; D is entered only from C reading a 1 and moving left, which gives 1 C> 1 1. Lean proves the steps from each context to the halt (halt_ctx, halt_ctx_A, halt_ctx_E). The argument backwards is checked in Lean too, by enumerating the cells the head reads: a configuration halts three steps later if and only if it is 1 C> 1 1 (halt_iff_3; one and two steps before a halt: halt_pred_1, halt_pred_2), so a halting run from blank passes through it (halts_blank_pred_3).

The twin's token rules are this machine

Lean proves, on the generated table of this machine, that every token rule of the twin (words L = 1010, O = 000, I = 100, defects 10, 1, 0) is a run of this machine from five entry forms: B after 1 0 computes A, C after 1 0 or 1 1 computes Ê, B after 0 0 or C after 1 0 on 0 W computes E0, each for any tape further left (sound, 25 generated runs). One round: in E on 0 0 0 1 0 S the machine reaches E two cells further left on 0 0 0 1 0 1 0 A(S) (round_run), and from blank tape it is there with S empty after 4 steps (start). From blank tape it is at the start of round 9 (E on 0 0 0 1 0 x a9) at step 7,834 (round9, kernel evaluation). With the twin's one-defect theorem and its fuel nx: if every round from 9 on has nx W ≤ 1 on its tape x W, this machine never halts from blank tape (nonhalt_of_need, the twin's hypothesis word for word). A first version, nonhalt_of_clean, assumed every defect dies from round 0; that is false (round 2's defect survives), so it was vacuous and is removed. Only propext and Quot.sound.

The far end is a conveyor (the twin's eighth pass)

This machine's rounds are the twin's token tapes. There the clean tape after each visit has v = 16/15 − c·2−m + O(2−2m), its digit-only end is exactly that number's binary expansion below height 2m − 11, and below height m every digit climbs 4 heights per round unchanged. A defect that reaches these exact layers dies within 20 words, with at most one visit needed. Open in this form: that no defect dies inside them, and the two-round height monotonicity.

The floor under the worst digits

Rounds 100 to 1,500 with an adversary that rewrites every digit of the digit-only end at height 2m − 8 or more before every round's visit (all 000, all 100 100, or a fresh random mix). The defect hits the floor in 11 or 12 of the 1,401 rounds, at least 19 rounds apart, with gaps growing by about 1.3 each time; a hit never goes deeper than height 2m − 27, and the top of the exact layers is back at 2m − 12 or higher within 7 rounds (it heals at 3 heights per round). The need is 3 or 4 visits in every round. So deaths inside the floor are harmless when rarer than about one in 8 rounds. A test, not a proof; the adversary controls only the digit end.

The correspondence on any tape

Started in E on 0 0 0 1 0 S, this machine reaches 0 0 0 1 0 1 0 A(S), with A the visit function of the twin, for all 1,517 of 2,000 random tapes S on which A(S) is defined, and halts on the other 483. Its visits close up on the token words with five entry forms, and every token rule of the twin is a run of this machine through them (symbolically). A counter with doublers and one travelling defect

In the words L = 1010, O = 000, I = 100 the function A is a binary counter (O, I the digits) in which every carry crossing an L becomes two. Each round adds one defect (a 10, 1 or 0 that does not fit the words), which travels through the counter, rewrites it, and disappears where it turns 1 I O into O L. A tape with at most one defect cannot halt (proved in Lean for the twin's rounds, lean/Total.lean there); a halt needs two defects side by side. The token rules reproduce the exact tape cell for cell (rounds 5 to 24), and in every round from 13 to 4,500 the defect disappeared about 40% of the way into the tape, long before the round ended.

A conserved value

For the twin 1RB0LE_0LC0RA_1LE0RD_0RB---_0LF0LD_1LA0LF, whose round words this machine carries: a value of the tape (each digit 1 counts 2-b, b = doublers minus digits before it, with corrections for the defect) grows by exactly 1 with every visit of A, with or without a defect: worked out by hand, checked with exact fractions on every round. At the start of each round it is 1/15 up to about 2-k/2: the far end of the tape is the binary expansion of 1/15, I O O O repeated k/8 times.

open Open

Does it halt from blank tape?

Not known. Halting needs C on a 1 with 1s on both sides, which the words of the tape have never offered; whether they never will depends on the counter in the middle, whose rule is not found.

Does every defect disappear in time?

From round 9 on, if the defect of every round needs at most one visit (nx W ≤ 1), the machine never halts (proved in Lean, nonhalt_of_need). The early rounds are not like that: round 2's defect survives its round. Where a defect dies depends on the digits of the counter, which look irregular; no proof.

The one missing lemma

With the conserved value, the defect of a round must disappear if the tape ends in a few periods I O O O and every digit before them is reached by many visits (b larger than a few times log2 k). Measured, b is at least 2m - 5 in the part rich in doublers; a proof of a lower bound is missing. It would show that the machine never halts. 22 November 2026: on the twin the digit end has four layers, and only the bottom, irregular one (about 0.27 k digits) is ever eaten; the lemma would follow if no defect ever crossed all of it in one round. Not proved.
