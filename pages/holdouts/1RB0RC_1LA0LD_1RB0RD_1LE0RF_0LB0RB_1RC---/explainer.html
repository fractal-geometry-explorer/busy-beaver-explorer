A 6-state Busy Beaver machine · Status as of 9 November 2026.

Does this machine ever halt?

1RB0RC_1LA0LD_1RB0RD_1LE0RF_0LB0RB_1RC---

No. For its first 1.67×1010 steps this machine goes through five ever longer epochs; then it settles into an exact repeating pattern, a bouncer: the head sweeps between the two ends, and every two sweeps one more block of 13 cells appears on the left while a fixed stretch of 222,182 cells is carried along. Lean proves that the pattern repeats for ever and, chunk by chunk, that the run from blank tape gets there.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 1. F is entered only from D1 (writes 0, moves R): D>1 1. So a halt is the moment this pattern appears, with the head on the cell after >.

First look

The shape of the run

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.538).

After 109 steps the tape spans 57,599 cells (252 left of the start, 49,179 right), with a density of 1s of 0.36.

Structure

What the tape is made of

From step 16,730,681,219 on, every second time the head comes back to the left end the tape is

C k = 0^inf A> 0 (1010001000100)^k X 0^inf

The head, in state A, stands on the leftmost cell. Then come k copies of the block 10 1000 1000 100 (13 cells), then a stretch X of 222,182 cells that is always the same. X is what is left of the earlier epochs: an irregular record of 10s, 100s and 1000s that the sweeps rewrite on the way out and restore on the way back.

Over one period (two sweeps) the left end moves 4 cells left, one block is added, and X ends up 9 cells further right, so the right end grows 9 cells per period. The time per period grows by 184 steps per block, so the tape grows like the square root of the step count, the bouncer signature.

Exact rule

One period, piece by piece

Over the blocks the machine is easy to follow symbolically, for any number of them; inside X it is not, but X is a fixed string, so the run there is simply computed. The two kinds of piece meet at the boundary between the blocks and X:

and 1 0 (1000100010010)^(n+1) r2 = (1010001000100)^(n+2) X: the period ends at C (n+2), after 184n + 3,029,224 steps in all. In each excursion the head never moves left of the cells written next to it (1, or 0 1 1), so what the excursion does does not depend on n. The passes are proved by Lean's kernel for every n; the excursions and the final equality are evaluated with native_decide, about 3 million steps on a list of 222,000 cells.

The long run

How it gets there: five epochs

Before the bouncer the leftward sweeps do not always reach the left end. The cell where they turn back (green below) creeps right, about 7 cells per sweep, while the right end (red) gains 4.5 cells per sweep; when the turning point catches up with the right end it runs back to the left end, and the next epoch starts. Five epochs, each about 3.7 times longer than the last, end at sweeps 250, 950, 3,600, 13,350 and 49,300. After the fifth the turning point stays at the left end: the tape is then C 7, and the period above repeats from there on.

Logged every 200 sweeps by py/lturn.c up to 1011 steps (84,927 sweeps). After sweep 49,300 the step counts of the turns follow a quadratic exactly.

Halting

Why it never halts

The only halting transition is F reading 1. State F is entered only from D reading 1 (D1 = 0RF), so a halt needs the head in state D on 1 1. In the bouncer phase this never happens: the period is proved for every number of blocks, and the run over X is the same every time. Before it, Lean checks the whole run of 16,730,681,219 steps from blank tape, in eight chunks of about 2×109 steps: the C simulator proposes the configurations at the chunk boundaries, and a block simulator proved correct in Lean (blocks of 16 cells, one table lookup per block crossing) checks each chunk, with native_decide.

period, not_halts_C, nonhalt_of_reach, lean/Period.lean
One period of the bouncer, for every number of blocks

With C k = 0^inf A> 0 (1010001000100)^k X 0^inf: C (n+1) reaches C (n+2) in exactly 184n + 3,029,224 steps, for every n. So from any C (m+1) the machine runs for ever, and if the run from blank tape reaches some C (m+1), the machine does not halt.

brun_ok, mstep_ok, msim_ok, chkF_ok, lean/Block.lean
A block simulator, proved correct

The tape cut into blocks of 16 cells, and a table that says, for each state, block and side of entry, what the machine does in the block until the head leaves it. Each table entry is computed by a run on the block's cells that is proved to be a run of the machine whatever lies outside (brun_ok); the simulator msim looks up one entry per block crossing, and chkF_ok turns a successful check of a run of exactly t steps (macro steps, then single steps) into steps t ... = some ....

Kernel
dsweep, blk_cross, lean/Sweep.lean
The rightward sweep over the Q encoding is a block transducer

In state D, moving right, the head crosses each of the blocks 1000, 100100, 1001000, 10010100, 100101000 in state D without looking past it, so it crosses any word made of them block by block. A building block for the earlier phase; the period proof above does not use it.

Heuristic
py/lturn.c, py/chart37.py
Before the bouncer: a turning point that runs out and back in epochs

Up to step 1.67×1010 the leftward sweeps do not all reach the left end: the cell where they turn moves right, about 7 cells per sweep, until it meets the right end (sweeps 150, 650, 2,550, 9,500, 35,550, right end at 774, 3,024, 11,648, 42,923, 160,189 cells), then runs back to the left end (sweeps 250, 950, 3,600, 13,350, 49,300). Each epoch is about 3.7 times longer than the one before. After the fifth return the configuration is C 7 and the bouncer above takes over.
