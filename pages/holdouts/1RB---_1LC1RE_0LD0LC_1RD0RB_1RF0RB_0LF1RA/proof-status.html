1RB---_1LC1RE_0LD0LC_1RD0RB_1RF0RB_0LF1RA

Nobody knows whether this six-state machine halts from blank tape. Like 1RB---_1RC0RD_1RD1RA_1LE1RB_0LF0LE_1RF0RD it runs two binary counters: a long block of 1s at the right end that counts to 2j, and the single 0s between the blocks on its left, which receive 2j at each full count. Its overflows are different from that machine's and are not modelled. This page lists what has been established, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. The event rule is proved in Lean for every size (the proof of 1RB---_1RC0RD_1RD1RA_1LE1RB_0LF0LE_1RF0RD, states renamed); with blank_to_P it follows that the machine can only halt at an overflow. The overflow rule is not known; the exact accelerated run (jumps between overflows whose endpoints are proved, with step counts checked against the direct run; overflows simulated) reaches the third overflow at step 1.649·1012 without a halt, and the next one is about 1015 steps away.

Shift rules

C erases a block of 1s leftwards; D fills 0s rightwards; F walks left over 0s; B rewrites pairs 1 1 as 1 0; C on a separator walks left through a block, moving it one cell right. Each for every length and every surrounding tape.

The event rule, for every size

This machine is 1RB---_1RC0RD_1RD1RA_1LE1RB_0LF0LE_1RF0RD with one transition changed: with the states renamed (B, C, D, E, F there are E, F, B, C, D here) the tables agree except that machine's C0 = 1RD, here F0 = 0LF. In the counting phase that transition is used only on a counter digit, E> 0 0 x (E0 1RF, F0 0LF, F1 1RA, A0 1RB, then B on x), which does what the other machine does in 5 steps instead of 3. So the proof of lean/Count.lean carries over with the states renamed and two step counts changed: count, iter and event_rule (from P(d, b1 :: lo ++ h) to P(d+1, b1 :: lo ++ inc h) when lo has d bits and h has a 0), event_to_P, and blank_to_P (the run reaches P(0, 1100111) at step 311). Every pair of consecutive P configurations of a run to 2·107 steps follows the rule (33) or is an overflow (2).

event_rule, lean/Count.lean; 1RB---_1RC0RD_1RD1RA_1LE1RB_0LF0LE_1RF0RD/py/pchain.py

Halting only at an overflow

Follows from blank_to_P and event_rule (the deduction is not itself a Lean theorem): the run from blank reaches a P configuration and the rules are runs, so the machine can halt only in a phase P(d, bs) whose addition of 2d+1 carries out of the top bit.

event_rule, lean/Count.lean

The exact run to the third overflow (step 1.649·1012)

py/accel.py follows the run from P configuration to P configuration with the proved rules (jumps whose endpoints are proved; the step count of each phase is a closed form in the carry lengths, read off the lemmas' proofs since the Lean statements give no step counts, and is checked against a direct run on every phase to 3·106 steps), and simulates only the overflows cell by cell (c/transient.c). It reproduces the two overflows of the direct run (P configurations at steps 1,308 and 1,491,493) and finds the third: at step 1,649,096,662,853 the string 100000000000011011011000011010110001 (d = 34) overflows, and 1,347,301 steps later the run is at P(28, 00000000000000000000000000000011100111110110110) (47 bits), step 1,649,098,010,154, without a halt. The next overflow is near d = 46, about 1015 steps.

The current phase cannot halt

In a phase the bits below the current position j never change again. In the phase from step 1,491,439 the event at step 206,159,921,357 has j = 33 and its 33 bits below j (000000000011011011000011010101111) include 0s, so the string never becomes all ones in this phase; it ends with an overflow after j = 35, near step 1.6·1012 (the time per event doubles). (Now also a consequence of event_rule.)

The overflow rule

What an overflow writes is not known as a formula. By direct simulation of all 240 overflowing phases P(d, bs) with at most 6 bits, the next P configuration has d = 0 in 219 cases (1 to 3 in the others) and a string 4 to 17 bits longer (mostly 5 to 12), in a way that depends on more than the low bits of R; the only 5 that halt are P(M−2, 10…01), the phases that end in the all-ones halting pattern. The exact accelerated run gives the real overflows but no rule.
