What is known about 1RB0LF_1LC0RB_0LD1LA_0RA1LE_0LA0RA_1LA---

1RB0LF_1LC0RB_0LD1LA_0RA1LE_0LA0RA_1LA---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. Lean now proves whole rounds, not just sweeps: from a round start A> (10)^4 110 (10)^N 10010 T, for every N in a residue class mod 4 and the short or long tail T, the machine reaches the next round start, with an exact step count (four branches: N → (3N+5)/2, 9N/4 + 24, 11N/4 + 47/2 (with the tail's length), (3N+10)/2). Chaining them from blank tape, Lean's kernel proves that the machine reaches the round with N = 19,199 at exactly step 1,842,640,229 without halting. The tail keeps changing shape (a new one appears at N = 19,199), so the rounds do not yet close into a single map whose orbit decides the question.

The counting sweep

For all a, b, c and any tape R further right: A> (10)^(a+1) 110 (10)^(b+2) 10010 (110)^(c+1) R (A at the left end of the tape) reaches A> (10)^(a+4) 110 (10)^b 10010 (110)^(c+2) R in 14a + 8b + 83 steps: one sweep moves the counter (a, b, c) to (a+3, b−2, c+1). Also the shift rules the sweep is made of.

Four branches of the round map, for all N

With RS(N, T) the round start A> (10)^4 110 (10)^N 10010 T (A on the leftmost cell, blank tape left), the short tail Ts = (10)^11 1, the long tail Tl(m) = (10)^m 1 (10)^11 0101 and TD(p) = 1 (10)^p 1 (10)^9 0101101: for all j and m, RS(4j+5, Ts) → RS(6j+10, Tl(3j+6)); RS(4j+2, Tl(m)) → RS(9j+m+27, Ts); RS(4j+4, Ts) → RS(9j+33, Ts); RS(4j+4, Tl(m)) → RS(6j+11, TD(3j+m+5)), each in an exact number of steps. A round is the first sweep (sweep0), the counting sweeps chained by induction (sweeps: k sweeps in k(14a+8x+83) + 29k(k−1) steps) and a conversion found and proved as one symbolic run by bbtools.symtm.

round_A … round_D, sweeps, lean/Round.lean; conversions in lean/Conv.lean (from py/round.py)

Eight conversions

The conversion at the end of the counting phase is proved, as a single symbolic run, for every residue of N mod 4 and both the short and the long tail (families A–H); four of them end at a proper round start and are chained above, the other four (N ≡ 3, or N ≡ 1 with the long tail, …) end at a left-end configuration of a different shape.

The shape of a halt

F on a 1 halts, and F is entered only from A on a 1 (writing 0, moving left), so the machine halts exactly when A reads a 1 with a 1 to its left: 1 A> 1 reaches F on a 1 in one step (the converse direction by reading the table, not formalized).

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.474). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.065).

Does it halt from blank tape?

Not known. The proved branches carry the run to N = 19199, but the round from there (N ≡ 3 with the tail TD) ends in a left-end configuration of a new shape, and new tail shapes keep appearing, so the rounds are not yet a closed map. The halting configuration 1 A> 1 never occurs in the proved rounds (they are exact runs), so a halt, if any, would come later. A macro simulation (words 10, 110, 10010) finds the next left-end start at step 4,516,954,072: A> (10)^4 110 (10)^28802 1 110 (10)^30401 110 (10)^5 10010 (110)^2 1, where the run is followed by 1 110 instead of 10010.
