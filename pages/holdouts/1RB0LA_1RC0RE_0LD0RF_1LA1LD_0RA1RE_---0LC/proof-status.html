What is known about 1RB0LA_1RC0RE_0LD0RF_1LA1LD_0RA1RE_---0LC

1RB0LA_1RC0RE_0LD0RF_1LA1LD_0RA1RE_---0LC

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. Its run is a sequence of epochs, each starting from one long reservoir of blocks and a short tail. For seven of the eight tails that have turned up, the next epoch is now known for every size (a symbolic run, not yet in Lean). The eighth, S1, starts an epoch that contains a binary counter, and what the counter leaves behind is not understood. This page lists what has been established, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open. Lean proves by the kernel the round-trip rule of the main regime and the 14-trip cycle of the second one for all sizes. A symbolic run of the accelerated simulator gives the epoch map for the tails S0 and S2 to S7 for every reservoir size n ≥ 2000 (28 classes by n mod 4, none halts; checked against the plain simulator, not in Lean). Epochs with the tail S1 run a binary counter with about log2 n digits, and their outcome depends on those digits: no finite set of classes covers them. No halt in the first 4.9·1014 steps (accelerated run).

Epochs: the tape comes back to A> (01111)^n S

Along the run from blank tape the left-A records of the form A> (01111)^n S (S at most 60 cells, n ≥ 20) are n = 63, 293, 2363 and 18924, at steps 42,291, 853,349, 54,698,577 and 3,502,378,736. Write E(n, S) for that configuration. Started from E(n, S) on otherwise blank tape, the machine reaches a next epoch E(n', S'). Only six tails S0–S5 have turned up so far, besides a few rarer ones from S1. For S0, S2, S3, S4 and S5, both n' and S' depend only on n mod 4, and n' is affine in n on each class: from S0, n ≡ 1 gives S0 with n' = 8n + 19, and n ≡ 0, 2, 3 give S1 with n' = 8n + 23, 8n + 17 and 8n + 20. From S2, n' = 8n + 54, 52, 53, 50. From S3, S4 and S5 the slope is 9/2. These hold at n = 100–115 and n = 400–407 for every tail, and at n = 20–39 from S0. They predict the run's epochs: 293 ≡ 1 gives E(2363, S0), and 2363 ≡ 3 gives E(18924, S1), which the run reaches at step 3,502,378,736. With the accelerated simulator the run from blank tape goes on to n = 350131 (tail S3, step 1,196,474,995,557), n = 1575589 (S3, step 24,366,344,552,101) and n = 7090149 (S1, step 493,555,240,386,637); these follow the class table below (18924 is an S1 epoch).

The epoch map for seven tails, for every size

For the tails S0, S2, S3, S4, S5 and the two rarer ones S6 = 0011110111110011110111 and S7 = 0011110111101111001, and every n ≥ 2000, the next epoch is known: 28 classes (tail, n mod 4), each with one symbolic run of the accelerated simulator in which n = r + 4x and x is a free variable. The simulator refuses any step whose outcome would depend on x, so a run that ends at E(k + c x, S') holds for every x. From S0, S2 and S6: n' = 8n + 17 … 54 (c = 32 per 4). From S3, S4, S5 and S7: n' = 9n/2 + d (c = 18 per 4). For S0 to S5 the next tails are exactly those of the table measured earlier at n = 100–115 and 400–407. No class halts, and every class leads to S0, S1, S3 or S4; the tails S2, S5, S6 and S7 arise only from S1. All 28 classes were compared at x = 0 and x = 1 with the plain C simulator: next n, next tail and the step count agree in 56 of 56 runs. This is a result of our own tool, not a Lean theorem.

An S1 epoch contains a binary counter

From E(n, S1) the reservoir is first turned into a block (110011)^k with k about n/2 (k = 200 for n = 400). Then the right-end eater takes the blocks 110011 one at a time, and between it and the big block (100)^N a binary number appears, written with the words 100 (digit 0) and 11100 (digit 1) after a leading 11100: it goes up by one for every two blocks eaten (observed for n = 400: 1, 10, 11, 100, …, 1100010 after 196 blocks), and each new digit costs the big block one word. When the blocks 110011 are used up the eater takes the number apart digit by digit from the low end (50 round trips for 7 digits at n = 400) and leaves a word to its right that depends on the digits. So the outcome of an S1 epoch depends on the binary digits of about n/4, which explains why it shows no residue pattern.

Growth shape: sqrt/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.538). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.385).

Big cycles that grow about eightfold

From blank tape the regimes come in the order Q with reservoir 292, Q with 296, Z with c = 293 and d from 288 down to 2 (4,090,752 to 22,188,348 steps), a transition, then Q with 2362, Q with 2366, Z with c = 2363 (from 217,524,700 steps, still running at 3·108). Each big cycle multiplies the reservoir by about 8. The transitions (the eater meeting the end of its blocks, the reservoir running out) are not analysed.

Taking the counter apart is not a finite-state process

On tapes of the shape seen just before the blocks 110011 run out, with a random number in place of the counter (200 samples each): the part of the tape right of the remaining digits takes 114 different values for numbers of up to 6 digits, 524 for up to 12 and 1,221 for up to 24, and its longest value grows from 60 to 90 cells. A finite set of classes (the method that proved 1RB0RD_1RC0LF_1LA0LB_---1RE_1LB1RA_0LC0RA) therefore does not cover the S1 epochs; a proof would need an invariant over all digit strings. None of the 600 samples halts.

Does it halt from blank tape?

Not known. For seven of the eight tails seen, the epoch map is settled for every n ≥ 2000 by symbolic runs, and no class halts. Everything now rests on the S1 epochs. An S1 epoch counts in binary up to about n/4 and then takes the number apart, and the result depends on the digits. A proof that it never halts needs an invariant that holds for every digit string, which is a different kind of argument from a finite set of residue classes. The run from blank tape is in an S1 epoch from step 4.9·1014 (n = 7090149); the S1 epoch before it (n = 18924) ended at E(350131, S3).
