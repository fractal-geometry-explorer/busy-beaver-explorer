A 6-state Busy Beaver machine · Status as of 8 November 2026.

Does this machine ever halt?

1RB0LA_1RC0RE_0LD0RF_1LA1LD_0RA1RE_---0LC

Nobody knows. Started on a blank tape, this machine builds its tape out of 5-cell and 3-cell blocks. In one regime each round trip of the head turns one block of a reservoir into two new blocks; in another a little machine at the right end eats blocks four at a time. Both are proved in Lean for every size; what happens in between, where each big cycle comes out about eight times bigger, is the open part.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 0. F is entered only from C1 (writes 0, moves R): C>1 0. So a halt is the moment this pattern appears, with the head on the cell after >.

Where it could stop

The one way to halt

The only halting entry is F reading a 0. F is entered only from C reading a 1 (C writes 0 and moves right), so the machine halts exactly when C>1 0 occurs: C on a 1 with a 0 to its right. In the first 108 steps that moment comes 6.8 million times and the cell to the right has always been a 1.

Macro structure

The main regime: a reservoir turned into growth

Stop the simulator whenever the head reaches a new cell at the left end in state A. For long stretches the tape then reads

A>(01110)^a 0 1 1 1 1 (001)^a (01111)^b …

A round trip of the head runs right over the two repeats (E crossing the 3-cell blocks, D and A coming back), takes the first block 01111 of the reservoir and returns; the left part has gained one block 01110 and the middle one block 001. For example a = 5, b = 287 at step 853,764 becomes a = 6, b = 286 after 167 steps. Lean proves it for every a and every tape behind the reservoir: Q (a+1) (01111 01111 R) becomes Q (a+2) (01111 R) in 28a + 55 steps (Q_step), and by induction j trips eat j blocks (Q_iter). The tape to the right of the reservoir is never looked at.

Macro structure

The eater at the right end

The second regime has a little machine at the right end of the tape. The tape reads

A>(01110)^a 0 1 1 1 1 (001)^c 1 1 0 0 1 0 0 1 1 1 1 (001)^d 1 1 0 0 1

and the five cells 1 1 0 0 1 at the end are the eater's resting shape. Each round trip changes its shape (it grows to a dozen cells and shrinks again); after 14 trips it is back, 4 blocks 001 further left, while the left part has grown by 14 blocks. Lean proves the 14-trip cycle for all a, c, d (Z_step, Z_iter). The block (001)^c in the middle is not touched; it is the reservoir of the previous main regime.

The eater does not start in its resting shape: when the regime begins it goes through a few hundred irregular trips first, sometimes even giving a block back, before it falls into the 14-trip cycle. That start-up is only observed.

The long run

Big cycles, about eight times bigger each time

py/phases.py labels every sample. From blank tape:

  • main regime with reservoir b = 1, 6, 7, 62, then 292 (steps 853,349 to 2,042,666) and 296;
  • the eater with c = 293, d = 278 down to 2 (steps 4,090,752 to 22,188,348);
  • a transition of about 30 million steps;
  • main regime with b = 2362 (steps 54,698,577 to 132,769,764) and 2366, then the eater with c = 2363, still running at 3·108 steps.

So each big cycle multiplies the reservoir by about 8 and lasts about 64 times as long. Within a cycle everything is proved; a proof that the machine never halts needs the transitions as rules for all sizes, which is the next step. Whether a transition can go wrong depends on the residues of the sizes (the eater eats 4 blocks per period, so where it stops depends on d mod 4), so the cycle map may be Collatz-like.

The big cycles have clean boundaries. At steps 853,349, 54,698,577 and 3,502,378,736 the tape reads A> (01111)^n S with n = 293, 2363 and 18924: one long reservoir and a tail of 14 to 16 cells. Starting the machine on A> (01111)^n S for many n shows that only six tails occur. For five of them the next such tape depends only on n mod 4, with n multiplied by 8 (or 9/2) plus a constant: from the tail S0 = 0011110111110111, n ≡ 1 mod 4 leads back to S0 with 8n + 19, which is the step from 293 to 2363. The sixth tail, S1 = 00111101111001, reached from 2363 with n = 8·2363 + 20 = 18924, behaves differently. Its cycle carries a second long counter, and where it ends shows no pattern in n. That is where the open part of this machine now sits.

Computed
py/epochs.py run 6e9, py/epochs.py table 100, table 400, c/epochs.c
Epochs: the tape comes back to A> (01111)^n S

Along the run from blank tape the left-A records of the form A> (01111)^n S (S at most 60 cells, n ≥ 20) are n = 63, 293, 2363 and 18924, at steps 42,291, 853,349, 54,698,577 and 3,502,378,736. Write E(n, S) for that configuration. Started from E(n, S) on otherwise blank tape, the machine reaches a next epoch E(n', S'). Only six tails S0–S5 have turned up so far, besides a few rarer ones from S1. For S0, S2, S3, S4 and S5, both n' and S' depend only on n mod 4, and n' is affine in n on each class: from S0, n ≡ 1 gives S0 with n' = 8n + 19, and n ≡ 0, 2, 3 give S1 with n' = 8n + 23, 8n + 17 and 8n + 20. From S2, n' = 8n + 54, 52, 53, 50. From S3, S4 and S5 the slope is 9/2. These hold at n = 100–115 and n = 400–407 for every tail, and at n = 20–39 from S0. They predict the run's epochs: 293 ≡ 1 gives E(2363, S0), and 2363 ≡ 3 gives E(18924, S1), which the run reaches at step 3,502,378,736.

Heuristic
py/epochs.py map 00111101111001 100 180
The S1 epochs are irregular

From E(n, S1) the next epoch does not follow a short residue pattern. For n = 100–179 the offset n' − 8n jumps around (about 3.5n for odd n, 10n–14n for even n, never periodic). S' runs over all six tails and some new ones, e.g. 0011110111110011110111 at n = 120, 168 and 405. Inside an S1 epoch the tape carries a second long counter, a list (001111)^k made from the reservoir, so the epoch contains an epoch of its own. The run is in an S1 epoch from step 3.5·109, with n = 18924.

Open
Does it halt from blank tape?

Not known. The epoch map E(n, S) → E(n', S') is affine on residue classes mod 4 for five of the six tails, so for those a certificate of finitely many symbolic templates looks within reach. The approach is the one used for 1RB0LF_1LC0LA_1RA0RD_---1RE_1LA1RC_0LB0RC: the Q and Z trips as round templates, plus the transitions and the eater's start-up as symbolic runs in n. The sixth tail, S1, is the obstacle. Its epochs contain a second counter, and their outcome shows no residue pattern, so a full proof needs the inner dynamics of S1 epochs as a map of their own. The run from blank tape is in an S1 epoch from step 3.5·109.
