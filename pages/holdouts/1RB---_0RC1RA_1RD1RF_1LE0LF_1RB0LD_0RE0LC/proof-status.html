What is known about 1RB---_0RC1RA_1RD1RF_1LE0LF_1RB0LD_0RE0LC

1RB---_0RC1RA_1RD1RF_1LE0LF_1RB0LD_0RE0LC

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

Open. Between rare rebuilds the machine is a binary counter written with four-valued digits on a background of the word 01011111; this is checked against the simulator over 108 steps. The rebuilds (ten so far, the last at step 29,787,121; none up to 2·1010) are not understood, so there is no decision.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Shift-overflow structural counter. These are labels read off the run by others, not results.

The counter passes

At every right-end turn in the first 10^8 steps where the tape ends in digits separated by runs of 01011111, the next pass steps the lowest digit a → b → c → d → a and passes a carry left exactly on d → a and a → b (2,480 passes checked).
