1RB0LA_0RC---_0RD0RF_1LD0LE_0LA1LE_0RA0LA

Nobody knows whether this six-state machine halts from blank tape. Its tape is almost all 1s: a few blocks of 1s separated by single 0s ("holes"). Each round, the head turns the first block into alternating cells and then sends them back to the right one pair at a time as small gliders, each of which moves a hole 3 cells. The blocks get reshuffled every round, a little like a Collatz map; the two even cases of that map are proved in Lean.

Status as of 8 November 2026.

In short

The question is open. Lean proves the full round for a first block of even length (any length, any second block), and no halt in the first 107 steps. Odd first blocks make the sweep run on through the next block; that step is proved (cross), the rest of such a round is not yet written as rules. In 109 steps every round started on blocks separated by single 0s, which is what keeps the one halting pattern (B>0 1 0 0 1, a sweep meeting two 0s) away.

The pieces of a round

The sweep 0 C> (11)^n becomes (01)^n 0 C> in 4n steps; the glider 0 0 D> 1^n becomes 1^n 0 0 D> in 5n steps; one glider cycle 1 0 1 0 1 E> 0 1^(p+2) 0 1 becomes 1 E> 0 1^(p+3) 0 1 1 1 1 in 6p+22 steps (the hole moves 3 cells left); the sweep through an odd block 0 C> (11)^n 1 0 1 becomes (01)^n 0 0 1 0 C> in 4n+5 steps (the hole becomes a 0 0 mark among the pairs and the sweep goes on into the next block); and the first and last pieces of a round.

Every round starts on single holes

At each of the 685 times after step 204 that the head is at the left end in state E on a 0, up to step 109, the tape is blocks of 1s separated by single 0s: 2 blocks 560 times, 3 blocks 107 times, 4 blocks 17 times, 5 once. The first block's length mod 4 is 0, 1, 2, 3 in 181, 188, 167, 149 of them.

The even rounds follow the formula

All 347 rounds from an even first block in the first 109 steps go from [x, a, b, ...] to [a + K, 3K + 3 + b, ...] (x = 4K) or [a + K, 3K + 6 + b, ...] (x = 4K + 2), with b = 0 when there is no third block.

py/rounds.py

Odd rounds depend on many blocks

From an odd first block the sweep crosses holes (cross) for as long as the parity keeps it on the last 1 of a block, so the round merges several blocks and its result depends on all their parities: e.g. [41, 20, 30, 14, 16] → [65, 75], [41, 20, 30, 15, 16] → [35, 99], [41, 20, 31, 14, 16] → [10, 97, 21].

plain simulation of single rounds

A class of round starts that is nearly closed

Take as round start E on the 0 left of a tape 0? 1^a1 (0 1^ai)* (single holes, a1 ≥ 1, the other blocks ≥ 2). For all 4,616 such tapes of at most 20 cells the round ends without halting on a tape of the same class. For 24 cells (21,303 tapes) two do not: 101111011011111101101111 and 101111011110111101101111 end with a block of length 1 inside (both give 0 1^3 0 1 0 1^28 0 1^6). So this simple class is not an invariant; one that is must say more about the blocks.

Growth shape: power/power

Left of the start, the visited part of the tape grows like a power of the step count other than 1/2 (fitted exponent 0.329). Right of the start it grows like a power of the step count other than 1/2 (fitted exponent 0.312).

tools/py/bbtools/triage.py

No small automaton proof

A finite-automata-reduction search (a DFA on one side, the least NFA on the other) finds no certificate with a DFA of up to 8 states on the left, or up to 7 on the right; DFAs built from windows of up to 4 cells with parity and pattern flags fail too.

py/far.c

Why the width grows like t1/3

A round from a first block x sends about x/4 gliders through the second block a, each taking about 6a steps there and back, so a round costs about 1.5·x·a steps, of the order of the width squared; it adds 3 to 18 ones (3 for x = 4K, 4 for x = 4K + 2, more for odd x). Width w after t steps then satisfies w2 dw ~ dt, so w ~ t1/3.

py/rounds.py

The only way to halt

The halting transition is B reading 1. B is entered only from A on a 0, and A sits on a 0 with a 1 to its right only after C, F, A in a row, so a halt is exactly a rightward sweep meeting B>0 1 0 0 1: an odd stretch of ones followed by two 0s. Inside a round two 0s appear only as gliders and as marks left behind the sweep, never ahead of it, in all the rounds simulated. A closed-language (CTL) search with windows of 8 cells does not see this: it finds abstract configurations that halt.

Does it halt from blank tape?

Not known. The even rounds are proved, and so is the sweep's step through a hole that starts an odd round; the rest of an odd round (gliders crossing the marks, over any number of merged blocks) is not. Single holes with blocks of at least 2 is not an invariant (two 24-cell counterexamples), so a proof needs a finer one.
