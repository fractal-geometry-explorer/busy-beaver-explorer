What is known about 1RB0LF_1RC1RA_0RD0RB_1LE---_0LA1LE_1RD1LA

1RB0LF_1RC1RA_0RD0RB_1LE---_0LA1LE_1RD1LA

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 9 November 2026.

In short

Reported to halt: an external Rocq proof exists (busycoq pull request 60, by Yeyito, 7 November 2026), which we have not compiled. It proves a map on tapes A(a, b) from the raw machine and checks, with 313 compiled jobs (275 core-hours by its README), that the orbit from blank tape reaches the halting case at a = 28·285 − 6, about 1055 steps. We cross-checked it against our own Lean map: its state (a, b) is our round P((a−6)/2, b), its first 2,000,000 map steps all appear in order in our orbit, and both maps halt from the same final round. The middle of the orbit (about 1025 returns) rests on that proof alone. Until it is compiled here or merged upstream, this page keeps the machine as open.

Our own result: reduced in Lean to a question about an explicit map. It is a Lean theorem (kernel-checked, no native_decide) that the machine halts from blank tape if and only if the orbit of the reset configuration S(13) = 0^inf 1^13 1110 B> 0^inf under an explicit map F on four kinds of tape (the reset S(x), the doubling round P(k, m), and two leftover shapes Q(u, n), T(u, v)) reaches a doubling round P(k, 0) that finds no 1s at all (halts_iff_H, lean/Map.lean). F is written as a Lean function and every one of its cases is a proved rule of the machine. The orbit does not halt in its first 107 nodes (Lean, compiled evaluation; 105 by the kernel) and, iterated in C, in its first 108 returns to S (X up to 1.5·1010); our own runs stop there.

Community label

In the community's BB(6) tracker the machine's class is Cubic Mess. Its 3 November 2026 edition lists the machine as a cryptid: its halting is thought to come down to a Collatz-like question that no known method decides. These are labels read off the run by others, not results.

The doubling phase of a return, for every X

Write S(X) for 0^inf 1^X 1110 B> 0^inf and P(k, m) for 0^inf F> 0 0 (10)^k 1^m R. Lean proves: the blank tape is in S(13) after 110 steps; S(X) reaches P(3, X) for X ≥ 6; for k ≥ 2 and m ≥ 2k + 3, P(k, m) reaches P(2k + 3, m − 2k − 3) (one doubling round: one pair becomes the wall block, k − 1 zig-zag rounds by induction, then the 1s are turned back into 2k + 3 pairs); and in closed form, if 12·2t ≤ X + 3t + 12 then S(X) reaches P(6·2t − 3, X + 3t + 12 − 12·2t). So the doubling phase ends, and the overflow starts, at the first t with 24·2t > X + 3t + 15: these are the doubling thresholds where f changes regime.

The overflow, for every size

When the ones run out in the middle of a doubling round the tape is O(p, i, r) = 0^inf 1^6 0 (10)^p (1111)^i F> 1 0 1^r 0 1 0^inf (p pairs left, i zigs done, r < 2 ones left). Proved for all p, i: O(2q+1, i, 0) → P(2q+6, 4i+2); O(2q+1, i, 1) → T(q, 2i+3); O(2q+2, i, 0) → Q(q+1, 4i+7); O(2q+2, i, 1) → S(4q+4i+17); O(0, i, 0) → S(4i+7); O(0, i, 1) → S(4i+13). With Q(u, n) = 0^inf F> 0 0 (10)^3 (1110)^u 1^n 0 1 0^inf and T(u, v) = 0^inf F> 0 0 (10)^3 (1110)^u 1111 0 (10)^v 0 1 0^inf: Q(u+1, c+9) → P(2u+11, c), Q(u+1, 1) → S(4u+17), Q(u+1, 3) → Q(1, 4u+11), Q(u+1, 5) → P(6, 4u+10), Q(u+1, 7) → S(4u+19), T(u, v+1) → Q(1, 4u+2v+11); and the rounds that run out at once: P(k, 0) halts, P(k, 1) → S(2k+7) or Q(k/2, 3), P(k, 2) → T((k−1)/2, 1) or S(2k+9) (k odd or even). Each is one symbolic run (generated by py/overflow.py), restated on the named shapes in lean/Map.lean.

Halts iff the orbit of S(13) reaches a round with no ones

The nodes s x = S(x+6), p a m = P(a+3, m), q u c = Q(u+1, 2c+1), t u v = T(u, v+1) and the map F on them are Lean definitions; F_sem proves that every value of F is where the machine goes (in at least one step), and that F = none only where the machine halts. Hence: the machine halts from blank tape iff the orbit of s 7 (= S(13), reached at step 110) under F reaches none (halts_iff), iff it reaches a node p a 0, a doubling round 0^inf F> 0 0 (10)^(a+3) 0 1 0^inf (halts_iff_H). Only the standard axioms (propext, Quot.sound, Classical.choice).

heuristic Evidence only

Growth shape: power/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.359). Right of the start it grows like a power of the step count other than 1/2 (fitted exponent 0.313).

tools/py/bbtools/triage.py

Why the map looks Collatz-like

Inside one return the zig-zag doubles a block of pairs, k → 2k + 3 from 3 (3, 9, 21, 45, 93, ...), until it runs out of 1s; the parity of the pairs left and of the 1s left then picks one of six overflow cases, some of which start a new, smaller doubling chain from a block of units 1110. So the next X depends on X modulo small powers of 2 and on where X lies between doubling thresholds: constant increments for long stretches (+40, +96, +100, ...), irregular jumps at thresholds. Each threshold is a fresh chance to land on a halting round.
