What is known about 1RB0RB_1LB0LC_1RD1LC_1RE0RA_0RF1RA_---1LB

1RB0RB_1LB0LC_1RD1LC_1RE0RA_0RF1RA_---1LB

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open, and reduced in Lean to a Collatz-like map. Sampled with the head at the left end, the tape is a run of ones with one hole: p ones, the hole, r ones. Lean proves, for all p, r ≥ 1, that one sample leads to the next by an explicit map f (division of p by 3 when p ≡ 2 mod 3, a jump of the hole to the right end otherwise) in an explicit number of steps, or halts (p = 2 with r divisible by 3), and that the machine halts from blank tape if and only if the orbit of (3, 1) under f reaches that halting case. Following the proved map, the kernel shows no halt in the first 103747 steps. Whether the orbit ever hits the halting case is a Collatz-like question; heuristically the chance is about 10-4.

The halting family

With the head in C on the leftmost cell of 1 1 0 1^(3m+3) and blank tape around, the machine reaches F on a 0 with blank tape to its right in 5m + 21 steps and halts there, for every m.

to_halt, halts_family, lean/Rules.lean

The hole map, for all p and r

Write S(p, r) for the head in state C on the leftmost cell of 1^p 0 1^r, blank tape around. For all p, r ≥ 1: S(1, r) → S(r+4, 1); S(2, 3m+1) → S(3m+6, 1); S(2, 3m+2) → S(3m+5, 2); S(2, 3m+3) halts; S(3k+3, r) → S(4k+r+6, 1); S(3k+4, r) → S(4k+r+8, 1); S(3k+5, r) → S(k+1, 2k+r+5), each in an exact number of steps cost p r (quadratic in k: a block drifts right over the ones, then is consumed 111 by 111). Built from 15 symbolic rules found and proved by bbtools.symtm, chained by induction over the drift, the consumption and the division rounds.

sample_step, lean/Map.lean; rules in lean/Steps.lean (from py/steps.py)

The reduction

From blank tape the machine reaches S(3, 1) in 11 steps, and it halts if and only if the orbit of (3, 1) under the map reaches the halting case p = 2, 3 | r.

The hole map, checked

From each sample (C on the leftmost cell, reading 1; N cells, a single 0 at position p): p ≡ 0, p ≥ 3: N' = N + p/3 + 3, p' = N' − 2; p ≡ 1: N' = N + (p−1)/3 + 4, p' = N' − 2; p ≡ 2, p ≥ 5: N' = N + 1, p' = (p−2)/3; p = 2: halt if 3 | N, else N' = N + 4, p' = N' − 2 (N ≡ 1) or N' = N + 3, p' = N' − 3 (N ≡ 2). The machine follows this from every sample with N < 120 and 1 ≤ p ≤ N−2 (exhaustive), along the run for the first 3·107 steps (27 samples), and at all 45 samples of the run to 1.9·1010 steps. (Now proved for all N: see above; this check also confirms the step counts.)

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.068). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.524).

tools/py/bbtools/triage.py

Why it probably never halts

A division chain p → (p−2)/3 → … ends at 2 only if it starts at p = 3k − 1, and chains start at N − 2 or N − 3 with N growing by a factor about 4/3 per step. So the run would have to land exactly on one of the sparse numbers 3k + 1 (and then pass a test mod 3). Treating N as random at its scale, the expected number of such hits beyond N ≈ 105 is about Σk≥11 3/(3k ln(4/3)) ≈ 10-4.

Does it halt?

Not proved either way. By the kernel claims above, the question is exactly whether the orbit of (3, 1) under the hole map ever reaches p = 2 with r divisible by 3 (equivalently, a sample of length 3k + 1 with 3 | k followed by its division chain), a Collatz-like question with no visible invariant that rules it out.
