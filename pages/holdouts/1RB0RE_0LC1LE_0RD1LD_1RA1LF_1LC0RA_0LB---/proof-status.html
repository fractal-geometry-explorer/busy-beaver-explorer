1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open, and Collatz-like. The run is a sequence of phases Z → (3Z + c)/2 on a run of zeros (the sweeps are proved in Lean); Z mod 4 drives a counter in a short word D at the fixed left end. 1,500 phases from blank tape (far past 10350 steps) do not halt, With the residues chosen freely, words D on which a phase halts are reachable; the real orbit has not produced one.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Bell-like. These are labels read off the run by others, not results.

The phase map

From PS(D, Z) = D 0^Z 1 0 0 E> the next phase start is PS(D', Z') with Z' = (3Z + c)/2, where D' and c depend only on D and Z mod 4: found by running the machine at three Z of the same residue and extrapolating, checked against the plain machine on the 16 phase starts from blank tape (to step 8.7·107).

py/phases.py, c/nextps.c

The counter in D

For D(a, b) = 0 1 0^a 1 0 1 (001)^b: Z ≡ 1 leaves D alone, Z ≡ 3 makes it D(a−1, b+1), Z stays odd; at a = 0 a phase with Z ≡ 3 resets D to 0 1 0^(3b+5) 1, which continues as D(3b+4, 0) if Z ≡ 3 mod 8 and leaves the family otherwise. Checked for a, b < 16.

py/phases.py

No halt in 1,500 phases

Iterating the phase map from the first phase start (assuming the linear extrapolation, checked as above): resets of the counter at phases 5, 29, 92, 332 stay in the family (cycles of length 11, 35, 107, 323); at phase 1001 (Z has 178 digits) the word leaves it and a second-level counter starts. No halt up to phase 1,500.

Rounds between end events, by remainder class

Sample the run whenever the head is in state B reading 1 with only 0s to its right. Read leftwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m modulo 1 or 4 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (48 events) the class map predicts the next event in all 28 rounds it applies to. This is an extrapolation checked by computation, not a proof.

Halting words exist

With the residue Z mod 4 chosen freely at every phase, 23,305 words of at most 24 cells are reachable from the first phase start, and 7,145 of the (word, residue) pairs met halt, for example 0 1 0 0 1 1 1 0 1 with Z ≡ 3. So halting is not excluded by the words alone; it depends on the residues along the real orbit.

2,930 rounds of the class map without a halt

Iterated with exact integers from the event at step 29,339 of the run (A = 11, U = 0, m = 171, B = 101 0101): 2,930 rounds without meeting a halting class; m then has 865 bits (about 10520 steps of the machine). 1,410 distinct contexts occur, the longest of 1,428 cells.

Does it halt from blank tape?

Not known. It reduces to the orbit of the map Z → (3Z + c)/2 and the nested counters it drives in D: whether the residues along the orbit ever build a halting word.
