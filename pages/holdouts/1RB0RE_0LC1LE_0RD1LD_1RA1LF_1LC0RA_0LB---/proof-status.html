OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 23 November 2026.

In short

The question is open, and Collatz-like. The run is a sequence of phases Z → (3Z + c)/2 on a run of zeros; Z mod 4 drives a counter in a short word at the fixed left end. Five phase rules, proved in Lean for any tape left of the counter, cover all but 17 of the first 1,000,000 phases, and those 17 cycle ends are proved one by one. Lean's kernel runs the resulting map 100,000 phases from blank tape (no halt in 1017610 steps); native_decide runs it 1,000,000 phases (10176092 steps). Whether a halting word ever appears depends on the residues of Z at the cycle ends, and those are the 2-adic digits of the orbit: there is no finite law for them. With free residues halting is reachable (a concrete start with a 64,000-bit Z halts), and with fair coin flips the halting rate per cycle-level step is flat, so the heuristic says it halts, far beyond any computation.

The sweeps of a phase

With 4j + 4 zeros left of 1 0 0 0 (100)^n 0 A> at the right end, j sweeps eat 4j zeros and add 2j words 100 to the wall (one sweep: 18n + 64 steps, any tape to the left).

sweep, wall_left, lean/Rules.lean; sweeps, lean/Sweeps.lean

The counter in D

For D(a, b) = 0 1 0^a 1 0 1 (001)^b: Z ≡ 1 leaves D alone, Z ≡ 3 makes it D(a−1, b+1), Z stays odd; at a = 0 a phase with Z ≡ 3 resets D to 0 1 0^(3b+5) 1, which continues as D(3b+4, 0) if Z ≡ 3 mod 8 and leaves the family otherwise. Checked for a, b < 16. Now proved for all a, b (see the next claims); the check for a, b < 16 was the first evidence.

py/phases.py; lean/Phase.lean

Whole phases of the level-1 words

For D(a, b) = 0 1 0^a 1 0 1 (001)^b and R(a) = 0 1 0^a 1, for every a, b, j: Z = 4j + 9 keeps D(a, b) with Z' = 6j + 15; Z = 4j + 11 turns D(a+1, b) into D(a, b+1) with Z' = 6j + 15, and D(0, b) into R(3b + 5) with Z' = 6j + 18; Z = 4j + 10 turns R(a+1) into D(a, 0) with Z' = 6j + 15. Each phase is the generated start and end rules chained with the sweeps.

The phase map

From PS(D, Z) = D 0^Z 1 0 0 E> the next phase start is PS(D', Z') with Z' = (3Z + c)/2, where D' and c depend only on D and Z mod 4: found by running the machine at three Z of the same residue and extrapolating, checked against the plain machine on the 16 phase starts from blank tape (to step 8.7·107).

Rounds between end events, by remainder class

Sample the run whenever the head is in state B reading 1 with only 0s to its right. Read leftwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m modulo 1 or 4 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (48 events) the class map predicts the next event in all 28 rounds it applies to. This is an extrapolation checked by computation, not a proof.

No halt in the first 3.50×10139210 steps (region-memo accelerator)

The region-memo accelerator tools/py/bbtools/regaccel.py ran the mirrored table (so that the counter is at the left end), with blocks of 3 cells, from blank tape for 3600 seconds and reached step 3.50×10139210 without a halt. It keeps the tape run-length coded and, for each stretch of tape from the left end, a macro (the run until the head first leaves that stretch) computed by a symbolic run of the machine with the long runs as variables; a macro is used only when the linear inequalities its symbolic run assumed hold, otherwise the stretch is run again by the same recursion. So the run is exact, step count included. A start with a 64,000-bit Z that halts

Following a random halting walk of 35 steps and fixing the bits of Z0 one at a time with the exact engine, a Z0 of about 64,000 bits makes the exact run from the phase start PS(D(2,0), Z0) halt at phase 63,939. The words and phase rules do not exclude halting; only the bits of the blank-tape orbit can.

Halting words exist

With the residue Z mod 4 chosen freely at every phase, 23,305 words of at most 24 cells are reachable from the first phase start, and 7,145 of the (word, residue) pairs met halt, for example 0 1 0 0 1 1 1 0 1 with Z ≡ 3. So halting is not excluded by the words alone; it depends on the residues along the real orbit.

No finite law for the cycle ends

Each phase is Z' = (3Z + c)/2, so Zt mod 8 is fixed by Z0 mod 2t+3, and adding 2t+2 to Z0 flips Zt mod 8 by 4 without changing an earlier phase. Every sequence of residues at the phases is met by exactly one 2-adic Z0: the residues at the cycle ends are the digits of a 3/2-map orbit, as in Mahler's 3/2 problem, not a finite pattern.

py/cycles.py, README

A halting path in 17 cycle-level steps

With Z = 4j + 8 + r, j = 2m + bit and m symbolic (each phase then holds for every Z of that residue mod 8) and the counter run-downs jumped by the Lean rules, a breadth-first search from the first phase start halts after 17 cycle-level steps: the prefix of D walks down 2 1, 1 1 2, 0 1 2 2, 0 0 1, 0 0 0 1 and the next phase halts.

py/cycles.py explore 300

A flat halting rate

With fair coin flips for the free bits, 400 walks to depth 2,000 cycle-level steps: 213 halt, at a rate of about 3.7·10-4 per step that stays flat from the first 250 steps to the last (3.2 to 4.4). The prefix of D outside the counters stays at 1 to 10 gaps: the words recur, they do not grow. If the blank-tape bits behave like coin flips the machine halts with probability 1, but the real orbit makes only about two such steps per threefold cycle (19 in 20,000 phases), so the expected halt lies at a number of phases with hundreds of digits.

Does it halt from blank tape?

Not known. It reduces to the orbit of the map Z → (3Z + c)/2 and the nested counters it drives in D. There is no finite law for the residues at the cycle ends, halting paths exist when the residues are free, and a concrete large start halts; whether the blank-tape orbit's residues ever take such a path is a 3/2-map question like Mahler's.
