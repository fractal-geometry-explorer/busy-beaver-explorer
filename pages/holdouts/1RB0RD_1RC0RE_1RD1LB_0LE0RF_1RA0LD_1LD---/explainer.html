Does this machine ever halt?

1RB0RD_1RC0RE_1RD1LB_0LE0RF_1RA0LD_1LD---

Nobody knows. The tape is a list of numbers written in unary, each a block of 4k+3 ones; every round trip of the head rewrites the list. This page shows the encoding, the proved sweep rules, and what a halt would need.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 1. F is entered only from D1 (writes 0, moves R): D>1 1. So a halt is the moment this pattern appears, with the head on the cell after >.

The run at a glance

Space-time diagram and records

The diagram stacks the tape at many moments. Sampling at each new cell shows the shape of the run as the visited region grows; sampling evenly in time shows where the head spends its time. The records list every step at which the head reaches a cell no earlier step reached, with the side, the width so far and the whole tape: the first place to look for a repeating macro structure.

The structure

A list of unary numbers, rewritten every round trip

The head runs from end to end; a visit adds 1 to 4 cells at the left end and 3 to 8 at the right. Just after a rightward sweep the tape is a list of blocks of ones separated by single 0s, and almost every block has a length 4k+3: the tape is a list of numbers k1, k2, ... in unary. The leftward sweep rewrites each block: state D turns each pair 11 into 10, and the left end of a block 0111 into 00010, so a block of 4k+3 ones becomes 2k+1 single 1s, 000 1 0 1 0 ... 1 0, and the blocks are separated by 000. The rightward sweep zigzags: at every block it backs up a few cells, and over the inside of a block it turns 001, 010, 100 into 110, 101, 011 (states E, A, B), rebuilding blocks of 4k+3 ones, but not the same ones.

How the list changes from one round trip to the next has no known formula. Seen at the right end, the first numbers repeat a short cycle (1 0 0 3 1 0 0 ... comes back every few round trips) while the rest looks random: the run is a one-dimensional cellular automaton on the list, seen once per round trip.

Halting

What a halt would need

F1 is the only halting transition, and F is entered only from D on a 1 (writing 0, moving right). So the machine halts exactly when D reads a 1 followed by another 1. In the first 109 steps F is entered 112,249,403 times; the cell after was 0 every time. No halt in 1010 steps.

Twin of 1RB1RA_1RC0RE_1RD1LB_0LE0RF_1RA0LD_1LD--- (1RB1RA_1RC0RE_1RD1LB_0LE0RF_1RA0LD_1LD---), which differs only in A1 (1RA there, 0RD here). In this run A reads a 1 only when a 0 follows (all 409,996 times in the first 2·10^7 steps), and then 0RD, 0LE, 1RA put the 1 back and leave A on the 0 after 3 steps, where the twin gets in 1 (rule `a_one`): the two machines write the same tapes, this one 2 steps slower each time (the first 2,000 tapes at visits to the right end are identical).

Open
Does it halt from blank tape?

Not known. The list of numbers is rewritten each round trip by a sequential process with a finite carry (the zigzag of the rightward sweep), but how the list evolves is not understood; a proof would need an invariant of the list (a closed language of lists) that keeps D away from two adjacent 1s.
