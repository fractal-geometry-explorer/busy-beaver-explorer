What is known about 1RB1RF_1LC---_1LE1RD_1RA0RC_0LF0LA_0LD0RB

1RB1RF_1LC---_1LE1RD_1RA0RC_0LF0LA_0LD0RB

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 12 November 2026.

In short

The question is open, and Collatz-like. Each time the head turns at the left end the tape is 1n (01)k 111 (or all ones), and the next such state is given by an explicit map on (state, n, k): while n is odd the ones are doubled at the cost of (n+5)/2 pairs 01, or the pairs are doubled when that cannot be paid; when n is even the pairs are drained into ones. The machine halts if and only if a doubling in state D leaves exactly one pair, that is the orbit reaches D(n, k) with n odd and 2k = n+7 (as far as the computed map is right: it is checked against the machine on thousands of states, not proved). From blank tape the map has been iterated through 8,598 epochs, more than 103,100 steps, without a halt.

The drain

How a halt happens

A sweep in state D over an even block of 1s that ends in 0 111 reaches B on a 1 (no transition) in 2n+3 steps, whatever lies to the right; over an odd block ending in 0 1111 it passes to the right end.

The left-end map

With A(n, k), D(n, k) the head in state A two cells (D: three cells) left of 1n (01)k 111 (k = 0: 1n): for n even, s(n, k) → other(n+4, k−1), and other(n+7, 0) when k = 1, other(n+3, 0) when k = 0; A(n, 0) → D(1, (n+1)/2) and D(n, 0) → D(3, (n+1)/2) for n odd; for n odd and k ≥ 2: D(n, k) → D(2n+7, k−(n+5)/2) and A(n, k) → A(2n+6, k−(n+5)/2) when 2k > n+5, all ones of length 2n+10 resp. 2n+9 when 2k = n+5, other(n−2k+6, 2k) when 2k < n+5; n odd and k = 1 halts. Equal to the plain machine on all 7,000 states with n < 70, k < 50, 300 random larger states, the first 170 left-end states from blank tape and every epoch N ≤ 150; its epoch values agree with the 126 epochs of the accelerated run to 10100 steps. Checked, not proved.

The halting condition

By the map, the machine halts iff the orbit from D(3, 0) reaches D(n, k) with n odd and 2k = n+7: the doubling leaves one pair, D(2n+7, 1), and the machine stops within the next sweeps (the Lean lemma halt_even shows the kind of sweep that stops it). A doubling in A leaves n even and a failed doubling leaves k even, so there is no other way.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.433). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.09).

tools/py/bbtools/triage.py

A halt needs an exact remainder

Each doubling stage in D ends with a remainder between 0 and about n/2, and a halt needs it to be exactly 1: about 2/n per stage if remainders behave like random numbers, with n growing geometrically. Past the epochs already followed the chance is around 2−10,000.

Does it halt from blank tape?

Not known. It is the question whether the orbit of the left-end map ever reaches D(n, (n+7)/2) with n odd: a Collatz-like question. The map and this reduction are computed, not yet proved in Lean (the doubling stage, a nested zig-zag, is the missing part).
