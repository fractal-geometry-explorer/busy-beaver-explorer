A 6-state Busy Beaver machine · Status as of 9 November 2026.

Does this machine ever halt?

1RB---_1LC0LD_0RF0LD_0LE0RA_0LC1RA_1RC1RD

Probably never. The machine multiplies a number n by 3/2 or by 9/8 at each pass. A short word at the right end of the tape carries a second, much smaller counter, which mostly moves up or down by one and occasionally grows by half. Halting needs the small counter to catch up with the big one, and the big one is far ahead.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in A reading 1. A is entered only from D1 (writes 0, moves R): D>1 1; E1 (writes 1, moves R): E>1 1. So a halt is the moment one of these patterns appears, with the head on the cell after >.

What it does

A big number and a small counter

Every so often the head is in state E at the left end, on six 0s, followed by n copies of 10 and a short tail word. The tail is 1, Xk = 000 (10)^k 1, Yk = 11 (01)^k or Zk = 000 (10)^k 0001.

With the tail 1, one pass multiplies n by 3/2: n even gives (3n+6)/2 and the tail stays 1, n odd gives (3n+1)/2 and the tail X0. With an X or Y tail, a pass multiplies n by 9/8 and changes the small counter k according to n mod 8:

n mod 801234567
from XkYk−1YkXk+1XkXk+1Yk−2Yk−1×3/2
from YkYk−2Yk−1×3/2Yk−1YkXk+1XkXk+1

Here ×3/2 means that k becomes 3k/2+3 (tail X) when k is even, and (3k+1)/2 with the tail Z when it is odd. When k would go below 0, the tail goes back to 1. A Zk tail does one 3/2 pass that subtracts about 4.5k, then returns to 1 or X0. So the run alternates between phases of 3/2 passes and phases of 9/8 passes, during which a small counter wanders and sometimes grows. From blank tape, n = 0, 3, 5, 8, 12, 21, …, and n = 48,351 at step 2.1·1010.

Can it stop?

Only if the small counter catches up

All of these rules hold for every n, except the Zk rule, which needs n ≥ 12k+12. Below that bound the tail turns into longer words and the machine can halt (for example from Z15 with n = 189). So the machine can only halt if, at some Z-event, the counter k is at least about n/12.

That is very unlikely. k starts again from 0 in every 9/8 phase, and it grows by half only at 1 pass in 8, with an even k, while n grows at every pass. In the run the tightest moment was pass 28 (n = 3,989, k = 5), with a margin of 55. After pass 70 the margin is above a million, and after 105 passes n has 8,063 digits while k has never passed 1,046.

What is checked

The map is proved; the question is about one orbit

  • Every pass is proved. Lean's kernel checks that from every E-event (except Zk with n < 12k+12) the machine reaches the E-event the map predicts, in exactly the predicted number of steps. The proof is split into 83 cases (by tail and by n mod 8 or mod 2). Each case is a run of the symbolic simulator through a few sweeps, with the repeated part (three rounds of the 9/8 phase, or one of the 3/2 phase) done once and iterated by induction.
  • The orbit from blank tape is checked by evaluating the map in Lean: 3,000 passes in the kernel (more than 10450 steps), 105 passes compiled (1016000 steps), never entering the unproved region.
  • What is missing for a non-halting proof is an argument that k never catches up with n along the whole orbit. The residues of n that drive k are themselves a Collatz-like sequence, so this is as hard as the usual Collatz-type questions.
First look

The shape of the run

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.128). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.41).

After 109 steps the tape spans 13,857 cells (61 left of the start, 9,722 right), with a density of 1s of 0.5.

The E-pass map, for all n

With an E-event E> 0^6 (10)^n T (Ev n T): next T n gives the next E-event and the exact number of steps to it, for every tail T (1, Xk, Yk, Zk) and every n, except Zk with k = 0 or n < 12k+12. next_sound proves that the machine goes there in exactly that many steps. It rests on 83 case theorems (tail 1 by parity of n; X and Y by n mod 8, with a generic k and a few small k; Z by the parities of k and n), each a chain of symbolic-simulator segments and loops (three rounds of the 9/8 phase, or one round of the 3/2 phase) proved by induction. Axioms: propext and Quot.sound only.

The E-pass map against direct simulation

With an E-event E> 0^6 (10)^n T (n maximal): the tail T is always 1, Xk = 000 (10)^k 1, Yk = 11 (01)^k or Zk = 000 (10)^k 0001. The next E-event has n' = (3n+c)/2 for tails 1 and Zk, and n' = (9n+c)/8 for Xk and Yk. The new tail and c depend on the tail and on n mod 2 or n mod 8, and the index k changes by −2 to +1 or becomes 3k/2+3 or (3k+1)/2 (table in py/emap.py). The X and Y rules hold for all n ≥ 0, and Zk needs n ≥ 12k+12. Checked against direct simulation on a grid (every tail with k < 25 at 120 values of n each: 9,120 starts, no mismatch) and against the 200 rules measured independently by direct simulation. Heuristic
README
Probviously non-halting: the index would have to catch up with n

A halt can only start from Zk with n < 12k+12. In a phase of X/Y tails, k moves by −2 to +1 and is multiplied by 3/2 at 1 pass in 8, and it starts again from 0 at every phase. Along the orbit the fraction of Z-events with k ≥ K falls like K−1.1 to K−1.7 (0.6% for K = 100), while n grows by a factor of about 9/8 per pass. So the chance that some phase reaches k ≈ n/12 is about (n/12)−1.2 per phase: about 10−5 at the end of direct simulation, and far smaller after that, where n has thousands of digits.

Open
Does it halt from blank tape?

Not known, but very probably not. Unlike Antihydra-type machines, the bad region is not reached by a fair random walk: k would have to grow as fast as n. No simple invariant k ≤ f(n) is in sight: within a 9/8 phase the residues n mod 8 that drive k are themselves a (9n+c)/8 orbit, and since (9n+c)/8 is a bijection on residues, any finite sequence of residues occurs for some n. So a bound on k is a Collatz-type statement about this orbit. Of the 3·105 starts (1, n) with n < 3·105, only n = 8, 11, 13, 15 reach the uncovered region within 200 passes.
