OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

The question is open. The run is a Collatz-like map g → 3g/2 + c on a counter, whose residues mod 4 drive a slowly growing stack R; the inner sweep is proved in Lean, the epoch map is checked against simulation, and 300 epochs of it (about 10110 steps) show no halt. Like Antihydra, a proof would need control of the residues of a 3/2 map.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Bell-like. These are labels read off the run by others, not results.

The epoch map

From E(g,R) = 0^inf A> 0 1 0^g R the next epoch is E(3g/2 + c, R'), where c (one of -9, -6, -3, +6) and R' depend only on g mod 4 and R. Checked for four values of g in each class for every R tried, and against direct simulation epoch by epoch up to 3·1011 steps.

py/epochs.py direct, py/epochs.py uniform

300 epochs without a halt

Iterating the epoch map with g an exact integer from g = 4206: 300 epochs, g up to about 1055 (about 10110 steps), no halt; the right part R grows from 13 to about 190 runs. This rests on the epoch map being independent of g within a class, which is checked, not proved.

py/epochs.py abstract 300

Rounds between end events, by remainder class

Sample the run whenever the head is in state A reading 1 with only 0s to its left. Read rightwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m modulo 1 or 4 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (48 events) the class map predicts the next event in all 22 rounds it applies to. This is an extrapolation checked by computation, not a proof.

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.52). Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).

Why a halt looks unlikely

Each epoch rewrites only the first few runs of R, like the top of a stack, and R grows by about 0.6 runs per epoch, with the real residues and with random ones alike. Every halting R found in a random search contains a lone 1, which the run never makes near the front; a halt would need the front to dig down through a stack that keeps getting deeper.

No halting class among 5,000 contexts

Breadth first from the starting context, with every remainder at every context (whether or not the numbers can really produce that sequence of remainders, and only for m large compared with the contexts): 5,000 contexts expanded, 8,184 found, to depth 14. None of them halts; the search is not complete (the set of contexts keeps growing), and it says nothing about a halt that needs a context as long as the block itself.

Does it halt from blank tape?
