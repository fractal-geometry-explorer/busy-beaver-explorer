1RB0LD_1LC1RE_1LF0RA_1LA1LD_1RC0RE_---1LC

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

The tape is made of the words 10 and 1110 (runs of one or three 1s, each followed by a single 0), with a few longer runs of 1s; at the left end it begins with a run of 11010 (7 copies around step 1.9·109) followed by one long run of 1s (47 of them). Both ends grow logarithmically. No exact rule has been found.

Status as of 8 November 2026.

In short

The question is open. 49 event rules, proved in Lean for every size, cover 65,854,171 of the 65,868,043 visits of the head to cell −134 in state E in the first 3·109 steps (99.98%); none of them halts (each ends at the next event). Every halt passes through 0 C> 0 (from the table; from there it halts, Lean halt_ctx), which never occurs in 3·109 steps; C read a 0 with a 1 on its left only 25 times, 19 before the first event and 6 in the 13,872 uncovered events.

The halt from the halting context

From 0 C> 0 the machine reaches its halting transition (proved step by step, then step_none_iff). The halting transition is F reading a 0. F is entered only from C reading a 0 (C writes 1 and moves left), so the machine halts exactly when C reads a 0 with a 0 on its left. Lean (halt_ctx) proves only that from this context the machine halts; that every halt passes through it is read off the table, not proved in Lean.

Does it halt from blank tape?

Not known. Halting needs C on a 0 with a 0 on its left; the words 10 and 1110 never put two 0s side by side, so only the irregular places (the ends, the long runs) could; without the rule of the counter this is not proved.
