1RB1RF_1RC0RB_0RD1LF_1LE1RE_1LA---_1RA0LC

Nobody knows whether this machine halts from blank tape. Its run is built from doubling chains, like the Collatz-like sibling 1RB---_1RC1LE_0RD0RF_0RE0LA_1LF0LB_1LA1LD: a block of 1s at the right end doubles again and again, paid for by a run of 10 pairs on its left, until the pairs run out. One chain step is a Lean theorem for all sizes; the bookkeeping at the end of a chain, which involves a whole stack of pair runs, is only observed.

Status as of 8 November 2026.

In short

The question is open. One step of a doubling chain is proved in Lean for every size and every tape further left, and the chain rule matches all 776 chain steps of the first 109 steps. What a chain does when its pairs run out depends on the stack of pair runs further left and is not yet a map.

One doubling step, for all parameters

For every tape L and all K, j: L (10)^(K+2j+5) 1^(4j+2) A>0 reaches L (10)^K 1^(8j+16) A>0, and L (10)^(K+2j+5) 1^(4j+4) A>0 reaches L (10)^K 1^(8j+22) A>0; the start of a chain, L (10)^(k+1) 0 1^5 A>0, reaches L (10)^k 1^18 A>0. Each step is a start piece, j or j+1 inner cycles (each moves two pairs from the left run into the 1s; chained by an induction written by hand) and an end piece, the pieces proved by bbtools.symtm.

chain_even, chain_odd, chain_start, cycN, lean/Chain.lean; pieces in lean/Rules.lean

A chain end at a 0 marker

When the pairs run out at a 0 marker, the marker is absorbed (absorb0), and a second cycle (eat) follows: L (10)^(x+2) C>(10)^(k+1) 110 (1010)^(n+1) R reaches L (10)^x C>(10)^(k+5) 110 (1010)^n R. end0 chains them for t turns, for all parameters and any tapes L, R. The inner cycle is also proved with any tape on the right (cycR). What happens when x or the blocks run out is not proved.

The run follows the chain rule

Sampling each time the head is in A at the right end on a 0, the first 109 steps contain 162 chain starts and 776 chain steps, all as the rule says (no mismatch); the other 406 transitions are chain ends.

How far back the chain ends read

Of the 1,506 sample transitions in the first 109 steps, 229 stay in the final ones, 1,015 read into the last pair run, 115 into the run before it, 1 into the third, and 146 reach the left end of the tape. The run passes 51 times through the start of absorb0 and 73 times through an E frame. So the samples are not a finite set of frames, and the whole-tape frame-map method does not apply as it is.

Growth shape: power/power

Left of the start, the visited part of the tape grows like a power of the step count other than 1/2 (fitted exponent 0.284). Right of the start it grows like a power of the step count other than 1/2 (fitted exponent 0.348).

Chain ends work on a stack of pair runs

Left of the last pair run the tape is a list of pair runs separated by markers 1 0 0 or 1 1 0, for example (10)^209 1 (10)^344 0 (10)^32 0 (10)^112 0 1^5 at step 4,999,243. When a chain's pairs run out, the block 1^m is turned back into pairs and runs are merged, split or doubled; the examples show several different cases.

Does it halt from blank tape?

Not known. The chain step is proved; the missing piece is a map for the chain ends (a stack machine on the pair runs), and then the halting question for that map, which is probably Collatz-like.
