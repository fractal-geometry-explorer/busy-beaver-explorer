1RB0LC_0LC1RF_1LE1RD_0RC1RC_0LA1LA_---1RA

Open: a cryptidIts halting is thought to come down to a Collatz-like question that no known method decides (the community's label, not a result).

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 9 November 2026.

In short

Open, and probably never halting. From step 118 the run is the orbit of an explicit map on two numbers, U(a, b) and V(a, b). The map is proved in Lean's kernel for every even a: from every event with a even, a ≥ 2 and b ≥ 1 the machine reaches the event the map gives, in exactly the steps it gives, except at the halting events (a divisible by 4, b = 1). The run from blank tape only ever has even a. Lean reduces non-halting to a statement about the map alone (not_halts_of_orbit) and checks the orbit: 3,000 passes in the kernel (no halt in 10500 steps), 105 compiled (1010000 steps). Reaching b = 1 needs b to land within a few units of a, so the chance of a halt is about 2/a, and a grows exponentially.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Quadratic Mess. Its 3 November 2026 edition lists the machine as a cryptid: its halting is thought to come down to a Collatz-like question that no known method decides. These are labels read off the run by others, not results.

The pass map for every even a

Events: Ev .U a b = A> 011011 1^a 0 1^b and Ev .V a b = A> 1110 1^a 0 1^b. next F a b gives the next event and the exact number of steps to it; next_sound proves that the machine goes there. next_isSome: it is defined at every event with a even, a ≥ 2 and b ≥ 1 except U/V(a, 1) with a = 0 mod 4. The cases: a = 2 mod 4 with b odd (to o((3a+10)/2, b)); a = 0 mod 4 with b = 3, 5 or b ≥ 7 odd; a, b even with b ≥ a+4, b ≤ a−2, b = a or b = a+2. Each is a family with a generic part and a few small values, 32 case theorems in all, built from symbolic-simulator segments and four loops proved by induction: a round of the b-odd phase (four 1s of a become six) for each residue of a mod 4, and a round of the Euclid phase (both blocks lose 11) for each of the two orders. Axioms: propext and Quot.sound only.

next_sound, next_isSome, lean/Map.lean; lean/Cases.lean, generated by py/gen_map.py and py/gen_mapdef.py

Non-halting reduces to the map; 3,000 passes checked

init_U: blank tape reaches U(4, 3) after 118 steps. not_halts_of_orbit: if the orbit of next from U(4, 3) never gets stuck, the machine never halts. Each pass takes at least one step (next_pos), so the orbit's step count grows without bound. The kernel evaluates the first 3,000 passes: never stuck, so no halt in the first 10500 steps (no_halt_3k). Pass 34 is U(35,354, 10,986) at step 1,916,511,832, as direct simulation finds (orbit_34).

The pass map against direct simulation, including odd a

Sample the run when the head is in A at the left end. From step 118 the tape is U(a, b) = A> 011011 1^a 0 1^b or V(a, b) = A> 1110 1^a 0 1^b. The next such configuration is given by an explicit map with cases on a mod 4, the parity of b, and b compared with a (written out in py/emap.py): for example U(a, b) with a = 0 mod 4 and odd b ≥ 7 goes to U((3a+16)/2, b−5), and with a and b even and b ≤ a−2 to V(3b+4, a−b−1). The map was checked against direct simulation for every start with a < 60 and b < 70 (7,980 starts the map covers), 300 random starts with 15 ≤ a < 2,000, and 84 starts with small odd a and large b. The cases with odd a, which the run never reaches, are checked this way only; the even-a cases are now proved (above).

py/emap.py grid 60 70, py/emap.py random 300 1

The halting condition

The machine halts exactly when it reaches U(a, 1) or V(a, 1) with a = 0 mod 4: the head then reads a 0 in state F. Every other U/V configuration leads to another one; for even a this half is now proved in Lean (next_isSome). That the halting events do halt was checked by simulation on the grid above.

py/emap.py grid

The map against the run from blank tape

The 38 U/V-events of the direct run from blank tape up to 8.7·109 steps, from U(4, 3) at step 118 to U(74,180, 24,362) at step 8,744,109,161, each follow from the one before by the map.

py/emap.py blank 1.2e10

No halt in the first 106 passes

Iterating the map from U(4, 3) with exact big integers gives no halt in 106 passes. Both numbers then have about 96,600 digits. 14% of the passes make a smaller (a subtraction-and-swap step), and b came down to 2 a few times, but never to 1 with a = 0 mod 4. (The first 105 of these passes are also checked in Lean, above.)

py/emap.py far 1000000

heuristic Evidence only

Probviously non-halting: the chance of a halt is about 2/a

Reaching b = 1 needs a subtraction step that leaves exactly 1, so b has to land on one of a few values next to a (b = a−2, a+4, a−7, a−13), and then a has to be divisible by 4. Iterating the map from 20,000 random starts at each scale (100,000 at S = 10⁴) S (a in [S, 2S), b in [0, 2S)) gives halting frequencies 2.0·10−2, 2.5·10−3 and 2.1·10−4 for S = 102, 103 and 104, so the frequency is about 2/S. Since a grows exponentially, this sum is dominated by its first terms. From the last simulated event (a = 74,180) the estimate is about 3·10−5, and after the 106 passes iterated it is about 10−96,600.

py/emap.py mc 1000 20000

Does it halt from blank tape?

Not known, but probably not. A proof would need to show that the subtraction steps never leave exactly b = 1 with a = 0 mod 4 along this orbit: a question about the long-run residues of a 3/2-Collatz-like orbit, which is out of reach.
