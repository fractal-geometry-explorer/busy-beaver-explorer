1RB1RA_1LC0RF_1LD1LC_1LE0LB_0LF---_1RA1RB

OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 22 November 2026.

In short

The question is open, and it is now the Pascal machine's question. This table is the table of 1RB0RE_0RC---_1LD1LE_1LE1LD_1RF0LC_1RA1RF in a mirror, started in state D: every bounce writes the next row of Pascal's triangle mod 2, an odd frozen block halts, and the machine never halts if that machine's list program never fails from EO [b, a, b, a, a, a] none 0 (all Lean, kernel). The list program ran 106 steps from there without failing.

Shift rules

For every length n of the run and any tape around it: L A> 1^n R reaches L 1^n A> R; L 1^n C> 1 R reaches L C> 1 1^n R. These are the moves the head makes across the long uniform stretches of the tape.

lean/Shifts.lean (written by bbtools.symtm.prove)

The four block rules

For all block sizes and every tape around them: C passes a single 1 (x 1 0 1 0 1^c <C becomes x <C 1 1 0 1^(c+2)); C bounces off a block of two or more (1 1 0 1^c <C becomes 0 1 1 A> 1^(c+1)); A shreds an odd block into single 1s (A> 1^a 0 1^(2k+1) 0 becomes 1^(a+1) 0 (1 0)^k 1 A>); A turns round at an even block.

pass, bounce, shred, turn, lean/Blocks.lean

The halting pattern

C, going left over a block of 1s onto a 0 that has 1 0 on its left, brings the machine to E reading a 1, the halting transition. By the transition table this is the only way to halt: E is entered only from D reading 0, and D only from C reading 0.

halt_pattern, lean/Blocks.lean

The Pascal machine in a mirror

This table is the table of 1RB0RE_0RC---_1LD1LE_1LE1LD_1RF0LC_1RA1RF read in a mirror, with that machine's states A to F renamed D, E, F, A, B, C. The blank tape is its own mirror image, so the run from blank tape is, cell for cell in the mirror, the run of the Pascal table started in state D, and this machine halts if and only if that run halts.

is_mirror, halts_iff, lean/Mirror.lean (written by py/port_mirror.py of the folder of 1RB1RA_1LC0RF_1LD1LC_1LE0LB_0LF---_1RA1RB)

One bounce is one row of Pascal's triangle mod 2

Every theorem of the Pascal machine's folder holds here with left and right exchanged; its Lean files are compiled here unchanged (lean/P75625/). At a left turn in B, with the zone right of the head a word in the 4-cell letters 0111 and 1111 and the frozen tape 1 1 1 ... left of it, one bounce turns the zone into the next row of Pascal's triangle mod 2 (closed form by Lucas' theorem), and takes two cells from the frozen block. A frozen block of odd length followed by 0 1 halts, whatever the zone, clean or walled (the halt: C reading 0 with 1 0 to its left).

bounce, bounces, halts_of_odd, halts_of_odd_wall, lean/Mirror.lean; closed_form, lean/P75625/Lucas.lean

The holdout is the Pascal machine's list program, from another start

The first left turn in B, at step 46, is the list state EO [b, a, b, a, a, a] none 0 of the Pascal machine's list machine arun (zone b a b a a a). If that list machine never fails from there, this machine never halts. The Pascal machine's own run starts it at EO [b, a] none 1.

start, not_halts_of_arun, lean/Mirror.lean; astep, lean/P75625/End.lean

Where the list machine can fail

For every state: a turn with no lone 1 in the zone never fails; a crossing turn with a clean far part whose tape ends in a single 1 never fails, and plain and crossing turns ending in a single 1 hand that on. So the list machine fails only at a crossing turn with blank end, at an EO turn during a crossing, or at a crossing turn whose far part is not clean.

astep_T, astep_EO, astep_T2_end, astep_endOne, astep_none, lean/Fail.lean

Where a halt can come from

If the machine halts on its third step from a configuration, that configuration is one of: C with 1 two left, 0 left, 0 under the head. So a run can reach a halt only through one of these patterns, and a proof that the machine never halts only has to rule them out. The proof splits on the state and the five cells around the head.

No periodic structure, no cellular-automaton rule

Up to 3·108 steps the tape has no long periodic stretch, and no sliding-block code of radius up to 7 (with any fixed shift) maps the tape at one visit of the right end to the next on the last 400 sweeps.

No halt in the first 2·1010 steps, and no near miss

Direct simulation: C reads a 0 1,250,049,447 times and bounces 208,505 times; the smallest block bounced off, other than the leftmost, has 3 cells (a block of 2 would make the halting pattern). D reads a 0 only 56 times, each time on the blank cell left of the whole tape.

c/echeck.c

A structure mod 4

At 50,072 sampled moments when C reads a 0 in the first 4·106 steps, 5,365,538 of the 5,366,200 blocks right of the head (not counting the first and the last) have length 3 mod 4. Left of the head, an even block other than the leftmost has length 0 mod 4 and is followed by an odd number of single 1s.

No proof by window automata

Closed position sets and finite automata reduction with automata that remember the last 2 to 8 runs of a side by length class (exact, then mod 2 or mod 4), the parity of runs of single 1s and flags for even blocks further out find no certificate.

Regular-language deciders tried (F11)

None of these closes: each reaches a halting configuration in its abstraction, which says nothing about whether the machine halts. n-gram CPS (tools/c/ngramcps.c), equal widths on both sides: a halting local configuration is reached with plain up to width 24, history 1 up to width 24, history 2 up to width 24, history 3 up to width 24, LRU history up to width 3 (larger widths ran out of the 150 s or 60 million configuration budget). n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 20, p = 3 up to width 20, p = 4 up to width 20, p = 6 up to width 20. n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets. Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4). Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..7; n = 8 not finished in 150 s.

heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.505).

tools/py/bbtools/triage.py

The run stays in a small set of rows

Changing one far block of the tape at step 3·105 by 2, 4 or 8 cells, or adding or deleting single 1s, never led to a halt in 6·105 more steps (30 trials each); adding 1 or 3 cells to a block left of the head led to a halt in 16 of 30 trials. Random rows of odd blocks halt quickly in more than half of the trials.

Does it halt from blank tape?

Not known. It halts exactly if the Pascal table started in D halts (Lean), and it never halts if the Pascal machine's list machine never fails from EO [b, a, b, a, a, a] none 0 (Lean). Whether it fails is the same open question as for the Pascal machine, from another start.
