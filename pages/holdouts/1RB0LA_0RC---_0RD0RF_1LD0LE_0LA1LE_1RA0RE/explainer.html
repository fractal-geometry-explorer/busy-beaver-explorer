Does this machine ever halt?

1RB0LA_0RC---_0RD0RF_1LD0LE_0LA1LE_1RA0RE

Nobody knows. A pair of 0s rides right through the first block of 1s, leaving 1 0 pairs behind; at the end of the block it becomes a glider, and every two pairs make another one, each knocking a hole 3 cells left. Rounds cost about the square of the width and add a few cells, so the width grows like the cube root of the time.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in B reading 1. B is entered only from A0 (writes 1, moves R): A>0 1. So a halt is the moment this pattern appears, with the head on the cell after >.

What it does

A pair of 0s, pairs of cells, gliders

Stop the machine each time the head is at the left end in state E. The tape is then a few blocks of 1s separated by single 0s: at step 996,038,575 it is E>0 1^646 0 1^2825 0 1^438, blocks [646, 2825, 438].

A round starts by turning the first two 1s into a pair of 0s, which then rides right through the block: A> 0 0 1 1 1 becomes 1 0 A> 0 0 1 every 6 steps, leaving 1 0 pairs behind. If the block is odd, the pair reaches its last 1, the hole is filled, and the pair carries on as a glider through the second block, one cell every 5 steps. At the next hole it fills three 0s and the hole reappears 3 cells to the left. E walks back to the pairs, two pairs make a new glider, and so on until the pairs are used up.

Lean proves the whole round for every odd length: [4K+3, a, b, …] becomes [a+K, 3K+6+b, …] and [4K+1, a, b, …] becomes [a+K−1, 3K+6+b, …]. The old second block moves to the front, the hole after it disappears into the new second block, and a new hole opens about three quarters of the old first block before the next one. All 344 odd rounds of the first 109 steps match.

The hard case

Even blocks, and the halting pattern

In the twin machine 1RB0LA_0RC---_0RD0RF_1LD0LE_0LA1LE_0RA0LA it is the even blocks that end the sweep at the hole. Here, with a different state F, it is the odd ones; at the end of an even block the pair of 0s passes through the hole into the next block, leaving a mark, and the round's result depends on several blocks at once. Those rounds add 4 to 23 ones.

The machine halts only when B reads a 1. B comes only from A on a 0, and that needs C on a 1 followed by 0 0 1 (C, F, A, B in a row): a sweep meeting two 0s in a row before a 1. At the start of every round seen the holes were single.

Growth law

Why the width grows like t1/3

Each glider crosses the second block and E walks back over it, so a round from [x, a] costs about 1.5·x·a steps, of the order of the width squared, and adds 3 to 23 ones. A constant gain per w2 steps gives w3 ~ t: 3,914 cells after 109 steps.

The pieces of a round

The start E> 0 1 1 1 → 1 0 A> 0 0 1; one sweep step A> 0 0 1 1 1 → 1 0 A> 0 0 1 (6 steps; it looks one cell ahead, so the sweep over n pairs is an induction, sweep); the end of an odd block A> 0 0 1 0 1^(a+3) 0 1 → 1 E> 0 1^(a+2) 0 1 1 1 1; the glider; the glider cycle 1 0 1 0 1 E> 0 1^(p+2) 0 1 → 1 E> 0 1^(p+3) 0 1 1 1 1; the last pieces.

Heuristic
py/rounds.py
Why the width grows like t1/3

About x/4 gliders each cross the second block and come back, so a round costs about 1.5·x·a ~ w2 steps; it adds 3 ones (x = 4K+3), 4 (x = 4K+1) or 4 to 23 (even x). So w3 ~ t.

Open
Does it halt from blank tape?

Not known. The odd rounds are proved; an even first block makes the sweep pass through the hole into the next block, a case still to be written as rules. A proof needs those rounds too and an invariant (single holes at every round start) that all rounds keep.
