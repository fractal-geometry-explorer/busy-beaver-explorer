What is known about 1RB0RE_1RC0RF_1LD1RA_1LB1LD_1RA1LB_---0LD

1RB0RE_1RC0RF_1LD1RA_1LB1LD_1RA1LB_---0LD

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 12 November 2026.

In short

Open. The run is a sequence of phases. In each, a block of ones eats a gap of X zeros in about X/4 rounds (proved in Lean for every X); at the end of the gap the head meets a short tail of blocks, rewrites its first blocks according to X mod 4, and the next phase starts with a gap of about 3X/2. The question is whether this Collatz-like interaction between the gap parity and the tail ever reaches the halting transition.

The rounds of a phase

From 0^inf B> 0 1 0^X T with X = 4k+r+7 ≥ 24 (a single 1 at the left end of the tape, a gap of X zeros, any tape T after it) the machine reaches 0^inf 1 C> (11)^(3k+3) 000 1111 0^r T: k+1 rounds, each growing the block of ones by six and moving the marker 000 1111 four cells into the gap.

The gap grows by a factor 3/2 per phase

In all 34 observed phase changes, X' = 3X/2 + d with d ∈ {+6, −6} when X ≡ 0 (mod 4) and d ∈ {+3, −3, −9} when X ≡ 2 (mod 4); which d occurs is decided by the first blocks of the tail, which the phase end also rewrites.

The phase map depends on the gap only through X mod 4

One phase simulated cell by cell from 0^inf B> 0 1 0^X T gives the next gap X' = (3X + d)/2 and the next tail T'. For every tail met on the orbit, four gaps X in each residue class mod 4 (X between 200 and 330) give the same d and the same T'. So the run is the iteration of a map on (X mod 4, T). This is a measured table, not a proof. Started at X = 6, T = 1^8 it reproduces the 35 phases of the macro simulator exactly.

2,009 phases without a halt

Iterated with exact integers, the table map makes 9 phases simulated directly and 2,000 more by the table without a halt; the gap then has 1,179 bits and the tail 12,469 cells in 1169 blocks. X is even throughout (X mod 4 is 0 or 2, about equally often). At every one of these phases the three other residues of X mod 4 were tried as well: 0 of the 6,000 alternatives halt. Unlike its sibling 1RB0RF_1LC---_1LF1LD_1RE0LD_0RC0RE_1LC1RA, no halting entry of the table has been seen at all.

heuristic Evidence only

The tail is a slowly growing stack

The tail T (right of the gap, about 100 cells after 35 phases) is a list of blocks 1^a 0^b; each phase end edits its first one or two blocks and occasionally pushes a new one. It behaves like the digits of a counter driven by the parities X mod 4, much as in other Collatz-like holdouts with a growing state.

The tail is rewritten at its front by a few rules with parameters

Most phase ends follow rules like these on the first blocks of the tail (X mod 4 = 0 or 2): 1^a 0^b becomes 1^(a+12) 0^(b-6) when X ≡ 2 and 1^11 0^(a-3) 1^4 0^(b-4) when X ≡ 0 (a odd, a ≥ 11); 1^4 0^b becomes 1^4 0^3 1^4 0^(b-7) when X ≡ 0 and 1^11 0^3 1^4 0^(b-4) when X ≡ 2. With b ≥ 8 these four rules account for 1,440 of the first 2,000 table phases, with no exception; other rules apply when the block of zeros is shorter or the tail starts differently. They were read off the orbit and are not proved; a closed set of them would turn the question into one about a stack driven by the parities of the 3/2 map.

Does it halt from blank tape?

The only halting transition, F on 0, can be met only during a phase end, while the head works through the tail. Whether some phase end ever reaches it depends on the joint evolution of the gap parity and the tail, which has not been decoded.
