What is known about 1RB1RA_1LC1RE_---0LD_1LE1LD_0RA0LF_1LF0LB

1RB1RA_1LC1RE_---0LD_1LE1LD_0RA0LF_1LF0LB

OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 14 November 2026.

In short

The question is open. This machine is the mirror image of 1RB1RA_0LC0RF_1LD1LC_1RE1LB_---0RA_1RF0RD with its states renamed, started in another state (an exact comparison of the two tables). The two runs stay in step: the same irregular word W next to a run of 1s that counts the visits, this machine's run one cell shorter.

It halts only if W eats the whole run between two visits. An exact simulation that keeps the run as a number followed it for 3·107 visits (8.6·1014 steps): the run gains 0.96 cells a visit and W never eats more than 14 cells at once. A halt is extremely unlikely, but W's behaviour is not understood, so there is no proof.

Shift rules

For every length n of the run and any tape around it: L A> 1^n R reaches L 1^n A> R; L 1^n D> 1 R reaches L D> 1 1^n R. These are the moves the head makes across the long uniform stretches of the tape.

At every visit of the far end the irregular word W is the same in both machines (mirrored) and this machine's run of 1s is one cell shorter: checked cell for cell at the first visits, and by W's length and the depth and eating statistics at 3·107 visits.

No halt in 3·107 visits

The simulator that keeps the run as a number (checked against its cell-by-cell mode) runs 30,000,000 visits = 864,573,434,721,961 steps without a halt; the run is then 28,822,305 cells and W 1,178,039.

c/runsim.c

A halt needs blank tape left of the head

The closed tape language from windows of 3 cells covers the run from blank tape and allows the halting transition C0 only with blank tape left of the head: the machine halts only if W eats the whole run. (Computed; for the sibling the mirrored statement is a Lean theorem.)

python3 -m bbtools.ctl 1RB1RA_1LC1RE_---0LD_1LE1LD_0RA0LF_1LF0LB 3

No halt in the first 3.33×1011 steps (region-memo accelerator)

The region-memo accelerator tools/py/bbtools/regaccel.py ran with blocks of 4 cells, from blank tape for 600 seconds and reached step 3.33×1011 without a halt. It keeps the tape run-length coded and, for each stretch of tape from the left end, a macro (the run until the head first leaves that stretch) computed by a symbolic run of the machine with the long runs as variables; a macro is used only when the linear inequalities its symbolic run assumed hold, otherwise the stretch is run again by the same recursion. So the run is exact, step count included. Check: 85 configurations of this run (every time the head faced blank tape on the right, up to 2×109 steps) agree cell for cell with a direct run (tools/py/regcheck.py). This is a bounded run and says nothing about later steps.

python3 tools/py/bbtools/regaccel.py 1RB1RA_1LC1RE_---0LD_1LE1LD_0RA0LF_1LF0LB 4 600; holdouts/regaccel.json

heuristic Evidence only

It almost certainly never halts

W eats at most 14 cells of the run in one visit in 3·107 visits, with a geometric tail, while the run gains 0.96 cells a visit: a halt at visit v needs about v cells eaten at once.
