Does this machine ever halt?

1RB1RA_1LC0RB_1LD0LB_1RA0LE_---1LF_1LB0LA

Nobody knows. This machine runs in phases: in each one a block of 0s is eaten four cells per sweep while a block of 1s grows six cells per sweep, and the 1s then turn into the next, half-again-larger block of 0s. The page runs the real machine and explains the phases.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in E reading 0. E is entered only from D1 (writes 0, moves L): 0 D>1. So a halt is the moment this pattern appears, with the head on the cell after >.

Macro structure

Phases: eating zeros, growing ones

Look at the tape whenever the head reaches a new cell on the right. After the first few hundred steps it always has the form P 0^z 1^b, where P is a short, fixed-looking prefix. Each sweep the head zig-zags left through the 1s, bites four 0s off the zero block and comes back, leaving the 1s six cells longer: 0^z 1^b becomes 0^(z-4) 1^(b+6). Lean proves this sweep for every size.

When fewer than four 0s are left (one or three, since z is odd), the head walks into P, changes its right end, and on the way back turns the whole block of 1s into 0s. That starts the next phase with a zero block about one and a half times as long:

z = 4k+1 → z' = 6k+1    z = 4k+3 → z' = 6k+7

So z runs 11, 19, 31, 49, 73, 109, 163, 247, 373, 559, 841, … a Collatz-like map, z' ≈ 3z/2, whose residue mod 4 behaves like a coin toss (466 phases with z ≡ 1, 434 with z ≡ 3 in the first 900). A phase takes about 9/4 times as many steps as the last; the phase starting at z begins near step 0.77·z2.

The prefix

A stack that remembers the residues

The prefix P is a list of blocks, 1s in multiples of 6 and even runs of 0s: after phase 30 it looks like 1^6 0^24 1^6 0^24 1^12 0^18 1^6 0^4 1^12 0^18 1^6 0^4 1^6 0^10 1^6 0^8 1^6 0^4 1^6. Each phase end rewrites only its last few blocks, depending on z mod 4: with z ≡ 3 the last zero block shrinks by 4 and the last block of 1s grows by 8 (the same game one level down); with z ≡ 1 a new pair 0^12 1^6 or similar is split off. When an inner zero block runs out, the head reaches one level deeper and the next zero block of the outer phase gets a small bonus c (62 five times, and 56, 98, 146, 26 and 50 once each, in the first 900 phases; 0 in all the others).

P grows by about 4.5 cells per phase, 4,056 cells after 900 phases, and its first 60 cells have not changed since phase 5. The machine halts only if state C reads a 0 with 0 1 to its left; that never happens inside a sweep, so a halt would have to come from one of these phase-end walks into the stack.

Evidence

Simulating 10319 steps

Phases grow too fast for direct simulation (phase 26 is already about 1010 steps). But a phase seems to depend on its zero block only through z mod 4, as long as z is larger than anything in P. So py/drive.py runs each phase with a small stand-in zero block of the right residue and carries the true z exactly as a big integer. The first 25 phases were also run full size and agree. In this way 900 phases ran without a halt, by then z has 160 digits and the machine has made about 10319 steps.

What is missing for a proof: (1) prove the phase-end walks for general z (a fixed number of shift rules per prefix shape), and (2) understand the stack well enough to show the halting pattern can never appear, which looks like a question about the coin-toss sequence z mod 4, the kind of question that is open for Collatz-like maps.

First look

The shape of the run

Left of the start, the visited part of the tape stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.489).

After 109 steps the tape spans 40,047 cells (31 left of the start, 28,737 right), with a density of 1s of 0.567.

Does it halt from blank tape?

Not known. Halting needs state C on a 0 with 0 1 to its left. It would have to come from a phase end that walks unusually deep into the stack; no phase end has rewritten more than the last 7 blocks (106 cells) of it, and its first 60 cells have not changed since phase 5.
