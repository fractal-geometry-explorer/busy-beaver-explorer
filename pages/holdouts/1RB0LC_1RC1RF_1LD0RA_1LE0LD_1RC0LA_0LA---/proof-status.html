What is known about 1RB0LC_1RC1RF_1LD0RA_1LE0LD_1RC0LA_0LA---

1RB0LC_1RC1RF_1LD0RA_1LE0LD_1RC0LA_0LA---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 12 November 2026.

In short

The question is open; the structure is partly known. The run passes through Y(n) = (101)^n 10 A> 0 for n = 23, 69, 349, 965, 4657, 11789 (step 804,211,967). Between two of them the tape is (101)^a w (110)^b A> 0: the block of 110s doubles (b → 2b or 2b+4) in each round while the 101s are used up, and when they run out the 110s become the next Y. This looks like the doubling counter of 1RB0LD_1LC0RA_1RA1LB_1LA1LE_1RF0LC_---0RE, but the cost of a round and the endings are not yet worked out.

Third pass (12 November). Seen from the left end, the tape is a list of runs of 100 and the machine is a list rewriting system with thirteen exact rules (quadrupling, flips by parity, carries, restarts), which predict all 46 events of the run from blank tape up to step 1.95·1011. One way to halt is known exactly: a quadrupling round that uses up the second run to the last copy while more runs follow. That needs an exact hit, with chance about (log b)/b per phase, so the machine probably never halts; no halt occurs in 1018 steps.

The quadrupling round, exact

C> 000 (100)^c (010)^(b+2c+1) X → C> 000 (100)^(4c) (010)^b X in 60c²+13c+39 steps (c ≥ 3), for any tape X to the right: checked by direct simulation for c = 3..39, b = 0..7 and four tails X (1,184 cases, step counts included); the round never looks at X.

The tape is a list of runs of 100, with exact rules

Sampled when the head is at the left end in state C reading 000, the tape is 000 (100)^n1 s1 (100)^n2 s2 … (100)^nk 1 with separators 0, 1 or 00, written [n1 s1, …, nk 1]. The first run quadruples, paid 2c+1 at a time by the second ([c 0, b s, …] → [4c 0, b−2c−1 s, …]); when the second run cannot pay, a flip rewrites the front ([c 0, b 1] → [2c−b−1 1, 2b+2 1] for b even, [2 0, 2c−b−3 0, 2b+2 1] for b odd; [c 1, d 1] → [2c−d−1 0, 2d+2 1] or [2c−d+1 0, 2d+1 1]; carries into a third and fourth run), and [2 0, x …] restarts the counter at 10. Thirteen rules, each checked against direct simulation for every parameter below 40: 60,000 cases, all agree. Lists with odd runs below the front follow rules not yet written.

One exact way to halt

[c 0, 2c+1 1, d s, …] → [4c 01, d s, …] → halt before the next event, for c ≥ 3: a quadrupling round that uses up the second run exactly, in a list of at least three runs with second separator 1. Checked for c = 3..39 with many tails (3,498 cases); [640 0, 98 01, 162 1] halts after 5,029,947 steps. With two runs only, [4c 01] does not halt.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.461). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.094).

tools/py/bbtools/triage.py

Probably non-halting

The known halt needs the second run to be hit exactly: b = (2c+1) + (8c+1) + … for the counter c at which a phase starts (10 or 8 after a restart). For a second run of size b that is about log4 b targets among b values, a chance of about (log b)/b per phase, and b roughly doubles from flip to flip (it is above 105 now). The sum converges and is small. This assumes the remainders behave like random numbers and that no other list shape halts; neither is proved.

Does it halt from blank tape?

Not known. One exact way to halt is known (a quadrupling round that uses up the second run exactly, in a list of three or more runs); the run from blank tape has not met it in 1018 steps and the chance that it ever does looks small, but nothing is proved. The rules for lists with odd runs below the front are not written, so other ways to halt are not excluded.
