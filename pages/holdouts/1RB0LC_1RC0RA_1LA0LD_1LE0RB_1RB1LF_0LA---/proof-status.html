1RB0LC_1RC0RA_1LA0LD_1LE0RB_1RB1LF_0LA---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. Lean proves that between visits of state A the machine follows ten rewriting rules, for every tape, and halts exactly when state A reads a 1 with 1101 on its left. On the tape the rules move cursors through runs of 01, tripling the runs; cursors stall behind each other and collide, and whether a collision ever produces the halting pattern depends on the exact run lengths. No halt in 1011 steps.

Ten rules between visits of state A

From any configuration in state A the next one is given by R1 (A> 01 → 10 A>), R2 (A> 00 1k 0 → 1 0k A>1 1) or, when A reads 1, by the cells on its left (L1 … L8). Each is proved for every tape; L4 (1101 A>1) halts.

R1, R2, L1…L8, bad_halts, lean/Rules.lean (generated by py/rules.py)

Passes and rounds

The right and left passes over a run of 01 and over a separator 00110 (the left pass moves two pairs across the separator), the left end, and nine rounds for all run lengths: a cursor moving through a run (a “1” b → a+2 “0” b → a+6 “1” b−2), crossing a separator, and two cursors vanishing.

heuristic Evidence only

Growth shape: fixed/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.483). Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).

tools/py/bbtools/triage.py

Macro structure (observed)

A layered bouncer: the tape is runs (01)^n separated by the marker 00110, in repeating pairs whose lengths triple from layer to layer ((9, 41), (27, 131), (81, 401), ...), while a block (10)^m at the left end grows and is spent.

Does it halt?

Unknown. A halt needs the pattern 1101 A>1, which a single cursor among long runs never makes; it could only come from a collision of cursors with short runs, and which collisions happen depends on the exact run lengths and budgets.
