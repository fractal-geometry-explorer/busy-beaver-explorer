Does this machine ever halt?

1RB0RE_0LC0RF_1LD1LC_1RA0LD_0RD1RE_---0LB

Nobody knows yet. This machine works in levels: it moves a long block of the tape to the left one word at a time, drains what it built, and starts again with a block 2 to 6.6 times as long. Most levels follow an exact formula; some contain a binary counter and are not understood.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 0. F is entered only from B1 (writes 0, moves R): B>1 0. So a halt is the moment this pattern appears, with the head on the cell after >.

The only way out

When it would halt

The machine has one halting instruction: state F reading a 0. F is reached only from state B reading a 1, and B then leaves a 0 behind and moves right. If F finds a 1 it steps back onto that 0, and nothing happens. So the machine stops only if B finds a 1 with a 0 right after it, and B gets to such a place only from state A reading a 0.

It halts exactly when the head, in state A, is on a 0 and the next two cells are 1 and 0.

In the whole run so far the head in state A on a 0 has always found either another 0 or two 1s to its right.

Tape as words

Visits and levels

Look at the tape only at the moments when the head reaches a new cell at the far left. It then reads

0 0 1^5 (00111)^a · X

where (00111)^a means the word 00111 written a times. Between two such moments the head sweeps to the right and comes back: one visit. A visit adds one word 00111 at the left and changes the rest X in a way that does not depend on a.

Now and then a visit rewrites the whole left block as (10111)^a. The tape is then

0 0 1^5 100 (10111)^b · tail

and a new level starts. A level is described by the block length b and the short tail after the block. During a level the block is moved to the left one word per visit (the grow phase), then the pile of words 100 that this leaves is removed four words per 14 visits (the drain phase), and the left block is recycled.

From one level to the next

The level map

Four short tails keep coming back; call them P = 100 1111 0 1111 00 111, Q = 100 1111 0 1111 0 111, R = 100 1111 0 11111 0 111, S = 100 1111 0 1111 00 1. For P and Q the next level is given by the remainder of b when divided by 4:

tailb = 4kb = 4k+1b = 4k+2b = 4k+3
P(9b+10)/2, tail P(9b+11)/2, tail Q(9b+10)/2, tail R(9b+9)/2, tail S
Q(9b+12)/2, tail P(9b+13)/2, tail Q(9b+12)/2, tail R(9b+11)/2, tail S

So such a level multiplies the block by 4.5, and the remainder mod 4 picks the next tail, as in a Collatz-type problem. Tail R gives b+4 and leaves a second long block on the tape; tail S doubles b and leaves a block of six-cell words whose length m is about b/2.

These formulas are checked in two ways: by plain simulation for b = 12 to 27, where every visit is an instance of a Lean rule, and by a symbolic run with b as a free variable (a Python program, not Lean) for every b.

The hard part

A binary counter between the blocks

After a level with tail S the tape carries a block (100111)^m. In the next level the machine does something new. Between the pile of words 100 and that block a string of two kinds of words appears: 100 and 11100. Read 100 as the digit 0 and 11100 as the digit 1: the string is a number in binary. Each time the block at the right loses one word, the number goes up by one:

1000 → 1001 → 1010 → 1011 → 1100 → …

until the block is used up and the number is m−1. Then the digits are consumed from the right, and how the level ends depends on them. With b = 400 and m from 1 to 69, the next block length takes values from 1,205 to 2,657 and the next tail nine different shapes, in no order that we can see.

This is why the method that settles similar machines does not finish here. That method lists finitely many tape shapes with free block lengths and shows that each leads to another in the list. A counter passes through a different shape for every value, so a proof needs a different kind of invariant: a set of tapes that allows any string of the two digit words in the middle.

No level start that was tried halts: all remainders for the common tails, about 25,000 random level starts, and the counter levels with small m. The evidence points to a machine that runs for ever, but it is evidence, not a proof.

Exact halting condition

The machine halts exactly when a configuration A> 0 1 0 occurs: state A on a 0 whose right neighbours are 1 then 0. (F is entered only from B reading 1; if F reads 1 it steps back onto the 0 that B wrote. So only B reading 1 followed by 0 halts, and B gets there from A reading 0.) A hand argument from the table, not in Lean.

120 one-visit rules for the other phases

Each visit of the left end in the phases of the four common level types is a theorem for every block size: entering the drain phase (tails P, Q, R, S), the 14-visit drain cycle that removes four words 100, the four endings according to the block length mod 4 up to the recycling of the left block, and the pour phase of tail S. Each rule is one visit: from one tape with the head at the left end to the next.

Computed
py/closure.py
The level map for every b (12 of 14 level types)

A symbolic run with the block counts as free variables, which stores a cycle only after re-running it with free counts and splits into cases by remainder when a jump needs it, follows a level from start to the next level start. For 12 of the 14 level types that occur, every case ends in a level start of one of the 14 types (91 cases), with the next block length a linear form such as 18k+113 from 4k+24. The check fails for the two types that contain the binary counter (2 cases), so the set is not closed. Python, not checked by Lean.

py/counter.py
A binary counter inside some levels

In a level whose tail is (100111)^m the tape between the blocks is a string of the words 100 (digit 0) and 11100 (digit 1). Read as a binary number it goes up by one each time the tail loses one word, from 0 to m−1 (six runs, m up to 100). The next level depends on the digits of m: for b = 400 and m = 1..69 the next block length lies between 1,205 and 2,657 and the tail takes nine shapes.

Open
Does it halt from blank tape?

Not known. A proof that it runs for ever needs a closed description of the counter levels: a set of tapes with an arbitrary string of the two digit words between the blocks. Nothing suggests a halt.
