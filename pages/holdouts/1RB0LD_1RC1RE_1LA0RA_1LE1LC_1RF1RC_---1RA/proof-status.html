1RB0LD_1RC1RE_1LA0RA_1LE1LC_1RF1RC_---1RA

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. The run is a walker and carry machine whose carries apply a 5/4 map to the length of the tail, a Collatz-like rule. The walker sweeps, the shallow carries and their step counts are exact (Lean proves the walker sweeps for all lengths); the deeper carries are run cell by cell. No halt in the first 3.2·1012 steps (the run stopped inside a deep event with a tail of 853,485 groups).

kernel Proved in Lean, kernel-checked

The walker, for all lengths

A marked group loses three 1s and the tail gains two groups (walk_down); the walker steps one group left and the tail gains one (walk_left); it merges into the marked group before it (walk_merge); a tail ending in 1^6 becomes a marked item (push). Each for every tail length and every tape further left, in 10q + 23 steps (13 for push).

The shallow carry

When the last marked group is 1 0 (m = 1) and the tail has q = 4k + r groups, and the item has at least k + 1 groups: the item gives up k + 1 groups and is marked 6 (r < 2) or 3 (r ≥ 2); the tail becomes 5k groups (r < 2) or 5k + 3 (r ≥ 2), ending in 1^6 when r is odd; the sweep takes 50k² + 88k + 28 steps (r < 2) or 50k² + 138k + 82 (r ≥ 2), plus 7 when r is odd. Checked against cell-by-cell sweeps on 1,111 random carries (with 1,023 random walker sweeps and 488 pushes).

c/walker.c, py/walker.py check

The hybrid simulator is exact

Walker phases are applied at once (x steps left: 2x sweeps, tail +3x, 20qx + 30x(x−1) + 56x steps), shallow carries in closed form, everything else cell by cell. Without phase jumps it reproduces every sweep start of the first 3·107 steps of the direct run (the Python model in py/walker.py does the same for 107 steps); with them it reaches the same configurations at the same steps.

heuristic Evidence only

Collatz-like

The tail length is multiplied by about 5/4 at each carry and by about 3 at each walker pass; which branch a carry takes depends on q mod 4 and on how much the item before can give. Halting configurations exist among the deep carries (for example the items (0,1) (3,3) (1,1) with a tail of 10 groups halt after 1,164 steps; py/walker.py check runs it), so whether the run ever reaches one is a question about this map.
