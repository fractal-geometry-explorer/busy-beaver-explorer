What is known about 1RB0LA_0RC0RB_1LD1LA_1LC1RE_1RF0RD_1LC---

1RB0LA_0RC0RB_1LD1LA_1LC1RE_1RF0RD_1LC---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

Open; probviously halting, astronomically late. At each E-pass the run is a pair (context word c, block length n): n → (3n+δ)/2 and c → c', decided by c and n mod 4. The arithmetic is now derived from the machine and proved in Lean for every context and every n; the context is rewritten like a binary counter read from the right. Two rules halt (11111 and 1111011 with ⌈n/2⌉ odd; proved). The bits ⌈n/2⌉ mod 2 are provably uniform over residues of n, so halting has a fixed rate of 8.9·10−13 per pass: a halt is expected after about 1.1·1012 passes. No halt in the first 4.3·109 passes (218 of them proved in Lean, more than 1045000 steps).

The E-pass for every context

For every left tape P and every n: P E> 1^n reaches P C> 1^(3k+2) (k = ⌈n/2⌉ even) or P 1 C> 1^(3k+2) (k odd): the block is halved into (01)^k and every two 01 become six 1s. The arithmetic of the map does not depend on the context.

pass0–pass3, lean/Pass.lean; pieces in lean/Rules.lean (symtm)

The context rewrites of the 55 contexts the orbit uses

For each context met in the first 230 passes and each bit b, the rewrite c C> 1^m → c' E> 1^(m+a) for every block length m of the right parity: 110 rules, generated with symtm.

The halting criterion

If the orbit reaches the context 11111 or 1111011 with ⌈n/2⌉ odd, the machine halts; if it stays in the table forever, it never halts. These two rules carry all but 10−16 of the halting rate of the Markov model.

halts_of_orbit, not_halts_of_forall, halt_11111_1, halt_1111011_1

heuristic Evidence only

Probviously halting, after about 1012 passes

The bits ⌈n/2⌉ mod 2 of the next k passes are a bijective image of n mod 2k+1 for every context, so they are fresh fair bits whatever the size of n. The context is then a Markov chain with absorption rate 8.87·10−13 per pass (mean 1.1·1012 passes); its stationary distribution matches the orbit's context frequencies to four digits. A halt in the 4.3·109 passes checked had probability 0.4 %.

py/markov.py rate 400, py/markov.py bits 12

Does it halt from blank tape?

Not known. A halt is expected after about 1012 passes, i.e. some 107·1010 steps; deciding it needs control of the parity sequence of a 3/2-Collatz orbit.
