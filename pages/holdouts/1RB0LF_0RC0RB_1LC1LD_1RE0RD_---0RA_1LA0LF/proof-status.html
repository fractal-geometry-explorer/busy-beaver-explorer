What is known about 1RB0LF_0RC0RB_1LC1LD_1RE0RD_---0RA_1LA0LF

1RB0LF_0RC0RB_1LC1LD_1RE0RD_---0RA_1LA0LF

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open. Lean proves (kernel) that a halt needs a D-run (halt_needs_drun) and proves exact cycle rules of the particle dynamics (cycleP, for all values of their parameters). In the run, D-runs happened only four times, all in the first 2.4·106 steps and all at the wall at the right end. No halt in the first 1011 steps (C); the twin 1RB0RA_1LC0RA_0LD0LC_1RD1RE_1LF0LE_---0LB runs the same tape with one extra 1 at the wall.

The halting configurations

The machine stops exactly when it reads the symbol of a halting transition (E0); the generated statement covers every configuration.

step_none_iff, lean/Blank.lean

Where a halt can come from

If the machine halts on its third step from a configuration, that configuration is one of: D with 1 under the head, 0 right, 0 two right. So a run can reach a halt only through one of these patterns, and a proof that the machine never halts only has to rule them out. The proof splits on the state and the five cells around the head.

halt_route, lean/Route.lean (written by py/route.py)

No halt in the first 10,000 steps

The list simulator of the shared library, proved to agree with the machine's semantics, runs 10,000 steps from blank tape without a halt, evaluated by Lean's kernel.

A halt needs a D-run

Two steps before a halt the head is in state D reading a 1: E (the halting state, on a 0) is entered only from D0, and D from C1 (then E reads the 1 that C wrote) or from D1.

halt_needs_drun, lean/Halt.lean

Regular-language deciders tried (F11)

None of these closes: each reaches a halting configuration in its abstraction, which says nothing about whether the machine halts. n-gram CPS (tools/c/ngramcps.c), equal widths on both sides: a halting local configuration is reached with plain up to width 14, history 1 up to width 12, history 2 up to width 10, history 3 up to width 10, LRU history up to width 2 (larger widths ran out of the 150 s or 60 million configuration budget). n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 12, p = 3 up to width 12, p = 4 up to width 12, p = 6 up to width 12. n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets. Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4). Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..7; n = 8 not finished in 150 s.

Particles and their speeds

Sampled once per cycle of the left gadget, the junctions (00, 11) of the tape form 11 to 15 small clusters whose displacements per cycle are constants (gadget 8 cells, o 4, P 12, Q 8); the head only reaches the far particles when the near ones are used up, like a carry.
