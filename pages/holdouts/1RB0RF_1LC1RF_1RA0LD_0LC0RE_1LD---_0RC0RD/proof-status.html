What is known about 1RB0RF_1LC1RF_1RA0LD_0LC0RE_1LD---_0RC0RD

1RB0RF_1LC1RF_1RA0LD_0LC0RE_1LD---_0RC0RD

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 12 November 2026.

In short

The question is open, and reduced to a counter. Write the tape as gap words 0^g 1. At the sample points it is 0^∞ 1 1 1 C> 0 0 1 [0^g1 1] ... [0^gk 1], so a state is the list of gaps; most are 3, forming blocks. Read the separators 1 1 1, 1, 5 between blocks as digits 2, 1, 0: one round trip of the head is a ternary decrement (a 2 gives a 3 to the block before it, a 1 takes a 3 from the block after it, the zeros below become 2, the first block gains a 3). A second kind of digit (1 0 1, 2 1, 0) stops the borrow and drains the block after it; blocks that run out bring merges and a special return. Every rule is proved in Lean for all sizes, and the machine halts from blank tape iff this model reaches the gaps (0,0,0) or (4,0) (halts_iff_model, kernel-checked, assuming the model never meets a pattern it does not cover; since 12 November also halts_iff_hybrid, with nothing assumed, for the model completed by plain machine steps on the uncovered patterns). The model matches the machine at all 129,587 bounces to 2·1010 steps and runs about 1089 bounces without halting or getting stuck.

Sweep rules

The head sweeps over long runs of a repeated word, rewriting each copy, for any number n of copies and any surrounding tape. Examples:

  • L F> (0001)^n R → L (0111)^n F> R
  • L C> (0010)^n R → L (1110)^n C> R
  • L A> (0100)^n R → L (1101)^n A> R
  • L B> (1000)^n R → L (1011)^n B> R
Generated by py/rules.py (tools/py/bbtools/symtm.py).

One bounce rewrites the gap list

For every gap list: C sweeps right over gaps 3 and 5, the pairs (0,1) and (2,3) and the run (0,0,3,3), stops at the first other pattern (ten kinds, e.g. 1, x → x+2, 2, 1 → 3, 0, 0, x+2 → 1, 0, x, x+7 → 1, 0, x+1), and returns in a normal or a special state that rewrites what it passed (a 5 becomes 1 1 1); at the left end a 3 or 1 1 1 is put in front. 29 symbolic pieces from py/counter.py (bbtools.symtm), inductions over the passed tokens by hand.

bounceM_next, scan_ret, ret_all, finish_ok, lean/Counter.lean

The two halting patterns

A sweep that reaches the gaps (0,0,0) or (4,0) ends with E reading 1: the machine halts.

bounceM_halt, h_000, h_40, lean/Counter.lean

Halting from blank tape is exactly halting of the counter model

Blank tape reaches the gap list [1,1,1,1,0] in 71 steps. If the model started there never meets a pattern it does not cover (stuck), the machine halts from blank tape if and only if the model reaches halt. Axioms: propext, Classical.choice, Quot.sound.

halts_iff_model, blank_to_cfg, lean/Model.lean

With nothing assumed: halting is halting of the hybrid model

The gap counter has rules for the patterns that occur; on any other pattern it answers stuck. The hybrid model hstep is defined on every state: it makes a bounce of the gap counter where that is defined, and otherwise it continues with single steps of the machine itself, on the configuration written out cell by cell. Proved: each move of the hybrid model is a run of the machine of at least one step, its halt is a halting configuration, and therefore, in plain words, the machine halts from blank tape if and only if the hybrid run from the gap list [1,1,1,1,0] reaches halt (halts_iff_hybrid). Nothing is assumed. Also proved: as long as the gap counter is not stuck, the hybrid run is exactly the run of the gap counter (hrun_of_runM). What this does not give: any understanding of the uncovered patterns. After such a pattern the hybrid model simply is the machine. The theorem removes the hypothesis from the statement, not the question whether an uncovered pattern is ever reached.

heuristic Evidence only

Growth shape: power/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.509). Right of the start it grows like a power of the step count other than 1/2 (fitted exponent 0.19).

tools/py/bbtools/triage.py

Why the rules were not simply completed

Tried on 12 November. From every uncovered stop pattern with up to three leading gaps ≤ 9 (840 cases, with different continuations) the machine itself comes back in the normal or the special return mode, or halts; it never leaves in another way (py/model.py has the covered cases only; the experiment is a plain simulation). But the outcomes do not form a short table: some uncovered patterns behave like further passable tokens (for example the gaps 2, 2 are passed and become 3, 0, 3, and the sweep goes on), and a cell-by-cell search for a complete decision tree does not close at depth 16. A complete gap-level model would need a second layer of sweep rules. An invariant of the run that keeps it inside the covered patterns is not known either.

No halt for about 1089 bounces of the model

py/model.py far applies whole stretches of the ternary counter at once (checked against single bounces for 3·107 bounces) and extrapolates periodic stretches linearly, re-running one period at the far end of each extrapolation (sound if the periods depend on the block sizes only through lower bounds, which is argued, not proved). In 870 seconds it ran about 1089 bounces with no halt and no uncovered pattern; the list of gaps grew to 371 run-length entries, the largest blocks to about 90 digits.

Does it halt from blank tape?

Open. By halts_iff_hybrid (nothing assumed) it is the question whether the hybrid model halts; by halts_iff_model, as long as the gap counter stays inside its rules, it is the question whether the counter ever reaches the gaps (0,0,0) or (4,0). The counter is Collatz-like, as for the other base-3 counters; no halt and no uncovered pattern in about 1089 bounces.
