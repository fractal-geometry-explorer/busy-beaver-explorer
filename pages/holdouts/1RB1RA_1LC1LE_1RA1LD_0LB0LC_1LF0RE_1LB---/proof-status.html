What is known about 1RB1RA_1LC1LE_1RA1LD_0LB0LC_1LF0RE_1LB---

1RB1RA_1LC1LE_1RA1LD_0LB0LC_1LF0RE_1LB---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Its run is a block 1^(4j+1) at the left end that grows by four cells per overflow while the gap doubles, so a binary counter is at work, and a word of blocks 1, 1^5, 1^9 (binary-like digits) on its right. Each overflow changes the word only from some block on, and that block moves right about two blocks per overflow; when it reaches the end the word is rebuilt and the block at the left end starts again.

Status as of 8 November 2026.

In short

The question is open. Lean proves no halt in the first 107 steps (native_decide); the C simulator finds no halt in the first 1011 steps.

What it does. At each overflow the tape reads C>0 1 0 1^(4j+1) 0 W. Since the last restructure, at step 1,354,998, j has grown by one per overflow, 30 times, to 1^125 at step 73,018,175,570, and the gap between overflows has doubled (ratio 2.0000 at the last 15). W has 54 to 56 blocks, and the first block that changes from one overflow to the next has moved from block 0 to block 50.

Why it is hard. The sweep should reach the end of W within a few more overflows (a few times 1011 steps); what happens then, a restructure or possibly a halt (state F reading a 1), depends on a rule that has not been worked out.

The overflow configurations of the run

There are 65 moments in the first 1011 steps where the head reaches a new cell at the left end with the tape reading C>0 1 0 1^k 0 W. From step 830 on k has the form 4j+1 and rises by 4 from each to the next, except at restructures where it falls back to 5: at steps 1,525, 4,520, 166,083 and 1,354,998. The last is at step 73,018,175,570 with k = 125.

A restructure is due soon

If, as in the similar machine 1RB1LC_1LA1RE_0RD0LA_---1LB_1LD0RF_0RE1RB, the epoch ends when the sweep reaches the end of W (not checked for the earlier epochs of this machine), then at its current pace that happens in two or three more overflows, near 1.5·1011 to 3·1011 steps.

the records of the 1011-step run

No simple arithmetic rule

Reading W as a binary number N, N changes by roughly 3·4j−1 per overflow, but the rule fails when the machine is started from constructed configurations with arbitrary low digits, so the run depends on the particular words it writes.

The restructures, and the question itself

Not known: the per-overflow rule for W, the restructure rule, and whether the machine halts. A closed tape language that confined the halt to the left edge looked plausible in Python but failed Lean's check, so no edge theorem is claimed.
