What is known about 1RB0RE_1LC1LF_1RA0LD_1LB1LA_1RB1RC_---0LA

1RB0RE_1LC1LF_1RA0LD_1LB1LA_1RB1RC_---0LA

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 9 November 2026.

In short

The question is open. The tape is a list of blocks of the word 110. Its main move is an exact transfer cycle between three neighbouring blocks: (x, y, z) → (x−2, y+3, z−1) in 28y+111 steps, checked on all 8,397 cycles in the first 108 steps. Lean proves the shift rules inside blocks. What happens when a cycle runs out, and so the map on whole lists, is not known.

Shift rules of the sweeps

a_right: going right, A shifts a block of n words 110 by one cell (3n+1 steps). d_left and c_left: going left, D and C cross a block written as 110 or 101 words. All three hold for every n and every surrounding tape.

README

The transfer cycle

When the tape around the head reads (110)^x 0 (110)^y 1 A> 1 0 1 0 1 1 0 0 (110)^z 0, the next turn in state A at the same place finds (x, y, z) changed to (x−2, y+3, z−1) after exactly 28y+111 steps. All 8,397 such cycles in the first 108 steps follow this, step count included.

Why it is hard

The main move is a 3-for-2 exchange between three neighbouring blocks, the arithmetic of Collatz-like machines. Each cycle is exact, but which blocks meet next depends on how earlier cycles ended, and those end rules are not known yet.

Does it halt from blank tape?

Not known. The machine halts if F reads a 0.
