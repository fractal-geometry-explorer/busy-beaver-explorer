Does this machine ever halt?

1RB0LC_0LC0RF_1RD1LC_0RA1LE_---0LD_1LF1LA

Nobody knows, and it is a Collatz-type problem. The machine runs a counter that grows by half each round, and pays for its even rounds from a budget; when the budget runs out it either halts or refills it, depending on a parity that behaves like a coin flip. Lean proves that this description is exact.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in E reading 0. E is entered only from D1 (writes 1, moves L): 0 D>1. So a halt is the moment this pattern appears, with the head on the cell after >.

The records list every step at which the head reaches a cell no earlier step reached, with the side, the width so far and the whole tape: the first place to look for a repeating macro structure.

Macro structure

Three counters on the tape

Stop the machine every time the head, in state D, is at the left end of the tape. The tape then always reads

D>0 0 1^a 0 1^b (0 1)^c

two blocks of 1s, of lengths a and b, followed by c pairs 0 1. In one round the head carries a hole through the first block and comes back: two 1s leave the first block and three join the second. So while a ≥ 3, a round is (a, b, c) → (a − 2, b + 3, c).

When the first block is down to 1 or 2 cells, the second block becomes the new first block, a fresh second block of 3 or 4 cells is written, and pairs are spent:

  • a = 1: (1, b, c) → (b + 1, 4, c − 1); one pair spent (none if c = 0, and then the new block has 3 cells);
  • a = 2: (2, b, c) → (b + 6, 4, c − 3); three pairs spent; with only 2 or 1 pairs left they are all spent;
  • a = 2 and c = 0: if b is even the pairs are refilled from the second block, (1, 1, b/2 + 1); if b is odd the head reads a 1 where it needs a 0 and the machine halts.

Starting with first block a, the round sequence ends at a = 1 (a odd) or a = 2 (a even), and the new first block is about 3a/2: exactly 3a/2 + 7 for even a and (3a + 7)/2 for odd a. This is the same 3/2 map as in Antihydra, and even values cost three pairs while odd ones cost one.

Lean proves each of these rules for all values (lean/Rules.lean), and from them that the machine halts from blank tape if and only if this map, started at (1, 1, 4), reaches the halting case (halts_iff in lean/Map.lean).

Open question

A budget that runs out

The pairs are a budget. Each even value of the counter costs 3 and each odd one costs 1, and the budget only comes back when it is completely spent and the next even value of the counter comes with an even second block, which happens when that value is 0 mod 4. If it is 2 mod 4, the machine halts.

From blank tape the budget has run out four times, and four times it was refilled: at cycle 3 (to 9 pairs), 8 (31), 25 (4,966) and 2,549 (a number of 1,479 bits, about 1.4·10445). Each refill is about half the second block, which by then is enormous, so the next budget lasts about 21478 rounds. No computer will get there.

If the residues mod 4 of the counter are like coin flips, as they appear to be, each budget ends in a halt with probability 1/2, so the machine would halt with probability 1, but only after a time that dwarfs everything here. Proving it either way would mean controlling the parities of a 3/2 map, the same obstacle as for Antihydra and the Collatz problem.

The shape of the run


Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.618). Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).

Heuristic
README
A coin flip per budget
Each time the budget runs out, the machine halts if the next even value of a is 2 mod 4 and refills otherwise. If those residues behave like fair coins, the machine halts with probability 1, but at a time beyond the fifth budget, about 21478 rounds of a map whose counter grows by half each round.

    
Open
Does it halt from blank tape?
Equivalent to whether the orbit of (1, 1, 4) under the map ever ends a budget on the wrong parity: a Collatz-type question like Antihydra's, out of reach of current methods.
