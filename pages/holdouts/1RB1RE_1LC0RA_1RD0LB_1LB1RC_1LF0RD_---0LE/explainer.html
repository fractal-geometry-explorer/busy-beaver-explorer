Does this machine ever halt?

1RB1RE_1LC0RA_1RD0LB_1LB1RC_1LF0RD_---0LE

Nobody knows, but the question is now about one number. Read at the moments the head is at the left end, the tape holds a single number n; Lean proves that the machine halts exactly when a simple map on n, started at 1, lands on one of the thresholds 3, 12, 31, 70, 149, ... The map has been iterated 1.25 million times without that happening.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 0. F is entered only from E0 (writes 1, moves L): 0 E>0. So a halt is the moment this pattern appears, with the head on the cell after >.

What the tape is made of

One number, and a ruler

Whenever the head is at the left end of the tape, the tape reads

S n  =  C>0 (10)^n 1

a block of n pairs 10. From blank tape the first such sample is S 1, after 4 steps. A round has two phases.

Phase 1 turns the block into a run of 2n − 2 ones and then measures it: the tape becomes

V K i m  =  1^(2K) 0 A>0 (10)^(2i) 111 0 (10)^m 1

and each bounce takes two ones from the left and one pair from the right block and adds two pairs to the middle: V (K+1) i (m+1) → V K (i+1) m. When the right block is used up, the middle block moves over to the right with five extra pairs: V (K+4) i 0 → V K 0 (2i+5). So the right block is a ruler of 0, 5, 15, 35, 75, ... = 5·2t − 5 pairs, doubling each time, paid for by the ones on the left.

The phase ends when the ones run out. Most of the time this happens in the middle of a bounce sequence (V 0 i (m+1)); at the end of a sub-phase it can end four ways, V 2K i 0 for K = 0, 1, 2, 3, and K = 2 is the halting transition (state F reading 0).

Phase 2 turns C>0 (10)^x 111 0 (10)^z 1 back into a sample, S (2x + z + 4).

The rule

Triple, and subtract a power of two

With thresholds ci = 10·2i − i − 7 (−1, 3, 12, 31, 70, 149, 308, 627, ...), for ci < n ≤ ci+1:

next(n) = 3n − 2c_i + i + 3     if n < c_(i+1)
          HALT                  if n = c_(i+1)

Lean defines the map one bounce at a time and proves the machine follows it; the closed form above is checked against that definition for every n below 10,000. The orbit of 1, which matches the machine's samples exactly:

The left end of the tape moves once per round while n roughly triples, so the left side grows like the logarithm of time; the head sweeps the whole block, so the right side grows like its square root.

Does it halt?

Only by landing exactly on a threshold

Write n = ci + d. The offset d, somewhere between 0 and 10·2i, becomes 3d + i + 3: it triples and wraps into the next level or the one after. The machine halts only if the offset lands exactly on the end of a level. In 1,250,000 steps of the map that never happened; n has 833,000 bits by then.

If the offset behaves like a random number, the chance of an exact hit at a step of level i is about 1/(10·2i), and these chances add up to almost nothing: the machine is expected to run forever. Proving it would mean controlling the digits of an orbit of a map like n → 3n − 2k, a Collatz-like problem, so this machine is a cryptid.

First look

The shape of the run

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.066). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.523).

After 109 steps the tape spans 36,587 cells (54 left of the start, 33,791 right), with a density of 1s of 0.512.

The rules of a round

Every rule of both phases, for all values of the counts: the sample S (n+3) becomes V (n+2) 0 0, one bounce V (K+1) i (m+1) → V K (i+1) m, the end of a sub-phase V (K+4) i 0 → V K 0 (2i+5), the five ways the first phase ends (one of them the halt), and the second phase T x z → S (2x+z+4).

ph_spec, lean/Phase1.lean
The map

For all K, i, m: V K i m reaches the sample S n when ph K i m = some n, and halts when ph K i m = none; ph is a recursive function following the rules one bounce at a time.

Heuristic
py/orbit.py
Why a halt looks unlikely

Write n = ci + d; the offset d, between 0 and 10·2i, becomes 3d + i + 3, wrapping into the next level or the one after. A halt needs the offset to land exactly on the end of its level; treating d as random the chance is about 1/(10·2i) per step, and i grows by about 0.67 per step, so the expected number of future hits is far below 2-100000. A halt at the next step needs 3n = 4ci + 3, possible only for i ≡ 0, 1 (mod 6); the closest approach seen was |3n − 4ci − 3|/ci ≈ 5.9·10-6.
