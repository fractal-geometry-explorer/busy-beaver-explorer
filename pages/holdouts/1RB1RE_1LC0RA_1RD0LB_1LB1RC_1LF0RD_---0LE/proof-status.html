What is known about 1RB1RE_1LC0RA_1RD0LB_1LB1RC_1LF0RD_---0LE

1RB1RE_1LC0RA_1RD0LB_1LB1RC_1LF0RD_---0LE

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open, and reduced to a map on one number. Lean proves (kernel, no native_decide) that the machine halts from blank tape if and only if the orbit of 1 under the map next reaches none. In closed form the map is n → 3n − 2ci + i + 3 for ci < n < ci+1, with ci = 10·2i − i − 7, and it halts exactly when n = ci+1. Iterated 1,250,000 times, the orbit never lands on a threshold; n then has about 833,000 binary digits. A probability argument says a hit is ever less likely (about 1/2i per step), so the machine is expected never to halt, but no proof is known.

The map

For all K, i, m: V K i m reaches the sample S n when ph K i m = some n, and halts when ph K i m = none; ph is a recursive function following the rules one bounce at a time.

ph_spec, lean/Phase1.lean

Halts if and only if the orbit hits none

From blank tape the machine reaches S 1 in 4 steps; so it halts if and only if the orbit of 1 under next n = ph (n−1) 0 0 reaches none.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.066). Right of the start it grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.523).

tools/py/bbtools/triage.py

Why a halt looks unlikely

Write n = ci + d; the offset d, between 0 and 10·2i, becomes 3d + i + 3, wrapping into the next level or the one after. A halt needs the offset to land exactly on the end of its level; treating d as random the chance is about 1/(10·2i) per step, and i grows by about 0.67 per step, so the expected number of future hits is far below 2-100000. A halt at the next step needs 3n = 4ci + 3, possible only for i ≡ 0, 1 (mod 6); the closest approach seen was |3n − 4ci − 3|/ci ≈ 5.9·10-6.

Does it halt from blank tape?

Not known. It is equivalent (in Lean) to whether the orbit of 1 under the map ever lands exactly on a threshold ci; that is a Collatz-like question with no known method of attack.
