Does this machine ever halt?

1RB0LC_1LC0RD_1LF1LA_1LB1RE_1RB1LE_---0LE

Nobody knows, and it is a Collatz-type problem. The machine runs a counter that grows by half each phase and pays two pairs of a budget per phase; when the budget runs out it either halts or refills it, depending on parities that behave like coin flips. Lean proves that this description is exact.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 0. F is entered only from C0 (writes 1, moves L): 0 C>0. So a halt is the moment this pattern appears, with the head on the cell after >.

The records list every step at which the head reaches a cell no earlier step reached, with the side, the width so far and the whole tape: the first place to look for a repeating macro structure.

Macro structure

Two blocks, a budget and a suffix

Stop the machine every time the head, in state E, reads the 0 at the left end of the tape. The tape then always reads

E>0 1^a 0 1 0 1^b (0 1)^c (1 1 1 0 1)^k 1

two blocks of 1s, of lengths a and b, then a budget of c pairs 0 1, then a suffix of k words 11101. In one round the head runs to the end of the second block and back: two 1s leave the first block and three join the second, (a, b) → (a − 2, b + 3). When the first block is down to 1 or 0 cells the second block becomes the first, a new second block of 7 cells is started and two pairs are spent: (1, b, c) → (b, 7, c − 2), (0, b, c) → (b − 1, 7, c − 2) (and (2, b) first becomes (0, b + 3)).

So a phase takes the first block a to about 3a/2: (3a + 11)/2 for odd a and 3a/2 + 6 for even a, the map of Antihydra with other constants, and every phase costs two pairs.

When only one pair is left, the pairs are refilled from the second block: with a = 0 to b/2 − 3 or (b − 1)/2 pairs, with a = 1 and b odd to (b − 1)/2 pairs, and each refill adds one word 11101 to the suffix. With a = 1 and b even the machine halts. When no pair is left at all, the first word of the suffix serves as one more pair.

Lean proves each of these rules for all values (lean/Rules.lean), and from them that the machine halts from blank tape if and only if this map, started at (15, 7, 7, 1), reaches the halting case (halts_iff in lean/Map.lean).

Open question

A budget that runs out

From blank tape the budget has run out four times. At phase 4 (b = 124, refilled to 59 pairs), at phase 34 (b = 2,734,834, refilled to 1,367,414 pairs), at phase 683,741 the even budget ran out completely and a pair was taken from the suffix, and at the next phase, with a = 1 and b odd (a number of 399,948 bits), it was refilled to a number of pairs with 399,947 bits. Spending that budget takes about 2399,946 phases; no computer will get there.

Whether the machine halts at the end of that budget depends on whether the last phase ends with a = 1 or a = 0 and on the parity of b, numbers that behave like coin flips. If they do, each budget end halts with probability about 1/4 and the machine halts with probability 1, but proving anything about those parities is the same obstacle as for Antihydra and the Collatz problem.

Try the map. Each line is one phase: the first block a is spent two cells at a time (three cells join the second block each time), then the second block becomes the first and two pairs of the budget are paid. When the budget is down to its last pair the parity of b decides.

The shape of the run

Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).



After 109 steps the tape spans 25,918 cells (21,154 left of the start, 13 right), with a density of 1s of 0.999.

Heuristic
README
A coin flip per budget
When the last pair is reached the machine halts if the phase ends with a = 1 (rather than 0) and b is even. If those parities behave like fair coins each budget end halts with probability about 1/4, so the machine would halt with probability 1, but only after a time beyond any computation.

    
Open
Does it halt from blank tape?
Equivalent to whether the orbit of (15, 7, 7, 1) under the map ever ends a budget on the wrong parities: a Collatz-type question like Antihydra's, out of reach of current methods.
