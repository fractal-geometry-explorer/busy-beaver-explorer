OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 9 November 2026.

In short

The question is open. At each left record the tape is 0^inf ell B>c (10)^D1 x1 (10)^D2 x2 … with single cells x = 1 or 0. The blocks form a binary counter, incremented once per long sweep while the first block counts down by 2. An exact block macro machine (py/blockmm.py) maps each record to the next by cached symbolic crossings; it agrees with direct simulation at all 15,144 records of the first 3·108 steps. Its 387 crossing rules used in the first 300,000 records are proved in Lean (kernel) for every block size and tape, and so is the even long sweep over any list of blocks (carry_even). The composition of rules is trusted Python, not Lean. The macro run: no halt through 16,409,053 left records and 338,536,834,271,065 steps (3.39·1014), across 28 resets. At the resets the countdown block follows X → 3X/2 + 1 (X even) or (3X + 5)/2 (X odd), heuristically, so the long run is a Collatz-like question; random block lists that look like records can halt, so no simple invariant is available.

The reset map

At each of the 28 resets found, the countdown block X becomes X' = 3X/2 + 1 (X even) or (3X + 5)/2 (X odd) at the next one: 142, 214, 322, 484, 727, 1093, …, 8,204,530. The next block follows Y' ≈ 3Y/2 + c with c slowly growing (8 to 40). Each phase takes about 2.25 times as many steps as the last.

README.md

Shape of the records

In the first 105 records: no block (0, 1) after the first; after a 0-block the next block has D + x even; the first block has D + x odd (or, right after a reset, 1 B>1 then (0, 0) then a block with D + x odd). 99.99% of macro steps are a single sweep: crossings right, one turn, crossings left.

README.md

These patterns are not an invariant

py/random_check.py: one macro step from 20,000 random block lists. 2 of the 14,742 lists that obey the record patterns halt (and 2 of the 5,258 that do not), so the patterns alone do not exclude the halt.

Does it halt from blank tape?

Not known. Missing: a Lean proof that the composition of the macro rules is sound, and an invariant of the reachable block lists that excludes 1 A>1, or a halts_iff reduction to the Collatz-like reset map.
