Does this machine ever halt?

1RB0LF_0LC0RE_0RA1LD_1LB0LD_0RA1RC_1LA---

Nobody knows yet. The tape is a binary counter on blocks of 10s, each closed by one cell. Every sweep adds one while a countdown block shrinks; when it runs out, the blocks come back about 3/2 larger, by a Collatz-like rule. An exact macro machine, its rules proved in Lean, finds no halt in 3.39·1014 steps.

The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 1. F is entered only from A1 (writes 0, moves L): 1 A>1. So a halt is the moment this pattern appears, with the head on the cell after >.

First look

The shape of the run

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.495). Right of the start it stopped growing in the second half of the run (bounded so far, or growing so slowly that no record fell in the last half).

After 109 steps the tape spans 55,183 cells (40,157 left of the start, 13 right), with a density of 1s of 0.5.

Structure

Blocks at a left record

Look at the tape when state B stands left of every cell visited so far. Write P for the pair 10. The tape is 0^inf ell B>c P^D1 x1 P^D2 x2 …: runs of P, each closed by a single cell i (a 1) or o (a 0). The blank right end counts as endless blocks P^0 o. Right after a reset, B carries an extra 1 on its left.

The basic move

One sweep, one increment

From the record the head runs right with a phase bit: state A (α) or B/E (β). Crossing a block P^D x flips the phase when D + x is even, and the sweep turns at the first o-block with D + phase odd. On the way out 1010 is rewritten as 1100; the way back restores it. The result is one increment of a binary counter: the first block loses 2, the even i-blocks before the turn become o-blocks, the turning o-block becomes an i-block. Lean proves this for any list of blocks (carry_even), and the short sweep that follows (short).

The tool

An exact block macro machine

py/blockmm.py keeps the tape as two stacks of words, each a block written as (1010)^(t+4) x or 10 (1010)^(t+4) x (or literally when short). Crossing a word of a given kind from a given situation is computed once by a symbolic run valid for every t, and cached. 387 such rules cover the first 300,000 records, and each is a Lean theorem. The glue between them is Python: it is checked against direct simulation at 15,144 records, not proved.

The emergent behaviour

A Collatz-like reset map

When the countdown runs out, the next block X becomes the countdown. At every reset so far X goes to 3X/2 + 1 (X even) or (3X + 5)/2 (X odd), and each phase is about 2.25 times as long as the last. Some of the resets (X, Y the first two blocks after it):

The danger

Where it could halt

The only halting transition is F reading 1, and F is entered only from A reading 1. So the machine halts exactly on 1 A>1. The run never produces it. But random block lists that share every visible pattern of the records halt now and then (2 in 14,742), so ruling out the halt needs a finer description of which lists the run reaches.

Status

What is proved

Lean, kernel: the 387 crossing rules (lean/Rules.lean), the even long sweep over any block list (lean/Sweep.lean), the short sweep and the reach from blank tape.

Computed: the macro machine matches direct simulation at 15,144 records; the macro run finds no halt in 3.39·1014 steps.

Open: Lean soundness of composing the rules, an invariant excluding the halt, and so the question.

Heuristic
README.md
The reset map

At each of the 28 resets found, the countdown block X becomes X' = 3X/2 + 1 (X even) or (3X + 5)/2 (X odd) at the next one: 142, 214, 322, 484, 727, 1093, …, 8,204,530. The next block follows Y' ≈ 3Y/2 + c with c slowly growing (8 to 40). Each phase takes about 2.25 times as many steps as the last.

Heuristic
README.md
Shape of the records

In the first 105 records: no block (0, 1) after the first; after a 0-block the next block has D + x even; the first block has D + x odd (or, right after a reset, 1 B>1 then (0, 0) then a block with D + x odd). 99.99% of macro steps are a single sweep: crossings right, one turn, crossings left.

Heuristic
py/random_check.py
These patterns are not an invariant

py/random_check.py: one macro step from 20,000 random block lists. 2 of the 14,742 lists that obey the record patterns halt (and 2 of the 5,258 that do not), so the patterns alone do not exclude the halt.

Open
Does it halt from blank tape?

Not known. Missing: a Lean proof that the composition of the macro rules is sound, and an invariant of the reachable block lists that excludes 1 A>1, or a halts_iff reduction to the Collatz-like reset map.
