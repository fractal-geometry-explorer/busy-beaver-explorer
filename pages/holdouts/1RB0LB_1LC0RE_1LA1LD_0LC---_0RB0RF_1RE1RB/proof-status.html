What is known about 1RB0LB_1LC0RE_1LA1LD_0LC---_0RB0RF_1RE1RB

1RB0LB_1LC0RE_1LA1LD_0LC---_0RB0RF_1RE1RB

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

Open, and probably never halting. The run from blank tape is, provably, the orbit of a Collatz-like map E(a, m) → E(a', m') with m' ≈ 4m/3 and a counter a that changes by +6, −1 or +4 according to m mod 3 (Lean, kernel-checked for all a ≥ 1 and m ≥ 2). The machine can only halt if the counter runs out; Lean checks that it does not in the first 20,000 map steps (more than 105000 machine steps). The counter drifts up by 3 per step, so the chance that it ever comes back down to 0 is about 10−28,000: the same kind of question as Antihydra.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Bell-like. Its 3 November 2026 edition lists the machine as a cryptid: its halting is thought to come down to a Collatz-like question that no known method decides. These are labels read off the run by others, not results.

The E-step map, for every counter and gap

With E(a, m) = 1 0 0 (10)^a 0^m E> 1 on blank tape: for a ≥ 1 and m ≥ 2 the machine goes to E(a+6, 4k+4) if m = 3k, to E(a−1, 4k+7) if m = 3k+1, and to E(a+4, 4k+4) if m = 3k+2, in exactly 4k²+23k+16a+94, 4k²+23k+28 and 4k²+23k+8a+56 steps. Proved from symbolic rules (a loop that turns three 0s of the gap into two 10, iterated by induction, and the three ends) for all values.

emap_sound, lean/Map.lean; rules in lean/Rules.lean (from py/rules.py)

The run from blank tape follows the map

The machine reaches E(4, 124) at step 9,008, and from there the run is the orbit of (4, 124) under the map for as long as the counter stays positive. Hence: if the counter never runs out, the machine never halts.

heuristic Evidence only

Probviously non-halting: a random walk drifting away from 0

If m mod 3 behaves like a fair three-sided die, the counter is a random walk with steps +6, −1, +4 (drift +3). The chance of ever coming down by d is about λd with λ = 0.33489 the root in (0,1) of λ7+λ5+1 = 3λ: about 10−27.6 from a = 58 at 1.08·1010 steps and about 10−28,700 from a = 60,462 where Lean leaves it. bbchallenge lists the machine as an Antihydra-like cryptid (Racheline, November 2024).

Does it halt from blank tape?

Not known: it halts only if the counter of a Collatz-like orbit runs out (and then only in some cases: at a = 0 with m = 1 mod 3 some gaps halt, others turn into a translated cycler or restart the counter). Deciding this is a problem of the Antihydra kind.
