What is known about 1RB---_1RC0LF_1RD1RD_1RE1RA_1LF0RC_1LC1LB

1RB---_1RC0LF_1RD1RD_1RE1RA_1LF0RC_1LC1LB

OpenNobody has proved whether this machine halts. Everything below is what is known so far.

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Seen at the moments the head, in state E, reaches a new cell on the right, the tape is a list of numbers: 1^(3a) 0 1^(3m1+2) 0 1^(3m2+2) 0 … 1^(3mk+2) 0 E>0, a first run of 1s whose length is a multiple of 3 and then blocks of 1s each two more than a multiple of 3, each followed by a single 0. In the 1011-step run 107 of the 130 such moments have exactly this form; the others are the moments when the head has just come back from the left end. The list ends in 2 0 0 … 0, and each new cell on the right appends one more 0 (a block 1 1 0). Further left one or two numbers change at each record, a pattern that walks left one block per record, and the time between records doubles each time: a binary clock. When the walk reaches the left part, the head visits the left end, the list is rewritten and a new walk starts.

At each new cell on the right in state E the tape is 1^(3a) 0 followed by numbers m written as blocks 1^(3m+2) 0 (most m are 0, 1 or 2), ending in a 2 and a run of 0s that grows by one at each record. Between two records the head runs over the list many times and the time doubles. From record to record a disturbance (a 3 or a 4) moves one number to the left; when it reaches the left end the first number a changes and, a few records later, the phase ends and the list is rewritten.

Status as of 9 November 2026.

In short

The question is open. The machine halts exactly from C> x 1 1 (both directions in Lean), never seen in 1011 steps. The run goes in phases: inside a phase every new right cell in state E takes twice as long as the previous one (up to a few hundred steps), one more 0 is appended to the list and a carry walks one number to the left. The phases seen end at steps 142,951,915, 776,063,293 and 1,601,996,125, each after the carry has reached the left end and changed the first number; the fourth ended at step 136,228,769,152 exactly as the earlier ones (first number 4, then 1, 1 3, 5, end), and the fifth repeats the corrections to doubling of the fourth, record for record, 7.7 times slower.

The halting context

From C> x 1 1 the machine reaches its halting transition (proved step by step, then step_none_iff). The halting transition is A reading a 1. A is entered only from D reading a 1, and D only from C, which writes a 1 and moves right whatever it reads. So C halts two steps later exactly when the two cells after it are both 1 (Lean: halt_ctx, halt_ctx'; the converse, that no other configuration halts two steps later, is halt_iff_2). C is entered from B on a 0, from E on a 1 (both moving right) and from F on a 0 (moving left, so F would need 0 1 under and after it); halt_pred_3 lists exactly these configurations three steps before a halt.

The walking carry and the end of a phase

Read as numbers (py/blocks.py), each record of a phase appends a 0 and moves a 3 or 4 one place left (... 1 1 3 1 0 ..., ... 1 3 1 1 2 ..., ... 3 1 1 1 2 ...). The first number a was 4 through each phase until the carry arrived; then a = 1 (steps 249,125,544 and 915,762,320), then 1 3, then a = 5, and the next record ended the phase (a = 5 at 106,838,677, 567,646,766 and 1,331,610,646; ends at 142,951,915, 776,063,293 and 1,601,996,125). In the current phase a = 1 at step 24,189,918,303. The same sequence ended phase 4: a = 1 with 1 3 at step 46,777,495,938, a = 5 at 91,952,651,237, end at 136,228,769,152.

The clock test

At the visits of the right end in state C on a 0 the tape is W (0 1 1)n 0 C>0. From the visit at step 1,603,719,355 (n = 1), the word W at the visit with n = k+2 is the word at the visit before after exactly 2k applications of one base map (the run from the visit with n = 1 to the next), for k = 0, …, 8 (up to 256 applications). This is the clock of the machines of holdouts/1RB0RA_0LC0RE_1LE1LD_0LE---_1LF0LC_1RA1LE, found by running the machine; its tick is not proved (the head works through the block like a counter, which is not the sweep–trip–merge template of gen_clock.py).

Growth shape: exp/exp

Left of the start, the visited part of the tape grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.047). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.083).

Phases repeat

The corrections c to exact doubling repeat from phase to phase: phase 4 has 177, −347, 93, 113, 9, 93, −179, 197, −179, 113, 9, 9, 361, −395, 29; phase 5 starts with five more records (29, 221, 241, 9, 9) and then repeats 177, −347, 93, 113, 9, 93, −179, 197, −179, 113, 9 up to step 222,918,842,017, each record 7.7 times longer than its match in phase 4. Extrapolated, phase 5 ends near 1012 steps. A phase end, where the left end is rewritten, is where the halting context would have to appear.
