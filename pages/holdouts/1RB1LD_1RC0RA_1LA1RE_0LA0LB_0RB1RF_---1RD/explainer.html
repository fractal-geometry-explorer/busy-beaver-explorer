The machine

6 states, two symbols, 1 halting transition

Each entry says what to write, which way to move and which state to enter. The machine starts in A on a blank tape (all 0s).

The machine stops when it is in F reading 0. F is entered only from E1 (writes 1, moves R): E>1 0. So a halt is the moment this pattern appears, with the head on the cell after >.

What it does

Three counters on one tape

Every time the head turns left into state D, the tape is one of

X(a,b,c) = 0^∞ 1^a 0  (10)^b 1 D> 0 1^c 0^∞
Y(a,b,c) = 0^∞ 1^a 00 (10)^b 1 D> 0 1^c 0^∞
Z(a,c)   = 0^∞ 1^a 0 D> 0 1^c 0^∞

a block of ones on the left, a block of 10s in the middle and a block of ones on the right, with the head between the last two. Between two such moments the head makes one trip over the middle block.

In X, each trip takes 3 ones from the left block, adds 2 10s to the middle block and uses one cell of the right block. In Y it is the other way round: the left block gains 3 and the middle block loses one 10. When a block runs out, a boundary rule switches between the shapes.

Lean proves every rule for all values (lean/Rules.lean), that the run from blank tape is at X(2,0,3) after 29 steps, and that the machine halts exactly when the orbit reaches some Z(a,2) (halts_iff). The direct run agrees with the map, step counts included, for the first 1.1·1010 steps.

Rounds

A doubling stage and an endgame

A round starts at X(0,0,N): the whole tape is N ones. It opens with a doubling stage, five rules per lap:

X(A,0,C) → X(1,…) → Y(3,…) → Y(…,0,…) → Z(…) → X(2A+8, 0, C−A−6)

from A = 7 and C = N − 6, so A + 8 = 15·2i, until the right block is too short for another lap. A short endgame follows (sometimes with a second doubling stage) and ends at X(2,b,1) → X(0,0,2b+9), the next round.

Does it halt?

One coincidence, never met

The only way to halt is a Y run that starts with c − b = 3: its middle block empties when the right block has 3 ones, the next rule gives Z(a,2), and the machine reaches F reading 0. In the doubling stage b and c are both even, so this cannot happen there. In the endgame nothing rules it out, but c − b is a number of the size of N, so the chance is about 1/N.

Iterating the map for 2,000 rounds (N about 10756, about 101511 steps) shows no halt; the closest approach after round 3 was |c−b−3| ≈ 10−5.5 N. A proof would need a closed form of the endgame, which is not known.

First look

The shape of the run

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.467). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.091).

After 109 steps the tape spans 35,203 cells (28,806 left of the start, 67 right), with a density of 1s of 0.813.

Heuristic
README
Almost surely nonhalting

Halting needs c − b = 3 exactly at the start of a Y run. In the doubling stage b and c are both even, so it cannot happen there; in the rest of a round, if c − b behaves like a random number of size N, the chance is about 1/N per run, and the sum over all later rounds is negligible. The closest approach after round 3 was |c−b−3| ≈ 10−5.5 N, over 2.5 million Y runs.

Open
Does the orbit ever reach Z(a,2)?

The endgame of a round (after the doubling stage) has no closed form yet; without one there is no handle on the coincidence.
