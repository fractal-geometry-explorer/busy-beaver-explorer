1RB0LE_0LC0RB_1RD1LD_1RA1LF_0LB1LE_---1LB

Nobody knows whether this six-state machine halts from blank tape. Its tape is a block of 1s at the left end and a word of short blocks on its right. The block is a clock: each tick makes it 3 cells longer and sends the head into the word twice as many times as the tick before; every trip rewrites the word by one fixed map P. This page lists what has been established, sorted by what each result rests on.

Status as of 9 November 2026.

In short

The question is open. The clock is proved in Lean for every k: tick k applies P 2k times whenever the 2k trips all return (a hypothesis met by the actual run, checked in Lean for its first 15 trips). An exact accelerated simulator built on it follows the run through 65 phases to 6.04·10187 steps without a halt; what happens at a phase end (a trip that does not return) is not described by a formula.

The halting configurations

The machine stops exactly when F reads a 0 (proved for every configuration). F is entered only from D reading a 1 (1LF, from the table), so a halt is the head in D on a 1 whose left neighbour is 0.

step_none_iff, lean/Blank.lean

No halt in the first 10,000 steps

The list simulator of the shared library, proved to agree with the machine's semantics, runs 10,000 steps from blank tape without a halt, evaluated by Lean's kernel.

blank_runs_kernel, lean/Blank.lean

Shift rules

B erases a block of 1s rightwards; E walks left over a block of 1s and stops on the 0 before it.

bclear, ewalk, lean/Rules.lean

The tick, for every k

If 2k P-steps (each a trip L 0 0 0 1 1 A> W → L E> 1^4 0 W' valid for every left tape L) take the word W to W' with total cost E, then L 0 0 0 E> 1^(4+3k) 0 W reaches L E> 1^(7+3k) 0 W' in exactly E + 19·2k − 3 steps. The tick is the sweep (the block becomes 0s), one P-step, the ticks 0, …, k−1 (each eats three of the 0s) and the merge.

tick, tick_left_end, lean/Clock.lean; rule_sweep, rule_merge, lean/ClockRules.lean

The clock carries the real run

From step 470, where the run from blank tape is E> 1^4 0 W, the 15 P-steps of the next four ticks are proved for the actual words, and the tick theorem then takes the run to step 2,964, E> 1^16 0 W', exactly the configuration of the plain run there: the hypothesis of the tick is not vacuous.

run_ticks, lean/Instance.lean (written by py/instance.py)

Where it can halt
