1RB0LD_0RC1RD_1LA1RA_1LE0LE_1RF0LA_0RA---

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 13 November 2026.

In short

Open, but the whole map is now known and no halt is in sight. Sample the run when the head is in state D at the left end: the tape is DL(m, T) = D> 1 00 (10)^m T with a short tail word T. One round multiplies m by 4/3 and rewrites T; for m ≥ 30 it depends on m only through m mod 3, so the round map (m, T) → ((4m + c(r,T))/3, τ(r,T)) is computed exactly from small representatives. It matches every DL event of the direct run up to 5·109 steps and was iterated for 100,000 rounds (past 1024990 steps) without a halt. The P-map of the first analysis (T = 1) is proved in Lean for every n. No (residue, tail) pair met so far, among 90,000 explored, halts.

A round depends on m only mod 3

For each (r, tail) pair used, four representatives m = 3j + r (j = 10..13) give the same tail τ(r,T), the same c = 3m' − 4m and a step count quadratic in j; the iteration relies on this. A Lean proof would state each round with symbolic k (the D-loop lemma already allows any tail).

Rounds between end events, by remainder class

Sample the run whenever the head is in state D reading 1 with only 0s to its left. Read rightwards from the head, the tape is then A U^m B: one long periodic block between two short context words. For each class (A, U, B, m mod 3) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·109 steps (30 events) the class map predicts the next event in all 21 rounds it applies to. This is an extrapolation checked by computation, not a proof.

heuristic Evidence only

Growth shape: exp/sqrt

Left of the start, the visited part of the tape grows like the square root of the step count, the signature of a head sweeping back and forth across the whole tape and adding a cell or a few at the end of each sweep (a bouncer-like shape) (fitted exponent 0.509). Right of the start it grows like the logarithm of the step count: each new cell costs a roughly constant factor more time, the signature of a counter or of a Collatz-like map whose values are written on the tape (fitted exponent 0.079).

No halting round is known at all

The tail behaves like a recurrent random process (driven by m mod 3, which is pseudo-random) on a language of block lists. Exploring the tail graph breadth-first with every residue allowed (30,000 tails, 90,000 rounds) finds no round that halts. So a halt is not merely unlikely: no reachable way to halt is known; this hints at an invariant that a stronger decider could prove.

Does it halt from blank tape?

Not proved either way. The round map is a finite-state rewrite of the tail word, so a proof of non-halting would be an invariant on the tail language that excludes the halting pattern (D reading 0 with a 0 on its left).
