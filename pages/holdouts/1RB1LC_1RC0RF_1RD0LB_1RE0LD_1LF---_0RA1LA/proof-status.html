What is known about 1RB1LC_1RC0RF_1RD0LB_1RE0LD_1LF---_0RA1LA

1RB1LC_1RC0RF_1RD0LB_1RE0LD_1LF---_0RA1LA

Open: a cryptidIts halting is thought to come down to a Collatz-like question that no known method decides (the community's label, not a result).

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 22 November 2026.

In short

The question is open, and it is a Collatz-like one. The run from blank tape is proved in Lean, with exact step counts, through the whole first level (more than 101543 steps) to the first configuration of the second level. Every reset at a short tail is a theorem for every n, and the list of short tails closes up after a third level: two classes halt, 29 classes loop forever, and the others start a new level or a new phase. Every level runs a prefix of one orbit of one digit map, f(10a + d) = 31a + K[d/2] from 22, and Lean proves the machine halts exactly when the walk halts where that orbit runs out of the 772-digit budget of level 2: about 2·10770 steps along it, with no closed form known.

Other proofs and outside reports

A halts-iff map in DeepMind's Lean, compiled here

M_1RB1LC_1RC0RF_1RD0LB_1RE0LD_1LFHHH_0RA1LA.lean in google-deepmind/cryptids (commit 3647718, 12 November 2026) proves IsHalt target ↔ CollatzHalts next start: the machine halts from blank tape if and only if an explicit map reaches its halting case. The module also proves a coarser higher-level version of the map. We built it with Lean v4.35.0-rc4 on 2026-11-17 (BusyBeaver.M_1RB1LC_1RC0RF_1RD0LB_1RE0LD_1LFHHH_0RA1LA.isHalt_iff_acceleration); it rests only on the axioms propext, Classical.choice, Quot.sound, and its transition table was checked against this machine. This repository has no finished halts-iff map for this machine. Halting itself stays open.

Community label

In the community's BB(6) tracker the machine's class is Bell-like. Its 3 November 2026 edition lists the machine as a cryptid: its halting is thought to come down to a Collatz-like question that no known method decides. These are labels read off the run by others, not results.

From blank tape to the start of the second level

Before the long tail exists the tail after the d block is 1001, and its resets are rules for every n: (n, 0) starts the new phase (10, ⌊n/2⌋ − 1) and (n, 2) the phase (10, ⌈n/2⌉ + 6), both keeping 1001; (n, 1) writes the long tail, (17, 0) with 10 (1110)^(n+6) 1. The first 7,106 steps (evaluated by the kernel on the list simulator) reach (10, 10) with the tail 1001; periods and these resets then give the phase ends (72, 0), (227, 0), (692, 2), (2,180, 2), (6,799, 1) and (17, 0, 6805) at step 374,475,636, exactly as measured. Level 1 (the phase map, previous claim) ends after 2,177 phases at (N, 3, 0) with the suffix 1; that reset reads the suffix and reaches (17, 0) with the tail 10 (1110)^(N+20) 1001101011001 in 440N + 9367 steps. So from blank tape the machine reaches, without halting, the first record of level 2, with N ≡ 63 (mod 100), 10771 ≤ N < 10772, after more than 101543 steps.

A halting class on the second level, and the way into it

From 0^inf B> 0 0 1 (1100)^(n+1) (10110110)^2 10 (1110)^2 1001101011001 0^inf the machine halts, for every n. The class is reachable from larger tails through the proved reset table: a phase end with six words 1110 left, r = 0 and n ≡ 0 or 9 (mod 10) resets to (10, ⌊(n+5)/2⌋) with two words left, and its periods end at r = 2: the machine halts. On the first-level tail (suffix 1) no class halts.

Fourteen classes never halt

The loop record 0^inf B> 0 0 1 (1100)^(n+1) 0 1 0^inf reaches the same record with five more words 1100 in 80n + 395 steps, so from it the machine runs for ever. Two classes of the tail 1001, six of the first-level tail and four of the second-level tail (and the loop record itself) reach it; for example r = 1 with the tail 101, seen for 3,000 rounds on 13 November, is now a theorem.

The third level: the short tails close up

Some second-level resets leave a short tail that is not a nearly empty tail of a suffix: 1100 1011001, 10 1101001, or 1001101011001 right after the d block. The reset at each of them, for every r that occurs, and at every short tail those lead to, is a theorem for every n: 39 rules. Only nine further short tails come up, and then nothing new, so the list is closed. One new suffix appears, 1011001: from 1001101011001 right after the d block with r = 0 the machine builds a long tail of n + 3 words 1110 ending in 1011001, the third level, and all fourteen nearly empty tails of that suffix are among the 39. The ends are: a long tail of suffix 1, 1001101011001 or 1011001 (a new level 1, 2 or 3), the tail 1001 of level 0, the loop record (fifteen more classes that never halt), or a halt: 0^inf B> 0 0 1 (1100)^n (10110110)^2 10 1101001 0^inf halts for every n. A second-level phase end with r = 2, one word 1110 left and n ≡ 6 or 7 (mod 10) gets there through the periods, so it halts too. With the generic rows of the reset table, which hold for any suffix, every reset the machine can meet from these levels is now proved: the run is a walk through a finite table of proved transitions, driven by the numbers n, r and t.

Halting is a question about one map on numbers

Every proved rule is put into one function on records (n, m, T), where T is a long tail of one of the three suffixes or one of the ten short tails. It applies the periods, the generic reset, or one of 72 rows for the nearly empty and short tails, and it ends in a halting class or in the loop record. Lean proves that the table covers every record the run can meet, and that each step is a real run of the machine. The machine halts from blank tape if and only if this walk, started at (17, 0) with 6805 words 1110 and the suffix 1, reaches a halting class. The walk is plain arithmetic, but level 2 alone takes about 10771 of its steps on numbers of about 10770 digits, so it cannot be followed to the end.

halts_iff_walk, walk_iff, wstep_good, lean/Walk.lean (generated by lean/walk.py); axioms propext, Quot.sound, Classical.choice

Every level is a prefix of one orbit of one digit map

On a long tail the walk of the table is the map f(10a + d) = 31a + K[d/2], K = 15, 27, 47, 35, 36, on one number x that stands for the phase end (10 + 31⌊x/10⌋, ⌊(x mod 10)/2⌋); one step of f uses 4, 5, 8, 3 or 2 words 1110 for r = 0, ..., 4, for every suffix. Every level starts at (17, 0), which after one phase is x = 22, so every level runs the same orbit 22, 89, 284, 915, ... and stops where its words run out. Level 1 (6801 words) stops after 1566 steps at r = 3 with no word left (by decide). The machine halts from blank tape if and only if the walk halts from the state where the orbit of 22 stops with the 772-digit budget of level 2.

Available in Lean here as a cited axiom: DeepMind's halts-iff map

deepmind_halts_iff states on this repository's definitions what DeepMind's compiled theorem proves: the machine halts from blank tape if and only if the orbit of their map next from start reaches none. The map is copied from their file unchanged, and running the copy and theirs for 120 steps gives the same states. It is an axiom: nothing in this repository proves it, and the translation from DeepMind's definitions (Mathlib's Turing machines) to ours is not checked by Lean. #print axioms names it in every theorem that uses it.

No halt in the first 10186095 steps (region-memo accelerator)

The region-memo accelerator tools/py/bbtools/regaccel.py ran with blocks of 8 cells, from blank tape for 1800 seconds and reached a step count of 186,096 digits (so at least 10186095) without a halt. With blocks of 4 cells the same engine stalls near 109: the words 10110110 of length 8 split into two different 4-cell blocks, so every run of them is broken up; with blocks of 8 they become one long run, and the first and second level of the counter are both visible on the tape ((11101110)^~10^771, the second-level tail of about 10771 words). It keeps the tape run-length coded and, for each stretch of tape from the left end, a macro (the run until the head first leaves that stretch) computed by a symbolic run of the machine with the long runs as variables; a macro is used only when the linear inequalities its symbolic run assumed hold, otherwise the stretch is run again by the same recursion. So the run is exact, step count included. Check: 7 configurations of this run (every time the head faced blank tape on the right, up to 2×109 steps) agree cell for cell with a direct run (tools/py/regcheck.py). This is a bounded run and says nothing about later steps.

heuristic Evidence only

Where the real run stands

The first level of the real run is proved (above) and ends at (N, 3, 0), N ≡ 63 (mod 100), a number of 772 digits; the second level starts with a tail of N + 20 words 1110 (proved). It then lasts about (N + 20)/2.5 phases of the proved phase map, about 10771, with n roughly tripling in each, and how it ends (one of the two halting classes, a loop, a return to the tail 1001 or a third level, all in the proved and closed table) depends on r, t and the parity or last digit of n at that moment, which nobody can compute. So the closed-set method does not apply: a halting class is reachable, and this is a Collatz-like question.

py/m7map.py, README

How a level ends, measured on the real orbit

Along the first 40,000 steps of the orbit of 22 each value of r comes up 19.7% to 20.2% of the time. Weighting every budget that stops between steps 2,000 and 40,000 alike, a level with the suffix 1001101011001 (level 2) ends in a proved loop 59.7% of the time, starts level 3 22.8%, level 1 7.6%, level 2 4.5%, and halts 5.4%. Chaining these odds over levels gives about a 6% chance that the machine ever halts. The last digits of an orbit are a one-to-one recoding of the start's digits (31 is invertible mod 10k), so no rule reading a bounded number of digits predicts the end, and no closed form for the orbit at step 2·10770 is known.

Does it halt from blank tape?

Not known. The only halting transition is E reading 1. It is proved that the machine halts exactly when the walk of the proved table halts from the point where the orbit of 22 under the digit map f(10a + d) = 31a + K[d/2] runs out of the 772-digit budget of level 2. That point is about 2·10770 steps along the orbit; no closed form is known, and the real orbit's statistics suggest a proved loop is the likeliest end (about 6% for a halt).
