Open: a cryptidIts halting is thought to come down to a Collatz-like question that no known method decides (the community's label, not a result).

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape: it is one of the holdouts left open by the bbchallenge project. This page lists what has been established about it, sorted by what each result rests on.

Status as of 8 November 2026.

In short

The question is open, and it is a Collatz-like one. The first level of the run is decoded (the period rule is proved in Lean, the resets are measured). When the tail the resets feed on runs out it is rebuilt, and on the second level there are remainder classes that halt, classes that loop forever and classes that build a third level, all checked by direct simulation. Which one the real run meets is decided after about 10770 phases by the last digit of a number that triples every phase.

Other proofs and outside reports

Community label

In the community's BB(6) tracker the machine's class is Bell-like. Its 3 November 2026 edition lists the machine as a cryptid: its halting is thought to come down to a Collatz-like question that no known method decides. These are labels read off the run by others, not results.

With a nearly empty second-level tail, one remainder class halts

From 0^inf B> 0 0 1 (1100)^n (10110110)^2 10 (1110)^2 1001101011001 the machine halts, for every n tried (60 to 69, 80, 101; 31,436 steps at n = 60). The class is reachable from larger tails: with six words 1110 left, r = 0 and n ≡ 0 or 9 (mod 10), the next phase ends in it and halts (n = 60, 69, 160, 1009 checked by direct simulation). With the first-level tail (ending in a single 1) no class with 0 to 7 words left halts.

Other classes loop forever or rebuild the tail

With an empty or nearly empty tail the other classes either enter a loop that adds five words 1100 per round without end (seen for 3,000 rounds; for example r = 1 with the tail 101), or rebuild a tail of about 3.1 n words 1110 with the suffix 1001101011001, or reach a short tail (1, 1001, 1011101). The tables list every class with 0 to 7 words left for both tails, n = 60 to 69.

Where the real run stands

Iterating the reset table (measured, not proved, for all n) the first level ends after 2,176 more phases at r = 3 with three words left and n ≡ 11 (mod 100), a number of 771 digits. For n ≡ 1 (mod 10) that reset builds the second-level tail with 31(n−1)/10 + 92 words (checked for n = 61 to 211). The second level then lasts about 10770 phases, n roughly tripling in each, and how it ends (halt, loop or a third level) depends on n mod 10 and r at that moment, which nobody can compute. So the closed-set method does not apply: a halting class is reachable, and this is a Collatz-like question.

open Open

Does it halt from blank tape?

Not known. The only halting transition is E reading 1. The first level (periods and the reset table) is decoded with exact step counts and never halts while the tail lasts; the question moves to the resets at a nearly empty tail, which start a next level whose numbers have hundreds of digits.
