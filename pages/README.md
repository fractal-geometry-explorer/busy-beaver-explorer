# Pages

Eleven self-contained HTML pages. Open any of them in a browser; they need no server. They load two fonts from Google
Fonts and fall back to system fonts offline. `index.html` is a landing page that links to the eleven, and
`.github/workflows/pages.yml` publishes this folder to GitHub Pages on every push to main.

| page | machine | what it shows |
|---|---|---|
| [`proof-status.html`](proof-status.html) | the holdout | where the formal proof stands: what `blank_halt_open_big` and the kernel-only `blank_halt_open_far_kernel` say, what each result trusts, what is open, and how to check it |
| [`closing-gap-rule-map.html`](closing-gap-rule-map.html) | the holdout `1RB0RE_1LC0RA_1LA1LD_1LA---_0RF0LB_0LD1RE` | the summary of the research in [`../bb6-holdout`](../bb6-holdout): what each rule does, the mark model, the loop and how it ends, and the table "What is established, and how firmly" |
| [`mark-rule-stepper.html`](mark-rule-stepper.html) | the holdout | steps the mark rules one round at a time from a tape you choose; on small tapes each round is also run on the bare machine and compared |
| [`1RB1RA_1RC1LB/proof-status.html`](1RB1RA_1RC1LB/proof-status.html) | the machine `1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB` | its proof status: what is proved in Lean, computed, or only observed, from [`../bb6-1RB1RA_1RC1LB`](../bb6-1RB1RA_1RC1LB) |
| [`1RB1RA_1RC1LB/reduction.html`](1RB1RA_1RC1LB/reduction.html) | the same machine | the reduction from the machine to "is N = 10 + Σ p_l·2^(m−l) ever a power of two?", link by link, with what each link rests on and a section to update as the open work lands |

The champion is a different machine from the holdout. Its two pages came first, and the holdout pages share their
design.

## Sources

Two pages are generated by Python 3 scripts that use only the standard library. Running a builder rewrites its page
here, and at the move both builders reproduced the committed pages byte for byte.

- `src/closing-gap-rule-map/build_m2.py` builds `closing-gap-rule-map.html`. `data_m2.py` and `m2sim.py` simulate the
  machine for every tape frame on the page; `established.py` is the table "What is established, and how firmly";
  `data/` holds the measured figures the page charts, from runs described in the research log. When a result changes,
  edit `established.py` or the text in `build_m2.py` and rebuild rather than editing the HTML.
- `src/champion-rule-map/build_map.py` builds `champion-rule-map.html` from `frames_out.json`, `warmmap.json` and
  `warm_tapes.json`. The first two are written by `frames.js` and `warmmap.js`, which run the champion on `engine.js`
  (the simulator of the explorer page):

  ```sh
  cd src/champion-rule-map
  node frames.js . '[["real",845,848,4,3],["real",835,839,2,6],["real",1064,1067,6,4],["real",1030,1044,9,11],["real",1013,1013,40,20]]'
  node warmmap.js .
  python3 build_map.py
  ```

  `warm.js` prints the warm-up of the run from blank tape that `warm_tapes.json` records.

`1RB1RA_1RC1LB/proof-status.html` is built by `../tools/pages/build_status.py` from
`../bb6-1RB1RA_1RC1LB/status.json`; `1RB1RA_1LC1LD/proof-status.html` the same way from
`../bb6-1RB1RA_1LC1LD/status.json`, and `1RB1RA_1RC1LB_1LD0RA_1LB0LE/proof-status.html` from
`../bb6-1RB1RA_1RC1LB_1LD0RA_1LB0LE/status.json`. Edit the JSON and rebuild. The status panel of
`1RB1RA_1RC1LB_1LD0RA_1LB0LE/explainer.html` comes from the same JSON: after editing it also run
`python3 ../bb6-1RB1RA_1RC1LB_1LD0RA_1LB0LE/py/explainer_status.py`; the rest of that page is written by hand.

`1RB1RA_1RC1LB/reduction.html`, `1RB1RA_1RC1LB/top-blocks.html` and `1RB1RA_1RC1LB/explainer.html` are written by hand. The reduction's section "What is
proved, what is trusted, what is heuristic" (marked `STATUS` in the HTML) is the part to update when a result changes,
together with `status.json`. The explainer's engine is the `<script id="engine">` block;
`../bb6-1RB1RA_1RC1LB/tests/test_explainer.py` runs it in Node against `py/macro.py`, `py/waves.py` and the reference
simulator.

The holdout's proof-status page, the stepper and the explorer are written by hand: the HTML file is the source. When a result
changes, update `proof-status.html` along with `established.py`. The stepper's mark-rule engine is also
in `../bb6-holdout/stepper/engine.js`, where the Node scripts cited in the research log use it.
