What is known about 1RB1RA_1RC1LB_1LD0RA_1LB0LE, and what is open

1RB1RA_1RC1LB_1LD0RA_1LB0LE_1LF1LD_---0LD

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape. This page tracks what has been established about it, sorted by what each result rests on. (It shares its first three states with 1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB, which has its own page; the two are different machines.)

The run is made of passes, and a pass is a map on the lengths of the blocks of ones. The closed form of that map is proved in Lean for every block list, and with it the reduction: the machine halts only if some pass's sweep stops at a block of a single 1.

Status as of 31 October 2026.

In short

The question is open. Lean proves no halt in the first 20,000 steps by the kernel alone and in the first 107 steps with native_decide; the C simulator finds no halt in the first 1011 steps.

Where it stands. At the start of each pass the tape is 1^y1 0 1^y2 0 … 0 1^yk A>0. Lean's kernel proves the closed form of the pass map for every block list, that a pass adds exactly four ones, that a halt needs the last block odd and all others even (so an odd number of ones), and from these the reduction: if the machine halts from blank tape, the orbit of block lists reaches a pass whose sweep stops at a block of a single 1 (halts_only_by_one). In 2·107 passes it never does: after pass 50 the smallest such block is 59, and the lists have 2 to 6 blocks, all of them a fixed fraction of the tape except a tail that halves each pass.

The pass

A pass starts with A on the blank cell right of the tape. A, B and C write three ones and D turns back (start). D and E then run left writing 0 and 1 in turn (de_sweep), halving the last block into (10)^m. Where E reaches a 0 between blocks it crosses into the next block on the left (e_cross), unless that block is empty: then F reads a 0 and the machine halts. Where D reaches one, the sweep ends (d_stop), and A, B and C zigzag back to the right end, each round absorbing a 0 1 and moving a 0 one cell right (zig), until C meets a 0 at the right end and the next pass begins.

So the last block is crossed if it is odd, the blocks before it are crossed while they are even, and the sweep stops at the first odd one, yj. The closed form (py/passmap.py): if yk = 2m is even, the last block goes and the two before it each gain m+2; if yk is odd, yj-2 gains (yj−1)/2, yj-1 gains (yj+1)/2 + hj+1, and the blocks from yj on become hj+1+hj+2, …, hk-1+hk, hk−1, with hi = yi/2 and hk = (yk+5)/2. The blank on the left counts as empty blocks. A stop block yj = 1 is the one case outside the form, and there the count of ones changes by an odd number.

The pieces of a pass, for every length

Each phase of a pass as a theorem about any tape around it and any block length: the start, the D/E sweep over an odd or even stretch, the crossing into the next block, the end of the sweep, one round of the zigzag, and the A and B sweeps. Proved along symbolic runs (single steps by rfl, repeats by the shared crossing lemmas).

The closed form of a pass, for every block list

The pass map is defined in Lean (next, with the sweep, the stop and the zigzag as sweep, bump and zag), and the machine follows it: from the pass start of any block list it reaches the pass start of next of it, and it halts whenever next says halt. Every block list, every length; the zigzag and the sweep are inductions on top of the pieces. The only case left out is a sweep that stops at a block of a single 1.

pass, pass_halt, lean/Pass.lean

The reduction to a stop block of 1

A pass adds exactly four ones and keeps every block nonempty (next_sum); a halting pass needs an odd count of ones (next_halt_odd). So pass n from blank tape starts with 4n ones and no pass halts (orbit_ok, orbit_ne_halt), and if the machine halts from blank tape then some pass of the orbit stops at a block of a single 1 (halts_only_by_one). Kernel only; the standard axioms (propext, Quot.sound, Classical.choice), no native_decide.

The closed form matches every pass of the first 109 steps

Every time the head is in A on a new cell at the right end in the first 109 steps (1,005 times), the tape is blocks of ones separated by single 0s, and the block lists are exactly the orbit of the closed form from [2, 2]. Pass n starts with 4(n+1) ones. The test checks the first 108 steps.

The orbit stays away from a stop block of 1

2·107 passes of the closed form from [2, 2]: no halt, no stop block of 1 (the smallest after pass 50 is 59), 2 to 6 blocks. The two-block states are [a, 2a+d] with |d| ≤ 3, reached every 1 to 32 passes in the first 2·106; in between a tail block halves each pass (1343, 673, 338, …).
