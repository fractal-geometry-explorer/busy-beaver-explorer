What is known about 1RB1RA_1LC1LD, and what is open

1RB1RA_1LC1LD_1LD0LB_1RE0RF_---1RD_1RA1RB

Nobody knows whether this six-state, two-symbol Turing machine halts when started on a blank tape. This page tracks what has been established about it, sorted by what each result rests on.

The work has just started: the machine is set up in Lean on the shared library, and the run from blank tape is simulated in Python, C and Lean. The macro structure of the run is not found yet.

Status as of 30 October 2026.

In short

The question is open. Lean proves no halt in the first 20,000 steps by the kernel alone and in the first 107 steps with native_decide; the C simulator finds no halt in the first 1011 steps. These are floors, not the way to an answer.

Where a halt would come from. The only halting transition is E0, and E is entered only from D reading a 0, which writes a 1 and moves right. So the machine halts exactly when D reads a 0 with a 0 to its right (proved in Lean). At the left end of the tape D keeps arriving on a 0, but in the first 3·109 steps (1,382 visits, C simulator) always with a 1 to its right.

The halting configurations

The machine stops exactly in state E reading a 0, and D>0 0 halts after one more ordinary step, whatever the rest of the tape.

No halt in the first 20,000 steps

The list simulator of the shared library, proved to agree with the machine's semantics, runs 20,000 steps from blank tape without a halt, evaluated by Lean's kernel. At step 46 the tape is 1^2 0 1^5 A>0 (blank_at_46).

No halt in the first 1011 steps

The shared C simulator runs 1011 steps from blank tape without a halt (12,410 ones at the end; at 1010 steps 5,580 ones and 6,278 cells visited). The C simulator agrees with the Python reference simulator on the first 80 records of the run (a test).

No simple conserved quantity

No a·ones + b·pos + W[state] is conserved modulo 2 to 12, so the mod-3 argument of the first holdout has no counterpart of this linear kind here.

heuristic Evidence only

The tape grows slowly and splits into two regions

The visited width grows roughly like the square root of the step count (about 6,300 cells after 1010 steps). The left part of the tape fills with blocks 1^2 0, with an occasional 1 0, and the head sweeps over it; the right part holds a few long blocks of 1s. The head reaches new cells mostly on the right.
