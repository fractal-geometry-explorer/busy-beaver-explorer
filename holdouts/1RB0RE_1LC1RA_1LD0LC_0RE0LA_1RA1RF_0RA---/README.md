# 1RB0RE_1LC1RA_1LD0LC_0RE0LA_1RA1RF_0RA---

bbchallenge id 113824, group G12. Whether it halts from blank tape is **open**. Family: two-level counter on odd blocks (fast tail, leftward carry, full rewrites).

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1LC | 1RA |
| C | 1LD | 0LC |
| D | 0RE | 0LA |
| E | 1RA | 1RF |
| F | 0RA | --- |


## The picture

At the moments the head is in A on the first blank cell right of everything written: Read the tape as words `a = 01`, `b = 0111`, `c = 011111`, `d = 0 1^7`, `e = 0 1^9` (a 0 followed by an odd run of 1s) and `z = 00`; `a^4` is four a's. The fast counter is the run `1^(2k)` at the right end: it grows by 2 per round, and each round takes twice as long as the one before plus about 2 steps (T′ = 2T + 2 in regular stretches).

| step | tape | |
|---|---|---|
| 25,501,321 | `a z 1 z 1 z 1 z 1 z 1 z 1 z 1 z 1 a z 1 b a^4 1 a^3 1 b a^2 b a^3 b a b^4 a^2 c a^8 … d b c a^3` | after a rebuild |
| 30,668,857 | `… b a b^4 a^2 b a b a^6 b a b a^2 b a b a^6 c^3 … d b c b e 1^26` | a carry in the middle |
| 108,182,695 | `… b a b a^2 b^2 a^2 c a^8 b a b … e 1^34` | further left |
| 686,952,827 | `… 1 a^4 c a^2 b a b^4 a^2 c a^8 … e 1^40` | further left |

Left of the fast counter is a slow list, a word in a, b, c, d, e: blocks of odd length separated by single 0s. In each round one local change happens in it, a little further left each time (a carry: for example `c a^3` → `b a b a^2`, `b^3` → `a^2 b^2`), so the list behaves like the low digits of a slow counter whose digits are the odd block lengths. When the change reaches the left end, the head sweeps the whole tape: going left, state C erases runs of 1s and the tape is rewritten into words `1^2 0^k`, and going right it is rewritten back, a rebuild that makes the list longer. This pair shares the first rows `1RB0RE_1LC1RA_1LD0LC` and differs in D0 and E1; both behave in the same way.

Rebuilds seen at about 1.66·10^6 and 2.55·10^7 steps.

## The proved neighbours (round 6)

The community tracker says: "One table, three starts, one entry away from a machine proved in merged PR 36. [...] The
rare entry keeps changing the head of the word, so the neighbour's invariant does not carry over."

- **The table and its starts.** This machine is the table of `1RB1RF_1RC0RA_1LD1RB_1LE0LD_0RA0LB_0RB---` started in that machine's state B (its states B, C, D, E, A, F are A, B, C, D, E, F here); a third holdout, `1RB0RA_0LC0RE_1LE1LD_0LE---_1LF0LC_1RA1LE`, is the mirrored table from another start.
- **The neighbours.** `1RB0RE_1LC1RA_1LD0LC_1LA0LA_1RA1RF_0RA---` and `1RB0RE_1LC1RA_1LD0LC_1RA0LA_1RA1RF_0RA---` (D0 = `1LA`, `1RA`; here `0RE`), proved non-halting in busycoq pull request 36 (in the copy we read:
  `verify/PR_SOMDC_Class1.v`). They have this table except for the entry D0.
- **Is the entry used from blank tape?** Yes (trusted C++, `transcount`): first at step 4; 27 times in the first 10^10 steps (10 in the first 10^3, 13 in 10^4, 14 in 10^5, 15 in 10^6, 25 in 10^7, 26 in 10^8, 27 in 10^10).
- **What it does here** (Lean, kernel, `lean/Halt.lean`). The entry fires when C, erasing 1s leftwards, reads a 0 with another 0 on its left: four steps later (C0, D0, E1, F0) the cells read `0 1 0` and A is on the next cell to the right.
  In the neighbours the same moment writes a 1 instead of the 0 and carries on differently.
- **Halting patterns** (Lean, kernel). `halt_b`: B reading a 0 with two 0s on its left (`0 0 B>0`) halts. `halt_a`: A reading `1 1 1` halts. Each is proved for every tape around the
  cells named. That these are the only two ways to halt is read backwards from the table, on paper.
- **Why the proof does not transfer.** It is not a matter of an unreached entry. The neighbours' proofs are long
  inductions over a word-and-counter description of each machine's own run (about 1,200 to 1,700 lines of Coq
  each); they depend on what the entry leaves at the left end of the word. Here the entry leaves `0 1 0` and sends
  the head right, where the neighbours extend the word. We did not find an invariant that survives this.

No proof was transferred. The decision stays open.
