## Status

**Open.** One of sixteen holdouts that run the same *marker counter*: a base-5 counter written on the tape as markers between long blocks of `0010`, whose markers drift and occasionally collide. The family is described in full in the family lead [`1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---/README.md). Lean proves the pieces of a sweep and whole sweeps for all block lengths (kernel); an exact accelerated simulator runs the machine to 10^16 steps without a halt.

## What it does

The tape between two sweeps is `1 (0010)^b0 m1 (0010)^b1 ... mk (0010)^bk 000`: blocks of the word `0010` separated by markers, each in one of the phases `1` (0), `0` (0'), `0011` (1), `011` (2), `11` (3), `00111` (4). Each sweep adds one to the counter whose digits are the phases: the last marker goes up one phase, a marker in phase 4 carries into the one before it, and when every marker is in phase 4 a new marker appears at the end. The blocks around a marker change with its phase, so the markers drift left, the later ones faster, until one uses up the block before it and *merges* with the marker there. See the family lead for the rules.

D1 is 0LF and F0 is 0LE: at a merge where D reads a 1, F reads the next cell to the left; a 1 there would halt the machine, a 0 lets F0 finish the merge.

**Same class as** (the same tapes at another pace for the direct members, the same markers for the mirrored ones; these are not the same run): [`1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_1LA---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_1LA---/README.md), [`1RB0LC_0RC0RF_1RD0RE_1LE0RA_0LA0LE_0RC---`](../1RB0LC_0RC0RF_1RD0RE_1LE0RA_0LA0LE_0RC---/README.md), [`1RB0LC_0RC1RF_1RD0RE_1LE0RA_0LA0LE_0LA---`](../1RB0LC_0RC1RF_1RD0RE_1LE0RA_0LA0LE_0LA---/README.md) (class III: the tape at every sweep end is the same as in `1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_1LA---` up to 10^11 steps; the mirrored members have the same markers at every sweep end as the direct ones from sweep 109,645 on, with a different first block).

## Family F05: one core, forty machines

This machine is one of 40 holdouts with the same five states. In frame A all of them are `1RB0LC_0RC0RB_1LD0RE_0LE?LF_1LA0LB_??---`: they differ in D1 (0LF or 1LF), in F0 and in the start state. This one is the core itself with D1 = 0LF, F0 = 0LE, started in A. `lean/Family.lean` proves it (`step_img`, `halts_iff`: the machine halts from blank tape iff `1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LE---` halts from blank tape in state A).

Shared by all 40 and proved in Lean on each machine's own frame-A table (`lean/Family.lean`, written by `holdouts/1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0RA---/py/gen_family_lean.py`):

- `go_spec`: the visit rule for every depth (a clean visit to [b1, ..., bk] makes five visits to the list without b1);
- `go_closed`, `visit_closed`: its closed form (b1-5, b2-18, b3-90, ..., bk+12·5^(k-2));
- `visit_conserves` (new): a clean visit conserves, for the blocks after the first and before the last, the residue of block i modulo 18·5^(i-2) and the drift b(i+1) - 5·b(i);
- `birth`, `fevent`, `fevent_reads_zero`: the birth of a block, and the harmless entry into F.

**Run (trusted).** The exact block-list map (`holdouts/1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0RA---/py/f05_run.py`, `hybrid.py`) reaches step 1.9·10^200 without a halt: 516 returns to the left end, 214 entries into F, all reading 0, tape around the head `010001000100[F]001010101010` (183x); `010001000100[F]001010110101` (31x). Its F-events agree with the plain simulation on the first 3e+09 steps (2 F-events). Summary and the first 80 left-end block lists: `data/f05_run.json`.

**Drifts (observed, at left-end events only).** Smallest |b(i+1) - 5·b(i)| after step 10^20: 56124; after step 10^100: 514634. Halting would need a drift near 0 at the moment its block runs out (two exceptional events close together); nothing proved excludes that, so the question stays open.
