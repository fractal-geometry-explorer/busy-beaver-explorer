# 1RB1RE_1RC0RF_0LD---_1LE1LD_1RA0LB_0RE1LC

bbchallenge id 157718. One of the six-state holdouts whose halting from blank tape is open. At the growing left end
two **blocks (011)^n and (01)^m grow by eating long runs of 1s further right** (one growth phase proved in Lean);
between these phases the head works through an irregular region of short words, and that part is not understood;
halting is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RE |
| B | 1RC | 0RF |
| C | 0LD | --- |
| D | 1LE | 1LD |
| E | 1RA | 0LB |
| F | 0RE | 1LC |


## What it does

The right end of the tape has not moved since early in the run; the left end grows like the square root of the
step count. Seen at the moments the head is at the left end in state B, the tape often reads

    0^inf B> 0 (011)^n 0 011 011 (01)^m (01101)^q 011 1^r ...

and over two cycles (six visits of the left end) the run of ones loses three cells while the blocks grow:

    n -> n+1,  m -> m+3,  r -> r-3        in 10m+20n+20q+204 steps          (lean/Rules.lean `eat`)

(proved for every n, m, q and every tape beyond, generated by py/rules.py with bbtools.symtm; the theorem states the
end configuration as the run re-brackets it). For example at step 11,262,236 n = 145, m = 433, q = 167, r = 230;
at 12,203,786, r = 6. When the run of ones is used up, the head starts working on the next part of the tape, an
irregular list of the words `011`, `01`, `10` and runs of 1s, and a new phase starts later with the next long run
of ones; the runs of ones that get eaten (1^606, 1^147, 1^125 in the first 10^7 steps) are made by earlier phases.
At 10^9 steps the head is inside the tape, between `(100)^6706 1` and `(101)^468 ...` (see the samples below).

## Where it could halt

The machine halts only on C reading 1. The CTL search of `bbtools.ctl` (K = 6) allows it only with six 1s to the
left of the head: inside or next to a long run of ones, which is exactly what the growth phases eat. A halt needs
the head to arrive in state C on a 1 just after such a run, which the phase rule above never does; it would have
to happen in the irregular part between phases.

## Status

Open. Proved in Lean: the halting configurations, no halt in 10^7 steps (`lean/Blank.lean`), one double cycle of the
growth phase (`lean/Rules.lean`). Observed (not proved): the phase structure. Not understood: the irregular region
between phases and how it makes the next run of ones, so there is no macro map yet.

### Next steps

- Restate `eat` in a normal form (`rep_rotate`) and iterate it, as for the other machines of this batch.
- Study the irregular region between phases: record it at each phase start and look for a rewriting system (it
  resembles the digit lists of 1RB1RF_1LC1LF_---1LD_1LE0RA_1RE1LB_1RD0LD).

## Where a halt can come from

`lean/Route.lean` (kernel, written by `py/route.py`): `halt_route`, two steps before any halt the machine is in one
of: A with 0 under the head, 0 right, 1 two right.
