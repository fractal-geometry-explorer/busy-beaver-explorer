# 1RB1RA_1RC0RF_1RD0RD_1LE---_0LC1LF_1RA0LE

bbchallenge id 155803. One of the six-state holdouts whose halting from blank tape is open. Family: bouncer over a list of blocks of 1s separated by single 0s (exp/sqrt), chaotic, not solved.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RA |
| B | 1RC | 0RF |
| C | 1RD | 0RD |
| D | 1LE | --- |
| E | 0LC | 1LF |
| F | 1RA | 0LE |

## Status

Open. Lean (`lean/Blank.lean`): the halting configurations (`step_none_iff`), no halt in 10,000 steps by
the kernel, in 10,000,000 by `native_decide`. Lean (`lean/Rules.lean`, kernel only): 4 sweep rules for all n.
C (`tools/c/triage.c`): no halt in 1,000,000,000 steps.

## Structure

Whenever the head extends the tape on the right in state A, the tape is a list of blocks of 1s separated by
single 0s (`c/blocks.c`). At step 774,448,167 the list has 5317 blocks: 2632 of length 3, 1352 of length 7, 658 of length 11, 329 of length 15, 165 of length 19, 91 of length 23, 50 of length 27, and a few
others: lengths 4m + 3, about half as many of each length as of the one before, as if they were random.

Between those events the head sweeps from the right part to the left end and back. At the left end it adds
cells, and the leftmost block grows by 4 cells per sweep (29, 33, 37, 41, 45 around step 3 x 10^7) until a
later sweep rewrites it. So the left side grows like the square root of the step count; the right side grows
in rare bursts, like a logarithm.

Lean (`lean/Rules.lean`, generated by `py/gen_rules.py`) proves 4 sweep rules for all n.

Halting is D1. D is entered only from C, which always moves right, so the machine halts exactly when the head
in state C steps right onto a 1. The sweeps have not produced that so far.

## For later

This needs more than a day of work.

- Find the exact rule by which one sweep rewrites the block list, and prove it in Lean from the sweep rules.
- The lengths look geometric; check whether the list encodes a known process (a binary counter, a
  Collatz-like map) before looking for an invariant.
