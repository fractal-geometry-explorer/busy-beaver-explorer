# Space Needle: 1RB1LA_1LC0RE_1LF1LD_0RB0LA_1RC1RE_---0LD

bbchallenge id 101957, the community's **Space Needle** (mxdys, January 2025; a cryptid). Whether it halts from
blank tape is open, and this folder proves in Lean that it is equivalent to a simple number-theoretic question:
**does Doucette's sequence 6, 10, 17, 41, 101, 251, ... ever reach a power of two?**

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LA |
| B | 1LC | 0RE |
| C | 1LF | 1LD |
| D | 0RB | 0LA |
| E | 1RC | 1RE |
| F | --- | 0LD |

## What it does

Write `X(b, c)` for the tape `0^inf A>0 1^b 0 0 1^c 0^inf`. From blank tape the machine reaches `X(3, 1)` at step 45,
and from then on it moves from one such configuration to the next (mxdys's rules):

| from | to |
|---|---|
| `X(0, c)` | `X(c + 2, 1)` |
| `X(1, c)` | halts (F reads a 0 twelve steps later; 13 steps in the bbchallenge count) |
| `X(2k + 2, c)` | `X(5k + c + 7, 1)` |
| `X(2k + 3, c)` | `X(k, k + c + 4)` |

Between them the head runs three kinds of phases on blocks of 1s separated by single 0s: a *bouncer*
(`L 0 1^(m+3) C>0 R` becomes `L 1 0 1^(m+1) C>0 1 R`: the middle block loses two, each side gains one), a *zig-zag*
that moves a block boundary (`0^inf A>0 1^(a+1) 0 1^b` becomes `0^inf A>0 1^a 0 1^(b+2)`, one cell further left), and
*merges* when a block runs out. An even step costs time cubic in b.

On the visits `X(b, 1)` put `D = b + 3`. The odd rule halves `D` exactly, so between two visits come `v` odd steps
(`2^v` the largest power of two dividing `D`) and one even step, and the next visit has
`D' = F(D) = D + v + 3a` where `D = 2^v (2a + 1)` (Katelyn Doucette's form). From `D = 6`:
6, 10, 17, 41, 101, 251, 626, 1095, 2736, 2995, 7486, ... If some `D` is a power of two, the halvings run down to
`D = 4`, i.e. `b = 1`, and the machine halts; otherwise they stop at an odd `D` and the even step follows.

## What is established

**Proved in Lean, kernel only:**

- `lean/Blank.lean`: the machine halts exactly when F reads a 0 (`step_none_iff`); no halt in 10,000 steps.
- `lean/Rules.lean` (generated by `py/gen_rules.py` with `tools/py/bbtools/symtm.py`): fifteen shift rules for all
  parameter values and any surrounding tape, including blank tape to `X(3, 1)` in 45 steps (`r_init`) and the halt
  of `X(1, c)` (`r_halt`).
- `lean/Macro.lean`: the three inductions (`bounce`, `zigs`, `shifts`), the four macro rules (`even_rule`,
  `odd_rule`, `zero_rule`, `halt_rule`), and **`halts_iff`: the machine halts from blank tape iff the orbit of
  (3, 1) under mxdys's map `g` reaches b = 1.**
- `lean/Collatz.lean`: `oddchain` (j odd steps from `(2^j E - 3, c)`), `macro_F`, `macro_pow2`, and
  **`halts_iff_pow2`: the machine halts from blank tape iff some `Fit k` is a power of two**, where
  `Fit 0 = 6`, `Fit (k+1) = F (Fit k)`.
- `lean/Bound.lean`: `Fit_kernel`: none of the first 20,000 terms is a power of two.

**Proved in Lean with `native_decide`:** `Fit_native`, none of the first 300,000 terms is a power of two
(`lean/Bound.lean`); no halt in 10^7 steps (`lean/Blank.lean`). `lean/Axioms.lean` prints the axioms of each.

**Computed** (trusted C):

- `c/verify.c`: a direct run of 3·10^10 steps meets the shape `X(b, c)` exactly at the configurations the orbit of `g`
  predicts, in order, and at no others (19 of them, the last `X(7483, 1)` at step 10,608,569,291 and
  `X(3740, 3745)` at step 10,636,589,390).
- `c/doucette.c`: none of the first 3·10^6 terms of Doucette's sequence is a power of two; the largest `v` is 24, the
  mean `v` 0.998, the 3·10^6-th term has about 2.8·10^6 bits (checked against Python big integers on the first 10^5
  terms). The community reports 10^8 terms, at most 25 factors of 2.

**Heuristic:** if the low bits of the terms are random, `v` is geometric with mean 1 and `D` grows by about 1.92 per
term (0.941 bits; LegionMammal978's estimate, 0.9414 measured). A term of n bits is a power of two with chance about
`2^-n`, so the machine is *probviously* non-halting.

**Open:** whether it halts. A proof of non-halting would have to control the 2-adic valuation of every term of the
sequence; no method for this is known.

## For later

- The sequence check could go to 10^8 terms with a faster bignum (GMP is not installed here).
- Backward analysis (which `2^n` are reachable from a term with given `v`, as in Doucette's blog post) gives
  congruence conditions on `n`; a Lean statement of the first few would be a small step, not a proof.

## Layout

| path | what it is |
|---|---|
| `lean/Rules.lean` | the shift rules (generated by `py/gen_rules.py`) |
| `lean/Macro.lean` | inductions, macro rules, `halts_iff` |
| `lean/Collatz.lean` | Doucette's map, `halts_iff_pow2` |
| `lean/Bound.lean` | the first 20,000 (kernel) and 300,000 (`native_decide`) terms |
| `lean/Axioms.lean` | the axioms of the main theorems |
| `py/gen_rules.py` | writes `lean/Rules.lean` |
| `c/verify.c` | the macro rules against a direct run |
| `c/doucette.c` | Doucette's sequence in multi-precision C |

## Check

```sh
. /etc/profile.d/lean.sh && holdouts/1RB1LA_1LC0RE_1LF1LD_0RB0LA_1RC1RE_---0LD/lean/check.sh   # about 2 minutes
cd holdouts/1RB1LA_1LC0RE_1LF1LD_0RB0LA_1RC1RE_---0LD
python3 py/gen_rules.py | diff - lean/Rules.lean
gcc -O2 -o /tmp/verify c/verify.c && /tmp/verify 30000000000 | tail -3
gcc -O2 -o /tmp/doucette c/doucette.c && /tmp/doucette 3000000 500000
```
