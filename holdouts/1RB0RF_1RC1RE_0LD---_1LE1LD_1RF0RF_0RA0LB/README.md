# 1RB0RF_1RC1RE_0LD---_1LE1LD_1RF0RF_0RA0LB

A unary counter beside a chaotic region: the left half of the tape is one block of ones (length 3 mod 4, growing by multiples of 4), the right half is blocks of ones of odd length separated by single 0s, rewritten every round trip. Halting is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RF |
| B | 1RC | 1RE |
| C | 0LD | --- |
| D | 1LE | 1LD |
| E | 1RF | 0RF |
| F | 0RA | 0LB |

## What it does

**The tape.** At a left turn: `0 1^n 0 1^a 0 1^b 0 …`, n = 3 mod 4 (n = 1,231 of a 2,299-cell tape at 2.9·10^6 steps),
a, b, … odd (148 blocks of 1, 52 of 3, 38 of 5, 16 of 7, … at that turn; one block 6 is the only even one). At a right
turn: `1^n 0 1^5 0 1^3 0^3 1^5 0 …`: blocks of ones separated by odd runs of 0s.

**The sweeps (proved, `lean/Rules.lean`).**

| rule | from | to | what it does |
|---|---|---|---|
| `f_ones` | `L 1 F> (1)^n R` | `L (1)^n 1 F> R` | Rightward: F crosses a block of ones (3 steps a cell). |
| `d_ones` | `L (1)^n D> 1 R` | `L D> 1 (1)^n R` | Leftward: D crosses a block of ones. |
| `f_01` | `L F> (01)^n R` | `L (00)^n F> R` | Rightward: F erases the ones of a run of 01. |
| `d_1110` | `L (1110)^n D> 1 R` | `L D> 1 (1101)^n R` | Leftward: D turns each 1110 into 1101. |
| `f_0111` | `L 0 F> (0111)^n R` | `L (1110)^n 0 F> R` | Rightward: F, a 0 behind it, turns each 0111 into 1110. |

**Emergent behaviour (observed).** n grows by 4, 8, 12 or 20 at some round trips and stays about half the tape; the
right region shows no frozen or translating part (its first blocks cycle through a few patterns, `1 1 7 1 1 7 1 1 5`,
`1 3 1 1 5 1 5 1 1`, `1 1 3 3 1 3 1 1 7`, the rest is irregular).

**Halting.** C1 halts; C is entered only from `B>0 1`. In 10^9 steps B reads a 0 29,488,351 times, never with a 1 on
its right (`c/prehalt.c`).

## For later

Prove the parity structure (odd blocks, n = 3 mod 4) as an invariant of a round trip; it may be what keeps `B>0 1`
away.

the kernel, in 10,000,000 by `native_decide`; `lean/Rules.lean`: the sweep rules, kernel only. C (`tools/c/triage.c`): no halt in 1,000,000,000 steps.

## Deciders tried (F11, 13 November 2026)

None closes. Each reaches a halting configuration in its abstraction, which says nothing about halting.

- n-gram CPS (`tools/c/ngramcps.c`), equal widths on both sides: a halting local configuration is reached with plain up to width 16, history 1 up to width 15, history 2 up to width 15, history 3 up to width 15, LRU history up to width 7 (larger widths ran out of the 150 s or 60 million configuration budget).
- n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 12, p = 3 up to width 12, p = 4 up to width 12, p = 6 up to width 12.
- n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets.
- Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4).
- Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..8; n = 9 not finished in 150 s.

## Where a halt can come from

`lean/Route.lean` (kernel, written by `py/route.py`): `halt_route`, two steps before any halt the machine is in one
of: A with 0 under the head, 0 right, 1 two right.
