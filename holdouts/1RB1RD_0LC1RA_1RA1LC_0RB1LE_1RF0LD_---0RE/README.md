# 1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE

bbchallenge id 70028. The tape is an alternating block `(10)^x` next to a solid block `1^y`; the machine doubles one at the other's expense, back and forth. It halts only after an all-ones tape `1^n` with n in a sparse list.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RD |
| B | 0LC | 1RA |
| C | 1RA | 1LC |
| D | 0RB | 1LE |
| E | 1RF | 0LD |
| F | --- | 0RE |

## What it does

Stop the run whenever the head reaches a new cell: the tape is `(10)^x 1^y` (plus a short end). Write `E(x,z)` for
`E>0 (10)^x 1^z` and `B(x,y)` for `(10)^x 1^y 0 B>0` (blank around).

- **Left phase** (states B, D, E, F, shared with `1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE`):
  `E(x,z) -> E(2x+4, z-2x-6)` while `z >= 2x+8`, in `4x^2+26x+34` steps.
- **Right phase**: `B(x,y) -> B(x-(y+3)/2, 2y+5)` for odd `y` while it fits, in `y^2+7y+14` steps.
- When a doubling no longer fits the phase switches and the tape grows by a few cells: width ~ t^(1/3).

Both rules held at all their 1,036 applications in the first 10^9 steps (`py/phases.py check`).

## Halting

F0 halts; F is entered only from E0, and E/F walk right over `0101...`, so a halt needs `E(x,0)` or `E(x,1)`.
Probing all two-block tapes with sizes < 150 (`py/phases.py probe`): `E(x,z)` with even `z >= 2` and `B(x,y)` with
`x >= 1`, odd `y` lead only to such tapes or to an all-ones tape. From `1^n 0 B>0` the run goes to `E(1, n+1)`, the
alternating block grows 1, 6, 16, 36, ..., and it halts iff the ones run out leaving exactly one:
n = 20*2^k - 2k - 12 (8, 26, 64, 142, 300, ...) (`py/phases.py ones`, all n <= 400).

All-ones moments: n = 2, 28, 492, 772, 2197, 2752, 3111 in the first 10^9 steps; 170265, 199166, 352295
between 10^9 and 10^15 (`c/mrun.c`). None is in the list. So it halts only if a doubling map lands exactly on a sparse target: very probably never, not proved.

## Files

- `c/mrun.c`: exact macro simulator, `gcc -O2 -o mrun c/mrun.c && ./mrun MACHINE 2 STEPS [EVERY]`.
- `py/gen_rules.py`: writes `lean/Rules.lean` (the pieces of the left phase, by `bbtools.symtm`); `lean/EPhase.lean`
  composes them, with induction on the bounces, into `ephase`.
- `py/phases.py`: `check` (phase rules along the run), `probe` (parity classes), `ones` (fatal all-ones lengths).

## The phase map in Lean

`lean/Phases.lean` defines the phases E(x, z) = `E>0 (10)^x 1^z`, R(x, y) = `(10)^x 1^y 0 B>0` and Q(m, k, t) = `(10)^m 1 D>0 0 (10)^k 1^t` and the map `next` between them, and proves:

- `next_sound`: every case of the map, for all parameters (the symbolic runs are in `lean/Pieces.lean`, generated by
  `py/pieces.py`; the bounces by induction);
- `halts_iff`: the machine halts from blank tape iff the orbit of R(0, 2) (reached from blank tape in 6 steps) reaches E(x, 0) or E(x, 1);
- `no_halt_phases` (`native_decide`): not in the first 10^8 phases, about 4.1*10^21 steps;
- `even_next`, `even_safe`: even phases lead only to even phases or to all-ones tapes;
- `fatal_list`, `ones_fatal`, `ones_safe` (`native_decide`): for n < 10^5, the all-ones tape of length n halts before
  the next even phase or all-ones tape iff n is 0 or 20*2^k - 2k - 12 (8, 26, 64, 142, ...).

`py/phasemap.py` is the same map in Python with step counts: `check` compares every case with small parameters
against the machine, `run K` iterates it, `fatal N` lists the fatal lengths.

## Status

Open. Lean (`lean/Phases.lean`, on `lean/Pieces.lean` generated by `py/pieces.py`): the whole phase map, every case for all sizes (`next_sound`); the machine halts iff the map's orbit from R(0, 2) (reached from blank tape in 6 steps) reaches E(x, 0) or E(x, 1) (`halts_iff`); no halt in the first 10^8 phases (`no_halt_phases`, `native_decide`; about 4.1*10^21 steps by the pieces' step counts); the even phases lead only to even phases or all-ones tapes (`even_next`, `even_safe`); the fatal all-ones lengths below 10^5 are 0 or 20*2^k - 2k - 12 (8, 26, 64, 142, ...) (`fatal_list`, `native_decide`). Also: no halt in 10,000 steps by the kernel and 10^7 by `native_decide` (`lean/Blank.lean`); no halt in 10^15 steps by exact macro simulation (`c/mrun.c`). Not proved: the fatal list for all n, and that the orbit avoids it.
