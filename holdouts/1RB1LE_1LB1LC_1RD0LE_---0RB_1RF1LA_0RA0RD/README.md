# 1RB1LE_1LB1LC_1RD0LE_---0RB_1RF1LA_0RA0RD

bbchallenge id 25239. One of the six-state holdouts whose halting from blank tape is open. Family: a Collatz-like
map on the lengths of blocks of 1s, piecewise linear on residue classes modulo powers of 2.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LE |
| B | 1LB | 1LC |
| C | 1RD | 0LE |
| D | --- | 0RB |
| E | 1RF | 1LA |
| F | 0RA | 0RD |

## What it does

The tape is a few long blocks of 1s separated by single 0s. The run keeps returning to
`Y(n) = 0^inf 1^n 0 B>0 0^inf`: from blank tape n = 2, 5, 8, 14, 39, 110, 232, 357, 1064, 1614, 4539, 13610, 23544,
67275, 201818, 576606, 1243308, 1864956, 2797428, 4196136, 8162799, 24488390, 37736994, 129867393, 389602172,
584403252, 876604872, 1397089014 (step 1.24·10^18), ...

- **Odd n.** B turns, A and E (which alternate on 1s) sweep to the left end, A arrives: `A>0 1^(n-2) 0 1^3`. Each
  round of shifts turns `A>0 1^a 0 1^b` into `A>0 1^(a-2) 0 1^(b+6)`; at a = 3 the blocks merge into Y(b + 5). So
  Y(n) leads to Y(3n - 7); Y(3) halts.
- **Even n.** E arrives at the left end and slides a 0 through the block; B on a double gap after a block of 2j + 4
  takes 4 from it and gives 1 to the left block and 3 to the right one (`r_g4`); the remainder mod 4 decides how the
  work moves to the block on the left. The run passes through two-block visits `0^inf 1^a 0 1^b 0 B>0` and returns
  to Y(n'). The map n -> n' is linear on residue classes mod 2^k: n = 4 (mod 8) gives 3n/2 - 6, n = 16 (mod 32)
  gives 9n/8 - 5, n = 22 (mod 32) gives 15n/8 - 9/4, n = 2 (mod 64) gives 27n/16 - 99/8, n = 14 (mod 64) gives
  45n/16 - 3/8, and finer classes for the rest. Some even n halt: 10, 12, 34, 48, 122, 138, 178, 186, 192, 230, 294,
  ..., every 3·4^k.
- **Halting.** D is entered from C (which leaves a 1 under it) and from F, so the only halt is E on a 0 before a block
  of a single 1 followed by a 0 (`r_halt`).

## What is established

**Proved in Lean, kernel only:** the halting configurations (`step_none_iff`, `lean/Blank.lean`); the shift rules of
`lean/Rules.lean` (generated by `py/gen_rules.py` with `tools/py/bbtools/symtm.py`) for all parameter values:
`r_halt`, `r_erule`, `r_merge`, `r_g4`, `r_y_odd`, `r_w_end`; no halt in 10,000 steps.

**Proved in Lean with `native_decide`:** no halt in 10^7 steps.

**Computed** (trusted C):

- `c/rle.h`: an exact run-length simulator that crosses a run in one move when a sweep's states cycle or a 0 slides
  through 1s; `c/rle_test.c` checks it against `tools/c/tm.h` move by move (state, position, 3,000 cells each side).
- `c/orbit.c`: no halt from blank tape up to step 1.88·10^18, the visits Y(n) listed above (the step counts of the
  first ones agree with direct simulation, e.g. Y(67275) at step 4,875,439,011).
- `c/ymap.c`: the odd rule for every odd n from 5 to 19,999; the even map for every even n up to 20,000 and from
  100,000 to 104,000 (57 halts below 20,000; one value near 100,000 exceeded the budget of 2·10^9 moves).
- A closed tape language of windows of 4 cells (`python3 -m bbtools.ctl 1RB1LE_1LB1LC_1RD0LE_---0RB_1RF1LA_0RA0RD 4`) allows a halt only as
  `0^inf 1 1 0 D>0`, at the leftmost block.

**Heuristic:** the fraction of even n that halt falls from 13% (n < 64) to 4%, 1.1%, 0.3% (4,096 to 20,000) and 0.1%
(around 100,000), roughly like n^-0.5. The orbit grows by about 2 per visit, so the chance of a halt after
n = 1.4·10^9 is of order 10^-4: probviously non-halting.

**Open:** whether it halts.

## For later

- Derive the even map in closed form (the nested block rules mod 4 suggest a recursion on the 2-adic digits of n), and
  prove the shift phase of the odd rule in Lean (an induction like `shifts` in Space Needle's `lean/Macro.lean`;
  each round of shifts is itself a few sub-rounds).
- The orbit run overflows 64-bit step counts near 9·10^18; switch `steps` to 128 bits to go further.
