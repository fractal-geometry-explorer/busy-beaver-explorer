The question "does this machine halt?" is answered here by walking down a ladder of five descriptions of the same run. Each level forgets detail that the level above keeps and has its own, longer unit of time. Each step down is a Lean theorem saying that one move at the lower level is a real run of the machine, at least one step long, from one configuration to the next. So a run that goes on forever at the bottom level is a run of the machine that goes on forever: the machine never halts. The badge on each card says what Lean used to check that step (Kernel: Lean's small trusted core; native_decide: a compiled program whose answer Lean takes on trust).

A tape of cells and a head in one of six states. One unit of time is one step. It can halt only when D reads a 0.

The tape as cells and stretches (01)n. One unit is one move: a single step, or a whole stretch crossed at once.

The list at the left end is template t with first count 3k + 4 and second 3j + β. One unit is one round trip.
Kernel (t, k + 1, j) to (nxt t, k, j + dj): round_0 … round_61 Level 4Epochs
k counts down to 0, then the second count takes the place of the first. One unit is one epoch end.
native_decide (t, 0, j + 200) to (endT t, j + endC1, endC2): ends_ok; the way in: start_ok Level 5One number Φ
Φ = j + 2k + pot(t). It never drops in a round trip and is at least 215 after an epoch end, so the next epoch end always has j ≥ 200.
