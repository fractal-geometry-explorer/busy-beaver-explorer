Between left-end moments the head sweeps across the long stretches. A stretch of a million cells would take a million steps to simulate, but what happens to it is simple, and Lean proves it once for every length:

  • Going right (sweep_right): B, with a 1 just behind it, turns each block 010101 into 011001 and comes out the other side, again in state B, after exactly 14 steps per block.
  • Going left (sweep_left): C, with 110 ahead of it, turns each 011001 back into 010101, 22 steps per block.

Each is proved by running one block for real (rfl, so Lean's kernel computes the 14 or 22 steps) and then a general lemma, cross_r or cross_l, that says: if one copy takes the head through in the same state, n copies do too, in n times the steps. Kernel

Any number of blocks. Type a number of blocks n. The browser runs the plain machine on the rule's starting tape until the head comes out the far side in the starting state, and compares the step count and the tape with what the theorem says.

Level 2: the tape as a list, moved by moves

A round trip from a template is a claim about infinitely many tapes, one for each size. Lean cannot simulate them one by one. Instead it runs the machine symbolically: the tape is a list of tokens, single cells and stretches (01)n whose count n is a formula such as 3k + 7. The checker steps the machine on cells it can see. When the head meets a stretch, it tries one copy on its own (as in the panel above) and, if the head comes out the far side in the same state, crosses the whole stretch in one move. If it would need to know whether a count is 0 or not, it gives up and the check fails.

The checker is a program, auto in lean/SymCheck.lean, and it comes with a theorem, auto_reach, proved once by the kernel: if auto answers true for a start and a target, then for every value of the variables the real machine goes from the start to the target in at least one step. Kernel That is the step from level 1 to level 2: every move at level 2 is a run of the machine.

This page has its own small version of the same idea, the shift-rule simulator: the tape is a list of tokens with ordinary numbers as counts, a whole stretch is crossed in one move whenever one copy tried on its own takes the head through in the same state, and at each left-end moment the list is written in normal form again. It is not the Lean program, and it works with numbers rather than formulas, but it makes about as many moves (for example 140,054 from blank tape to step 1,277,431, where Lean's checker makes about 148,000). The one-moment panel checks it against the plain machine at every moment; the next sections use it to run round trips and epoch ends of any size.
