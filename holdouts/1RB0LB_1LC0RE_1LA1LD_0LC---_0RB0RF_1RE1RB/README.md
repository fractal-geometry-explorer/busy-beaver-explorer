# 1RB0LB_1LC0RE_1LA1LD_0LC---_0RB0RF_1RE1RB

bbchallenge id 48788. Group G01. **Antihydra-like**: a Collatz-like map m → 4m/3 with a counter that moves +6, −1 or
+4 with m mod 3; the machine can only halt if the counter runs out. Listed by bbchallenge as an Antihydra-like
cryptid (Racheline, November 2024). Open; probviously non-halting.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0LB |
| B | 1LC | 0RE |
| C | 1LA | 1LD |
| D | 0LC | --- |
| E | 0RB | 0RF |
| F | 1RE | 1RB |

## What it does

Sample the run when the head is in state E on the last 1 of the tape. From step 9008 on, the tape is then always

    E(a, m)  =  1 0 0 (10)^a 0^m E> 1        (blank elsewhere)

a counter of `a` copies of `10` at the left end and a gap of `m` zeros. Between two samples the head runs a loop at the
right end: each round turns three 0s of the gap into two more `10` on its right (`loop`); when fewer than three 0s are
left the remainder decides the counter (`end1`, `end2`, `end0`), and a sweep turns the `10`s back into zeros. With
`m = 3k + r`:

| r | next | steps |
|---|---|---|
| 0 | E(a + 6, 4k + 4) | 4k² + 23k + 16a + 94 |
| 1 | E(a − 1, 4k + 7) | 4k² + 23k + 28 |
| 2 | E(a + 4, 4k + 4) | 4k² + 23k + 8a + 56 |

valid for every a ≥ 1 and m ≥ 2 (and, empirically, for a = 0 when r = 2). From blank tape: E(4, 124) at step 9008,
then E(3, 171), E(9, 232), E(8, 315), E(14, 424), …, E(58, 137643) at step 10,826,674,709.

**Halting condition.** The map is total while the counter is positive, so the machine can only halt if the orbit
reaches a = 0 with m ≢ 2 (mod 3). What happens there was sampled from `1 0 0 0^m E> 1`: for m ≡ 1 (mod 3) some gaps
halt within 10⁵ steps (m = 10, 37, 64, 91, 145), others become a translated cycler (all m ≡ 4 mod 9 tried, and
m ≡ 19 mod 27), others restart a counter; for m ≡ 0 the configuration runs on without returning to the E form in
10⁷ steps. None of this is reached: the counter is far from 0.

**Heuristic.** If m mod 3 is equidistributed (as for any Collatz-like map of this kind), the counter is a random walk
with steps +6, −1, +4, drift +3 per round. The probability of ever going down by d is ≈ λ^d with λ = 0.334895 the
root in (0, 1) of λ⁷ + λ⁵ + 1 = 3λ: 10^−27.6 from a = 58 (step 1.08·10¹⁰), 10^−28,700 from a = 60,462 (after the
20,000 rounds proved in Lean). Probviously non-halting, but a proof would need control of 4/3-Collatz residues, as
for Antihydra.

## Reproduce

```sh
. /etc/profile.d/lean.sh && holdouts/1RB0LB_1LC0RE_1LA1LD_0LC---_0RB0RF_1RE1RB/lean/check.sh
cd holdouts/1RB0LB_1LC0RE_1LA1LD_0LC---_0RB0RF_1RE1RB/py
python3 rules.py > ../lean/Rules.lean       # regenerate the rules (bbtools.symtm)
python3 emap.py grid 8 80                   # the map against direct simulation (4 min)
python3 emap.py blank 1.1e10                # the blank run's E-events against the map (a few min)
python3 emap.py far 1000000                 # 10^6 rounds of the map
```

`py/emap.py` uses the shared helpers in `../1RB0LA_0RC0RB_1LD1LA_1LC1RE_1RF0RD_1LC---/py/g01tools.py` and the C
simulator `../1RB0LA_0RC0RB_1LD1LA_1LC1RE_1RF0RD_1LC---/c/from.c` (compiled on first use).

## Further work

The question is now purely about the orbit of (4, 124) under the map. A proof of non-halting would need to show that
the counter never runs out, i.e. control of the distribution of m mod 3 along the orbit; this is of the same
difficulty as Antihydra. The boundary a = 0 has not been analysed exhaustively (it is not needed unless the counter
comes down).
