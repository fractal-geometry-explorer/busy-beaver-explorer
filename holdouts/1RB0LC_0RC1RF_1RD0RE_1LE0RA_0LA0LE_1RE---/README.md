## Status

**Open.** One of sixteen holdouts that run the same *marker counter*: a base-5 counter written on the tape as markers between long blocks of `0010`, whose markers drift and occasionally collide. The family is described in full in the family lead [`1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---/README.md). Lean proves the pieces of a sweep and whole sweeps for all block lengths (kernel); an exact accelerated simulator runs the machine to 10^16 steps without a halt.

## What it does

The tape between two sweeps is `1 (0010)^b0 m1 (0010)^b1 ... mk (0010)^bk 000` (in this machine mirrored: it grows to the left): blocks of the word `0010` separated by markers, each in one of the phases `1` (0), `0` (0'), `0011` (1), `011` (2), `11` (3), `00111` (4). Each sweep adds one to the counter whose digits are the phases: the last marker goes up one phase, a marker in phase 4 carries into the one before it, and when every marker is in phase 4 a new marker appears at the end. The blocks around a marker change with its phase, so the markers drift left, the later ones faster, until one uses up the block before it and *merges* with the marker there. See the family lead for the rules.

The mirror image of the core; B1 (the core's D1) is 1RF and F0 is 1RE: at a merge where B reads a 1, F reads the next cell, and halts if it is a 1.

**Same class as** (the same tapes at another pace for the direct members, the same markers for the mirrored ones; these are not the same run): [`1RB0LC_0RC0RB_1LD0RE_0LE0LB_1LA1RF_0LD---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LB_1LA1RF_0LD---/README.md), [`1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_0RE---`](../1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_0RE---/README.md), [`1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_1LB---`](../1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_1LB---/README.md), [`1RB0LC_0RC0RE_1RD1LF_1LE0RA_0LA0LE_0RB---`](../1RB0LC_0RC0RE_1RD1LF_1LE0RA_0LA0LE_0RB---/README.md) (class I: the mirrored members have the same markers at every sweep end as the direct ones from sweep 157,376 on, with a different first block).

## Results

- `lean/Rules.lean` (generated by `py/rules.py`): 13 rules for all block lengths (kernel): nine whole sweeps (one per phase of the last marker, carries, overflows) and the pieces that the mirrored form can state.
- `py/check.py` runs the family checks for this machine: `check_rl.py` (the run-length simulator `c/rl.c` of the family lead agrees with its own run without shift rules at every sweep end of the first 10^8 steps), `model.py` (to 10^11 steps: 251,421 sweeps, 251,375 regular turns and 16 overflows exactly as the rules say, 30 merges, 3 entries into F), `merges.py` (none of the 48 merges of two markers with long blocks around them halts, for any block lengths).
- `far.py` (family lead): no halt in 10,000,000,127,598,328 steps; F entered 14 times, always reading a 0.
- `clusters.py`: 51 of 2,000 random short tapes of the same shape halt within 20,000 steps, while no merge with long blocks around it halts: halting needs short blocks close together, that is two merges close together.
- Lean (`lean/Blank.lean`): no halt in 10^7 steps.
- To rerun: `python3 py/check.py 1e11` (the `model.py` count above; the default 1e10 is quicker).

## Family F05: one core, forty machines

This machine is one of 40 holdouts with the same five states. In frame A all of them are `1RB0LC_0RC0RB_1LD0RE_0LE?LF_1LA0LB_??---`: they differ in D1 (0LF or 1LF), in F0 and in the start state. Shared by all 40 and proved in Lean on each machine's own frame-A table (`lean/Family.lean`, written by `holdouts/1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0RA---/py/gen_family_lean.py`):

- `go_spec`: the visit rule for every depth (a clean visit to [b1, ..., bk] makes five visits to the list without b1);
- `go_closed`, `visit_closed`: its closed form (b1-5, b2-18, b3-90, ..., bk+12·5^(k-2));
- `visit_conserves` (new): a clean visit conserves, for the blocks after the first and before the last, the residue of block i modulo 18·5^(i-2) and the drift b(i+1) - 5·b(i);
- `birth`, `fevent`, `fevent_reads_zero`: the birth of a block, and the harmless entry into F.
