# 1RB1LF_1RC1LD_1LB1LE_1LE0LD_0LA0RE_1RD---

bbchallenge id 39511. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LF |
| B | 1RC | 1LD |
| C | 1LB | 1LE |
| D | 1LE | 0LD |
| E | 0LA | 0RE |
| F | 1RD | --- |

## What it does

Family: **Collatz-like (x6, x4/3) + frozen stack.**

Write `d` for `10010` and `c` for `1000`. Each time the tape grows on the right (17 times in 2.5·10^9 steps: the
logarithmic side) it reads

    0 d^h1 c d^h2 c ... c d^hk c (tail) E> 0

a stack of blocks of `d`s separated by single `c`s, followed by a short tail such as `d^6 1^2 0 d^7 1^2 0 d 1^2 0 d c`
(the tail alternates between ending in `d c` and in `d c^2`). Between consecutive events (computed, from the C run):

* a new block is pushed at the left end of the stack, and the block that was on top gains one `d`; all the blocks
  below stay as they are (`d^4 c d^12 c d^26 c d^49 c d^96 c d^566 c d^760` is frozen in place below the top);
* the new top is much larger than the old one: in the last rounds about 6 times and 4/3 times the old top,
  alternately (`95 -> 565 -> 759 -> 4545 -> 6067`), together with the parity of the tail;
* between events the head sweeps over the whole tape, so the left end grows like the square root of the steps.

| step | stack `h1 ... hk` (left to right) | tail |
|---|---|---|
| 656,289 | 95, 49, 26, 12, 4 | `d^2 1^2 0 d^7 1^2 0 d 1^2 0 d c` |
| 9,636,395 | 565, 96, 49, 26, 12, 4 | `d^8 1^2 0 d^3 1^2 0 d c^2` |
| 38,626,019 | 759, 566, 96, 49, 26, 12, 4 | `d^4 1^2 0 d^7 1^2 0 d 1^2 0 d c` |
| 613,097,321 | 4545, 760, 566, 96, 49, 26, 12, 4 | `d^10 1^2 0 d^3 1^2 0 d c^2` |
| 2,454,976,241 | 6067, 4546, 760, 566, 96, 49, 26, 12, 4 | `d^6 1^2 0 d^7 1^2 0 d 1^2 0 d c` |

**Halting.** The machine stops on F reading 1. F is entered only from A on a 1 (`1LF`, moving left), so a halt needs
`1 A> 1`: the head in A on a 1 with a 1 on its left.

The exact rule for the new top (it depends on the tail as well as on the old top) is not known, so the halting
question has not been reduced to a map.

## Status

Open. Lean, all by the kernel:

* `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`); no halt in 10,000 steps by the
  kernel, in 10,000,000 by `native_decide`.
* `lean/Rules.lean` (generated by `py/rules.py`): twenty-three shift rules over `(10010)^n`, `(1000)^n`, their
  rotations and `(011)^n`, `(101)^n`, `(110)^n` (for instance `cross_A_l_10010`: A runs left over `(10010)^n`
  leaving `(01000)^n`), for all `n` and any tapes around.

Computed: C run to 5·10^9 steps (no halt; the right-end events above are from it). C (`tools/c/triage.c`): no halt in 10^9 steps.

## For later

Where this stopped: the words `d` and `c`, the stack that gains one block per round, and the right-end events
above. Next: find the exact rule taking (top block, tail) to (new top, new tail), which seems to be a Collatz-like map
multiplying by about 6 or 4/3 according to the tail's parity; check it against the 17 events, prove the sweeps of one
round with `symtm` for all block lengths, and iterate the map: the halting question is then whether the tail ever
reaches a shape that puts `1 A> 1` on the tape.
