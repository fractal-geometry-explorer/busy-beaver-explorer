Everything above comes down to the following. There is no tape and there are no states left, only three whole numbers and five cases.

start with  c = 0,  u = 2,  v = 5

repeat:
    if 2u < v:                          u ← 2u,  v ← v + 1
    otherwise, if c > 0:
        if 2u > v:                      c ← c − 1,  u ← 2u − v,  v ← v + 1
        if 2u = v:                      c ← c − 1,  u ← 1,       v ← v + 2
    otherwise (c = 0):
        if 2u > v:                      c ← 2(v − u − 1),  u ← 2u − v,  v ← u + 3
        if 2u = v:                      stop

Kernel The machine 1RB1RA_0LC0RE_1LF1LD_1LA0LA_1LC1RB_---1LC halts from a blank tape if and only if this loop stops. (In the reset line the new v uses the new u, so v becomes 2u − v + 3 in terms of the old values.)

The same thing as a recursive definition

Write H(c, u, v) for "the loop stops when started from (c, u, v)". Then H is the predicate defined by

H(c, u, v) = H(c, 2u, v + 1)                        if 2u < v
H(c, u, v) = H(c − 1, 2u − v, v + 1)                if 2u > v and c ≥ 1
H(c, u, v) = H(c − 1, 1, v + 2)                     if 2u = v and c ≥ 1
H(c, u, v) = H(2(v − u − 1), 2u − v, 2u − v + 3)    if 2u > v and c = 0
H(c, u, v) = true                                   if 2u = v and c = 0

The machine halts  ⟺  H(0, 2, 5).

H is defined by unbounded recursion, so "H(0, 2, 5) is false" means "the recursion never terminates". Each case moves to a state with a larger v except the reset, which can lower it; that is why there is no measure that would make the recursion obviously finite or obviously infinite.

One lap at a time

Since every reset leaves u = v − 3, the loop can also be read as a recursion on laps. Lap(c, v) runs the loop from (c, v − 3, v) up to its (c + 1)-th wrap-around, the first one with c = 0; say that happens at (0, u, V). If 2u = V the machine halts; otherwise the next lap is Lap(2(V − u − 1), 2u − V + 3). The run from blank tape is lap 1 from (0, 2, 5) followed by Lap(2, 5), Lap(8, 6), Lap(4, 32), Lap(24, 16), …, and its 54th reset is at V = 35,143,437,691.

In Lean

This is the definition the theorem is about, copied from lean/Doubling.lean; none is the stop.

def op : Nat × Nat × Nat → Option (Nat × Nat × Nat)
  | (c, u, v) =>
    if 2 * u < v then some (c, 2 * u, v + 1)
    else match c with
      | c + 1 => if 2 * u = v then some (c, 1, v + 2) else some (c, 2 * u - v, v + 1)
      | 0 => if 2 * u = v then none else some (2 * (v - u - 1), 2 * u - v, 2 * u - v + 3)

def opIter : Nat → Nat × Nat × Nat → Option (Nat × Nat × Nat)
  | 0, s => some s
  | n + 1, s => (op s).bind (opIter n)

theorem halts_iff_op : HaltsFromBlank ↔ ∃ n, opIter n (0, 2, 5) = none

HaltsFromBlank is the machine's own halting from blank tape, defined from its transition table in lean/Machine.lean. The proof (lean/Map.lean for the tape, lean/Doubling.lean for the arithmetic) is checked by Lean's kernel with only the standard axioms; nothing about the run is assumed. What is not known is the value of H(0, 2, 5): the loop has been run for 1011 operations (107 of them inside Lean) without stopping.
