# 1RB1RE_1LC0RA_---1LD_1LA0LF_0LB0LC_1RB0LB

bbchallenge id 69308. One of the six-state holdouts whose halting from blank tape is open (group G09: the visited tape grows like the square root of the step count on both sides).

**What it does.** A bouncer whose tape, after a rightward sweep, is a sequence of pieces `1^a 0 (01)^b`: a list of pairs of numbers. The leftward sweep turns each `(01)^b` into a block of 2b ones and each block of ones into a stretch of `01` or `10`, so the numbers of a pair trade encodings every round trip; the list evolves like a cellular automaton with no known rule. The halt (C0) needs E or F turning left onto two 0s, which no run has shown. Decision: open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RE |
| B | 1LC | 0RA |
| C | --- | 1LD |
| D | 1LA | 0LF |
| E | 0LB | 0LC |
| F | 1RB | 0LB |

## The sweeps and the pieces

A visit adds 3 or 5 cells at each end (271, 244 left and 250, 248 right of the first 1,040 visits). After a rightward sweep (state B or E at the right end)
the tape is a sequence of pieces `1^a 0 (01)^b` with a at least 2, covering 98.7% of it at every 31st visit to the right end in the first 3·10^8 steps;
occasionally a separator `0 0 1 0`. For example, the start of the tape at the 635th visit to the right end:

```
(1)^10 0 (01)^10 (1)^7 0 (01)^4 (1)^3 0 (01)^4 (1)^13 0 (01)^11 (1)^3 0 (01)^4 (1)^13 0 (01)^15 (1)^13 0 (01)^11 (1)^3 0 0 1 0 (1)^34 0 (01)^24 ...
```

The rightward sweep shifts the `01` stretches (A turns `01` into `10`, B turns `10` into `01`); the leftward sweep turns `(01)^b` into `1^(2b)` (C) and
`(10)^b` into `1^(2b)` (D), and blocks of ones into stretches of `01`. The difference a − b of a piece is mostly 1 (8,496 pieces) or −1 (4,122), then 3,
2, 5, but ranges from −13 to 25. The rewriting of the list of pairs has no known rule.

## Halting

C0 is the only halting transition; C is entered only by B0 (write 1, move left). B is entered by A0 and F0 (write 1, move right: then C reads that 1)
and by E0 and F1 (write 0, move left). So a halt needs `0 0 E>0` or `0 0 F>1`. In the first 10^9 steps C is entered 157,760,038 times and reads 1 every
time.

## Sweep rules (`lean/Rules.lean`)

Generated by `py/rules.py` with `tools/py/bbtools/symtm.py`; every rule holds for all values of `n` and every tape `L`, `R`, with the exact step count. `S>` is the head in state S on the next cell, `(w)^n` is n copies of w, `0^inf` is blank tape.

|---|---|---|---|

| `right_B` | `L B> (10)^n R` | `L (01)^n B> R` | 2 · n |
| `left_C` | `L (01)^n C> 1 R` | `L C> 1 (11)^n R` | 4 · n |
| `left_D` | `L (10)^n D> 1 R` | `L D> 1 (11)^n R` | 4 · n |
| `left_C2` | `L (10)^n C> 1 R` | `L C> 1 (01)^n R` | 4 · n |
| `right_end` | `L 0 A> 0^inf` | `L D> 0 1 1 0^inf` | 3 |

## Deciders tried (F11, 13 November 2026)

None closes. Each reaches a halting configuration in its abstraction, which says nothing about halting.

- n-gram CPS (`tools/c/ngramcps.c`), equal widths on both sides: a halting local configuration is reached with plain up to width 24, history 1 up to width 24, history 2 up to width 24, history 3 up to width 24, LRU history up to width 24 (larger widths ran out of the 150 s or 60 million configuration budget).
- n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 20, p = 3 up to width 20, p = 4 up to width 20, p = 6 up to width 20.
- n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets.
- Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4).
- Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..8; n = 9 not finished in 150 s.
