# 1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE

bbchallenge id 137865. The tape is an alternating block `(10)^x` next to a solid block `1^y`; the machine doubles one at the other's expense, back and forth. It halts only after an all-ones tape `1^n` with n in a sparse list.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LE |
| B | 1RC | 1RA |
| C | 0LD | 1RB |
| D | 1LE | 1LD |
| E | 1RF | 0LA |
| F | --- | 0RE |

## What it does

Stop the run whenever the head reaches a new cell: the tape is `(10)^x 1^y` (plus a short end). Write `E(x,z)` for
`E>0 (10)^x 1^z` and `C(x,y)` for `(10)^x 1^y C>0` (blank around).

- **Left phase**: `E(x,z) -> E(2x+4, z-2x-6)` while `z >= 2x+8`, in `4x^2+24x+30` steps.
- **Right phase**: `C(x,y) -> C(x-floor(y/2)-2, 2y+5)` while it fits, in `y^2+6y+7` (y even) or `y^2+4y+5` (y odd) steps.
- When a doubling no longer fits the phase switches and the tape grows by a few cells: width ~ t^(1/3).

Both rules held at all their 992 applications in the first 10^9 steps (`py/phases.py check`).

## Halting

F0 halts; F is entered only from E0, and E/F walk right over `0101...`, so a halt needs `E(x,0)` or `E(x,1)`.
Probing all two-block tapes with sizes < 150 (`py/phases.py probe`): `E(x,z)` with even `z >= 2` and `C(x,y)` with
`x >= 1`, odd `y` lead only to such tapes or to an all-ones tape. From `1^n C>0` the run goes to `E(0, n+1)`, then
`E(4, n-5)`, the alternating block grows 4, 12, 28, 60, ..., and it halts iff the ones run out leaving exactly one:
n = 32*2^k - 2k - 12 (20, 50, 112, 238, ...); also 15 values of n below 40 (`py/phases.py ones`, all n <= 400).

All-ones moments: n = 2, 5, 10, 71, 279, 466, 763, 3002 in the first 10^9 steps; 5882, 10234, 12114, 24455,
37818, 48395, 53042, 405563 between 10^9 and 10^15 (`c/mrun.c`). None is in the list. So it halts only if a doubling map lands exactly on a sparse target: very probably never, not proved.

## Files

- `py/doubling.py`: `check` (the doubling form along the run), `ones` (all-ones tapes and the stop before), `residues N` (the residue search).
- `lean/Doubling.lean`: the phase map at its stops is the doubling map (`doubling`, `mid_ones`, `low`).
- `c/mrun.c`: exact macro simulator, `gcc -O2 -o mrun c/mrun.c && ./mrun MACHINE 2 STEPS [EVERY]`.
- `py/gen_rules.py`: writes `lean/Rules.lean` (the pieces of the left phase, by `bbtools.symtm`); `lean/EPhase.lean`
  composes them, with induction on the bounces, into `ephase`.
- `py/phases.py`: `check` (phase rules along the run), `probe` (parity classes), `ones` (fatal all-ones lengths).

## The phase map in Lean

`lean/Phases.lean` defines the phases E(x, z) = `E>0 (10)^x 1^z`, R(x, y) = `(10)^x 1^y C>0` and Q(m, k, t) = `(10)^m 1 A>0 0 (10)^k 1^t` and the map `next` between them, and proves:

- `next_sound`: every case of the map, for all parameters (the symbolic runs are in `lean/Pieces.lean`, generated by
  `py/pieces.py`; the bounces by induction);
- `halts_iff`: the machine halts from blank tape iff the orbit of R(0, 2) (reached from blank tape in 2 steps) reaches E(x, 0) or E(x, 1);
- `no_halt_phases` (`native_decide`): not in the first 10^8 phases, about 4.1*10^21 steps;
- `even_next`, `even_safe`: even phases lead only to even phases or to all-ones tapes;
- `fatal_list`, `ones_fatal`, `ones_safe` (`native_decide`): for n < 10^5, the all-ones tape of length n halts before
  the next even phase or all-ones tape iff n is 0, 6 or 32*2^k - 2k - 12 (20, 50, 112, ...).

`py/phasemap.py` is the same map in Python with step counts: `check` compares every case with small parameters
against the machine, `run K` iterates it, `fatal N` lists the fatal lengths.

`lean/Fatal.lean` proves the fatal list for every n, by the kernel: `ones_fatal_all` (a fatal length halts) and
`ones_safe_all` (any other length cannot halt before the next all-ones tape). R(0, n) goes to E(0, n+1). From
`E(x, z)` with z odd the run is a chain of doublings `E(x, z) -> E(2x+4, z-2x-6)`, which halts exactly when
`z = zHalt x k` (`e_out`, strong induction), and `zHalt_closed` gives the closed form, so the fatal lengths are
`n = 0`, `n = 6` or `n + 2k + 12 = 32*2^k`.
## A halt needs an all-ones tape of fatal length (22 November 2026)

`lean/Ones.lean` (kernel, axioms `propext`, `Classical.choice`, `Quot.sound` only) proves

- `halt_needs_ones`: `HaltsFromBlank ↔ ∃ i n, Fatal n ∧ iter i (.r 0 2) = some (.r 0 n)`;
- `halt_passes_ones`: a halting run from blank tape passes through the configuration R(0, n) for some fatal n;
- `fatal_before`: before any halting phase reached from an all-ones tape there is an all-ones tape of fatal length.

The proof is a strong induction on the number of phases: by `ones_safe_all` a halt after a non-fatal all-ones tape
comes after a later all-ones tape, so the last all-ones tape before the halt is fatal; a fatal one halts
(`ones_fate`). The same file, with the names changed, is in all four machines of this family
(`1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE`, `1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE`,
`1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE`, `1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE`). The halting question is now
exactly: do the all-ones lengths of the orbit ever land on the fatal list?

## The recursion in rule form

As the bbchallenge wiki writes Antihydra's: exact tapes, then rules with exact step counts. The families are the
phases of the Lean map (R is the C of "What it does"):

    E(x, z)    := 0^∞ E> 0 (10)^x 1^z 0^∞
    R(x, y)    := 0^∞ (10)^x 1^y C> 0^∞
    Q(m, k, t) := 0^∞ (10)^m 1 A> 0 0 (10)^k 1^t 0^∞

    0^∞ A> 0^∞        --2-->                      R(0, 2)
    E(x, z)           --4x² + 24x + 30-->         E(2x + 4, z - 2x - 6)       left phase, z >= 2x + 7
    R(x, y)           --y² + 6y + 7 (y even)-->   R(x - ⌊y/2⌋ - 2, 2y + 5)    right phase, y >= 1, x >= ⌊y/2⌋ + 2
                      --y² + 4y + 5 (y odd)
    E(x, z + 2)       --2x + 3-->                 Q(x, 0, z)                  enter
    Q(m, k, t)        --4bk + 4b² + 6b-->         Q(m - b, k + 2b, t - 2b)    b = min(m, ⌊(t-1)/2⌋) bounces; m >= 1, t >= 3
    Q(0, k, t + 5)    --8k + 27-->                E(k + 4, t + 1)             left end
    Q(0, k, 4)        --6k + 20-->                R(0, 2k + 10)               turn right
    Q(0, k, 3)        --6k + 18-->                R(0, 2k + 8)
    Q(m, k, t)        --2k + 2t + 2-->            R(m, 2k + 2t + 3)           t <= 2
    R(0, y)           --y + 2-->                  E(0, y + 1)                 all ones
    R(1, 0)           --7-->                      R(0, 4)
    R(1, 1)           --10-->                     R(0, 6)
    R(1, y + 2)       --y + 14-->                 E(2, y + 1)
    R(x + 2, 0)       --3-->                      Q(x, 1, 0)                  to the bounces
    R(x + 2, y + 1)   --y + 4-->                  Q(x, 0, y + 2)
    E(x, 0)           --2x + 2-->                 HALT
    E(x, 1)           --2x + 4-->                 HALT

The two phase rows are runs of the rows below them. Every other line is a case of `next` (`next_sound`, `e_halts`,
`init_r`, `halts_iff` in `lean/Phases.lean`), and its step count is the step number of its piece theorem in
`lean/Pieces.lean` (a bounce is `pc_round`, 4k + 10; `next_sound` itself only says some number exists). The b-bounce
total and the phase totals are sums, not stated in Lean; the left phase as a move is also `ephase` (x >= 1)
in `lean/EPhase.lean`. `py/rules.py` reads the cases and step counts from the Lean files and checks them against
`py/phasemap.py` and direct simulation: 17 cases on 891 phases, the table's rows on 4,262 instances, and every phase
of the first 3*10^7 steps from blank tape (1,877). Example: R(0, 20) = 1^20 C> 0 halts after 22 + 30 + 190 + 28 = 270
steps (E(0, 21), E(4, 15), E(12, 1), halt), as direct simulation gives. The bbchallenge wiki page (analysis by Marco
Dos Santos) has a finer map, one bounce per rule, on its own family E(a, b, c).

## The recurrence in closed form: a doubling map (24 November 2026)

Look at the run only at its stops: `E(x, z)` with `z` even and `R(x, y)` with `y` odd. Put `s = z + 2`,
`L = 2x + z + 8` at `E(x, z)` and `s = y + 5`, `L = 2x + y + 7` at `R(x, y)`. `lean/Doubling.lean` (kernel; axioms
`propext`, `Classical.choice`, `Quot.sound`) proves, for all sizes:

- `doubling`: from every stop except those below, the next stop (one to three phases on) is again a stop, with
  `L' = L + 2` and `s' = 2s` if `2s ≤ L`, `s' = 2s - L` otherwise. That is the doubling map `s ↦ 2s mod L` on a circle
  that grows by 2 a stop; not wrapping lands on the right, wrapping on the left.
- `low`: the low end, `s = 4` (`E(x, 2)` goes to `R(x, 3)`: `s' = 8 = 2s`, but `L` stays).
- `mid_ones`: at the midpoint `2s = L + 2` the next stop is the all-ones tape of even length `L - 4`.

From a stop, an all-ones tape of the fatal parity (even; fatal lengths are 0, 6 or 32·2^k - 2k - 12) comes only from the
midpoint; the others come from `2s = L` inside the map (and, at the first few stops, from the low end). The few
phases after an all-ones tape are not stops; they make another all-ones tape straight away only for a sparse list of
lengths, 4 → 8, 18 → 24, 48 → 56, 110 → 120, ...: the even targets are 2^j - 8 (j ≥ 4), never fatal, since 2^j - 8 = 32·2^k - 2k - 12 has no solution (checked for n < 3·10^5, `py/doubling.py relays`; not in Lean). So, unrolled, `s_j = 2^j s_0 - Σ ε_i 2^(j-1-i) L_i` with `L_i = L_0 + 2i` and wrap
bits `ε_i`, and **the machine halts only if the doubling map hits its midpoint exactly at a stop with
`L = 32·2^k - 2k - 8`** (from the midpoint on, the halt is the proved fatal chain of `lean/Fatal.lean`); proving that
the escape from an all-ones tape always returns to a stop or to a relay length would make this a theorem.
`py/doubling.py check` lists every stop where the doubling form fails along the run (in 10^6 phases: the low end,
the midpoints and the phases right after an all-ones tape, nothing else); `py/doubling.py ones` lists the all-ones
tapes with the stop they came from. The other three machines of the family (`1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE`, `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE`, `1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE`)
run the same map with other offsets; the orbits of `1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE` and `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE` coincide, stop for stop, for most of their first
10^6 stops.

**Residue search** (as for the doubling-map trio): `py/doubling.py residues N` runs the phase map mod `N` (every branch
the residues allow, both halves of every bounce count) to a closed set of classes from the start. For every `N` from 2
to 48 and for `N = 64, 96, 128, 192, 256`, some reachable all-ones class is a fatal length mod `N`: no congruence or
2-adic class keeps the run off the list. In the coordinates `(s, L)` there can be none: the branches `s ↦ 2s` and
`s ↦ 2s - L` with `L ↦ L + 2` reach every residue pair of the right parity mod every `N ≤ 64`. Which branch is taken
depends on the size of `s`, and only that keeps the run off the list.

Heuristic: with `s` uniform on the circle, a midpoint at a given stop has chance about `1/L`, so up to modulus `L`
there are about `½ ln L` midpoint all-ones tapes: 7.1 in the first 20,000,000 phases (`L` up to
13,300,000), against 10 seen. The fatal moduli double, so the chance of a fatal one after the 10^11 phases
already run (`L` about 6.7·10^10) is below 10^-10.

## Status

Open. Lean (`lean/Phases.lean`, on `lean/Pieces.lean` generated by `py/pieces.py`): the whole phase map, every case for all sizes (`next_sound`); the machine halts iff the map's orbit from R(0, 2) (reached from blank tape in 2 steps) reaches E(x, 0) or E(x, 1) (`halts_iff`); no halt in the first 10^8 phases (`no_halt_phases`, `native_decide`; about 4.1*10^21 steps by the pieces' step counts); the even phases lead only to even phases or all-ones tapes (`even_next`, `even_safe`); the fatal all-ones lengths below 10^5 are 0, 6 or 32*2^k - 2k - 12 (20, 50, 112, ...) (`fatal_list`, `native_decide`). Also: no halt in 10,000 steps by the kernel and 10^7 by `native_decide` (`lean/Blank.lean`); no halt in 10^15 steps by exact macro simulation (`c/mrun.c`). For every n (`lean/Fatal.lean`, kernel): the all-ones tape of length n halts before the next all-ones tape iff n is 0, 6 or 32*2^k - 2k - 12 (20, 50, 112, ...) (`ones_fatal_all`, `ones_safe_all`). Combined (`lean/Ones.lean`, kernel): **the machine halts from blank tape iff the orbit of R(0, 2) reaches an all-ones tape R(0, n) with n fatal** (`halt_needs_ones`; in machine steps, `halt_passes_ones`). Not proved: that the orbit avoids the fatal lengths. The run at its stops is the doubling map `s ↦ 2s mod L`, `L ↦ L + 2` (`lean/Doubling.lean`), and the fatal-parity all-ones tapes reached from a stop come only from its midpoint `2s = L + 2`; no congruence keeps it off the fatal list.

## The partner map (17 November 2026)

1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE and 1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE have phase maps that agree
under phi: e(x, z) -> e(x, z), r(x, y) -> a(x, y - 1), q(m, k, t) -> q(m, k/2, t), except at the all-ones phases and
q(0, k, 0) (`py/partner.py check` in the folder of 1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE). Their runs travel
together for long stretches and part only at all-ones tapes, which is exactly where each machine decides halting,
and there the two tests never agree: by the two `fatal_list` theorems no all-ones length n < 10^5 is fatal for the
first while n - 1 is fatal for the second. So they are two halting questions, not one (`holdouts/EQUIVALENCES.md`).
