# 1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---

bbchallenge id 84927. One of the six-state holdouts whose halting from blank tape is open. One of a pair with
`1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LD1RF_0RB---` (they differ only in E0). Family: *sweeping c/a-word counter with multiplying inner phases*.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RD |
| B | 1LC | 0RA |
| C | 1LA | 0LB |
| D | 1RE | 0LC |
| E | 1LC | 1RF |
| F | 0RB | --- |

## What it does

Words: `c = 1101010`, `a = 10`. Each time the head comes back to the leftmost cell (state C), the tape is
`11010 w (10)^k 1`, where `w` is a word over `c` and `a`. Moving right, B turns `c` into `0011001` and `a` into `01`
(`b_c`, `b_a`); moving left, C crosses the shifted `a`s unchanged (`c_a`).

**Outer phase.** One round trip moves one `a` from the last block to a new `c` at the front:

    11010 w (10)^(k+2) 1  ->  11010 c w (10)^(k+1) 1      in 24·#c(w) + 4·#a(w) + 4k + 41 steps

Lean proves this for every `w` with up to four blocks of `c`s (`sweep0` … `sweep3`, all exponents symbolic). E0 is not
read, so both machines of the pair have the same rules. `py/sweepcheck.py` checks it for every `w`: in 4·10^8 steps
there are 3,216 such round trips and no exceptions. From the blank tape, `init_run` reaches the first outer
phase after 12262 steps, with `w = c a^27 c a^8 c a^2 c, k = 43`.

**Inner phases.** When the last block is used up (it then eats the last `c` too: `c 1 → 1 a^2 1 → 1 a 1 → 1 1`), the
head stops reaching the left end. A long inner phase of shorter sweeps follows near the right part of the tape. It
moves `a`s one at a time between neighbouring blocks, so block lengths multiply, and it leaves a much longer last
block. Then the outer phase resumes. Recorded by `c/jumps.c`: the steps of the left-end arrivals
just before and after the jump, and the tape there, tokenised, without its first cells (`11010` or `1`) and its
trailing `1`s:

| outer phase stops | resumes | before | after |
|---|---|---|---|
| 53,616 | 745,695 | `c^47 a^27 c a^8 c a^2` | `c a^3 (c a^2 c a^10)^23 c a^31 c a^335` |
| 3,154,621 | 55,649,188 | `c^337 a^7 (c a^2 c a^10)^23 c a^31` | `764 tokens, last ones a^589 c a^1155` |
| 106,595,396 | 208,093,169 | `c^1157 …, 765 tokens` | `763 tokens, last a^1690` |
| 381,017,882 | 2,194,023,171 | `c^2851 …, 761 tokens` | `759 tokens, last ones a^17217 c a^19492` |

After 2·10^10 steps the visited part of the tape is 294,951 cells wide.

**State F.** F is the only state that can halt (F1). It is entered only from E1 and E only from D0, so a halt needs the
head in D on `0 1 1` (D is entered only from A1, so: the head in A on `1 0 1 1`). F is part of the regular sweeps: it is entered 343,472,060 times in 2·10^10
steps, always on a 0, with context `...0011 F>0` followed by `101...` or unvisited cells (`c/fhit.c`).

## Status

Open. Lean (`lean/`):

- `Blank.lean` (generated): the halting configurations, and no halt in 10^7 steps.
- `Rules.lean` (generated by `rules.py` with `tools/py/bbtools/symtm.py`): the token sweeps, the outer round trip for
  up to four blocks, and the run from blank tape.

`init_run` and `sweep3` need raised `maxHeartbeats`/`maxRecDepth`; `check.sh` takes about 3 minutes.

Not proved: the inner phases. A proof of non-halting would need them described as rules, with an invariant on the
words they produce that keeps `D>0 1 1` away.

## For later

- Prove the outer round trip for arbitrary `w` by induction over the word, from the token rules. The left end, with
  its zigzag over the front `c`s, and the right-end turn are fixed rules.
- Describe the inner phase as a recursive call of the same sweep mechanism on the last blocks, find its macro rule (how
  the block lengths are multiplied), and build an accelerated simulator to follow many more phases.

## Shared exact engine (24 November 2026)

The three machines `1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---`, `1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LD1RF_0RB---` and
`1RB0RD_1LC0RA_1LA0LB_1RE0LC_1RA1RF_0RB---` differ only in E0, which their outer round trip never reads; one engine,
[`trio.py`](../1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---/py/trio.py), runs all three. It is exact: it never
extrapolates.

- *Sweeps.* A run of n copies of a word is crossed at once when one copy, run on its own with up to three cells of
  context, gives back the same state and context (induction on n).
- *Bounce jumps.* From a turn of the head, every run it touches gets a variable for its count; counts and the step
  counter are carried along as affine forms and every decision that depended on a count is recorded as a guard. If a
  later turn has the same state, head cells and (after a string-preserving canonical form: each run turned to the least
  rotation of its word, absorbing the whole copies next to it) the same tape with every count shifted by a constant,
  that stretch of run is a proof, for all counts that meet the guards, of a rule `X(x) -> X(x + d)`. The jump applies
  it as many times as the guards allow, with the exact step sum.
- *Groups.* Repeated sequences of runs become one run of a longer word, up to 4096 cells.

So a jump here is a theorem about the machine checked by running it symbolically, not an observation; what is not
proved is the Python code itself. [`trio_check.py`](../1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---/py/trio_check.py)
compares tape, state and head with the plain C simulator.

**Result.** From blank tape the engine ran 7.92·10^15 steps of this machine in 2 hours on one core without reaching a halting transition. Its tape, state and head were equal to the C simulator's at 5 step counts, the last at 10,794,936,210 (`data/trio_check.json`). Unlike the older `rsim.py` run above, the steps after the last check rest on exact rules, with no extrapolation; they are still a computation, not a Lean proof.

**Nested blocks (observed).** The inner phases build blocks inside blocks. The groups the engine forms are runs of
words of 38, 110, 326, 974, 2918, 8750, 26246, 78734 and 236198 cells: 2 + 4·3^(j+2) cells at level j, each level 3
times the last minus 4. Each such word is two c's in a sea of a's, `c a^x c a^y`, with x + y = 6·3^(j+1) − 6 (12, 48,
156, 480, ...); level 0 is the `c a^2 c a^10` of the first inner phase. The same sizes appear in all three machines
(the largest ones only in runs that allowed longer groups than the 4096 cells of the final runs).
