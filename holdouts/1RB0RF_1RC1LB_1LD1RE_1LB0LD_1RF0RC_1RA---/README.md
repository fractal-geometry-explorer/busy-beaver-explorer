# 1RB0RF_1RC1LB_1LD1RE_1LB0LD_1RF0RC_1RA---

bbchallenge id 95121, group G12. Whether it halts from blank tape is **open**. Family: two-level block counter (fast tail, walking block in a unary list).

| A | 1RB | 0RF |
| B | 1RC | 1LB |

## The picture

At every moment the head is in C on the first blank cell right of everything written, the tape is a list of blocks of
1s separated by single 0s. The last block is a fast counter: +5 per round, each round about twice as long as the one
before. The rest is a slow list that changes by one step per round: a short block walks left through blocks of length
1 one position per round (sometimes absorbing them, `x 0 1 -> x+2`); when it reaches a big block they merge, and big
blocks later split into a 3 and a run of 1s, which restarts the walk. Example (blocks, `1^8` = eight blocks of length
1): step 361,682 `2 1^8 15 1^8 3 7 3 1^5 55`; step 10,806,442 `2 1^8 15 3 1^8 7 3 1^5 95`; step 21,292,197
`2 1^8 17 1^9 7 3 1^5 100`; step 42,263,740 `2 1^7 3 1^16 7 3 1^5 105`; step 671,409,304 `2 1^7 3 1 1 9 1^10 7 3 1^5 125`.
Each phase takes as many rounds as there are 1s to cross, so phases grow like iterated exponentials.

## What is established

**Proved in Lean, kernel only** — The halting configurations: The machine stops exactly when it reads the symbol of a halting transition (F1); the generated statement covers every configuration. (`step_none_iff`, `lean/Blank.lean`)

**Proved in Lean, kernel only** — No halt in the first 10,000 steps: The list simulator of the shared library, proved to agree with the machine's semantics, runs 10,000 steps from blank tape without a halt, evaluated by Lean's kernel. (`blank_runs_kernel`, `lean/Blank.lean`)

**Proved in Lean, kernel only** — Three rounds of the run, for any tape further left: Three consecutive rounds of the run from blank tape (between moments the head is in C on the first 0 right of everything written), each proved for every tape left of the cells it visits, with its exact step count. (`lean/Rounds.lean` (generated by `py/gen_rounds.py`))

**Proved in Lean with `native_decide`** — No halt in the first 10^7 steps: The same run, evaluated by compiled code. (`blank_runs_native`, `lean/Blank.lean`)

**Computed (trusted C/Python)** — No halt in the first 10^9 steps: The C simulator `tools/c/triage.c` runs 10^9 steps without a halt; at the end 203 cells have been visited and 70 of them hold a 1. (`holdouts/triage.json`)

**Computed (trusted C/Python)** — Doubling rounds: No halt in 10^9 steps. Between consecutive moments the head is in C at the right end on a pure block tape the last block grows by 5; from step 3·10^5 on each round takes twice the time of the one before plus a small constant c (c = 5 or 9 during a walk, between −55 and 33 when the list is rebuilt). (`tools/c/tmrun.c` (`at C R`))

**Heuristic / observed** — A walking block in a unary list: In every round outside the rebuilds the list changes by one block moving left one position, possibly growing by 2; rebuilds merge it with a big block or split a big block into a 3 and a run of 1s. Seen in all 75 rounds of the first 10^9 steps; not shown for all sizes. (`README.md`)

**Open** — Does it halt from blank tape?: Not known. See the heuristic claims above for what a halt would need.
