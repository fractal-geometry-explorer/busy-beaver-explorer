# 1RB0RF_1RC1LB_1LD1RE_1LB0LD_1RF0RC_1RA---

bbchallenge id 95121, group G12. Whether it halts from blank tape is **open**. Family: two-level block counter (fast tail, walking block in a unary list).

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RF |
| B | 1RC | 1LB |
| C | 1LD | 1RE |
| D | 1LB | 0LD |
| E | 1RF | 0RC |
| F | 1RA | --- |


## The picture

The same model as for [`1RB0RE_0RC0RF_1LD1RA_1RE0LD_0LB1RC_1LE---`](../1RB0RE_0RC0RF_1LD1RA_1RE0LD_0LB1RC_1LE---), in another coding. At the moments the head is in C on a 0 just
right of a 1 the tape is

    1^b0 0 1^b1 0 ... 0 1^bk 0 1 0 1^l  C>  0^g1 1 0^g2 1 ... 0^gr 1

a list of blocks (the interior), a block of one 1, a last block l and a zone of single 1s. In a *regular* configuration
b0 is even, the other b_i are odd, l is a positive multiple of 5, g1 is a positive multiple of 5 and the other gaps are
4 mod 5. One *sub-round* (to the next such moment) does two independent things:

- **W** on the interior: `(..., x, 2a+1) -> (..., x+2, 1, ..., 1)` (a blocks of 1). In digits a_i = (b_i - 1)/2: drop the
  last digit a, add 1 to the one before, append a zeros.
- **the counter**: l and the zone are a binary counter; l + segments = 5(m + 1) during the 2^m sub-rounds of round m
  (`enc`/`dec` in `py/model.py`).

A list with digits a_1..a_k is a single block after exactly T = sum_i 2^(a_i + ... + a_k + k - i) steps of W. With a
single block left the sub-rounds are irregular for a while (the *transient* of a rebuild), then regular again with a
longer list. No rule is known for the transient. All of this is observed and checked against the machine, not proved.

`py/model.py run` takes regular sub-rounds by arithmetic and everything else by direct simulation (`c/trans.c`): 3,792
rebuilds, more than 2^31,736 sub-rounds, no halt. Some transients contain a second kind of regular stretch
(the block before l is 2l/5 + 1, the list counts the sub-rounds upwards in binary, a zone gap of 5q + 4 cells is used up
in about 2^(q+1) sub-rounds); the run simulates these cell by cell (q = 24 in transient 1,504) and stops after rebuild
3,792 at one that is too long.

## What is established

**Proved in Lean, kernel only** — The halting configurations: The machine stops exactly when it reads the symbol of a halting transition (F1); the generated statement covers every configuration. (`step_none_iff`, `lean/Blank.lean`)

**Proved in Lean, kernel only** — No halt in the first 10,000 steps: The list simulator of the shared library, proved to agree with the machine's semantics, runs 10,000 steps from blank tape without a halt, evaluated by Lean's kernel. (`blank_runs_kernel`, `lean/Blank.lean`)

**Proved in Lean with `native_decide`** — No halt in the first 107 steps: The same run, evaluated by compiled code. (`blank_runs_native`, `lean/Blank.lean`)

**Computed (trusted C/Python)** — No halt in the first 109 steps: The C simulator `tools/c/triage.c` runs 10^9 steps without a halt; at the end 203 cells have been visited and 70 of them hold a 1. (`holdouts/triage.json`)

**Proved in Lean, kernel only** — Three rounds of the run, for any tape further left: Three consecutive rounds of the run from blank tape (between moments the head is in C on the first 0 right of everything written), each proved for every tape left of the cells it visits, with its exact step count. (`lean/Rounds.lean` (generated by `py/gen_rounds.py`))

**Computed (trusted C/Python)** — Doubling rounds: No halt in 10^9 steps. Between consecutive moments the head is in C at the right end on a pure block tape the last block grows by 5; from step 3·10^5 on each round takes twice the time of the one before plus a small constant c (c = 5 or 9 during a walk, between −55 and 33 when the list is rebuilt). (`tools/c/tmrun.c` (`at C R`))

**Computed (trusted C/Python)** — Between rebuilds: a binary counter that applies one list operation per tick: The same model as for the sibling `1RB0RE_0RC0RF_1LD1RA_1RE0LD_0LB1RC_1LE---`, in another coding. At the moments the head is in C on a 0 just right of a 1, the tape is a list of blocks of 1s separated by single 0s (the interior), then a block of one 1, a last block l, and to the right of the head a zone of single 1s. Call it regular if the first block is even, the other interior blocks are odd, l is a positive multiple of 5, and the gaps of the zone are 0 mod 5 (the first, counted from the head) and 4 mod 5 (the others). From one such moment to the next (a sub-round) the interior takes one step W: (..., x, 2a + 1) becomes (..., x + 2, 1, ..., 1) with a blocks of 1. The last block and the zone are a binary counter: with segments s_1 = g_1, s_i = g_i + 1, a last block l > 5 becomes a new first segment l − 5 and l = 5; with l = 5 the n leading segments equal to 5 are removed, the next segment loses 5 cells (blank tape supplies them if there is none) and l = 5n + 10. So l plus the segments is 5(m + 1) for 2^m sub-rounds (one round), then m grows by 1. Checked against the machine one sub-round at a time: of the 400,000 sub-rounds after step 1,399 (16 million steps) the 399,965 regular ones all follow this; the other 35 are the transient of the first rebuild. Observed and checked, not proved. (`holdouts/1RB0RF_1RC1LB_1LD1RE_1LB0LD_1RF0RC_1RA---/py/model.py` (`check 400000`))

**Computed (trusted C/Python)** — The list is the binary expansion of the time it has left: With digits a_i = (b_i − 1)/2, W removes the last digit a, adds 1 to the digit before it and appends a zeros. A tail (..., q, a) becomes (..., q + a + 1) after exactly 2^a steps, so an interior with digits a_1, ..., a_k is a single block after exactly T = Σ_i 2^(ai + ... + ak + k − i) steps of W. (This is arithmetic on the rule W, not on the machine.) Checked on the machine: the model predicts the single block at sub-round 7,964 of that run and it is there; and after the first rebuild the lists at six ends of rounds, up to step 1.07·10^10, are those of a direct run of the machine (`2 1^7 3 1^3 7 1^10 7 3 1^4 | 1 | 120` at step 335,864,993, ..., `2 1^6 3 15 1^10 7 3 1^4 | 1 | 145` at step 10,737,738,872). (`holdouts/1RB0RF_1RC1LB_1LD1RE_1LB0LD_1RF0RC_1RA---/py/model.py` (`check 400000`, `rounds`))

**Heuristic / observed** — 3,792 rebuilds without a halt: A run that takes the regular sub-rounds by arithmetic (any number at once, with the two rules above) and gives everything else to the machine itself, cell by cell: the transient after each single block. It passes 3,792 rebuilds; by then the counter has made more than 2^31,736 sub-rounds, so the machine more than 10^9,553 steps. A halt could only be found by the direct part and none was. The arithmetic part rests on the two rules above for all sizes, which are checked, not proved. The run stops there for a practical reason. Some transients contain a second kind of regular stretch (observed, not modelled): the block before the last one is 2l/5 + 1 instead of 1, the list counts the sub-rounds upwards in binary instead of downwards, and a gap of the zone of 5q + 4 cells is used up in about 2^(q+1) sub-rounds. The 1,504th transient has one with q = 24, which the run simulates cell by cell (about 10^9 steps); after rebuild 3,792 comes one that is too long for that. (`holdouts/1RB0RF_1RC1LB_1LD1RE_1LB0LD_1RF0RC_1RA---/py/model.py` (`run 3792`), `c/trans.c`)

**Open** — Does it halt from blank tape?: Not known. Between rebuilds the machine cannot halt if the model is right; what the transient of a rebuild does has no rule yet, and a second kind of regular stretch inside the transients, in which the list counts upwards, is not modelled. The sibling `1RB0RE_0RC0RF_1LD1RA_1RE0LD_0LB1RC_1LE---`, which follows the same model, has tapes of its own shape that halt, so the shape alone is unlikely to decide this machine either.

## For later

1. Model the second kind of regular stretch (block before l equal to 2l/5 + 1, the list counting upwards, a zone gap
   that is 4 mod 5 used up 5 cells at a time; at the end the count becomes one block and the configuration is regular
   again), so that the run can go on past rebuild 3,792.
2. The transient: find its rule, so that the whole run becomes arithmetic.
3. Lean: W and the counter step as rules for all sizes, then T by induction; shared with the sibling.
