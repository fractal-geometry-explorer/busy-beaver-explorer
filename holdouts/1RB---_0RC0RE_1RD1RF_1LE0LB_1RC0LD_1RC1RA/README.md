## Status

**Open; probably nonhalting.** A counter multiplied by about 8/3 per phase drives a word of blocks; no halting word
was found. Lean proves the rounds of a phase and a whole residue-0 phase; the word dynamics is measured by simulation (trusted).

## What it does

At every phase start the head, in state C, is at the right end of the tape and the tape reads `P 1^n 0 C>0` (P a word
ending in 0, blank beyond). Each round of a phase takes three 1s from the counter and writes four pairs `01` at the
right. With fewer than three 1s left, the residue n mod 3 sends the head into P, which it edits, and on the way back the
pairs become the new counter: n' = 8(n div 3) + d, with d and the next word depending only on P and n mod 3. A
residue-0 phase absorbs the last block of P into the counter; the other residues push or edit blocks, often by a
smaller phase of the same kind run on a block of P: the word is a stack of nested counters.

Exploring the word dynamics breadth first for every sequence of residues (600 words, the longest 43 cells): no transition halts, and every one returns to a phase start.

From the first phase start (step 110, P = `1111110`, n = 12), computed exactly: no halt in 2,000 phases (n then has 2,835 bits); 20 distinct words, the longest 17 cells, and the word keeps returning to empty.

No halting word is known, so there is no coin-flip argument for a halt (unlike Antihydra-type machines); nonhalting is
plausible but needs an invariant on all reachable words, more than this pass could do.
