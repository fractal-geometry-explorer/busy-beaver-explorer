# 1RB0RB_1RC0LE_1LD1LA_---0LC_1RF1LE_1RA0RA

bbchallenge id 25221, group G10 (one side grows like √t, the other like a smaller power). Family: **halving at the wall, sandpile of even blocks**. Halting from blank tape: **open**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RB |
| B | 1RC | 0LE |
| C | 1LD | 1LA |
| D | --- | 0LC |
| E | 1RF | 1LE |
| F | 1RA | 0RA |

## What it does

Almost the whole tape is a list of blocks of 1s separated by single 0s: `1^2 0 1^6 0 1^4 0 1^10 0 1^20 0 1^40 0 1^76 0 1^46 0 1^16 0 1^4 0 1^2 0 1^2 0 … 1^2 0`. The blocks have even lengths, and the right end is a growing tail of `1^2 0` blocks (right extent ~ t^0.35; the left end barely moves: 183 cells left of the start after 10^9 steps).

**Halving.** Write W(x, R) for the wall configuration `0^inf E> 0 1^x 0 0 1 0 R` (the head in E at the left end).
If x = 2k is even, the machine cuts the block into two halves and returns to the same shape with x = k:
`W(2k, R) → W(k, 1^k 0 R)`. In the run: x = 80 → 40 → 20 → 10 → 5 (steps 252,861 to 260,127). **Lean theorem** for
every k ≥ 2 and every tape R (`halve_W` in `lean/Halving.lean`). The cut is k − 2 rounds

    0^inf 1^j E> 0 1^(2m+6) 0 0 1^p R  →  0^inf 1^(j+1) E> 0 1^(2m+4) 0 0 1^(p+1) R      (6m+27 steps, `half_round`)

(each round takes two 1s off the big block, one goes to the wall block and one past the gap) and a last round from a
block of 4 (`half_four`) that rebuilds the separator `0 0 1 0`.

**The halt.** For x = 2 the halving does not happen: the machine halts 8 steps later (D reads 0; `two_to_halt`,
`two_stuck`). Hence (**Lean**, `W_pow_halts`): W(2^j, R) halts for every j ≥ 1 and every R; and (`W_chain`)
W(2^j·q, R) reaches W(q, R') for every q ≥ 2. A chain that starts from 2^j·odd, odd > 1, stops at the odd number and
the head leaves on a long rightward sweep, which merges and shifts the blocks (the sandpile-like part: `1^8 0 1^4 0 1^4`
becomes `1^10 0 1^8 0 1^2`) before coming back with a new x. The blank tape reaches W(1, blank) after 8 steps
(`blank_to_W1`).

In the first 10^9 steps there are 121 chains; their starting values grow irregularly to about 1,800 (1, 5, 6, 7, 17, 14, 18, 12, 41, 37, 51, 76, 46, 80, …, 1635, 1413, 1258, 749) and none is a power of two. The number of halvings per chain (the 2-adic valuation of the start) is distributed like that of random integers (0: 63, 1: 32, 2: 14, 3: 8, 4: 3, 5: 1).

## Halting

A chain starting at a power of two halts (a theorem). That this is the only way to halt is heuristic: the long sweep from W(odd) to the next wall is not proved. The 5-cell closed language agrees on where: it allows a halt only at the left wall, D reading 0 with one 1 to its left and blank beyond. If the chain starts behave like random numbers of size N, the chance of a power of two is about log₂N/N per chain, and the starts grow, so the expected number of hits converges: probably never halts, but nothing here proves it.

Closed tape language with 5-cell windows (`python3 -m bbtools.ctl M 5`, trusted Python check): a halt (D reading 0) needs the head at the left wall: one 1 to its left and blank tape beyond, `01010`/`01011` to the right (only 2 of the abstract configurations can halt). This is the halt at x = 2 of the halving chains.

## What is proved

- `lean/Halving.lean` (hand-written induction over `lean/HalvingRules.lean`, generated by `py/rules.py` with
  `bbtools.symtm`), kernel: `halve_W` (W(2k, R) → W(k, 1^k 0 R), k ≥ 2), `W_two_halts`, `W_pow_halts` (W(2^j, R)
  halts, j ≥ 1), `W_chain` (W(2^j q, R) → W(q, R'), q ≥ 2), `blank_to_W1`.
- `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`); no halt in 10,000 steps (kernel) and 10^7 steps (`native_decide`).
- `lean/Sweeps.lean`: 2 shift rules, kernel-checked: D and C cross `10`/`01` leftward unchanged (`sweep_lD_10_1`, `sweep_lC_01_0`).
- `lean/Rules.lean`: `two_to_halt`, `two_stuck` (kernel).

Not proved: the sweep from W(odd, R) back to the next wall configuration (so the sequence of chain starts is only
observed), and that a halt can only happen at the end of a chain (the 5-cell closed language says so, trusted
Python). Nothing proved here decides halting.

## For later

Find the rule of the sweeps (block list → block list) and so the map from one chain start to the next; then halting
becomes a question about that map hitting a power of two (open, Collatz-like). What the run shows: after an odd chain
end the head moves right through the list, shifting each block by a zig-zag that moves two 1s per round
(`1^a 0 1^(2i) 0 B> 1^(b-2i) …`); at the right end each bounce adds a block `1^2 0` and sends a leftward carry that
changes a few middle blocks (`1^76 0 1^46 0 1^16 0 1^4` → `1^76 0 1^48 0 1^20 0 1^2`). Many bounces happen between two
wall visits, so the map between chain starts is a composition of many sandpile-like moves; the next step is to write
one bounce as a rule on the block list and prove it like the halving.
