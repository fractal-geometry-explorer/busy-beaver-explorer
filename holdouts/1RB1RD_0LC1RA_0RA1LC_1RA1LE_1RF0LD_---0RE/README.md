# 1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE

bbchallenge id 113619. The tape is an alternating block `(10)^x` next to a solid block `1^y`; the machine doubles one at the other's expense, back and forth. It halts only after an all-ones tape `1^n` with n in a sparse list.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RD |
| B | 0LC | 1RA |
| C | 0RA | 1LC |
| D | 1RA | 1LE |
| E | 1RF | 0LD |
| F | --- | 0RE |

## What it does

Stop the run whenever the head reaches a new cell: the tape is always `(10)^x 1^y` (plus a short end). Write
`E(x,z)` for `E>0 (10)^x 1^z` (head at the left end, blank around) and `A(x,y)` for `(10)^x 1^y A>0`.

- **Left phase**: `E(x,z) -> E(2x+4, z-2x-6)` while `z >= 2x+8`, in `4x^2+24x+30` steps. The head bounces between
  the blocks; each bounce moves one `10` across and turns two 1s into a `10`.
- **Right phase**: `A(x,y) -> A(x-y/2, 2y+2)` for even `y` while it fits, in `y^2+2y+6` steps.
- When a doubling no longer fits, the phase switches and the tape grows by a few cells. Doubling a block of size x
  costs about x^2 steps, so the width grows like t^(1/3).

Both rules held at all 1,041 doublings of the first 10^9 steps (`py/phases.py check`).

## Halting

F0 halts; F is entered only from E0, and E/F walk right over `0101...`. So it halts only from `E(x,0)` or `E(x,1)`:
a left phase that leaves exactly one 1 (`z - 2x - 6 = 1`).

Probing all two-block tapes with `x, y, z < 150` (`py/phases.py probe`): call `E(x,z)` with even `z >= 2` and `A(x,y)`
with `x >= 1`, even `y` *even*. An even tape always leads to an even tape or to an all-ones tape `1^n A>0`, never to
a halt. From `1^n A>0` the machine halts exactly for n in {1, 3, 6, 13, 35, 81, 175, 365} (n <= 400): n = 12*2^k - 2k - 9
and 1, 6 — the left phase restarts at x = 2, x goes 2, 8, 20, 44, ... and the ones run out leaving one.

All-ones moments are rare: n = 5, 10, 14, 30, 61, 89, 169, 222, 382, 542, 781 in the first 10^9 steps (the last at
step 6,712,466). Between 10^9 and 10^15 steps (`c/mrun.c`) only five more: n = 9705, 59501, 77694, 271974, 311881. None is in the list. So the halting question is whether a doubling map ever lands exactly
on a sparse target: very probably not, but not provable with these tools.

Near-duplicates `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE` and `1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE` share the
left phase and behave the same way.

## Files

- `c/mrun.c`: exact macro simulator (blocks of K cells, runs crossed at once), `gcc -O2 -o mrun c/mrun.c`,
  `./mrun MACHINE 2 STEPS [EVERY [SIDE]]`.
- `py/gen_rules.py`: writes `lean/Rules.lean` (start, bounce and end pieces of both phases, by `bbtools.symtm`);
  `lean/EPhase.lean` composes them, with induction on the bounces, into `ephase` and `aphase`.
- `py/phases.py`: checks the phase rules along the run (`check`), probes the abstract map (`probe`), and lists the
  all-ones lengths that halt (`ones`).

## The phase map in Lean

`lean/Phases.lean` defines the phases E(x, z) = `E>0 (10)^x 1^z`, A(x, y) = `(10)^x 1^y A>0` and Q(m, j, t) = `(10)^m 1 D>0 0 (1010)^j 1^t` and the map `next` between them, and proves:

- `next_sound`: every case of the map, for all parameters (the symbolic runs are in `lean/Pieces.lean`, generated by
  `py/pieces.py`; the bounces by induction);
- `halts_iff`: the machine halts from blank tape iff the orbit of A(0, 0) (the blank tape) reaches E(x, 0) or E(x, 1);
- `no_halt_phases` (`native_decide`): not in the first 10^8 phases, about 4.1*10^21 steps;
- `even_next`, `even_safe`: even phases lead only to even phases or to all-ones tapes;
- `fatal_list`, `ones_fatal`, `ones_safe` (`native_decide`): for n < 10^5, the all-ones tape of length n halts before
  the next even phase or all-ones tape iff n is 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...).

`py/phasemap.py` is the same map in Python with step counts: `check` compares every case with small parameters
against the machine, `run K` iterates it, `fatal N` lists the fatal lengths.

`lean/Fatal.lean` proves the fatal list for every n, by the kernel: `ones_fatal_all` (a fatal length halts) and
`ones_safe_all` (any other length cannot halt before the next all-ones tape). From `E(x, z)` with z odd the run is a
chain of doublings `E(x, z) -> E(2x+4, z-2x-6)`, which halts exactly when `z = zHalt x k` (`e_fate`, strong induction),
and `zHalt_closed` gives the closed form, so the fatal lengths are `n = 1` or `n + 2k + 9 = 12*2^k`.

## Status

Open. Lean (`lean/Phases.lean`, on `lean/Pieces.lean` generated by `py/pieces.py`): the whole phase map, every case for all sizes (`next_sound`); the machine halts iff the map's orbit from A(0, 0) (the blank tape) reaches E(x, 0) or E(x, 1) (`halts_iff`); no halt in the first 10^8 phases (`no_halt_phases`, `native_decide`; about 4.1*10^21 steps by the pieces' step counts); the even phases lead only to even phases or all-ones tapes (`even_next`, `even_safe`); the fatal all-ones lengths below 10^5 are 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...) (`fatal_list`, `native_decide`). Also: no halt in 10,000 steps by the kernel and 10^7 by `native_decide` (`lean/Blank.lean`); no halt in 10^15 steps by exact macro simulation (`c/mrun.c`). For every n (`lean/Fatal.lean`, kernel): the all-ones tape of length n halts before the next all-ones tape iff n is 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...) (`ones_fatal_all`, `ones_safe_all`). Not proved: that the orbit avoids the fatal lengths.
