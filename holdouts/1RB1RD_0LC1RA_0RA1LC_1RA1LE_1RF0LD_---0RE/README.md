# 1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE

bbchallenge id 113619. The tape is an alternating block `(10)^x` next to a solid block `1^y`; the machine doubles one at the other's expense, back and forth. It halts only after an all-ones tape `1^n` with n in a sparse list.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RD |
| B | 0LC | 1RA |
| C | 0RA | 1LC |
| D | 1RA | 1LE |
| E | 1RF | 0LD |
| F | --- | 0RE |

## What it does

Stop the run whenever the head reaches a new cell: the tape is always `(10)^x 1^y` (plus a short end). Write
`E(x,z)` for `E>0 (10)^x 1^z` (head at the left end, blank around) and `A(x,y)` for `(10)^x 1^y A>0`.

- **Left phase**: `E(x,z) -> E(2x+4, z-2x-6)` while `z >= 2x+8`, in `4x^2+24x+30` steps. The head bounces between
  the blocks; each bounce moves one `10` across and turns two 1s into a `10`.
- **Right phase**: `A(x,y) -> A(x-y/2, 2y+2)` for even `y` while it fits, in `y^2+2y+6` steps.
- When a doubling no longer fits, the phase switches and the tape grows by a few cells. Doubling a block of size x
  costs about x^2 steps, so the width grows like t^(1/3).

Both rules held at all 1,041 doublings of the first 10^9 steps (`py/phases.py check`).

## Halting

F0 halts; F is entered only from E0, and E/F walk right over `0101...`. So it halts only from `E(x,0)` or `E(x,1)`:
a left phase that leaves exactly one 1 (`z - 2x - 6 = 1`).

Probing all two-block tapes with `x, y, z < 150` (`py/phases.py probe`): call `E(x,z)` with even `z >= 2` and `A(x,y)`
with `x >= 1`, even `y` *even*. An even tape always leads to an even tape or to an all-ones tape `1^n A>0`, never to
a halt. From `1^n A>0` the machine halts exactly for n in {1, 3, 6, 13, 35, 81, 175, 365} (n <= 400): n = 12*2^k - 2k - 9
and 1, 6 — the left phase restarts at x = 2, x goes 2, 8, 20, 44, ... and the ones run out leaving one.

All-ones moments are rare: n = 5, 10, 14, 30, 61, 89, 169, 222, 382, 542, 781 in the first 10^9 steps (the last at
step 6,712,466). Between 10^9 and 10^15 steps (`c/mrun.c`) only five more: n = 9705, 59501, 77694, 271974, 311881. None is in the list. So the halting question is whether a doubling map ever lands exactly
on a sparse target: very probably not, but not provable with these tools.

Near-duplicates `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE` and `1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE` share the
left phase and behave the same way.

## Files

- `py/doubling.py`: `check` (the doubling form along the run), `ones` (all-ones tapes and the stop before), `residues N` (the residue search).
- `lean/Doubling.lean`: the phase map at its stops is the doubling map (`doubling`, `mid_ones`, `low`).
- `c/mrun.c`: exact macro simulator (blocks of K cells, runs crossed at once), `gcc -O2 -o mrun c/mrun.c`,
  `./mrun MACHINE 2 STEPS [EVERY [SIDE]]`.
- `py/gen_rules.py`: writes `lean/Rules.lean` (start, bounce and end pieces of both phases, by `bbtools.symtm`);
  `lean/EPhase.lean` composes them, with induction on the bounces, into `ephase` and `aphase`.
- `py/phases.py`: checks the phase rules along the run (`check`), probes the abstract map (`probe`), and lists the
  all-ones lengths that halt (`ones`).

## The phase map in Lean

`lean/Phases.lean` defines the phases E(x, z) = `E>0 (10)^x 1^z`, A(x, y) = `(10)^x 1^y A>0` and Q(m, j, t) = `(10)^m 1 D>0 0 (1010)^j 1^t` and the map `next` between them, and proves:

- `next_sound`: every case of the map, for all parameters (the symbolic runs are in `lean/Pieces.lean`, generated by
  `py/pieces.py`; the bounces by induction);
- `halts_iff`: the machine halts from blank tape iff the orbit of A(0, 0) (the blank tape) reaches E(x, 0) or E(x, 1);
- `no_halt_phases` (`native_decide`): not in the first 10^8 phases, about 4.1*10^21 steps;
- `even_next`, `even_safe`: even phases lead only to even phases or to all-ones tapes;
- `fatal_list`, `ones_fatal`, `ones_safe` (`native_decide`): for n < 10^5, the all-ones tape of length n halts before
  the next even phase or all-ones tape iff n is 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...).

`py/phasemap.py` is the same map in Python with step counts: `check` compares every case with small parameters
against the machine, `run K` iterates it, `fatal N` lists the fatal lengths.

`lean/Fatal.lean` proves the fatal list for every n, by the kernel: `ones_fatal_all` (a fatal length halts) and
`ones_safe_all` (any other length cannot halt before the next all-ones tape). From `E(x, z)` with z odd the run is a
chain of doublings `E(x, z) -> E(2x+4, z-2x-6)`, which halts exactly when `z = zHalt x k` (`e_fate`, strong induction),
and `zHalt_closed` gives the closed form, so the fatal lengths are `n = 1` or `n + 2k + 9 = 12*2^k`.

## A halt needs an all-ones tape of fatal length (22 November 2026)

`lean/Ones.lean` (kernel, axioms `propext`, `Classical.choice`, `Quot.sound` only) proves

- `halt_needs_ones`: `HaltsFromBlank ↔ ∃ i n, Fatal n ∧ iter i (.a 0 0) = some (.a 0 n)`;
- `halt_passes_ones`: a halting run from blank tape passes through the configuration A(0, n) for some fatal n;
- `fatal_before`: before any halting phase reached from an all-ones tape there is an all-ones tape of fatal length.

The proof is a strong induction on the number of phases: by `ones_safe_all` a halt after a non-fatal all-ones tape
comes after a later all-ones tape, so the last all-ones tape before the halt is fatal; a fatal one halts
(`ones_fate`). The same file, with the names changed, is in all four machines of this family
(`1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE`, `1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE`,
`1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE`, `1RB1RD_0LC1RA_0RA1LC_1RA1LE_1RF0LD_---0RE`). The halting question is now
exactly: do the all-ones lengths of the orbit ever land on the fatal list?

## The recursion in rule form

As the bbchallenge wiki writes Antihydra's: exact tapes, then rules with exact step counts. The families are the
phases of the Lean map:

    E(x, z)    := 0^∞ E> 0 (10)^x 1^z 0^∞
    A(x, y)    := 0^∞ (10)^x 1^y A> 0^∞          (the blank tape is A(0, 0))
    Q(m, j, t) := 0^∞ (10)^m 1 D> 0 0 (1010)^j 1^t 0^∞

    E(x, z)           --4x² + 24x + 30-->         E(2x + 4, z - 2x - 6)       left phase, z >= 2x + 7
    A(x, y)           --y² + 2y + 6 (y even)-->   A(x - ⌈y/2⌉, 2y + 2)        right phase, y >= 1, x >= ⌈y/2⌉
                      --y² + 4y + 6 (y odd)
    E(x, z + 2)       --2x + 3-->                 Q(x, 0, z)                  enter
    Q(m, j, t)        --8bj + 4b² + 6b-->         Q(m - b, j + b, t - 2b)     b = min(m, ⌊(t-1)/2⌋) bounces; m >= 1, t >= 3
    Q(0, j, t + 5)    --16j + 27-->               E(2j + 4, t + 1)            left end
    Q(0, j, 4)        --12j + 19-->               A(0, 4j + 9)                turn right
    Q(0, j, 3)        --12j + 17-->               A(0, 4j + 7)
    Q(m, j, 2)        --4j + 5-->                 A(m, 4j + 6)
    Q(m, j, 1)        --4j + 3-->                 A(m, 4j + 4)
    Q(m + 1, j, 0)    --8j + 10-->                Q(m, 0, 4j + 2)             no 1s left
    Q(0, 0, 0)        --15-->                     A(0, 5)
    Q(0, j + 1, 0)    --8j + 27-->                E(2, 4j + 4)
    A(x + 1, y + 1)   --y + 8-->                  Q(x, 0, y + 1)              to the bounces
    A(x, 0)           --6-->                      A(x, 2)
    A(0, 1)           --30-->                     E(2, 1)                     all ones
    A(0, 2)           --14-->                     A(0, 5)
    A(0, y + 3)       --y + 19-->                 E(2, y + 1)
    E(x, 0)           --2x + 2-->                 HALT
    E(x, 1)           --2x + 4-->                 HALT

The two phase rows are runs of the rows below them. Every other line is a case of `next` (`next_sound`, `e_halts`,
`init_pa`, `halts_iff` in `lean/Phases.lean`), and its step count is the step number of its piece theorem in
`lean/Pieces.lean` (a bounce is `pc_round`, 8j + 10; `next_sound` itself only says some number exists). The b-bounce
total and the phase totals are sums, not stated in Lean; the phases as moves are also `ephase` (x >= 1) and
`aphase` (even y >= 4, x >= y/2 + 1) in `lean/EPhase.lean`. `py/rules.py` reads the cases and step counts from the Lean files and checks them against
`py/phasemap.py` and direct simulation: 18 cases on 891 phases, the table's rows on 2,967 instances, and every phase
of the first 3*10^7 steps from blank tape (1,891). Example: A(0, 13) = 1^13 A> 0 halts after 29 + 94 + 20 = 143 steps
(E(2, 11), E(8, 1), halt), as direct simulation gives. The bbchallenge wiki page (analysis by Marco Dos Santos) has a
finer map, one bounce per rule, on its own families P_1, P_2 and D.

## The recurrence in closed form: a doubling map (24 November 2026)

Look at the run only at its stops: `E(x, z)` with `z` even and `A(x, y)` with `y` even. Put `s = z`,
`L = 2x + z + 6` at `E(x, z)` and `s = y + 2`, `L = 2x + y + 6` at `A(x, y)`. `lean/Doubling.lean` (kernel; axioms
`propext`, `Classical.choice`, `Quot.sound`) proves, for all sizes:

- `doubling`: from every stop except those below, the next stop (one to three phases on) is again a stop, with
  `L' = L + 2` and `s' = 2s` if `2s ≤ L`, `s' = 2s - L` otherwise. That is the doubling map `s ↦ 2s mod L` on a circle
  that grows by 2 a stop; not wrapping lands on the right, wrapping on the left.
- `low`: the low end, `E(x, 2)` (`s = 2`; it goes to `A(x - 1, 6)`: `s' = 8 = 4s`).
- `mid_ones`: at the midpoint `2s = L` the next stop is the all-ones tape of odd length `L - 3`.

From a stop, an all-ones tape of the fatal parity (odd; fatal lengths are 1 or 12·2^k - 2k - 9) comes only from the
midpoint; the others come from `2s = L - 2` inside the map (and, at the first few stops, from the low end). The few
phases after an all-ones tape are not stops; they make another all-ones tape straight away only for a sparse list of
lengths, 2 → 5, 11 → 15, 33 → 39, 79 → 87, ...: the odd targets are 3·2^j - 9 (j ≥ 3) and 5, never fatal, since 3·2^j - 9 = 12·2^k - 2k - 9 has no solution with j ≥ 3 (checked for n < 3·10^5, `py/doubling.py relays`; not in Lean). So, unrolled, `s_j = 2^j s_0 - Σ ε_i 2^(j-1-i) L_i` with `L_i = L_0 + 2i` and wrap
bits `ε_i`, and **the machine halts only if the doubling map hits its midpoint exactly at a stop with
`L = 12·2^k - 2k - 6`** (from the midpoint on, the halt is the proved fatal chain of `lean/Fatal.lean`); proving that
the escape from an all-ones tape always returns to a stop or to a relay length would make this a theorem.
`py/doubling.py check` lists every stop where the doubling form fails along the run (in 10^6 phases: the low end,
the midpoints and the phases right after an all-ones tape, nothing else); `py/doubling.py ones` lists the all-ones
tapes with the stop they came from. The other three machines of the family (`1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE`, `1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE`, `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE`)
run the same map with other offsets; the orbits of `1RB1LE_1RC1RA_0LD1RB_1LE1LD_1RF0LA_---0RE` and `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE` coincide, stop for stop, for most of their first
10^6 stops.

**Residue search** (as for the doubling-map trio): `py/doubling.py residues N` runs the phase map mod `N` (every branch
the residues allow, both halves of every bounce count) to a closed set of classes from the start. For every `N` from 2
to 48 and for `N = 64, 96, 128, 192, 256`, some reachable all-ones class is a fatal length mod `N`: no congruence or
2-adic class keeps the run off the list. In the coordinates `(s, L)` there can be none: the branches `s ↦ 2s` and
`s ↦ 2s - L` with `L ↦ L + 2` reach every residue pair of the right parity mod every `N ≤ 64`. Which branch is taken
depends on the size of `s`, and only that keeps the run off the list.

**Residues with the level and the size** (26 November 2026, section G of
`holdouts/recent-proofs/technique-survey-nov26.md`). The search above takes the fatal lengths mod `N` for every `k`
at once and ignores sizes. `py/sizeresidues.py` (in the folder of 1RB1RD_0LC1RA_1RA1LC_0RB1LE_1RF0LD_---0RE, with the
offsets of all four machines) refines it on the doubling form: a class is (`s mod N`, `u mod N`, `k mod P`, the cell
of `s/L` among `B` cells, the half of the level), where `k` is the level of `L`, `u` its distance from the fatal
`L` of that level, and `P` a common period of `k` and `2^k`. From the class of a point far along a model orbit it
follows real steps of the map from members of many sizes. For `N` = 2..13, 15, 16, 24, 27, 32 and `B` = 2, 8, 32
every one of the 51 searches reaches the class of a fatal midpoint, for each of the four machines. So no closed set
of such classes keeps the doubling map off its fatal midpoints. Trusted (Python, about 80 s); no hit, so nothing to
check in Lean.

Heuristic: with `s` uniform on the circle, a midpoint at a given stop has chance about `1/L`, so up to modulus `L`
there are about `½ ln L` midpoint all-ones tapes: 7.1 in the first 20,000,000 phases (`L` up to
13,300,000), against 11 seen. The fatal moduli double, so the chance of a fatal one after the 10^11 phases
already run (`L` about 6.7·10^10) is below 10^-10.

## Status

Open. Lean (`lean/Phases.lean`, on `lean/Pieces.lean` generated by `py/pieces.py`): the whole phase map, every case for all sizes (`next_sound`); the machine halts iff the map's orbit from A(0, 0) (the blank tape) reaches E(x, 0) or E(x, 1) (`halts_iff`); no halt in the first 10^8 phases (`no_halt_phases`, `native_decide`; about 4.1*10^21 steps by the pieces' step counts); the even phases lead only to even phases or all-ones tapes (`even_next`, `even_safe`); the fatal all-ones lengths below 10^5 are 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...) (`fatal_list`, `native_decide`). Also: no halt in 10,000 steps by the kernel and 10^7 by `native_decide` (`lean/Blank.lean`); no halt in 10^15 steps by exact macro simulation (`c/mrun.c`). For every n (`lean/Fatal.lean`, kernel): the all-ones tape of length n halts before the next all-ones tape iff n is 1 or 12*2^k - 2k - 9 (3, 13, 35, 81, ...) (`ones_fatal_all`, `ones_safe_all`). Combined (`lean/Ones.lean`, kernel): **the machine halts from blank tape iff the orbit of A(0, 0) reaches an all-ones tape A(0, n) with n fatal** (`halt_needs_ones`; in machine steps, `halt_passes_ones`). Not proved: that the orbit avoids the fatal lengths. The run at its stops is the doubling map `s ↦ 2s mod L`, `L ↦ L + 2` (`lean/Doubling.lean`), and the fatal-parity all-ones tapes reached from a stop come only from its midpoint `2s = L`; no congruence keeps it off the fatal list.

## Long orbit run (16 November 2026)

`tools/c/doubling_phases.c` (machine 1) is `next` of `lean/Phases.lean` transcribed case by case into C with 64-bit
counts (with the step count of each case from `py/phasemap.py`, for reporting only); its states and step counts agree
with `py/phasemap.py` on the first 300,000 phases. From the blank tape (A(0, 0)) it iterated **10^11 phases**

## Later
