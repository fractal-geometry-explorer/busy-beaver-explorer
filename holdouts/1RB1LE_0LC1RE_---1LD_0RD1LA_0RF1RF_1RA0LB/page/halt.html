The machine can only halt in state C on a 0, and C is only entered when B reads a 0 and steps left. Inside the tape every 0 stands alone, so this needs B at the blank left end.

When the fuel is gone, the tail is 0 3 1 0 3 1 0 5 with blank tape behind it, and an H-hit is due. Its first three calls come back as usual. In the fourth the head runs through the tail in state C, turns the last pairs over, and B arrives on the blank cell left of the tape: one step left, C reads a 0, and the machine halts. The halting step is given in the bottom line.

The earlier arrivals at the left end (visits 3, 11, 25, 3,006) came in other states and only reset the ladder.

How many steps. The halting step is known exactly (see the bottom line): about 1.2736·10758, so between 10758 and 2·10758. The Lean proof states it (halt_step), and two independent programs give the same number. A rough estimate explains its size: the halt comes at visit 6.46·10378, which is about 9.3·(8/3)887 because each of the 887 levels gets 3/8 of the hits of the one above it. The tape grows by about two cells per visit, and each visit runs over the whole tape, so the step is about 3·(visits)2. The Coq proof shows that the machine halts but does not count steps.

Kernel last_visit_halts in lean/Levels.lean: the last visit on the word without its 887 levels, 2 1 0 3 1 0 3 1 0 5 with blank tape to the left, reaches a halting configuration after 278 steps. With the levels in between, the halt comes in the same call, later by the steps each level makes before it (haltUp_sound, frontHalt_sound, and the constants of level_halt).
