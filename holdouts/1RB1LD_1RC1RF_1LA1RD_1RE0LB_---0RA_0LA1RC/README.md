# 1RB1LD_1RC1RF_1LA1RD_1RE0LB_---0RA_0LA1RC

bbchallenge id 157488. One of the six-state holdouts whose halting from blank tape is open. In every run so far (10^9 steps) it writes the same tape as
[`1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD`](../1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD/README.md), step for step. This is observed; Lean proves it only up to
the first break (see Related machines). What is proved or computed there about the tape holds here while the two agree. The tools are in that folder.

## What it does

**A base-4 countdown on a list of blocks, and an exact map for the whole run.** At the start of every tick the tape
reads `0^inf 1110 (111110)^n 1 A> [word] 0^inf`, with n even. Read in cell pairs `1b` -> b, the word is a bit string
made of blocks of v = `010` and the separators `0`, `10`, `001`, `1` (r, q, p, s). A tick is a borrow into the
separator after the first block, the timer:

- r -> q costs the block after it one;
- q -> p costs the block before it one;
- p -> s changes nothing;
- s -> r costs the block before one, gives the block after one, and passes the borrow on.

The w-block on the left grows by two copies per tick. When a borrow runs through every separator to the far end
(overflow), the list (n; x1, ..., xk) becomes (6; n+1, x1-1, x2-1, x3, ..., xk): the grown w-block becomes the new
timer. The [twin's README](../1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD/README.md) has the full rule set: the other phase of the tick, the
wall `0101 v^x`, the events, and the far end.

## The twin

The two machines write the same symbol at the same cell and move the same way at every one of the first 10^9 steps
(`holdouts/1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD/c/twin.c`). Their tick boundaries agree to 6·10^9 steps
(`c/rword.c`). State C of one is split between C and E of the other, according to the symbol under the head. The
correspondence lasts as long as three local patterns hold: after B reads 0 the next cell is 0, after D reads 0 it is
1, and after E reads 1 it is 1.

## The map against the machine

`holdouts/1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD/py/macro.py`, given this machine's transitions, computes its
events by running this machine on cut copies. Over the first 6·10^9 steps it reproduces 22,198 of 22,198 tick
boundaries exactly: n, the word and the step count. 53 of the moves are events, each computed with two cuts that
agree.

## Rules proved in Lean (`lean/Rules.lean`, generated by `lean/rules.py`)

These are the same nine statements as for the twin, proved for this machine's transitions:

- `tick_r`, `tick_q`, `tick_p`, `tick_s`: the four ticks;
- `tick_w`, `tick_q2`, `tick_p1`: the wall cycle;
- `overflow_2`, `overflow_3`: overflow with two and three blocks.

## Status

**Open, the same as its twin.** Proved in Lean: the halting configurations, no halt in 10^7 steps
(`lean/Blank.lean`), and the nine rules (`lean/Rules.lean`). Checked against the machine: the map reproduces every
tick boundary of the first 6·10^9 steps. The far end and the long run of the map are in the twin's README.

## Related machines

Other holdouts of the list of 608 that are tied to this one. The comparison of tables is exact; everything about runs was checked on the first 10^7 steps of each machine and is an observation, not a proof (`holdouts/related.py`, `holdouts/related.json`).

**Same run as [`1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD`](../1RB1LD_1RC1RE_1LA0RA_1RC0LB_0LA1RF_---1RD/README.md) (observed, not proved).** At every one of the first 10^7 steps from blank tape the two machines have the same tape and the head on the same cell. Their tables differ, and no renaming of the states turns one into the other. While they run, the states pair up as A–A, B–B, C–C, C–F, D–D, E–C, F–E (this machine first), which is not one to one. Transitions not used in these steps: this machine never uses E0 and the other never uses F0. Lean proves (`lean/Twin.lean` here, `lock_or_break`, `not_halts_of_noBreak`) that the two runs have the same tape, the same head position and paired states up to the first break, a configuration where the paired states act differently, and that neither machine halts if no break ever comes. A halt of either machine is itself a break, and the halting transitions of the two do not correspond, so the two are not known to halt together.

**Same table as the machine below, started in another state.** Renaming the states as shown turns this machine's table into the other one, the halting transition included. The other machine starts in its own state A, which is not this machine's A: its run from blank tape is the run of this table started in another state. These are different runs: in the first 10^7 steps of each, no configuration of this machine's run occurs in the other, even up to a shift of the tape. So each of these holdouts is its own halting question, and settling one does not settle another.
