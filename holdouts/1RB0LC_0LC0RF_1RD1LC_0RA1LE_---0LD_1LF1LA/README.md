## Status

**Open; a Collatz-type problem, reduced exactly to a three-counter map** (Lean, kernel).

## What it does

Every time the head, in state D, is at the left end of the tape, the tape is `D> 0 0 1^a 0 1^b (01)^c` (blank on both
sides). From one such moment to the next:

| case | becomes |
|---|---|
| a ≥ 3 | (a − 2, b + 3, c) |
| a = 1, c ≥ 1 | (b + 1, 4, c − 1) |
| a = 1, c = 0 | (b + 1, 3, 0) |
| a = 2, c ≥ 3 | (b + 6, 4, c − 3) |
| a = 2, c = 2 / 1 | (b + 6, 3, 0) / (b + 5, 3, 0) |
| a = 2, c = 0, b even | (1, 1, b/2 + 1): the pairs are refilled |
| a = 2, c = 0, b odd | **halt** (D reads a 1, E reads a 0) |

So a run of rounds takes the first block a to about 3a/2 (3a/2 + 7 for a even, (3a + 7)/2 for a odd: Antihydra's map),
and the `01` pairs are a budget: an even value costs 3 pairs, an odd one 1. When the budget is gone the next even value
decides: 0 mod 4 refills the budget with half the second block, 2 mod 4 halts.

From blank tape the run reaches (1, 1, 4) at step 138. The budget has run out four times and was refilled each time,
at cycles 3, 8, 25 and 2,549, to 9, 31, 4,966 and a 1,479-bit number of pairs. The next decision is about 2^1478
rounds away. If the parities behave like coin flips the machine halts with probability 1 (each budget is a fair
coin), but proving anything about them is the same problem as for Antihydra.

## Results

- `lean/Rules.lean` (generated by `py/rules.py` with `tools/py/bbtools/symtm.py`): the ten rules and the halt, for
  all values of the parameters (kernel).
- `lean/Map.lean`: `halts_iff`: the machine halts from blank tape iff the orbit of (1, 1, 4) under `next` reaches
  `halt` (kernel; `init_X` by `decide +kernel`).
- `py/map.py check 4e8`: the map agrees with the C simulator at all 27,727 left-end visits of the first 4·10^8 steps.
- `py/map.py orbit`: the four refills (exact big-integer iteration).
- Lean (`lean/Blank.lean`): no halt in 10^7 steps; C (`tools/c/triage.c`): none in 10^9.
