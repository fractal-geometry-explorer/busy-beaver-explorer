# 1RB---_0RC0LD_1LB1RC_0LE0LF_1RD1LE_1RF1RA

bbchallenge id 15414. One of the six-state holdouts whose halting from blank tape is open. Family: **two-thirds block splitter**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | --- |
| B | 0RC | 0LD |
| C | 1LB | 1RC |
| D | 0LE | 0LF |
| E | 1RD | 1LE |
| F | 1RF | 1RA |

## Status

Open, reduced to an exact question. Lean (`lean/Blocks.lean`, kernel only): the machine is the **block map** below
(`next_sound`); it halts from blank tape iff the block map, from the frame `B [1] []`, reaches one of three critical
frames (`halts_iff_critical`). By `native_decide` none of the first 10^8 frames is critical (`no_halt_frames`;
300,362,311,724 machine steps by `py/blockmap.py run 100000000`). C: no halt in 10^9 steps.

## The block map (Lean)

`blk [a, b, c, ...]` is the tape `1^a 0 1^b 0 1^c 0 ...`, then blank, read away from the head (a block may be empty:
`0 0` is an empty block; the empty list is blank tape). A frame is a state and the block lists of both sides:

    E L R :  blk(L) E> 0 blk(R)        C L R :  blk(L) C> 0 blk(R)
    B L R :  blk(L) B> blk(R)          F L R :  blk(L) F> blk(R)

The map (`next` in `lean/Blocks.lean`, `nxt` in `py/blockmap.py`; a missing block counts as 0):

| frame | condition | next frame | steps |
|---|---|---|---|
| `E (i :: L) (m :: R)` | m = 0 | `E L (i+1 :: R)` | i+3 |
| `E (i :: L) (1 :: r :: R)` | | `C (r :: i+2 :: L) R` | r+5 |
| `E (i :: L) (m :: R)` | m ≥ 2 | `C (m−2 :: i+2 :: L) R` | m+7 |
| `C (0 :: L) (r :: R)` | | `C (r+1 :: L) R` | r+3 |
| `C (1 :: b :: L) (r :: R)` | | `E L (b :: 0 :: r+1 :: R)` | b+3 |
| `C (2 :: b :: L) (0 :: R)` | | `B (b+5 :: L) R` | 8 |
| `C (2 :: L) (r :: R)` | r ≥ 1 | **halts** (`0 1 1 C> 0 1`) | |
| `C (a :: L) (r :: R)` | a ≥ 3 | `C (r+1 :: a−1 :: L) R` | r+7 |
| `B (a :: L) (0 :: s :: R)` | | `C (s :: a :: L) R` | s+1 |
| `B (0 :: b :: L) (r :: R)` | r ≥ 1 | `E L (b :: 0 :: r−1 :: R)` | b+2 |
| `B (1 :: b :: L) (1 :: R)` | | `F (b+4 :: L) R` | 6 |
| `B (1 :: b :: L) (2 :: R)` | | `B (b+5 :: L) R` | 7 |
| `B (1 :: L) (r :: R)` | r ≥ 3 | **halts** (`0 1 B> 1 1 1`) | |
| `B (a :: L) (r :: R)` | a ≥ 2, r ≥ 1 | `C (r−1 :: a :: L) R` | r+4 |
| `F (a :: L) (0 :: R)` | | `F (a+1 :: L) R` | 1 |
| `F (a :: L) (1 :: R)` | | `B (a+2 :: L) R` | 2 |
| `F L (r :: R)` | r ≥ 2 | **halts** (`F> 1 1`) | |

Every row is a theorem for all block lists (one symbolic run each, `lean/BPieces.lean`, generated by `py/blocks.py`
with `bbtools.symtm`); the three halting rows are `none_halts`, and `next_none_iff` says they are the only frames
without a next frame. `py/blockmap.py check 3000000` follows the machine itself: 42,875 frames, each at exactly the
step the table gives.

The cut of the next section is rows 3, 8, 5 in a row: `E (i :: L) (m :: 0 :: j :: R)` → `C (m−2 :: i+2 :: L) (0 :: j :: R)`
→ `C (1 :: m−3 :: i+2 :: L) (j :: R)` → `E (i+2 :: L) (m−3 :: 0 :: j+1 :: R)` for m ≥ 5. A sweep to the right is row 8
repeated (each block hands one cell to the next); at blank tape row 8 leaves a block of one cell, and row 5 turns
the head round.

## What it does

At the left end in state E the tape is `E>0 1^x 0 0 1^y ...` (single 0s between the other blocks). A
**splitting step** takes it to `E>0 1^x' 0 0 1^y' ...` with x' = ⌈2x/3⌉, y' = y + x − x' + 1 (the second block
sometimes written `1 0 1^(y'−2)`), the rest unchanged: 810 of the 1,241 consecutive left-end visits in 10^9 steps
(`tmrun M 1000000000 at E L`), e.g. 494 → 330 → 220. Cost ≈ x²/3 steps (2,827,525 for x = 2,903).

The cut is a zigzag between the single 0 inside the first block and the double 0 (`1^i 0 1^m 0 0 1^j`): per trip
i += 2, m −= 3, j += 1.

When the first block is short the head goes to the right end (state C) and rebuilds long blocks there
(`... 0 1^522 0 1^2831 0 1 C>0` at step 968,216,616 → `... 0 1^1682 0 1^1745 0 1 C>0` at 972,860,864); the next
left-end visit starts from a long block again. Not yet described exactly.

Halting: A on a 1, entered only from F on a 1. In block terms: the three halting rows of the table (proved to be
the only ones). Growth: a series of cuts costs ≈ 0.6·x² steps for O(1) new cells, so width ~ t^(1/3) (3,612 cells
at 10^9).

Scripts: `py/blockmap.py` (the block map: `check`, `run`, `show`), `py/blocks.py` (writes the two Lean files),
`py/splits.py` (splitting-step statistics from a `tmrun ... at E L` log).

## Later

1. Compose the rows into rules for a whole cut (induction on the trips: i += 2, m −= 3, j += 1) and a whole sweep
   (induction on the list), to get a coarser map whose step is one cut or one sweep; `halts_iff` carries over.
2. Look for an invariant of the block lists that excludes the three critical frames (in 10^8 frames: C after a
   block of two only with an empty block ahead; B after a block of one only on a block of one or two). The
   community tracker calls the machine a "lottery" (simulated there to 2.7·10^19 steps), so there may be none.

## Accelerated run
