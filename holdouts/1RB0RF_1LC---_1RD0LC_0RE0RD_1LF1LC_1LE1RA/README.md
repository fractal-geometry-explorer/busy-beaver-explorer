## What it does

Sample configuration (head in C at the left end of a block of five 1s, blank to the right):

    K(P, m) = 0^inf P (10)^m C> 1 1 1 1 1 0^inf

From blank tape: K(1, 1) at step 30, then K(1000, 4), K(101, 10), K(1, 19), K(1000, 31), K(1, 52), K(empty, 82), ...

* **Round trip** (`sweep`, Lean): `L (10)^(m+2) C> 1 (11)^(j+1) 0^inf -> L (10)^m C> 1 (11)^(j+4) 0^inf` in 4j + 20
  steps: C eats two words 10, D runs right turning the ones to 0s, E/F run back turning them to 1s.
* **End of a pass**: with no 10 left (or one), the block of 3⌊m/2⌋ + 5 ones is rewritten as words 10 and the prefix
  P changes. The next count is m' = 3⌊m/2⌋ + 4 + δ, δ ∈ {0, 1, 3}, and P' depends only on P and m mod 2:

      K(empty, 2n) -> K(1, 3n+4)        K(empty, 2n+1) -> K(empty, 3n+7)       (Lean)
      K(1, 2n)     -> K(empty, 3n+4)    K(1, 2n+1)     -> K(1000, 3n+4)        (Lean)
      K(1000, 2n)  -> K(101, 3n+4)      K(1000, 2n+1)  -> K(1, 3n+7)           (measured)
      K(101, 2n)   -> K(1, 3n+4)        K(101, 2n+1)   -> K(11000, 3n+4)       (measured)

So the emergent behaviour is a **Collatz-like map m -> ~3m/2** (the square-root side of the tape: the bouncer that
carries it out) **driving a counter-like prefix** at the left end (the logarithmic side).

## Halting

The only halting transition is B1. It fires from prefixes with four 1s close together (e.g. P = `111101`, m odd;
found by running every prefix up to 10 cells). The shortest route of parities from the empty prefix to a halt is 42
samples (`py/kmap.py` prints it); any wrong parity on the way sends the prefix back down. Heuristically (parities of
m -> (3m+c)/2 behave like coin flips) each return to the empty prefix wins with probability ~2^-41, so the machine
halts with probability 1 but after ~10^12-10^13 samples (~10^(10^12) steps). It is thus "probably halting", far
beyond simulation; deciding it needs control of a Collatz-like parity sequence.

Checked: the measured map (`py/kmap.py 10000`) runs 10,000 samples without a halt (m with 1,762 digits, prefix at
most 7 cells; only m mod 2 ever mattered); its first 24 samples (up to m = 88,201) agree with a direct C run to 9.3·10^9 steps;
`python3 -m bbtools.cycles M 2 1e40` reaches 10^40 steps without a halt. n-gram CPS (widths 3..7) fails.

## Remainder classes (family survey)

- **Rounds between end events, by remainder class** (trusted). Sample the run whenever the head is in state A reading 0 with only 0s to its right. Read leftwards from the head, the tape is then `A U^m B`: one long periodic block between two short context words. For each class (A, U, B, m mod 2) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·10^9 steps (22 events) the class map predicts the next event in all 15 rounds it applies to. This is an extrapolation checked by computation, not a proof.
