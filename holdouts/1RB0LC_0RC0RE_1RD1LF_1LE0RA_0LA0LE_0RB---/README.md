## Status

**Open.** One of sixteen holdouts that run the same *marker counter*: a base-5 counter written on the tape as markers between long blocks of `0010`, whose markers drift and occasionally collide. The family is described in full in the family lead [`1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LF_1LA0LB_0LC---/README.md). Lean proves the pieces of a sweep and whole sweeps for all block lengths (kernel); an exact accelerated simulator runs the machine to 10^16 steps without a halt.

## What it does

The tape between two sweeps is `1 (0010)^b0 m1 (0010)^b1 ... mk (0010)^bk 000` (in this machine mirrored: it grows to the left): blocks of the word `0010` separated by markers, each in one of the phases `1` (0), `0` (0'), `0011` (1), `011` (2), `11` (3), `00111` (4). Each sweep adds one to the counter whose digits are the phases: the last marker goes up one phase, a marker in phase 4 carries into the one before it, and when every marker is in phase 4 a new marker appears at the end. The blocks around a marker change with its phase, so the markers drift left, the later ones faster, until one uses up the block before it and *merges* with the marker there. See the family lead for the rules.

The mirror image of 1RB0LC_0RC0RB_1LD0RE_0LE0LB_1LA1RF_0LD---: its C1 = 1LF, F0 = 0RB detour does what the core's E1 = 0LB does, whenever F reads a 0, which it does at every entry so far.

**Same class as** (the same tapes at another pace for the direct members, the same markers for the mirrored ones; these are not the same run): [`1RB0LC_0RC0RB_1LD0RE_0LE0LB_1LA1RF_0LD---`](../1RB0LC_0RC0RB_1LD0RE_0LE0LB_1LA1RF_0LD---/README.md), [`1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_0RE---`](../1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_0RE---/README.md), [`1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_1LB---`](../1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_1LB---/README.md), [`1RB0LC_0RC1RF_1RD0RE_1LE0RA_0LA0LE_1RE---`](../1RB0LC_0RC1RF_1RD0RE_1LE0RA_0LA0LE_1RE---/README.md) (class I: the mirrored members have the same markers at every sweep end as the direct ones from sweep 157,376 on, with a different first block).

## Results

- `lean/Rules.lean` (generated by `py/rules.py`): 13 rules for all block lengths (kernel): nine whole sweeps (one per phase of the last marker, carries, overflows) and the pieces that the mirrored form can state.
- `py/check.py` runs the family checks for this machine: `check_rl.py` (the run-length simulator `c/rl.c` of the family lead agrees with its own run without shift rules at every sweep end of the first 10^8 steps), `model.py` (to 10^11 steps: 251,420 sweeps, 251,374 regular turns and 16 overflows exactly as the rules say, 30 merges, 628,328 entries into F), `merges.py` (none of the 48 merges of two markers with long blocks around them halts, for any block lengths).
- `far.py` (family lead): no halt in 10,000,000,062,707,029 steps; F entered 182,040,016 times, always reading a 0.
- `clusters.py`: none of 2,000 random short tapes of the same shape halts within 20,000 steps. Here F is reached through the C1 detour, in regular sweeps as well as at merges, and it has read a 0 every time; no configuration that makes it read a 1 is known.
- Lean (`lean/Blank.lean`): no halt in 10^7 steps.
- To rerun: `python3 py/check.py 1e11` (the `model.py` count above; the default 1e10 is quicker).
