# 1RB0RF_1RC0RD_1LD1LB_1RE0LC_1RA1RD_1RD---

bbchallenge id 92022. One of the six-state holdouts whose halting from blank tape is open (group G09: the visited tape grows like the square root of the step count on both sides).

**What it does.** A bouncer over a periodic background. After a leftward sweep the tape is almost all `001` repeated, after a rightward sweep almost all `111110`; the sweeps translate one form into the other word by word (proved, `lean/Rules.lean`). What is not background is a sparse set of *defects*, gaps of length 1 or 4 between the 1s of the `001` form. They drift at a few fixed speeds, change kind, and are created at the two ends; the number of defects grows about linearly with the number of sweeps. The machine halts only if a rightward sweep finds two adjacent 1s at one phase, which no run has shown. Decision: open. This machine is the twin of [1RB0RC_1LC1LA_1RD0LB_1RE1RC_1RA0RF_1RC---](../1RB0RC_1LC1LA_1RD0LB_1RE1RC_1RA0RF_1RC---/README.md): renaming the states A, B, C, D, E, F here to E, A, B, C, D, F gives that machine's table, so this one is it started in state E.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RF |
| B | 1RC | 0RD |
| C | 1LD | 1LB |
| D | 1RE | 0LC |
| E | 1RA | 1RD |
| F | 1RD | --- |

## The sweeps

The head runs from end to end. A visit to the left end adds 3 new cells there (sometimes 1 or 5), a visit to the right end 5 (sometimes 11, 17, 27,
..., and rarely hundreds: in one visit near step 2.9·10^7 the head stays at the right end and adds 1,725 cells). The tape grows by about 8 cells per
round trip, a round trip costs about the width of the tape in steps, so the width grows like the square root of the step count.

## The tape as words

Just after a leftward sweep (head at the left end, state C) the tape is almost all `001`; just after a rightward sweep, almost all `111110`. Write
the `001` form as the lengths of the gaps of 0s between consecutive 1s: the background is the gap 2; the only other gaps seen away from the ends are
1 (`01`, a defect *a*) and 4 (`00001`, a defect *b*). For example, the tape at the 380th visit to the left end (step 11,750,756, 7,510 cells), gap 2 written `.`:

```
a.....a.....(176 more).....b...................b.......b.....(129 more).....b.....b.....(22 more).....
```

Tracking defect positions from one visit to the next (`py/sweeps.py STEPS L FROM N 0`):

- defects drift at one of two speeds (measured against the background, 1 or 3 periods of 3 cells per round trip); in one epoch the *b*s and some
  *a*s move 9 cells left per round trip and other *a*s 3 cells, in another the directions are reversed against the growing left end;
- a block of *b* defects moves as a rigid body; *a*s change into *b*s at a front that moves one defect per round trip;
- a lone *a* runs to the left end, where it is absorbed, and the next defect changes kind (an "epoch" boundary);
- both ends create defects: the end rules leave `0 001 001` (right end, arrival in D) or `0 0001 001` (arrival in F), and on pure background
  the left end does not give back pure background either. The number of defects grows about linearly with the number of round trips: about 20
  after 50 visits to the left end, 130 after 500, 320 after 1,050.

So the machine is a sweeping system of particles on a periodic background, more like a one-dimensional cellular automaton seen at the sweep ends than a
counter; no exact rule for the motion of the defects has been written down.

## Halting

F1 is the only halting transition; F is entered only by A1 (write 0, move right). So it halts exactly when A reads a 1 whose right neighbour is
a 1. In the rightward sweep over the background A reads the 1 of a `001` and F reads the first 0 of the next one, so a halt needs a gap of length 0
(two adjacent 1s) at that phase. It has never happened: in the first 10^9 steps F is entered 53,330,403 times and reads 0 every time.

## Sweep rules (`lean/Rules.lean`)

Generated by `py/rules.py` with `tools/py/bbtools/symtm.py`; every rule holds for all values of `n` and every tape `L`, `R`, with the exact step count. `S>` is the head in state S on the next cell, `(w)^n` is n copies of w, `0^inf` is blank tape.

| rule | from | to | steps |
|---|---|---|---|
| `right_sweep` | `L D> (001001)^n R` | `L (110111)^n D> R` | 6 · n |
| `left_sweep` | `L (111011)^n C> 0 R` | `L C> 0 (001001)^n R` | 12 · n |
| `right_end` | `L 0 D> 0^inf` | `L C> 0 0 1 0 0 1 0^inf` | 11 |
| `right_end_F` | `L 0 F> 0^inf` | `L C> 0 0 0 1 0 0 1 0^inf` | 17 |
| `left_end` | `0^inf C> 0 0 1 R` | `0^inf 1 1 1 1 D> R` | 5 |

## Status

Open. Lean, kernel only: the halting configurations (`step_none_iff`), no halt in 10,000 steps (`lean/Blank.lean`), the sweep rules (`lean/Rules.lean`). Lean with `native_decide`: no halt in 10^7 steps. C: no halt in 10^10 steps (`tools/c/tmrun.c`). Observed: the background-and-defects structure above; no gap of length 0 ever.

**For later.** A proof needs the defect dynamics: which gap patterns can follow which at the sweep ends. A closed tape language over the alphabet {background, *a*, *b*} with bounds on the gaps between defects is the natural candidate; the generic searches tried (windows of up to 11 cells, also with run-length parity) fail.
