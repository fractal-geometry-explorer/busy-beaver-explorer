# 1RB1RF_1RC0RB_0RD1LF_1LE1RE_1LA---_1RA0LC

bbchallenge id 131324. One of the six-state holdouts whose halting from blank tape is open (group G13). Family: **Collatz-like counters (doubling chains of a unary block over a stack of pair runs)**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RF |
| B | 1RC | 0RB |
| C | 0RD | 1LF |
| D | 1LE | 1RE |
| E | 1LA | --- |
| F | 1RA | 0LC |

## What it does

Write a for the pair `1 0`. Sample the run each time the head is in state A at the right end of the visited tape,
on a 0. The tape is then `P a^k 1^m` (P does not end in a pair).

### Doubling chains

A chain starts at `P a^k 0 1^5` and then, with P fixed, (k, m) runs through
(k, 11), (k-1, 18), (k-14, 48), (k-41, 110), (k-100, 232), (k-219, 478), (k-462, 968), ...:
m_0 = 18, m_t = (92*2^t + (-1)^t)/3 - 13, and the pairs fall by d_t = (m_(t+1) - m_t)/2 - (2 if t even else 4).
In the form proved in Lean:

- m = 4j+2: `P a^(K+2j+5) 1^(4j+2)` -> `P a^K 1^(8j+16)`;
- m = 4j+4: `P a^(K+2j+5) 1^(4j+4)` -> `P a^K 1^(8j+22)`.

One step: the head turns the block into pairs on the right, then zigzags; each round trip
(`P a^(p+2) 1^(8u+4) C>1 0 0 a^(r+2) 1` -> `P a^p 1^(8u+12) C>1 0 0 a^r 1`) moves two pairs from the left run into
the ones and uses up two pairs on the right.

### Chain ends

P is a list of pair runs separated by markers `1 0 0` or `1 1 0`, e.g.
`a^209 1 a^344 0 a^32 0 a^112 0 1^5` at step 4,999,243. When the last run cannot pay for the next step, the block is
converted back into pairs and the runs near the end are merged, doubled or split; then a new chain starts. Examples
(sample before -> after, as `P | k m`): `a^65 1 | 4 174 -> | 55 208`, `| 55 208 -> a^110 00 | 0 104`,
`a^5 0 | 24 110 -> a^9 1 a^47 0 a^30 0 | 0 5`. These cases are not yet a map.

How far back a transition reads (`py/ends.py 1000000000`, with `c/ev.c`; the leftmost cell the head visits between
two samples): of 1,506 transitions, 229 stay in the final ones, 1,015 read into the last run, 115 into the run
before it, 1 into the third run from the right, and 146 reach the left end of the tape. The number of runs rose
from 1 to 4 (first 2 runs at step 3,994, 3 at 20,402, 4 at 4,999,243). A trace of the left turns of the head
(step 244,872: `a^213 0 a^10 1^18`) shows that the round trips of a chain step do not stop at a `0` marker: when
the last run is used up, the marker is absorbed (`a^213 0 11 A>` becomes `a^213 1 A>`) and the round trips go on
taking pairs from the run before it, with the right part in a shifted phase (`a^p 11 A> a^q 11 0 a^r 11`).

So the samples are not a finite set of frames with block-length parameters. The method of
1RB1LC_1LC1RD_1LA0LB_0RB1RE_1RF0RA_---0RC (fit affine cases on whole-tape frames) does not apply as it is. It
would need frames with a left context: a window of the last runs, and steps that move a run between the window and
the context. In Lean that move is only a rewrite of the tape term.

### Halting

The machine halts on E1. E is entered from D (D0 = 1LE, D1 = 1RE). Where in the chain ends this could happen is not
known yet.

## Status

Open.

- Lean, kernel (`lean/Rules.lean`, generated by `py/gen_rules.py` with `bbtools.symtm`; `lean/Chain.lean` by
  hand): `chain_even`, `chain_odd` (one doubling step, for all K, j and any tape L on the left), `chain_start`.
- Lean, kernel (`lean/ChainEnd.lean`, pieces `absorb0`, `eat`, `cycR` in `lean/Rules.lean`): a chain end at a `0`
  marker. The marker is absorbed, then t turns of the eating cycle `L (10)^(x+2) C>(10)^(k+1) 110 (1010)^(n+1) R ->
  L (10)^x C>(10)^(k+5) 110 (1010)^n R` follow (`end0`). In the first 10^9 steps the run passes 51 times through the start
  of `absorb0` and 73 times through an eating frame (`c/end0.c`). The ends of the eating cycle are not proved.
- Lean (`lean/Blank.lean`): no halt in 10^4 steps (kernel) and 10^7 (`native_decide`).
- C + Python (`py/chains.py 1000000000`): 162 chain starts and 776 chain steps in the first 10^9 steps, all as
  the rule says; 406 other transitions (chain ends).

## Later

1. Build turn-level frames with a left context (window of the last runs; a run moves to or from the context by
   re-bracketing), fit their affine cases, and prove each with `bbtools.symtm`. Then classify the chain ends: run `py/chains.py`-style sampling, group the 406 non-chain transitions by the last two
   or three runs of P and the residue of k, m, and fit a rule for each group (as for the map of
   1RB---_1RC1LE_0RD0RF_0RE0LA_1LF0LB_1LA1LD).
2. Prove those rules with `bbtools.symtm` the same way (start piece, cycles by induction, end piece).
3. With the whole map, find where E1 can be reached and state the halting condition.

## Accelerated run
