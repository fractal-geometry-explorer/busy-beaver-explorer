# 1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LD1RF_0RB---

bbchallenge id 157647. One of the six-state holdouts whose halting from blank tape is open. One of a pair with
`1RB0RD_1LC0RA_1LA0LB_1RE0LC_1LC1RF_0RB---` (they differ only in E0). Family: *sweeping c/a-word counter with multiplying inner phases*.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RD |
| B | 1LC | 0RA |
| C | 1LA | 0LB |
| D | 1RE | 0LC |
| E | 1LD | 1RF |
| F | 0RB | --- |

## What it does

Words: `c = 1101010`, `a = 10`. Each time the head comes back to the leftmost cell (state C), the tape is
`11010 w (10)^k 1`, where `w` is a word over `c` and `a`. Moving right, B turns `c` into `0011001` and `a` into `01`
(`b_c`, `b_a`); moving left, C crosses the shifted `a`s unchanged (`c_a`).

**Outer phase.** One round trip moves one `a` from the last block to a new `c` at the front:

    11010 w (10)^(k+2) 1  ->  11010 c w (10)^(k+1) 1      in 24·#c(w) + 4·#a(w) + 4k + 41 steps

Lean proves this for every `w` with up to four blocks of `c`s (`sweep0` … `sweep3`, all exponents symbolic). E0 is not
read, so both machines of the pair have the same rules. `py/sweepcheck.py` checks it for every `w`: in 4·10^8 steps
there are 1,192 such round trips and no exceptions. From the blank tape, `init_run` reaches the first outer
phase after 1432 steps, with `w = a^7 c a^2 c, k = 13`.

**Inner phases.** When the last block is used up (it then eats the last `c` too: `c 1 → 1 a^2 1 → 1 a 1 → 1 1`), the
head stops reaching the left end. A long inner phase of shorter sweeps follows near the right part of the tape. It
moves `a`s one at a time between neighbouring blocks, so block lengths multiply, and it leaves a much longer last
block. Then the outer phase resumes. Recorded by `c/jumps.c`: the steps of the left-end arrivals
just before and after the jump, and the tape there, tokenised, without its first cells (`11010` or `1`) and its
trailing `1`s:

| outer phase stops | resumes | before | after |
|---|---|---|---|
| 286 | 1,283 | `c a^7` | `c a^3 c a^2 c a^14` |
| 6,536 | 37,179 | `c^16 a^7 c a^2` | `a^3 c a^10 (c a^2 c a^10)^7 c a^2 c a^2 1 a^2` |
| 42,579,653 | 4,182,562,330 | `c^1184 a^7 c a^2 c a^16 c a^32 … (37 tokens)` | `c^1159 a^27 c a^8 c a^40 … (83 tokens)` |

After 2·10^10 steps the visited part of the tape is 333,053 cells wide.

**State F.** F is the only state that can halt (F1). It is entered only from E1 and E only from D0, so a halt needs the
head in D on `0 1 1` (D is entered from A1 and from E0). F is part of the regular sweeps: it is entered 137,952,841 times in 2·10^10
steps, always on a 0, with context `...0011 F>0` followed by `101...` or unvisited cells (`c/fhit.c`).

## Status

Open. Lean (`lean/`):

- `Blank.lean` (generated): the halting configurations, and no halt in 10^7 steps.
- `Rules.lean` (generated by `rules.py` with `tools/py/bbtools/symtm.py`): the token sweeps, the outer round trip for
  up to four blocks, and the run from blank tape.

`init_run` and `sweep3` need raised `maxHeartbeats`/`maxRecDepth`; `check.sh` takes about 3 minutes.

Not proved: the inner phases. A proof of non-halting would need them described as rules, with an invariant on the
words they produce that keeps `D>0 1 1` away.

## For later

- Prove the outer round trip for arbitrary `w` by induction over the word, from the token rules. The left end, with
  its zigzag over the front `c`s, and the right-end turn are fixed rules.
- Describe the inner phase as a recursive call of the same sweep mechanism on the last blocks, find its macro rule (how
  the block lengths are multiplied), and build an accelerated simulator to follow many more phases.
