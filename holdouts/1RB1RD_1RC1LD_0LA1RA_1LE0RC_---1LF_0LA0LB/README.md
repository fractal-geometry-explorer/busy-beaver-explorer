# 1RB1RD_1RC1LD_0LA1RA_1LE0RC_---1LF_0LA0LB

bbchallenge id 18397, one of the six-state holdouts. **Open; partly understood.** The tape is a long block
a^N (a = 111110) on the left, a small counter, and a block c^M (c = 1^11 0) that the counter eats; the head
sweeps over the long block once per increment. When the c's run out the blocks are rebuilt with M about 4/3 of
its previous value. The two sweeps over the long block are proved in Lean for all lengths; the counter and the
rebuild are only observed.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RD |
| B | 1RC | 1LD |
| C | 0LA | 1RA |
| D | 1LE | 0RC |
| E | --- | 1LF |
| F | 0LA | 0LB |

## What it does

Words: `a = 111110`, `c = 1^11 0`. When the head is at the left end the tape reads

    0^inf F> 0 a^N [counter] c^M [right part]

(`c/events.c`), for example at step 27,213,697

    F> 0 a^974 1^4 a^2 1^2 a^3 1^2 a^3 1^2 a^3 1^2 a^2 1^4 c^86 1^6 c 1^4 a 1^4 a 1^2 a c 1^2 c a 1^4 a 1^2 ...

Each round trip of the head (about 25N steps) increments the counter between a^N and c^M and adds a cell at the
left end; the counter consumes c's as it carries (from c^110 to c^80 over 120 round trips around step 2.7·10^7),
and its digit patterns repeat with period 6 in the samples. The two sweeps over the long block, proved for all
lengths and any tapes around (`lean/Rules.lean`, generated by `py/gen_rules.py`):

    sweep_r:  L A> (aa)^n R                    ->  L (101110101101)^n A> R        (32n steps)
    sweep_l:  L (101110101101)^n E> 1 R        ->  L E> 1 (110111110111)^n R      (18n steps)

so going right the block is rewritten pair by pair, and going left it is written back (`1 (110111110111)^n` is
`(aa)^n` shifted by one cell). Because the left block grows by about one cell per round trip, the left side of the
tape grows like the square root of the time.

When the c's run out, the a's are converted and the round starts again with a new M; the values of M at those
moments (from simulation) are 24, 36, 50, 72, 116, 170, 248, 342, 454, 613, 814, 1100, 1466, 1967, 2628: a ratio of
about 4/3 per round, with N at the end of a round about 2M and the next M about 2N/3. The number of rounds is the
log side of the tape.

**Halting.** The only halting transition is E reading 0, and E is entered only from D reading 0 (D0 → 1LE). So the
machine halts exactly when the head in state D reads 0 with a 0 to its left.

## For later

Stopped after the sweep rules and the observed round sequence. Missing: (1) the counter between a^N and c^M
(its digits are the words between the `1^2`/`1^4` separators; its increments repeat with period 6); (2) the
exact rebuild when the c's run out, which gives the map M -> M' (about 4M/3, with a remainder that decides the
details). The halting question is presumably whether the rebuild ever reaches the pattern `0 D>0` for some
remainder, which would make this a Collatz-like (4/3) map. Next: sample the round boundaries with `c/events.c`
(L events around the steps where c^M disappears), fit M' as a function of M mod a small number, and prove each
case with `symtm.prove`.

## Status

Open. Lean: the halting configurations (`step_none_iff`), no halt in 10,000 steps by the kernel and in 10,000,000
by `native_decide` (`lean/Blank.lean`); the two sweeps for all lengths (`lean/Rules.lean`). C
(`tools/c/triage.c`): no halt in 1,000,000,000 steps.
