# 1RB0LD_1RC1RA_1LD0RB_1LE1LA_1RF0RC_---1RE

bbchallenge id 155226. A six-state holdout of BB(6). **Open, and reduced in Lean to a parity question about one
fixed integer sequence**: the machine halts from blank tape iff some *epoch* ends with an even pair count. The first
three epochs end odd; the fourth has a wall of 39,991 digits.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0LD |
| B | 1RC | 1RA |
| C | 1LD | 0RB |
| D | 1LE | 1LA |
| E | 1RF | 0RC |
| F | --- | 1RE |

## What it does

At every *phase start* the tape is

    0^∞ 1^a 0 0 (1 0)^K 1^(2j+1) C> 0^∞          written (a, K, j)

a **wall** of `a` ones, two 0s, `K` **pairs** `1 0`, and an odd **block** of 1s with the head in state C on the blank
cell after it. One **sweep** (theorem `inner`, 8j + 14 steps) runs left through the block, eats two pairs and comes
back: `(1 0)^(k+2) 1^(2j+1) C>` becomes `(1 0)^k 1^(2j+7) C>`. A phase is ⌊K/2⌋ sweeps; then, with J = j + 3⌊K/2⌋:

| end of phase | wall a ≥ 1 | wall a = 0 |
|---|---|---|
| K even | (a−1, J+1, 0)  (`end_even`) | **halt**: F reads 0 (`to_halt`) |
| K odd  | (a−1, J+3, 1)  (`end_odd`) | **reset**: (2J+7, 0, 1) (`reset_a`, `reset_b`) |

So while the wall lasts, (K, j) follows the map g(K, j) = (j + 3⌊K/2⌋ + 1, 0) for even K and (j + 3⌊K/2⌋ + 3, 1) for
odd K, roughly K → 3K/2 (a Collatz-like map; j records the parity of the previous K), and the wall loses one cell per
phase. When the wall is gone the machine halts if K is even; otherwise the whole tape becomes 1s, a new wall about 3K
long, and the next epoch starts again from K = 0. **Every epoch replays the same sequence** `seq i` (the orbit of g
from (0, 1): K = 0, 2, 4, 7, 12, 20, 31, 48, 74, 112, …) and stops it at the index A = its wall:

| epoch | wall A | K = (seq A).1 at its end | outcome |
|---|---|---|---|
| 1 | 3 (18 steps from blank) | 7 | odd: reset |
| 2 | 25 | 75,697 | odd: reset |
| 3 | 227,097 | a 132,845-bit number | odd: reset |
| 4 | ≈ 5.67·10^39990 (39,991 digits) | ? | ? |

The left end of the tape moves by one cell per reset only (hence "fixed"); the right end grows by about one cell per
sweep (hence "sqrt").

## Status

Open. Halting is equivalent to: for some i, the wall A = `epochs i` has (seq A).1 even. Deciding epoch 4 would need
the parity of the term of `seq` with an index of 39,991 digits; nothing is known that predicts it. If the parities
behave like fair coins, the machine halts with probability 1 (1/2 at the end of epoch 4, 1/4 at epoch 5, …), but after
more than 10^(10^39989) steps: a Collatz-like "cryptid", unlikely to be settled either way.

## What is proved

| result | level | where |
|---|---|---|
| the pieces of a phase, for all values of the variables and every tape on the left | kernel | `lean/Rules.lean` (`start`, `inner`, `end_even`, `end_odd`, `reset_a`, `reset_b`, `to_halt`), generated by `py/gen_rules.py` |
| the macro step: `mstep` is sound, and its only stuck case halts | kernel | `mstep_sound`, `mstep_halt`, `lean/Macro.lean` |
| halts from blank ⇔ the `mstep` orbit from (3, 0, 1) gets stuck | kernel | `halts_iff_mstep` |
| **halts from blank ⇔ ∃ i A, epochs i = some A ∧ (seq A).1 % 2 = 0** | kernel | `halts_iff` |
| walls 25 and 227,097 | kernel | `epochs_small` |
| (seq 227097).1 is odd; a halt can only come at the end of epoch 4 or later | native_decide | `epoch3_odd`, `epoch3_survives`, `halts_late`, `lean/Epoch3.lean` |
| no halt in 10^4 / 10^7 steps from blank | kernel / native | `lean/Blank.lean` |
| the macro step and its exact step counts agree with the direct simulator for 18 phases (1,828,247 steps) | trusted | `py/macro.py check 18` |
| step counts: epoch 1 ends after a few hundred steps, epoch 2 after about 10^10, epoch 3 after about 10^79,981 (`py/macro.py epochs`, 5 minutes) | trusted | `py/macro.py epochs` |

The general lemma `halts_iff_orbit` (a sound macro map whose stuck points halt decides halting both ways) is in
`lean/Macro.lean` and does not depend on this machine.

## For later

The reduction is complete; what remains is number theory. A proof either way would need to predict the parity of
`seq` at the index A₄ (or show some A_i hits an even term), e.g. from a 2-adic description of g. Searching for a
pattern in the parities of `seq` (over the first 10^5 terms half are odd, 50.007%, and the longest run of odd terms is 15) is the only obvious next step.
