# 1RB1LE_1LC1RC_1LA1RD_1LD0RB_0LC0LF_0LB---

bbchallenge id 22465. One of the six-state holdouts whose halting from blank tape is open.  It is a
**Collatz-like (3X/2) machine with a growing tail**: one long block of ones `1^X` is multiplied by about 3/2 per
cycle (it is first rewritten as `X/3` pairs `110`, which are then absorbed two at a time, each absorption adding 9
ones), and the remainder of `X` modulo 6 decides what is written into a short "tail" of blocks to its right.  The
tail grows very slowly (the "exp" side of the triage).  How the machine could halt is not understood.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LE |
| B | 1LC | 1RC |
| C | 1LA | 1RD |
| D | 1LD | 0RB |
| E | 0LC | 0LF |
| F | 0LB | --- |

## What it does

The tape is `0 0 1^X 0 T` with the head in state B on the blank cell left of it (an **S-state**), where `T` is a
short tail of blocks of ones.  One **cycle** goes from one S-state to the next:

1. **Conversion.**  B, C and D sweep right across the block, turning each `111` into `110`
   (`B1 -> 1RC`, `C1 -> 1RD`, `D1 -> 0RB`): the block becomes about `X/3` pairs `110`
   (`lean/Rules.lean`, `convert`, for `X = 3x + 9` and any tape right of the block).
2. **Absorption.**  Each sub-round adds 9 ones to a new block on the left and removes two pairs:
   `B>0 0 0 1^X 0 (110)^k R` becomes `B>0 0 0 1^(X+9) 0 (110)^(k-2) R` whenever `X = 2 mod 3`
   (`absorb`, for all `x, k` and any `R`).  After about `X/6` sub-rounds the pairs are used up and the new block
   has about `9 X / 6 = 3X/2` ones.
3. **The end of the cycle** depends on what is left (`X mod 6`) and on the tail, which it reads and rewrites.

So `X' = (3X + c)/2`, where `c` depends on `X mod 6` and on the tail (`py/smap.py table`, by direct simulation
from constructed S-states with `X` near 1200):

|---|---|---|---|---|---|---|
| `()` | c = 34, tail `(3)` | 49, `(3)` | 28, `(3,3)` | 45, `()` | 60, `()` | 39, `(3)` |
| `(3)` | 34, `(6)` | 51, `(6)` | 28, `(3,6)` | 51, `()` | 40, `(3,6)` | 39, `(6)` |
| `(6)` | 34, `(9)` | 87, `()` | 28, `(3,9)` | 57, `()` | 76, `(3)` | 39, `(9)` |
| `(3,6)` | 34, `(6,6)` | 51, `(12)` | 28, `(3,5,2,3)` | 51, `(6)` | 40, `(3,12)` | 39, `(5,2,3)` |

The tail is itself made of the same pieces (a block `3j` that turns into `5 2^(j-1) 3`, that is pairs `110`, when
it is converted), so it behaves like a second, slower copy of the main counter fed by the main one.  From blank

While the tail is empty and `X = 3 mod 6`, the cycle is just `X -> (3X + 45)/2` (seven times in a row above).
The accelerated simulator (`tools/py/bbtools/cycles.py`, cycle rules proved by symbolic simulation) follows the run
to 10^13 steps without a halt; the S-state at step 2,710,634,500,213 has `X = 2,125,526` and tail `(3)`.

## Status

Open.  Lean (`lean/Rules.lean`, generated by `py/rules.py`, kernel): the absorption sub-round and the conversion
sweep, for all values of their counts and any tape to their right.  Computed: the S-map table and the orbit above
(`py/smap.py`, C simulation from constructed tapes).  `lean/Blank.lean`: the halting configurations
(`step_none_iff`), no halt in 10,000 steps by the kernel, in 10,000,000 by `native_decide`.  C
(`tools/c/triage.c`): no halt in 1,000,000,000 steps.

How it could halt: the halting transition is F1, and F is reached only by `C0 -> A1 -> E1 -> F`, so the machine
halts exactly when it is in state C on a 0 with three 1s to its left (`1 1 1 C>0`).  None of the S-states tried
(every `X mod 6` with every tail of at most three blocks of length at most 9) halts before the next S-state.

## For later

Third pass (12 November 2026): no closed form for the tail yet. What was learned, all by simulation from
constructed tapes (not in the status claims):

- Work on **sub-rounds**, not cycles: every visit of the head in state B to the left end with the tape
  `0 0 0 1^X 0 U`, where `U` is any list of blocks (a pair `110` is a block of two). A cycle is about `X/6` of them.
- `X = 0 mod 3` is local and exact: `(X, u, …) → (4, 2^(X/3), u + 3, …)`, that is `1^X` becomes `1111 0 (110)^(X/3)`
  and three 1s are glued to the next block (a block `3` if there is none). `symtm` proves it for all `X = 3n + 9`
  (run from `0^inf B> 0 0 0 (111)^n+3 0 (1)^u+1 0 R`); it is the `convert` rule with its end.
- `X = 2 mod 3` with `U = 2, 2, …` is the proved `absorb` (`X + 9`, two pairs gone).
- `X = 1, 2 mod 3` otherwise is **not local**: the conversion sweep (B, C, D turning each third 1 into 0) keeps its
  phase mod 3 across the separators and rewrites the whole tail in one pass, e.g. from `X = 31` and tail `7, 7, 7`
  to `4, 2^9, 3, 11, 3, 12`. So the tail update is a three-state transducer over the list of blocks, composed with
  what the absorptions then do to the rewritten blocks. The S-map table above is the composition for a few tails.
- Next step: tabulate that transducer (state = phase mod 3 on entering a block, input = block length mod 3 and
  whether it is the last block), then the sub-round map on lists of blocks is a finite table like the round map of
  `1RB1RD_1LC0RD_1RF1RB_1LE0RA_0LB0LE_---0RC` (`py/roundmap.py` there), which was found the same way: guess the
  recursion from tables, then compare with simulation on random lists.
- Then: find which lists lead to `1 1 1 C>0` (the halting configuration), and prove the cycle in Lean (the
  absorption loop by induction on `k`, as `loopN` in
  `holdouts/1RB1LF_0RC1RD_1LA1LD_1LE0RA_---1LC_0LA1LA/lean/Rounds.lean`).
