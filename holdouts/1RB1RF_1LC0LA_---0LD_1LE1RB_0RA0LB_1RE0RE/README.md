# 1RB1RF_1LC0LA_---0LD_1LE1RB_0RA0LB_1RE0RE

bbchallenge id 12189. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RF |
| B | 1LC | 0LA |
| C | --- | 0LD |
| D | 1LE | 1RB |
| E | 0RA | 0LB |
| F | 1RE | 0RE |

## What it does: phase defects in a periodic tape, the main block growing by about 4/3

Read in blocks of 6 cells, the tape is almost entirely the periodic word `110100` (seen in its rotations `101001`,
`010011`, `100110`, `001101`, `011010`, depending on where a block starts) with stretches of `110` (`110110`,
`011011`, `101101`), and a handful of *phase defects* where the period is broken. For example at step 906,804,978,838:

    000000 110110^2 110101 101001^3 101011 011011^2 010011^238 010110 110110^2 100110^9523 101101^3 001101^230878 B>

The numbers that matter are the distances between defects (here 238, 9523 and 230878). The head sweeps back and forth;
as the defects move, blocks turn into other rotations of the same word and one block grows at the expense of
another. Every sweep is a linear cycle that `bbtools.cycles` proves symbolically (50 rules for the first
10^9 steps, `lean/Cycles.lean`, checked by Lean's kernel).

Over a *phase* of many sweeps the largest block grows by a factor close to 4/3 (13491, 18582, 24715, 32860, 43683,
58247, 77410, 101379, 134093, 175559, 230878; the ratio has drifted from 1.38 to about 1.31) while the smaller
blocks grow too and new defects appear at the left end. The step count grows by about (4/3)^2 per phase, so the tape
grows like the square root of the step count on the right; the left end, where defects are created, grows like the
logarithm.

## Does it halt?

The only halt is C reading 0, entered from B reading 0 (B0 = 1LC): it needs the head in B, moving left, onto two
blank-like cells `0 0`. In the run this never happens: the accelerated run (each jump k applications of a proved
cycle) reaches **9·10^11 steps** without a halt (`py/cycles_run.py`).

The large-scale map is not known in closed form. The growth by a non-integer factor near 4/3 suggests a
Collatz-like map on the defect distances (like the cryptids, where a block goes to 3/2 or 4/3 of its length and the
remainder decides the next step); if so, halting would be a question about residues of an exponentially growing
orbit, and nothing here decides it.

## For later

Stopped at: the block picture (6-cell words, defects), the proved cycle rules, the run to 9·10^11 steps. Next: (1) list
the defect types and write one phase as a map on the block lengths (fit exactly, as for the halving machines);
(2) find the residue that would lead to `B> 0` with a 0 on its left; (3) iterate that map far beyond what the
accelerator reaches.

## Files

- `lean/Cycles.lean` (generated by `python3 py/cycles_run.py 1e9 lean lean/Cycles.lean`): the 50 cycle rules used by

## Accelerated run

Trusted computation: `python3 tools/py/bbtools/rleaccel.py 1RB1RF_1LC0LA_---0LD_1LE1RB_0RA0LB_1RE0RE 6 175400000` runs 175,400,000 macro steps from blank tape without a halt, more than 1.87·10^14
machine steps (tape: 22,200,732 cells). The simulator codes the tape in runs, crosses a run in one step and jumps cycles whose
one-cycle rule it has first proved symbolically; it is tested cell for cell against direct runs
(`tools/tests/test_rleaccel.py`).
