# 1RB0LA_0RC---_0RD0RF_1LD0LE_0LA1LE_0RA0LA

bbchallenge id 97059. One of the six-state holdouts whose halting from blank tape is open. Family: **hole-wandering solid block**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0LA |
| B | 0RC | --- |
| C | 0RD | 0RF |
| D | 1LD | 0LE |
| E | 0LA | 1LE |
| F | 0RA | 0LA |

## Status

Open. Proved in Lean (kernel): the pieces of a round (`lean/Rules.lean`, generated by `py/rules.py`) and the
whole round from a first block of even length, for every length and every second block (`round_mod4`,
`round_mod2` in `lean/Round.lean`). Generated: halting configurations, no halt in 10^4 steps (kernel) and 10^7
(`native_decide`) in `lean/Blank.lean`. C: no halt in 10^9 steps.

## What it does

At the left end in state E the tape is blocks of 1s separated by single 0s (holes), e.g. step 994,226,005:
`E>0 1^2584 0 1^1236`, written [2584, 1236]. Between two such moments the machine does a **round**:

- **sweep**: B, C, F, A turn each `11` of the first block into `01` (`sweep`: `0 C> (11)^n` → `(01)^n 0 C>`, 4n steps);
- **glider**: an even block ends the sweep with `0 0` next to the hole; the pair runs right through the next block
  (`glide`: `0 0 D> 1^n` → `1^n 0 0 D>`, 5n steps); at the next hole (three 0s) D fills them and the hole reappears
  3 cells to the left; E walks back;
- **more gliders**: E stops at the pairs; two pairs `0 1 0 1` make the next glider, which moves the hole 3 more
  cells left (`cycle`: `1 0 1 0 1 E> 0 1^(p+2) 0 1 R` → `1 E> 0 1^(p+3) 0 1 1 1 1 R`, 6p+22 steps).

Proved for all K, a (`round_mod4`, `round_mod2`): [4K, a, b, ...] → [a+K, 3K+3+b, ...] and
[4K+2, a, b, ...] → [a+K, 3K+6+b, ...] (a ≥ 3 resp. 4, b ≥ 1 in the Lean statements; b = 0 at the right end, checked
numerically). All 347 even rounds in 10^9 steps follow it (`py/rounds.py`). So the hole after the second block
vanishes into the new second block and a new hole appears about 3x/4 cells before the next one: the hole jumps.

**Odd first block**: the sweep runs through the hole (`C>1 0 1` → `0 1 0 C>`), leaving a `0 0` mark among the pairs,
and carries on into the next block; the gliders then return over the marks. These rounds add 4–18 ones and depend
on several blocks' parities: the source of the chaotic look. The crossing step is proved (`cross`); the rest is
not yet written as rules.

**Growth**: a round costs ≈ 1.5·x·a ≈ w² steps and adds 3–18 ones, so w³ ~ t: width ~ t^(1/3) (3,824 cells at 10^9).

**Halting** needs B on a 1, i.e. a sweep meeting `B>0 1 0 0 1` (an odd stretch, two 0s, a 1). In 10^9 steps all
685 round starts after step 204 had single holes only (2–5 blocks); two 0s occur only as gliders and as marks behind
the sweep. CTL with 8-cell windows finds no closed language (it needs more than 100 rounds of window growth; with
5000 it closes with 97 halting abstract configurations).

**Odd rounds**: `cross` (Lean) is the sweep's step through a hole; a round from an odd block merges several blocks
and depends on all their parities ([41,20,30,14,16] → [65,75], [41,20,31,14,16] → [10,97,21]).

**Towards an invariant**: from every round start `0? 1^a1 (0 1^ai)*` (a1 ≥ 1, ai ≥ 2) of at most 20 cells (4,616
tapes) the round ends on the same class; at 24 cells two tapes fail (`py/classround.py`). A finite-automata-reduction
search (`py/far.c`) finds no certificate with up to 8 DFA states on the left or 7 on the right.

Machine-specific scripts: `py/rules.py` (writes `lean/Rules.lean`), `py/rounds.py` (round statistics from a tmrun
log), `py/classround.py`, `py/far.c`.

## Later

1. Write the rest of the odd rounds as rules (`cross` is done): the gliders crossing a `0 0` mark. Then a round is a function of the block list (all parities), provable like
   `round_mod4`.
2. Find the invariant. Single holes with blocks ≥ 2 is not one (`py/classround.py ... 24` finds two tapes whose
   round leaves a block of 1); the counterexamples start with a block of 1, which the real run never has after its
   first rounds. Show each round keeps the finer invariant. With
   the round map proved, non-halting follows by induction on rounds.
3. The same machinery fits 1RB0LA_0RC0RF_0RD0RA_1LD0LE_0LA1LE_---1LB (same even rounds) and
   1RB0LA_0RC---_0RD0RF_1LD0LE_0LA1LE_1RA0RE.
