# 1RB0RC_1LA0LD_1RB0RD_1LE0RF_0LB0RB_1RC---

bbchallenge id 32641, a six-state holdout of group G05 (growth class fixed/sqrt). **Does not halt**:
`nonhalting : ¬ HaltsFromBlank` in `lean/Reach.lean`, proved in Lean by the kernel plus `native_decide` for
the long fixed computations. After five epochs the run becomes an exact bouncer. Lean proves that the bouncer
configuration repeats for ever, and it checks, chunk by chunk with a block simulator proved correct, that the run
from blank tape reaches the bouncer at step 16,730,681,219.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RC |
| B | 1LA | 0LD |
| C | 1RB | 0RD |
| D | 1LE | 0RF |
| E | 0LB | 0RB |
| F | 1RC | --- |

## The bouncer (exact)

Let

    C k = 0^inf A> 0 (1010001000100)^k X 0^inf

be the head in state A on the left end, then k blocks `10 1000 1000 100`, then a fixed stretch X of 222,182 cells
(`lean/Data.lean`, taken from the tape at step 16,730,681,219). Then

    C (n+1)  ->  C (n+2)   in 184 n + 3,029,224 steps, for every n            (period)

The period is two sweeps. With `R` the tape right of the blocks:

| piece | from | to | steps |
|---|---|---|---|
| pass1 | `0^inf A> 0 (1010001000100)^(n+1) R` | `0^inf (0101010010001)^(n+1) 1 B> R` | 37n+38 |
| excursion 1 | `1 B> X` | `E> 0 r1` | 1,517,479 |
| pass2 | `0^inf (0101010010001)^(n+1) E> 0 R` | `0^inf (0101010010001)^(n+1) 0 1 1 B> R` | 92n+99 |
| excursion 2 | `0 1 1 B> r1` | `E> 0 r2` | 1,511,551 |
| pass3 | `0^inf (0101010010001)^(n+1) E> 0 R` | `0^inf A> 0 1 0 (1000100010010)^(n+1) R` | 55n+57 |

`pass3` is the first 55n+57 steps of the run in `pass2`. The period closes because
`1 0 r2 = 1010001000100 X` as words, and `1 0 (1000100010010)^(n+1) = (1010001000100)^(n+1) 1 0`. In an
excursion the head never moves left of the one or three cells written next to X, so the excursion does not depend
on n. Per period the left end moves 4 cells left, one block (13 cells) is added and X moves 9 cells right.

**Halting.** The only halting transition is F1, and F is entered only from D1 (0RF), so a halt needs `D> 1 1`.
The period is proved for every n, so the halt never comes once C 1 or any later C k is reached, and the run
reaches C 7.

## The reach (exact, checked in Lean)

`lean/Block.lean` holds a block simulator, proved correct by the kernel. The tape is cut into blocks of 16 cells,
kept as numbers. The macro configuration `MC` is the blocks left and right of the head, the state, and whether the
head is on the first cell of the right block or on the last cell of the left one. A table `tbl` has
6 · 2¹⁶ · 2 entries. Each entry says, for a state, a block and a side of entry, what the machine does inside the
block until the head leaves it (`mkEntry`, computed by `brun`; `brun_ok` proves such a run is a run of the machine
whatever lies outside). `msim` does one table lookup per block crossing and checks the key of the entry it finds.
`chkF T c t g = true` says: from `c`, macro steps and then single steps (`fsteps`) make exactly `t` steps and end
at `g`, up to trailing blanks. `chkF_ok` turns that into `steps t (sem c) = some g.toCfg`. The table is verified
once (`tblOk : tbl.all entryOk = true`).

The run of 16,730,681,219 steps is cut into eight chunks at T·i/8. The configurations there come from the C
simulator (`py/dumpT.c`) and are written to `lean/Bound.lean` by `py/gen_reach.py`. The simulator only proposes
them: Lean checks every chunk. The last chunk ends at `finalF`, and `finalF_ok` (`lean/Final.lean`) proves
`finalF.toCfg = C 7`.

## Before the bouncer (observed)

The leftward sweeps turn at a point that moves right about 7 cells per sweep while the right end gains 4.5. When
it meets the right end (sweeps 150, 650, 2,550, 9,500, 35,550; right end then at 774, 3,024, 11,648, 42,923,
160,189) it runs back to the left end (sweeps 250, 950, 3,600, 13,350, 49,300). Each epoch is about 3.7 times longer
than the last. After the fifth return (step 16,730,681,219) the tape is exactly C 7 and the turning point stays at
the left end. The rightward sweep in state D is a block transducer on the "Q encoding" (`1000`, `100100`,
`1001000`, `10010100`, `100101000`), proved in `lean/Sweep.lean`. The leftward sweep is a zigzag that I could not
reduce to a token transducer. X is the record those epochs leave behind.

## Status and evidence

* **Lean, kernel.** `lean/Pass.lean` (generated by `py/gen_pass.py` with `bbtools.symtm.prove`): `pass1`,
  `pass2`, `pass3`. `lean/Window.lean`: `wstep`/`wsteps`, a list simulator on a window that fails if the head
  leaves it on the left, and `wsteps_over` (`wsteps_over1`, `wsteps_over3`): a window run is a run with any tape
  on the left. `lean/Sweep.lean`: `blk_cross`, `dsweep`. `lean/Blank.lean` (generated): `step_none_iff`, no halt
  in 10,000 steps.
  `lean/Block.lean`: `brun_ok`, `mstep_ok`, `msim_ok`, `toF_ok`, `chkF_ok`. `lean/Final.lean`: `finalF_ok`.
* **Lean, native (`native_decide`).** `#print axioms nonhalting` shows the standard axioms plus these facts:

  | file | facts | time |
  |---|---|---|
  | `lean/Period.lean` | `w1_ok`, `w2_ok` (the two excursions), `close` | a few seconds |
  | `lean/TblOk.lean` | `tblOk` (the block table) | 20 s |
  | `lean/Chunk1.lean` … `lean/Chunk8.lean` | `chunk1` … `chunk8`, about 2.09·10⁹ steps each | about 2 min 50 s each |
  | `lean/Blank.lean` | `blank_runs_native` (10⁷ steps, not needed for the proof) | a few seconds |

  `Period.lean` builds `period`, `runs_C`, `not_halts_C` and
  `nonhalt_of_reach : steps t init = some (C (m+1)) → ¬ HaltsFromBlank` on these facts. `lean/Reach.lean`
  chains the chunks into `reach_C7 : steps 16730681219 init = some (C 7)` and proves `nonhalting`. The chunk
  files depend only on `Bound.lean` and `Final.lean`, so they can be checked in parallel; `check.sh` runs them one
  after another, about 25 minutes in all.
* **Computed (trusted, not needed for the proof).** `py/lturn.c`: no halt in 10¹¹ steps. From sweep 49,300 on, the
  turn times follow a quadratic exactly (third differences 0). At 10¹¹ steps the tape spans −71,625 … 382,423.
  `py/dumpT.c` also finds C 1397 at step 21,120,462,459, as the period formula predicts.
* **Heuristic.** The epoch description before step 1.67·10¹⁰.
