The clock, and the machine against it

Summed, the rule says that C k is reached at step 16,730,681,219 + 3,029,040 (k − 7) + 92 (k(k − 1) − 42) for every k ≥ 7. Type any k. The C simulator py/dumpT.c found C 1397 at step 21,120,462,459 (computed, not part of the proof), as the formula predicts. The button runs the real machine in the browser from C 7 and records each step at which the tape is exactly C k.

The machine run watches every time the head is on the left end of the tape in state A and then compares the whole tape with C k. That happens twice a period: once in the middle of pass 2, where the tape is not C k (pass 3 is the first 55n + 57 steps of pass 2), and once at the end of the period.
