Over the blocks the machine is easy to follow symbolically, for any number of them; inside X it is not, but X is a fixed string, so the run there is simply computed. The two kinds of piece meet at the boundary between the blocks and X. Starting from C (n+1):

The passes are proved in lean/Pass.lean (generated by py/gen_pass.py with bbtools.symtm.prove) for every n and for any tape R in place of X, one block at a time. Pass 1 is one step and then 37 steps a block, which turn each 1010001000100 into 0101010010001. Pass 2 is 55 steps a block going left in state E, which turn the blocks into 1000100010010; 3 steps at the left end, which write two cells there; then 37 steps a block going right and 4 more: 55(n+1) + 3 + 37(n+1) + 4 = 92n + 99. Pass 3 is the first 55n + 57 steps of the run in pass 2: the same leftward crossing and 2 steps at the left end, where it stops in state A.

The excursions are the run inside X. In each one the head never moves left of the cells written next to X (1, or 0 1 1), so they do not depend on n; how Lean computes them is the next section. Added up, the period takes 184n + 3,029,224 steps.
