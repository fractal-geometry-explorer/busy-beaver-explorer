# 1RB---_1RC1LE_0RD0RF_0RE0LA_1LF0LB_1LA1LD

bbchallenge id 26350. One of the six-state holdouts whose halting from blank tape is open (group G13). Family: **Collatz-like map on two counters (halts iff an orbit hits a near-power of 2)**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | --- |
| B | 1RC | 1LE |
| C | 0RD | 0RF |
| D | 0RE | 0LA |
| E | 1LF | 0LB |
| F | 1LA | 1LD |

## What it does

Sample the run each time the head, in state C, is at the right end of the visited tape. From step 216 on, the
tape is then `K(x, m, s) = 1^4 0 (10)^x 1^m` with the head on the cell `s` just right of the block of m ones
(blank beyond); at step 216, `(x, m, s) = (7, 1, 0)`. One sample per R step (below) is a solid tape `1^k` instead.

From one sample to the next:

| rule | when | (x, m, s) becomes |
|---|---|---|
| B | m even, x >= 1 | (x-1, m+4, 1-s) |
| R | m even, x = 0 | ((m+6)/2, 1 if s = 0 else 3, 0) |
| A' | m odd, x = (m+3)/2, s = 0 | (2x+3, 1, 0) |
| A | m odd, other 1 <= x < (m+5)/2 | (2x+1, m-2x+4, 1-s) |
| C | m odd, x >= (m+5)/2 | (x-(m+5)/2, 2m+7-s, s) |
| H | m odd, x = 0 | the machine halts (A reads a 1) |

A round: after R, a chain of C steps doubles m while using up pairs, an A step doubles x, B pours the pairs into
the block one by one, and R starts again. Sizes roughly double per round.

### When it would halt

Only a C step with s = 0 and x = (m+5)/2 leads to H. Along a chain of C steps with s = 0, m runs through
`(m+7) 2^i - 7`, so the chain from (x, m, 0) halts iff `x = (m+7)(2^(k+1)-1)/2 - k - 1` for some k >= 0; after an
R step with m = 1 that is `x = 2^(k+3) - k - 5` (3, 10, 25, 56, 119, ...). Whether the orbit ever meets this is a
Collatz-like question.

## Status

Open, and reduced in Lean to the map: `halts_iff` (lean/MapThm.lean) says the machine halts from blank tape iff
the orbit of (7, 1, 0) under `mstep` reaches H.

- Lean, kernel (`lean/Rules.lean`, generated by `py/gen_rules.py` with `bbtools.symtm`): rules B and R for all
  n, x and both s; A for x = 1; C for m = 1; the halt from K(0, 2n+1, s) for all n (`toHalt0/1`, `halt0/1`);
  the pieces of rules A and C (`ph1_0/1`, `cyc_0/1`, `fin_0/1`, `endA0`, `endA1`, `endA1z`, `endAp`).
- Lean, kernel (`lean/CRule.lean`, by hand): rule C for all parameters, `ruleC0`: K(i+n+3, 2n+1, 0) reaches
  K(i, 4n+9, 0); `ruleC1`: K(i+n+3, 2n+1, 1) reaches K(i, 4n+8, 1) (inner cycles chained by induction, `cycN0/1`).
- Lean, kernel (`lean/MapThm.lean`, by hand): rules A and A' for all parameters (`ruleA0`, `ruleA1`, `ruleA1z`,
  `ruleAp`); `step_ok`: every case of `mstep` holds on the machine (next sample in >= 1 step, or a halt);
  `start`: blank tape reaches K(7, 1, 0) in 216 steps; `halts_iff`: halts from blank iff `orbit` reaches H
  (`#print axioms`: propext, Classical.choice, Quot.sound).
- Lean (`lean/Blank.lean`): no halt in 10^4 steps (kernel) and 10^7 (`native_decide`).
- C + Python (`py/samplemap.py check`): every sample of the first 10^10 steps from step 216 on follows the map
  (51,486 B, 173 C, 43 A, 18 R steps; 22 samples show a solid tape: one inside each R step and 4 before step 216).
- Python (`py/samplemap.py small`): the map agrees with the machine from every K(x, m, s) with x < 25, m < 30,
  and with x < 45, odd m < 70.
- Python (`py/samplemap.py orbit 10000`): the map from (7, 1, 0) runs 10,000 R steps (29,225,208 C steps, 25,330 A
  steps) without H; with `halts_iff`, the machine does not halt in these rounds.
- Python (`py/heuristic.py`): the chance-of-a-hit sum (1/h per doubling chain) is 0.3187 over the whole orbit,
  under 10^-4 of it after round 20; x has 583 bits at round 1,000. The remainders at chain ends cover all of [0, h) (192 of 1,409 in the lowest tenth).

## Later

1. The question is now pure arithmetic: does the orbit of (7, 1, 0) under `mstep` ever meet
   `x + k + 1 = (m+7)(2^(k+1)-1)/2` at the start of a chain of C steps with s = 0? A proof of non-halting would need
   an invariant of the orbit (for instance a congruence that the chain starts never satisfy); none is known, and
   the remainders cover all of [0, h), so this is likely as hard as a Collatz-type problem.
2. Small: prove the chain criterion above in Lean (an induction on k), so the Lean statement reads directly as the
   number-theory condition.
