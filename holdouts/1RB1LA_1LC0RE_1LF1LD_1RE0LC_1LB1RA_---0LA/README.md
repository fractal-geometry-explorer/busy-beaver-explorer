# 1RB1LA_1LC0RE_1LF1LD_1RE0LC_1LB1RA_---0LA

bbchallenge id 130861, a BB(6) holdout (group G06). **Family: nested exponential counter with a residue-class
halt; probviously halting.**

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LA |
| B | 1LC | 0RE |
| C | 1LF | 1LD |
| D | 1RE | 0LC |
| E | 1LB | 1RA |
| F | --- | 0LA |

## What it does

`S_t(x, c)` is the head in A on the first cell of `1^x (01)^2 1^6 (01)^c 1^t 0 1^2`, t = 3 or 6. Blank tape
reaches `S_3(4, 4)` at step 388.

* **Step** (a phase is a countdown on c): `S_t(x, c+2) -> S_t(floor(3x/2)+7, c)`, in about 1.5·x² steps; each
  round moves two ones from the left block into the middle block as three.
* **Reset** when c reaches 2 or 1: either a halt (state D at `1 1 0` at the left end, then C, then F reads 0) or
  a new phase `S_t'(x', c')` with x' ∈ {4, 5, 6}, t' = 3 after c = 2 and 6 after c = 1, and c' linear in x with
  a constant depending on x mod P:

  | reset from | c' | halts for |
  |---|---|---|
  | c = 2, t = 3 | 9x/8 + O(1) | x ≡ 1, 6 (mod 8) |
  | c = 2, t = 6 | 9x/8 + O(1) | x ≡ 2, 5 (mod 8) |
  | c = 1, t = 3 | 3x/4 + O(1) | x ≡ 2 (mod 4) |
  | c = 1, t = 6 | 27x/16 + O(1) | x ≡ 0, 9, 11, 14 (mod 16) |

  One residue class in four halts in every case. Exact table in `py/model.py`; the exact map (`next` in
  `lean/Reset.lean`) is proved, and the table is read off it.

## The run from blank

| phase | start | end | reset |
|---|---|---|---|
| 0 | S_3(4, 4), step 388 | S_3(13, 2) | 13 ≡ 5 (mod 8): no halt |
| 1 | S_3(4, 22), step 2,684 | S_3(1007, 2) | 1007 ≡ 7 (mod 8): no halt |
| 2 | S_3(6, 1138), step 6,224,444 | S_3(x, 2), x ≈ 2.06·10¹⁰¹ (568 steps) | x ≡ 7 (mod 8): no halt |
| 3 | S_3(6, c), c ≈ 2.3·10¹⁰¹ odd, after ≈ 10²⁰³ steps | S_3(y, 1) | halts iff y ≡ 2 (mod 4) |

y is the ((c−1)/2)-th iterate of x ↦ floor(3x/2)+7 from 6, a number with about 10¹⁰¹ digits.

## Status

Open; **probviously halting**. Proved in Lean: the machine halts exactly when the orbit of (4, 4, 3) under the
phase map `next` meets a halting residue class, and phases 0–2 do not; the end of phase 3 needs the residue mod 4
of an uncomputable number. Heuristically each phase from 3 on halts with chance 1/4, so the machine halts with probability 1 in this
model, after a tower of exponentials of steps.

* Lean (kernel), `lean/Step.lean`: `step_rule`, S(x, c+2) reaches S(floor(3x/2)+7, c) for every x ≥ 1, c and rest
  of the tape, from the rounds `round_e`, `round_o`, `round_4`, `round_3` and the ends `end_*` of `lean/Rules.lean`
  (generated by `lean/rules.py`), by induction (`rounds`). Also checked by simulation (`py/rules_check.py step 60`).
* Lean (kernel), `lean/Reset.lean`: `next_spec`, S_t(x, c) leads to `next x c t` (a halt or a new phase) for
  every x ≥ 1 and c. At c = 0 or 1 the last step ends on the tail (`tend_*`), leaving `1^B` behind `1^4 0` or
  `1^5 0`; by the parity of B a conversion (`k4_*`, `k5_*`) halts or, maybe after a restart (`a2_*`, `a3_*`,
  `b3_*`, `q4_*`, `q5_*`), gives a new phase; after c = 1, t = 6 a short phase (rounds and an end) ends at
  S_3(floor(3y/2)+4, 1). `start`: blank tape reaches S_3(4, 4) at step 388. `halts_iff`: the machine halts from
  blank tape iff the orbit of (4, 4, 3) under `next` reaches `none`.
* Lean (native), `orbit_585`: the first 585 terms of the orbit (phases 0–2) have no halt; term 585 is S_3(6, c)
  with c odd, c > 10¹⁰¹. So no halt before phase 3.
* Trusted (`py/model.py next 3000`, `py/model.py verify 200`): the residue table above agrees with `next` for
  x < 3000 and with direct simulation for x < 200.
* Trusted: the run from blank reaches S_3(4, 4), S_3(4, 22), S_3(6, 1138) and the first 16 steps of phase 2.
* Heuristic: everything from phase 3 on.
* Lean (`lean/Blank.lean`): no halt in 10⁷ steps; C: no halt in 10⁹ steps.
