# 1RB1LC_1LA1LD_1LD0LC_0LE0RD_1RA1LF_1RC---

bbchallenge id 42011. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LC |
| B | 1LA | 1LD |
| C | 1LD | 0LC |
| D | 0LE | 0RD |
| E | 1RA | 1LF |
| F | 1RC | --- |

Epochs on a stack of blocks. One round of an epoch is proved in Lean for all sizes; the end of an epoch is
described from simulation.

## What it does

Write p = `10110`, q = `10000`, S = `1011`, r = `1000`.

- **Round** (`round`, Lean). From state D at the left end of `0 q 0 p^a S p^(b+1) S q^(c+1) R`, the machine reaches
  state D at the left end of `0 q 0 p^(a+1) S p^(b+2) S q^c R` in 50a + 50b + 287 steps, for every a, b, c and
  every R. One q of the top block becomes a p, and the first p-block gains a p, so the tape grows by 5 cells.
- **Epoch.** The tape after the p-blocks is a stack of q-blocks separated by r (or by S). When the top block is used
  up, the machine walks into the stack, turns the p's back into q's, and builds a new top. The next epoch then starts
  at `D> 0 q 0 S p^3 S q^(c0) r q^(c1) r …` (r-type) or `D> 0 q 0 p S q^(c0) S …` (S-type). The top c0 at
  successive epochs: 3, 9, 25, 50, 102 (S), 306, 414, 829, 1658 (S), 4975, 6641 (step 2,944,031,436). The old entries
  move down unchanged or grow by 3 (829 then 832, 414 then 417). The new top is about twice or three times the old
  one (1658 to 4975 = 3·1658 + 1) or about the sum of the stack: the Collatz-like part.

Each epoch about doubles the tape and costs about four times as many steps, so the tape grows like the square root
of the step count on the left. The right end hardly moves.

## Does it halt?

The halting transition is F1. F is entered only from E1 (`1LF`), so a halt needs E on a 1 with a 1 to its left. A
round never does that, so a halt could only come at the end of an epoch. Open.

## For later

- Prove the end of an epoch with symtm for both types (r and S), for all sizes of the stack entries, and extract
  the stack update as a map.
- Iterate that map with exact integers, and look for the configuration that leads to E1 followed by F1.
- `bbtools.cycles` with block size 5 accelerates the run (3·10^9 steps in under 100 s). Its cycle rules are about
  120 KB of Lean each, so none are kept here.

## Files

- `lean/Rules.lean`: `round`, generated by `py/gen_rules.py` (`bbtools.symtm`).
- `c/tok.c`: prints the tape at events (here: state D at the left end), tokenized into the words p, q, S, r.

## Status

Open. Lean: `step_none_iff`, no halt in 10,000 steps by the kernel and in 10^7 by `native_decide` (`lean/Blank.lean`),
and `round` (`lean/Rules.lean`, kernel). C (`tools/c/triage.c`): no halt in 10^9 steps.
