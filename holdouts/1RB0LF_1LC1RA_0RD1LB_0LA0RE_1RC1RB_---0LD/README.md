# 1RB0LF_1LC1RA_0RD1LB_0LA0RE_1RC1RB_---0LD

bbchallenge id 69875, a six-state holdout of group G05 (growth class fixed/sqrt). **Open.** The tape is a row of
*digits* (runs of the word `1 0^5`) separated by two kinds of markers, updated by bouncing sweeps; the digits are
mostly multiples of 3 and grow from left to right. One phase of the run (the bounce) is proved in Lean for all
parameters; the full digit rule is not yet found.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0LF |
| B | 1LC | 1RA |
| C | 0RD | 1LB |
| D | 0LA | 0RE |
| E | 1RC | 1RB |
| F | --- | 0LD |


## What it does

**Halting.** F is entered only from A reading 1 (`0LF`), and F halts on a 0. So the machine halts exactly when A reads
a 1 with a 0 on its left (`0 A>1`); in the first 10^10 steps A always reads its 1s with a 1 on its left.

**Words.** The tape (left end fixed, growth to the right) is made of the words a = `1 0^2`, b = `1 0^5`,
markers m = `1 0^3`, and the separators T = `1 0^2 1^5 0^2 (1 0^2)^3` and S = `1 0^2 1^2 0^5`. Each time C reaches the
left end the whole tape reads as a list of runs of b, separated by T or S (`py/digits.py`). At step 7,055,416,224:

    b2 T b3 T b15 S b42 S b9 S b15 S b18 T b30 S b339 T b243 T b339 T b912 S b348 T b798 T b5436 T b873 S b1452 T b2688 T b2861 a ...

Nearly every run has a length divisible by 3 (the last one and the first few excepted), and the lengths grow roughly
geometrically along the tape. The number of runs grows slowly (20 at 7·10^9 steps).

**The bounce** (proved, `lean/Bounce.lean`). In the configuration

    C n m = 0^∞ 1000 (100)^(n+1) 1000 100 100 E>0 0 (100)^m 1 0^∞

one excursion of the head (10m + 53 steps) moves the marker `1000` one unit left and adds two units at the right end:
`C (n+1) m → C n (m+2)` (`bounceC`). So `C n m` reaches `C 0 (m + 2n)` in `bcost n m = n(10m + 53) + 10n(n-1)` steps
(`bounces`, `bcost_closed`). Blank tape reaches `C 17 4` at step 5467 (`init_C`) and `C 0 38` at step 9768
(`init_meet`). This is the zigzag seen in the space-time diagram: the head bounces between the marker, which walks
left, and the right end, which walks right; it turns units on one side into twice as many on the other.

**Later phases** (seen, not proved): runs of a are turned into runs of b two for one (`(1 0^2)^2` and `1 0^5` have
the same length), runs of b are fed back one at a time as three units, and the separators T and S record which of
these moves ended a phase. This is a digit-by-digit update with carries, of the same flavour as the counters of the
other G05 holdouts, but the exact rule (which digit changes, by how much, and which separator appears) is not yet
written down.

## Status and evidence

**Lean, kernel only.** `lean/Rules.lean` (generated by `py/gen_rules.py`): `bounce`, the one-excursion cell rule for
every m and every tape on the left. `lean/Bounce.lean`: `bounceC`, `bounces`, `bcost_closed`, `init_C`, `init_meet`.
`lean/Blank.lean`: `step_none_iff`, no halt in 10,000 steps (kernel) and 10^7 steps (`native_decide`).

**Computed (trusted).** `tmrun` (C): no halt in the first 10^10 steps; 139 visits of C to the left end of the tape,
each listed as a digit tape by `py/digits.py`.

**Open.** Whether it halts. A proof needs the exact digit rule (a block machine with `halts_iff`, as for the other
machines of this group) and then an argument about it.

## For later

- Write the full digit rule: follow one phase between two visits of C to the left end at the level of the words a,
  b, m, T, S, find the formula for each move (with `bbtools.symtm.prove` for each, as `bounce` here), and assemble
  them into a block machine with `mstep_sound` and a `halts_iff` theorem, as in
  `holdouts/1RB0LD_1LC1RD_0LE1LA_0RB1RD_---0LF_1RA1LF/`.
- Then find out where `0 A>1` can arise in that machine (which digit values would make it) and run the block machine
  far past 10^10 steps.

## Accelerated run

Trusted computation: `python3 tools/py/bbtools/rleaccel.py 1RB0LF_1LC1RA_0RD1LB_0LA0RE_1RC1RB_---0LD 6 152800000` runs 152,800,000 macro steps from blank tape without a halt, more than 3.40·10^13
machine steps (tape: 7,087,446 cells). The simulator codes the tape in runs, crosses a run in one step and jumps cycles whose
one-cycle rule it has first proved symbolically; it is tested cell for cell against direct runs
(`tools/tests/test_rleaccel.py`).
