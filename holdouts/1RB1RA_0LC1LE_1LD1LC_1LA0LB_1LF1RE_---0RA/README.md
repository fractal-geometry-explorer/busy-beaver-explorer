# 1RB1RA_0LC1LE_1LD1LC_1LA0LB_1LF1RE_---0RA — Antihydra

bbchallenge id 9785. One of the six-state holdouts whose halting from blank tape is open; the community calls it
**Antihydra** (a cryptid: its halting problem is an open Collatz-like question). Family: **Collatz-like walk
(Antihydra)**. Decision: **open**.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RA |
| B | 0LC | 1LE |
| C | 1LD | 1LC |
| D | 1LA | 0LB |
| E | 1LF | 1RE |
| F | --- | 0RA |

## What it does

From blank tape the run keeps returning to configurations with three blocks of ones and the head in state B on the
blank cell right of them:

    Q p a b  =  0^∞ 1^p 0 1^a 0 1^b B> 0^∞

* **Sweep** (`inner`): `Q p (a+3) (b+1) → Q p (a+1) (b+4)` in `2b + 13` steps: the head runs left over the right
  block, takes two 1s off the middle block and writes three onto the right block. By induction, `k` sweeps at once
  (`sweep'`).
* **Odd ending** (`odd_a`, `odd_b`, `odd0`): `Q p 1 (c+2) → Q (p+2) (c+4) 2`: the head runs to the left end, the left
  block gains 2, the right block becomes the middle block.
* **Even ending** (`even`): `Q (p+1) 2 (c+2) → Q p (c+5) 2`: the left block loses 1.
* **Halt** (`halt0`): `Q 0 2 (c+2)` halts (F reads a 0 at the left end, after `c + 7` steps and the halting
  transition).

So with `b = 2` the run is the walk on `(p, a)`:

    a = 2k + 1  →  (p + 2, 3k + 4)
    a = 2k      →  (p − 1, 3k + 2)      (p ≥ 1; p = 0 halts)

started at `(2, 7)` after 62 steps (`blank_to_Q`): (2,7), (4,13), (6,22), (5,35), (7,55), (9,85), (11,130), … With
`x = a + 5` this is `x ↦ ⌊3x/2⌋` with a counter `p` that goes up 2 when `x` is even and down 1 when `x` is odd, and
the machine halts iff the counter would go below 0.

## What is proved (Lean, kernel only)

`lean/Macro.lean`, `halts_iff`: **the machine halts from blank tape if and only if the orbit of (2, 7) under `nxt`
reaches the halting case** (`a` even, `p = 0`). Both directions; the axioms are `propext`, `Classical.choice`,
`Quot.sound`. The shift rules in `lean/Rules.lean` are generated by `py/gen_rules.py` with `bbtools.symtm`.

## Evidence (computed, heuristic)

* `py/walk.py run 1000000`: the walk does not stop in its first 10^6 steps; `p` never falls below 2 and ends at
  498,505 (`a` then has 584,967 bits; 3 minutes).
* `py/walk.py check 3e6`: the first 12 points of the orbit agree with a direct simulation, cell for cell, at the
  step counts the Lean rules give (62, 173, 423, 923, 2132, …).
* If the parities of `x` behave like fair coins, `p` is a random walk with steps +2/−1 and drift +½; from height `p`
  it ever reaches −1 with probability `φ^-(p+1)`, `φ` the golden ratio. So a halt is not expected.

## What is open

Whether the walk ever stops. Proving that it never does would need control over the parity sequence of the iterates
of `⌊3x/2⌋`, the kind of problem (Mahler's 3/2 problem) that is far out of reach. Next steps, if any: none that
would decide it; the walk could be pushed to more iterations with GMP and the divide-and-conquer parity algorithm.
