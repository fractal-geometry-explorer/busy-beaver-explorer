# 1RB0RE_1LC1LD_0RA0LD_1LB0LA_1RF1RA_---1LB

bbchallenge id 48709. A six-state holdout of BB(6). **Open, reduced exactly to a Collatz-like question:** the
machine runs the map u -> 3*ceil(u/2) while it burns a fuel counter. When the fuel runs out it either halts or
turns its current number into new fuel. It has survived the rounds with fuel 5, 14 and 185. The fourth round has
fuel 22,205,951,667,644,132,025,548, which is far too much to compute.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1LC | 1LD |
| C | 0RA | 0LD |
| D | 1LB | 0LA |
| E | 1RF | 1RA |
| F | --- | 1LB |

## What it does

Here `(01)^k` means k copies of `01`, `S>` means the head is in state S on the next cell, and `0^inf` is blank tape:

    D(k, y, z) = 0^inf (01)^(k+1) D> 1^(y+1) (10)^z 1 0^inf
    A(m, z)    = 0^inf A> 1^m (10)^z 1 0^inf

The rules (`lean/Rules.lean`, generated by `lean/rules.py`; every rule holds for all values of its variables):

| rule | from | to | steps |
|---|---|---|---|
| `start` | blank | D(0, 0, 5) | 136 |
| `d_step` | D(k+1, y, z) | D(k, y+3, z) | 4k+15 |
| `d_zero` | D(0, y, z) | A(y+3, z) | 8 |
| `a_odd`, `a_odd_one` | A(2i+1, z+1) | D(i, 0, z) | 2i+4 |
| `a_even`, `a_even_two` | A(2i+2, z+2) | D(i+2, 0, z) | 6i+19 |
| `reset_odd` | A(2i+1, 0) | D(0, 0, i+1) | 6i+16 |
| `reset_even` | A(2i+2, 1) | D(0, 0, i+3) | 10i+39 |
| `halt_even` | A(2i+2, 0) | F on a 0, i.e. halt | 2i+4 |

In `lean/Macro.lean` these rules are combined into one round on (k, z). The round is D(k, 0, z) -> A(3k+3, z) -> D(next k z):

    next k z = k even: (3(k/2)+1, z-1) if z >= 1,  (0, 3(k/2)+2) if z = 0   (reset)
               k odd:  (3(k/2)+4, z-2) if z >= 2,  (0, 3(k/2)+5) if z = 1   (reset),  halt if z = 0

The theorem `halts_iff` says that **the machine halts from blank tape if and only if the orbit of (0, 5) under
`next` reaches `none`**. It is proved by Lean's kernel, with no `native_decide`.

With u = k + 2 the map on k is u -> 3*ceil(u/2). An even u costs one unit of fuel and an odd u costs two. Every
round starts at k = 0, so all rounds replay the same sequence 0, 1, 4, 7, 13, 22, 34, 52, 79, ... and the fuel z
alone decides where a round stops. A round with fuel z halts exactly when z equals the fuel already spent at some
odd u. Otherwise the k it stops at gives the next fuel, which is about (3/2)^(2z/3).

## Status

- The orbit (`py/orbit.py`) resets with fuel 14, then 185, then 22,205,951,667,644,132,025,548, after 138
  applications of `next`. No halt so far. The real run shows fuel 14 at step 653 and fuel 185 at step 59,197.
- Heuristic: for fuel 1..20,000, 33.6% of the rounds halt. If the reset values behave like random numbers, each
  round halts with probability about 1/3, so the machine halts with probability 1. Under this heuristic it
  probably halts, in the fourth round or a later one, after a number of steps with more than 10^21 digits.
- Open: we cannot decide whether 22,205,951,667,644,132,025,548 lands on an odd point of the u-sequence. That
  needs the parity of u_i for i near 1.5*10^22, a problem of the same kind as the open Hydra and Antihydra questions.
