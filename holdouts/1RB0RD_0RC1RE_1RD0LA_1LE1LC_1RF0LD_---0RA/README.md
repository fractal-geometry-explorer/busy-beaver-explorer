# 1RB0RD_0RC1RE_1RD0LA_1LE1LC_1RF0LD_---0RA

bbchallenge id 166535. One of the six-state holdouts whose halting from blank tape is open. **Lean proves that the
run is the orbit of an explicit Collatz-like map on two numbers**, and that the machine halts if and only if that
orbit reaches one particular kind of point. Family: *Collatz-like map with a draining counter* (Antihydra-like).

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RD |
| B | 0RC | 1RE |
| C | 1RD | 0LA |
| D | 1LE | 1LC |
| E | 1RF | 0LD |
| F | --- | 0RA |

## What it does

A *phase start* is the configuration

    P m n = 0^inf (1011)^m 1^n (10)^3 A> 1 0^inf

a stack of `m` words `1011`, a block of `n` ones, then `101010` with the head in state A on a 1 at the right end.
Blank tape reaches `P 14 5` after 1,098 steps.

During a phase the head bounces at the right end: each round eats three ones of the block and adds four `10`s
(`cycle`, iterated by induction in `loop`). When fewer than three ones are left, one sweep turns every `10` into
`11`, so the new block has about `8n/3` ones, and the left end of the block uses up one or two words of the stack.
When the stack is empty, a sweep pairs the `10`s into a new stack of about `2n/3` words (*reset*) and the block
restarts at 5 ones.

Exactly (`next`, `next_reach`, `halts_P1` in `lean/Map.lean`), with `n = 3k + 3 + r`, `r < 3`:

| | m ≥ 2 | m = 1 | m = 0 |
|---|---|---|---|
| r = 0 | `P (m-1) (8k+19)` | `P 0 (8k+19)` | `P (2k+4) 5` (reset) |
| r = 1 | `P (m-2) (8k+29)` | **halt** | `P 0 (8k+18)` |
| r = 2 | `P (m-2) (8k+35)` | `P (2k+8) 5` (reset) | `P 0 (8k+18)` |

So (`halts_iff`): **the machine halts from blank tape iff the orbit of `(14, 5)` under `next` reaches `(1, n)` with
`n % 3 = 1`.**

The orbit: the stack of 14 drains in 8 phases and resets (at `m = 1`, `r = 2`) to 11,292 words at step 445,346,602.
That stack drains in 6,811 phases, the block growing to 2,903 digits, and resets again (at `m = 0`) to a stack of
about 8.3·10^2901 words. The third cycle needs about 5·10^2901 phases: out of reach. Lean checks the first two
cycles by compiled evaluation and concludes there is no halt in the first 10^2899 steps (`runs_long`).

Heuristic: if residues mod 3 are like fair dice, the stack lands on `m = 1` with probability 3/5 and then halts with
probability 1/3, so each cycle ends in a halt with probability 1/5 (simulation of the map: 0.19 to 0.20). The
machine would halt with probability 1, after a tower of exponentials of steps; proving anything about the residues
is a Collatz-type problem.

## Status

Open, reduced to the map (kernel). Lean files in `lean/`:

- `Blank.lean` (generated): the halting configurations, no halt in 10^7 steps.
- `Rules.lean` (generated by `rules.py` with `tools/py/bbtools/symtm.py`): the pieces of a phase, each a symbolic
  run proved step by step: `cycle`, `entry`, `b1`, `b2`, `b3`, `z1`, `z2`, `reset`, `r1a`, `r1b`, `h_pre`,
  `init_run`.
- `Map.lean`: `P`, `loop` (induction), `phase_r0` … `phase_r2_zero`, `halts_P1`, `next`, `next_reach`, `init_P`,
  `orbit`, `orbit_reach`, `not_halts_of_orbit`, **`halts_iff`** (axioms: propext, Classical.choice, Quot.sound).
- `Orbit.lean`: `orbit_6819` (`native_decide`: phase 6,819 is `(M, 5)` with `M > 10^2900`), `orbit_stays`,
  `runs_long` (no halt in `10^2899` steps).

`py/m6check.py` checks the map against the machine on 598 phase starts (`c/m6c.c`), prints the resets of the orbit
and estimates the halting chance per cycle.
