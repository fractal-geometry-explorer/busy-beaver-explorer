# 1RB1LC_1LA1RF_0RD1RD_0RA0LE_1LA0LE_0RC---

bbchallenge id 65980. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LC |
| B | 1LA | 1RF |
| C | 0RD | 1RD |
| D | 0RA | 0LE |
| E | 1LA | 0LE |
| F | 0RC | --- |

Long runs of the word d = `110` with a few marks between them. The marks travel through the runs and merge. Four
crossings are proved in Lean for all sizes; the rest is described from simulation.

## What it does

Each time the tape grows on the right, it reads something like
`d^607 0 0 1 1 d^1899 1^6 d^149 1 1 d^2 1 1 d 1^4 d^2 1 0 A>` (step 117,127,344): runs of d, a mark `0 0 1 1`,
more marks, and the head at the right end.

- **Crossings** (Lean). The head shuttles between the marks and the right end and re-encodes the runs it crosses:
  `110` into `010` and back, and `110` into `011`, then `001`, then `110`. These are `dR`, `eL`, `eL2` and `cR`.
- **Rounds.** In the example, after one round of about 2.2·10^5 steps the tape reads `d^615 0 0 1 1 d^1891 1^6
  d^151 …`: the mark has moved 8 words to the right and the run after `1^6` has gained 2. Within a phase x + y (the
  runs on either side of the mark) is fixed.
- **Phases.** When y reaches 0 the mark merges with the next one, the runs are redistributed, and a new phase
  starts with x small. Values of x + y at phase starts: 25, 44, 64, 94, 147, 196, 204, 272, 325, 425, 459, 688,
  785, 993, 1203, 1409, 1899, 2073 and 2507 (the last at step 147,828,976). The rate at which a mark moves (8 or 16
  words per round in the phases looked at) and the result of a merge depend on the marks further right: a nested
  counter.

The tape grows to the right by about the square root of the step count; the left end hardly moves.

## Does it halt?

The halting transition is F1. F is entered only from B1 (`1RF`), so a halt needs the head in state B on `1 1`. The
crossings never do that, so a halt could only come at a merge. Open.

## For later

- List the marks and prove one round of each phase type with symtm, with the tail to the right left general. The
  tail is touched on every round, so this needs a description of the right part, presumably as a counter.
- Prove the merges, build a map on the run lengths and iterate it.

## Files

- `lean/Rules.lean`: the four crossings, generated by `py/gen_rules.py` (`bbtools.symtm`).
- `c/tok.c`: prints the tape at events (here: each new cell on either side), tokenized into the words d and a.

## Status

Open. Lean: `step_none_iff`, no halt in 10,000 steps by the kernel and in 10^7 by `native_decide` (`lean/Blank.lean`),
and the crossings (`lean/Rules.lean`, kernel). C (`tools/c/triage.c`): no halt in 10^9 steps.
