## Status

**Open; a Collatz-type problem, reduced exactly to a four-counter map** (Lean, kernel).

## What it does

Every time the head, in state E, reads the 0 at the left end of the tape, the tape is
`E> 0 1^a 0 1 0 1^b (01)^c (11101)^k 1` (blank on both sides). From one such moment to the next:

| case | becomes |
|---|---|
| a ≥ 4 / a = 3 / a = 2 | (a − 2, b + 3, c, k) / (1, b + 3, c, k) / (0, b + 3, c, k) |
| a = 1, c ≥ 2 | (b, 7, c − 2, k) (b = 1: (2, 4, c − 1, k)) |
| a = 0, c ≥ 2 | (b − 1, 7, c − 2, k) |
| result with c = 0 | read as (B, 10, 1, k − 1): the first `11101` of the suffix is one more pair |
| a = 1, c = 1, b odd | (2, 1, (b − 1)/2, k + 1): refill |
| a = 0, c = 1 | (5, 4, b/2 − 3, k + 1) for b even, (1, 1, (b − 1)/2, k + 1) for b odd: refill |
| a = 1, c = 1, b even | **halt** (F reads a 0) |

So a phase takes the first block a to about 3a/2 ((3a + 11)/2 for odd a, 3a/2 + 6 for even a: Antihydra's map with
other constants) and costs two pairs of the budget c. When the last pair is reached, a refill or a halt.

From blank tape the run reaches (15, 7, 7, 1) at step 1188. The budget ran out at phases 4, 34, 683,741 (c = 0, a
pair borrowed from the suffix) and 683,742, and was refilled to 59, 1,367,414 and then a 399,947-bit number of pairs.
The next decision is about 2^399,946 phases away. If the parities behave like coin flips each budget end halts with
probability about 1/4, so the machine would halt with probability 1, but proving anything about them is the same
problem as for Antihydra.
