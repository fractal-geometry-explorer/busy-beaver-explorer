# 1RB1LD_1RC1RE_0LA1LB_0LD1LC_1RF0RA_---0RC

bbchallenge id 91443. One of the six-state holdouts whose halting from blank tape is open. Lean reduces it exactly to a
Collatz-like map of the Antihydra kind.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LD |
| B | 1RC | 1RE |
| C | 0LA | 1LB |
| D | 0LD | 1LC |
| E | 1RF | 0RA |
| F | --- | 0RC |

## What it does

At the end of every round the head is at the left end of the tape in state D and the tape reads

```
E(m, k) = 0^inf D> 110 (10)^m (110)^k 0^inf
```

a block of m pairs `10` (the side of the tape that grows like the square root of the step count) and a counter of
k triples `110` (the side that grows like the logarithm). During a round the block is split by a `110` separator,
`B> 1110 (101010)^u 10 110 (10)^y (110)^k`, and the head bounces between the left end and the separator: each sweep
turns three `10`s of the left part into four `10`s of the right part (`sweep`, proved for all u, y, k). When the
left part is used up the round ends (`finish`). How the round starts depends on m mod 3, and that is where the
counter moves: for m = 3t the separator is taken out of the counter (k goes down, or stays 0 if there is none); for
m = 3t+1 and 3t+2 a new `110` is pushed (k goes up); for m = 3t+2 with k = 0 the machine halts (`to_halt`).

## The map

```
(3t,   k)  ->  (4t + 4, k - 1)      (k = 0 stays 0)
(3t+1, k)  ->  (4t + 4, k + 1)
(3t+2, k)  ->  (4t + 5, k + 1)      halt if k = 0
```

Lean proves this for every m >= 1 and every k (`round_some`, `round_none`), and that the run from blank tape is at
E(8, 1) after 280 steps (`blank_to_E`). So (`halts_iff`): **the machine halts from blank tape if and only if the
orbit of (8, 1) reaches a pair (3t+2, 0).**

The first round ends (step, m, k): (280, 8, 1), (611, 13, 2), (1274, 20, 3), (2413, 29, 4), (4470, 41, 5),
(8169, 57, 6), (14566, 80, 5), (26897, 109, 6), (49312, 148, 7), ... each matching the map.

## Does it halt?

Along the orbit k is 2, 3, 4, 5, 6, 5, 6, ..., never below 7 after round 10, and 331,763 after 1,000,000 rounds
(`py/orbit.py`, Python big integers; residues 0, 1, 2 of m came 334,119, 332,791 and 333,090 times). If the residues
behave like fair random digits, k is a walk with steps +1 (probability 2/3) and -1 (1/3), which comes back to 0 from
k with probability 2^-k; so halting is almost surely impossible, by the same heuristic as Antihydra. Proving it needs
control of the residues mod 3 of a 4/3 map, for which no method is known. **Open.**

## For later

The reduction is complete; what is left is the number-theoretic question, which is of Antihydra difficulty. Possible
extras: iterate the orbit further (the cost per round grows with m, which has about 0.125 digits per round), and look
for a known Collatz-like problem that this map is equivalent to (it is close to the Antihydra map with a counter that
goes down on one residue in three instead of up on odd values).

## Status

Open, reduced to the map above. Lean, kernel only: `lean/Rules.lean` (symbolic runs generated by `py/gen_rules.py`:

`py/orbit.py`: 1,000,000 rounds of the map without reaching (3t+2, 0).
