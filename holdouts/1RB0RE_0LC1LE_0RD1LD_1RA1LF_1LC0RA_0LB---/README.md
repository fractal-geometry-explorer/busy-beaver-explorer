# 1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB---

bbchallenge id 53125, one of the six-state holdouts (group G06: one side of the tape stops growing, the other grows
like a square root). Whether it halts from blank tape is open. It runs a Collatz-like map Z -> 3Z/2 ± c on a run of
Z zeros, and the residue Z mod 4 drives a counter in a short word D at the fixed left end of the tape; the counter
runs through cycles that grow threefold, and at the end of each cycle Z mod 8 decides whether the word stays in its
simple form or grows a new, more complicated level.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 0LC | 1LE |
| C | 0RD | 1LD |
| D | 1RA | 1LF |
| E | 1LC | 0RA |
| F | 0LB | --- |

## What it does

A *phase* starts at

```
PS(D, Z) = 0^inf  D  0^Z  1 0 0  E>  0^inf          D a word starting 0 1, at the fixed left end
```

From blank tape the phases start at steps 457, 827, 1,559, ... with Z = 15, 21, 33, 51, 75, 114, 171, 255, 381, ...
(17 of them up to step 8.7·10^7, listed in `py/phases.py`).

Within a phase a wall of `100` words grows right from the `1 0 0`: each sweep the head runs left across the wall
(state F, `wall_left`), eats four zeros at the right end of the zero run and comes back, and the wall gains two words
(`sweep`; chained j times in `sweeps`, all proved in Lean). After about Z/4 sweeps the zeros are gone, the head works
on D, and the wall (3Z/2 cells) becomes the next run of zeros: PS(D', Z') with Z' = (3Z + c)/2, c small. Each phase
costs about 9Z²/8 steps, hence the square-root growth.

D' and c depend only on D and Z mod 4 (`py/phases.py` computes them by running the machine on three small Z of the
same residue and extrapolating; checked against the plain machine on all 16 phases from blank tape). With

```
D(a, b) = 0 1 0^a 1 0 1 (001)^b          R(a) = 0 1 0^a 1
```

the rules are (checked by `py/phases.py` for a, b < 16 at three Z each):

| word | Z ≡ 1 (mod 4) | Z ≡ 3 | Z ≡ 2 | Z ≡ 0 |
|---|---|---|---|---|
| D(a, b), a >= 1 | same word, Z' = 3(Z+1)/2 | D(a−1, b+1), Z' = 3(Z−1)/2 | – | – |
| D(0, b) | same word, Z' = 3(Z+1)/2 | R(3b + 5), Z' = 3(Z+1)/2 | – | – |
| R(a) | same word | (other) | D(a−1, 0), Z' = 3Z/2 | leaves the family |

In D(a, b) the value of Z stays odd (3(Z±1)/2 with the sign that makes (Z±1)/2 odd), so only the first two columns
occur: a is a counter, decremented by every phase with Z ≡ 3. When it reaches 0, the next such phase resets the word
to R(3b + 5) with Z' even. If then Z' ≡ 2 (mod 4), that is Z ≡ 3 (mod 8) at the reset, the next phase is D(3b + 4, 0)
and a new, three times longer cycle starts (a0 = 11, 35, 107, 323, 971, ...: a0' = 3a0 + 2). If Z' ≡ 0, the word
leaves this family: it becomes `0 1 0^(a−4) 1 0 (001)^2`, a second level whose counter moves by 4 and 2 per phase
and which nests further.

## Status

**Open.** From blank tape, the first four resets (phases 5, 29, 92, 332) all have Z ≡ 3 (mod 8); the fifth
(phase 1001, Z with 178 digits, far past 10^350 steps) has Z ≡ 7 and the word leaves the simple family. No halt in
the first 1,500 phases (`py/phases.py 1500`), and the exact
run `py/phaseiter.py` finds none in 1,000,000 phases (about 10^352,184 steps). The first 1001 phases, and no halt in
the first 10^177 steps, are Lean theorems (`lean/Orbit.lean`). Halting words do exist: with the residue Z mod 4 chosen freely at every phase, `py/search.py 24` (six minutes)
reaches 23,305 words of at most 24 cells from the first phase start, and 7,145 of the (word, residue) pairs met
halt, for example D = `0 1 0 0 1 1 1 0 1` with Z ≡ 3. They have runs of ones (`1 1 1 0 1`) that the real orbit has
not produced so far.

So the question reduces to the orbit of a Collatz-like map Z -> (3Z + c)/2 with c fixed by Z mod 4 and the word D,
and to how the nested counters in D evolve under it: whether the residues along the real orbit ever build one of
the halting words.

## Proved in Lean

- `lean/Rules.lean` (generated by `lean/rules.py`): `wall_left` (state F crosses `(100)^n` leftwards, writing `110`
  words) and `sweep` (one whole sweep: `L 0^8 1 0 0 0 (100)^n 0 A>` to `L 0^4 1 0 0 0 (100)^(n+2) 0 A>`, 18n + 64
  steps, any L).
- `lean/Sweeps.lean` (by hand): `sweeps`, j sweeps by induction: 4j zeros eaten, 2j words added.
- `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`, F reading 1) and no halt in the first
  10^7 steps.

- `lean/Ends.lean` (generated by `lean/ends.py`): `blank_start` (from blank tape to the first phase start
  PS(D(2, 0), 15) in 457 steps), `start` (the first 41 steps of any phase) and nine `end*` rules, one for each word
  shape and residue: from the end of the sweeps, `0^inf D 0^(4+r) 1 0 0 0 (100)^n 0 A>`, to the next phase start, for
  every a, b, n.
- `lean/Phase.lean` (by hand): whole phases, for every a, b, j, with at least Z' steps each:
  `phase_D1` (Z = 4j + 9: D(a, b) stays, Z' = 6j + 15), `phase_D3` (Z = 4j + 11: D(a+1, b) → D(a, b+1),
  Z' = 6j + 15), `phase_D0` (Z = 4j + 11: D(0, b) → R(3b + 5), Z' = 6j + 18), `phase_R2` (Z = 4j + 10:
  R(a+1) → D(a, 0), Z' = 6j + 15). So the level-1 counter of the table below is a theorem, not an extrapolation.
- `lean/Orbit.lean` (by hand): the level-1 phase map `next1` on (word, Z) and its soundness (`next1_sound`,
  `iter1_sound`). Evaluated by Lean's kernel with exact integers (`decide +kernel`, no `native_decide`), it runs
  1001 phases from blank tape; the word leaves the family at phase 1001 (R(971) with Z ≡ 0 mod 4,
  `iter1_1002`). `blank_1001`: **no halt in the first 10^177 steps from blank tape**, a kernel-checked theorem.

## Computed (not proved)

- `py/phaseiter.py [PHASES]`: the run from blank tape phase by phase, **exact, no extrapolation**. The start and the
  sweeps of each phase are the Lean rules above (jumped over with their exact step count); the end of each phase,
  where the head works on the word D, is run on the run-length coded tape with the shift rules of
  `tools/py/bbtools/symtm.py` (the same moves `lean/ends.py` turns into Lean proofs, here with integer counts).
  `python3 py/phaseiter.py 1000000 --every 20000` (4.1 hours): **no halt in 1,000,000 phases**, about
  10^352,184 steps (Z then has 176,093 digits, the word D about 10^6 cells in 22 tokens). The words met all have a
  long run of zeros (the counter) and a long run of `001` (what the counter has paid out), with a short prefix that
  changes when a cycle ends. The cycle ends (`--events FILE` lists every change of shape; the word is written by its
  gaps, the numbers of zeros between consecutive 1s after the first):

  | phase | Z mod 8 | word (gaps) | what follows |
  |---|---|---|---|
  | 6, 30, 93, 333 | 2, 6, 6, 2 | R(11), R(35), R(107), R(323) | level 1 again (Lean: `iter1_1001`) |
  | 1002 | 0 | R(971) | `a 3 2^b`: a counter moving by 4 per Z ≡ 3 phase |
  | 1511 | 0 | 3, 1458 | the same with a prefix gap 3 |
  | 2234 | 6 | 2 1, 2187 | level 1 behind the prefix `2 1` |
  | 6567 | 2 | R(6569) | the prefix is gone: plain level 1 |
  | 19692 | 6 | R(19709) | level 1 |
  | 59119 | 0 | R(59129) | `a 3 2^b` |
  | 88536 | 4 | R(88695) | `a 3 2^b` |
  | 132982 | 4 | 3, 133044 | prefix 3 |
  | 199715 | 6 | 6 2, 199563 | level 1 behind the prefix `6 2` |
  | 598126 | 6 | 2 3 1, 598692 | level 1 behind the prefix `2 3 1` (still running at phase 1,000,000) |

  So the levels do not only nest: prefixes appear and are eaten again (phase 6567 is back to a bare R(a)). Each
  cycle is about three times as long as the one before.
  `--check 120 --xcheck 4000 1` compares it with the plain machine: the 17 phase starts from blank tape to step
  8.7·10^7, the 14 phases with Z < 3000, and at each of the first 4,000 phases the next phase start from that
  phase's word with a small Z of the same residue mod 8 (514 s; all agree).
- `py/phases.py [PHASES]` (compiles `c/nextps.c`; 300 phases in about ten minutes, longer as D grows): checks the
  extrapolated phase map against the machine on the 16 phases from blank tape, iterates it and prints every change of
  the word D.
- `py/search.py [LEN]` (six minutes for 24): the free-residue search for halting words.

## Remainder classes (family survey)

- **Rounds between end events, by remainder class** (trusted). Sample the run whenever the head is in state B reading 1 with only 0s to its right. Read leftwards from the head, the tape is then `A U^m B`: one long periodic block between two short context words. For each class (A, U, B, m modulo 1 or 4 (the smallest modulus that works for the context)) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·10^9 steps (48 events) the class map predicts the next event in all 28 rounds it applies to. This is an extrapolation checked by computation, not a proof. Command: `python3 holdouts/1RB0LD_0RC1RD_1LA1RA_1LE0LE_1RF0LA_0RA---/py/ctxround.py 1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB--- R B 1 check 3e9`
- **2,930 rounds of the class map without a halt** (heuristic). Iterated with exact integers from the event at step 29,339 of the run (A = `11`, U = `0`, m = 171, B = `101 0^101`): 2,930 rounds without meeting a halting class; m then has 865 bits (about 10^520 steps of the machine). 1,410 distinct contexts occur, the longest of 1,428 cells. Command: `python3 holdouts/1RB0LD_0RC1RD_1LA1RA_1LE0LE_1RF0LA_0RA---/py/ctxround.py 1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB--- R B 1 orbit 2930`
- **Some remainder classes halt** (heuristic). Breadth first from the starting context, with every remainder at every context (whether or not the numbers can really produce that sequence of remainders, and only for m large compared with the contexts): 5,000 contexts expanded, 7,830 found, to depth 17. **169 classes halt.** The nearest one is reached by the remainders 3 2 3 2 3^2 (6 rounds, moduli as above), ending at B = `10 1^3 0^101`. Command: `python3 holdouts/1RB0LD_0RC1RD_1LA1RA_1LE0LE_1RF0LA_0RA---/py/ctxround.py 1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB--- R B 1 bfs 5000`
