# 1RB0RE_0LC1LE_0RD1LD_1RA1LF_1LC0RA_0LB---

bbchallenge id 53125, one of the six-state holdouts (group G06: one side of the tape stops growing, the other grows
like a square root). Whether it halts from blank tape is open. It runs a Collatz-like map Z -> 3Z/2 ± c on a run of
Z zeros, and the residue Z mod 4 drives a counter in a short word D at the fixed left end of the tape; the counter
runs through cycles that grow threefold, and at the end of each cycle Z mod 8 decides whether the word stays in its
simple form or grows a new, more complicated level.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 0LC | 1LE |
| C | 0RD | 1LD |
| D | 1RA | 1LF |
| E | 1LC | 0RA |
| F | 0LB | --- |

## What it does

A *phase* starts at

```
PS(D, Z) = 0^inf  D  0^Z  1 0 0  E>  0^inf          D a word starting 0 1, at the fixed left end
```

From blank tape the phases start at steps 457, 827, 1,559, ... with Z = 15, 21, 33, 51, 75, 114, 171, 255, 381, ...
(17 of them up to step 8.7·10^7, listed in `py/phases.py`).

Within a phase a wall of `100` words grows right from the `1 0 0`: each sweep the head runs left across the wall
(state F, `wall_left`), eats four zeros at the right end of the zero run and comes back, and the wall gains two words
(`sweep`; chained j times in `sweeps`, all proved in Lean). After about Z/4 sweeps the zeros are gone, the head works
on D, and the wall (3Z/2 cells) becomes the next run of zeros: PS(D', Z') with Z' = (3Z + c)/2, c small. Each phase
costs about 9Z²/8 steps, hence the square-root growth.

D' and c depend only on D and Z mod 4 (`py/phases.py` computes them by running the machine on three small Z of the
same residue and extrapolating; checked against the plain machine on all 16 phases from blank tape). With

```
D(a, b) = 0 1 0^a 1 0 1 (001)^b          R(a) = 0 1 0^a 1
```

the rules are (checked by `py/phases.py` for a, b < 16 at three Z each):

| word | Z ≡ 1 (mod 4) | Z ≡ 3 | Z ≡ 2 | Z ≡ 0 |
|---|---|---|---|---|
| D(a, b), a >= 1 | same word, Z' = 3(Z+1)/2 | D(a−1, b+1), Z' = 3(Z−1)/2 | – | – |
| D(0, b) | same word, Z' = 3(Z+1)/2 | R(3b + 5), Z' = 3(Z+1)/2 | – | – |
| R(a) | same word | (other) | D(a−1, 0), Z' = 3Z/2 | leaves the family |

In D(a, b) the value of Z stays odd (3(Z±1)/2 with the sign that makes (Z±1)/2 odd), so only the first two columns
occur: a is a counter, decremented by every phase with Z ≡ 3. When it reaches 0, the next such phase resets the word
to R(3b + 5) with Z' even. If then Z' ≡ 2 (mod 4), that is Z ≡ 3 (mod 8) at the reset, the next phase is D(3b + 4, 0)
and a new, three times longer cycle starts (a0 = 11, 35, 107, 323, 971, ...: a0' = 3a0 + 2). If Z' ≡ 0, the word
leaves this family: it becomes `0 1 0^(a−4) 1 0 (001)^2`, a second level whose counter moves by 4 and 2 per phase
and which nests further.

## Status

**Open.** From blank tape, the first four resets (phases 5, 29, 92, 332) all have Z ≡ 3 (mod 8); the fifth
(phase 1001, Z with 178 digits, far past 10^350 steps) has Z ≡ 7 and the word leaves the simple family. No halt in
the first 1,500 phases (`py/phases.py 1500`). Halting words do exist: with the residue Z mod 4 chosen freely at every phase, `py/search.py 24` (six minutes)
reaches 23,305 words of at most 24 cells from the first phase start, and 7,145 of the (word, residue) pairs met
halt, for example D = `0 1 0 0 1 1 1 0 1` with Z ≡ 3. They have runs of ones (`1 1 1 0 1`) that the real orbit has
not produced so far.

So the question reduces to the orbit of a Collatz-like map Z -> (3Z + c)/2 with c fixed by Z mod 4 and the word D,
and to how the nested counters in D evolve under it: whether the residues along the real orbit ever build one of
the halting words.

## Proved in Lean

- `lean/Rules.lean` (generated by `lean/rules.py`): `wall_left` (state F crosses `(100)^n` leftwards, writing `110`
  words) and `sweep` (one whole sweep: `L 0^8 1 0 0 0 (100)^n 0 A>` to `L 0^4 1 0 0 0 (100)^(n+2) 0 A>`, 18n + 64
  steps, any L).
- `lean/Sweeps.lean` (by hand): `sweeps`, j sweeps by induction: 4j zeros eaten, 2j words added.
- `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`, F reading 1) and no halt in the first
  10^7 steps.

## Computed (not proved)

- `py/phases.py [PHASES]` (compiles `c/nextps.c`; 300 phases in about ten minutes, longer as D grows): checks the
  extrapolated phase map against the machine on the 16 phases from blank tape, iterates it and prints every change of
  the word D.
- `py/search.py [LEN]` (six minutes for 24): the free-residue search for halting words.

## For later

- Prove the phase ends for the family D(a, b), R(a) in Lean (bounded interactions with D, then the wall turning back
  into zeros), so that the level-1 dynamics is a theorem.
- Describe the second level and the nesting exactly (the experiments suggest each escape adds one level to D), and
  find whether the nested family can reach the halting words that the free-residue search finds.
