# 1RB0LE_0RC0RD_1LC0RB_0RE1RD_1LF1LE_0LA---

bbchallenge id 95916. Halting from blank tape is open; the run is the orbit of a halving-cascade map on lists of numbers, and it halts exactly if a carry past the end of the list is a power of 2. **That reduction is a Lean theorem** (`halts_iff` in `lean/Cascade.lean`).

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0LE |
| B | 0RC | 0RD |
| C | 1LC | 0RB |
| D | 0RE | 1RD |
| E | 1LF | 1LE |
| F | 0LA | --- |

## What it does

At each moment the head, in A, extends the tape to the left, the tape is

    0^inf A> 0 0 1^n1 0 0 1^n2 0 0 ... 0 0 1^nk 0^inf

(blocks of 1s separated by `00`). From step 13, list (1, 1), each such moment follows from the previous one by a
**halving cascade** (`py/cascade.py`):

    v = n1, i = 1
    repeat:  n_i = floor(v/2);  c = v - n_i
             if v is odd: n_(i+1) += c + 2;  n_(i+2) += 1;  stop
             else:        v = n_(i+1) + c;  i += 1        (past the last block, n_(i+1) is a new block 0)
    and a first block 1 merges:  (1, x, y, ...) -> (x + 3, y + 1, ...)

Example: (4, 56, 1877, 6) -> (2, 29, 953, 479, 482, 1).

The halving itself is a zig-zag: a gap `000` walks into the block and each round sends one 1 to each side,

    L 0 1^k 0 0 0 1^(m+2) D> 0 0 1^n R  ->  L 0 1^(k+1) 0 0 0 1^m D> 0 0 1^(n+1) R     (2m+11 steps)

**Halting.** Inside the list a halved value is at least 2, so no block vanishes. Past the end the carry c is halved
into new blocks c/2, c/4, ... until odd; if c is a power of 2 it reaches a block 0, which is a halt (e.g. lists [2],
[2, 1], [4, 2], [6, 1] halt). So the machine halts iff a cascade ever runs past the end with a power-of-2 carry.

**Statistics of the orbit** (`c/cascade.c`): the sum of the blocks after t map steps is exactly 3t + 2; the list has
5 to 9 blocks; about 1.5% of steps run past the end; in 6·10^10 map steps no carry past the end was a power of 2
(smallest odd part seen: 3).

## What is proved

- **Lean, kernel (`lean/Cascade.lean`): the reduction.** With `Wall ns = 0^inf A> 0 0 1^n1 0 0 1^n2 … 0 0 1^nk 0^inf`
  and the map `F` written as the machine computes it (`cascM` inside the list, `tailM` past its end, the merge):
  - `F_correct`: for every list ns of blocks ≥ 1, `F ns = some ns'` ⇒ the machine goes from `Wall ns` to
    `Wall ns'` (at least one step) and ns' has blocks ≥ 1; `F ns = none` ⇒ the machine halts from `Wall ns`;
  - `blank_to_wall`: blank tape reaches `Wall [1, 1]` in 13 steps;
  - **`halts_iff : HaltsFromBlank ↔ ∃ t, orbit t = none`**, where `orbit 0 = [1, 1]`, `orbit (t+1) = F (orbit t)`.
  `F ns = none` happens exactly when an even halving reaches 2 past the end of the list, i.e. when the carry past
  the end is a power of 2. `#eval` of the Lean orbit agrees with `py/cascade.py` (checked for 300 steps).
- Lean, kernel (`lean/Rules.lean`, generated by `py/rules.py` with `bbtools.symtm`): the 13 pieces the proof chains:
  `halve` (the halving round for all k, m, n), `d_run`, `e_run`, `wall_start`, `even_end`, `odd_run`, `dgap`,
  `atom`, `atom1`, `wall_end`, `merge_run`, `past_end`. The induction over the list is hand-written
  (`rounds`, `halving`, `sweep`, `odd_finish`, `casc_correct`, `tail_correct`).
- Lean (`lean/Blank.lean`, generated): the halting configurations; no halt in 10^4 (kernel) / 10^7 (`native_decide`)
  steps.
- Computed: the cascade map agrees with the machine for all 1,779 transitions of the first 10^9 steps and for 1,500
  random lists (`python3 -c 'import cascade; cascade.random_check(1500)'` in `py/`); 6·10^10 map steps without a block 0
  (`c/cascade.c`, 13 min; 778,155,275 cascades past the end, smallest odd part of a carry there 3).

## Open

Whether a carry past the end is ever a power of 2: a question about the map only (the machine's part is proved). Under a naive randomness model the expected number of such events
grows like log(time), so the model says "halts eventually, astronomically late"; nothing proves either way.

## For later
