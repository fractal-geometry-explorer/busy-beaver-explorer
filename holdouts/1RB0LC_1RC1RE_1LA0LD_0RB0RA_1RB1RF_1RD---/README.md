## Status

**Open; probably nonhalting.** A counter multiplied by about 8/3 per phase drives a word of blocks; no halting word
was found. Lean proves the rounds of a phase and a whole residue-0 phase; the word dynamics is measured by simulation (trusted).

## What it does

At every phase start the head, in state B, is at the right end of the tape and the tape reads `P 1^n 0 B>0` (P a word
ending in 0, blank beyond). Each round of a phase takes three 1s from the counter and writes four pairs `01` at the
right. With fewer than three 1s left, the residue n mod 3 sends the head into P, which it edits, and on the way back the
pairs become the new counter: n' = 8(n div 3) + d, with d and the next word depending only on P and n mod 3. A
residue-0 phase absorbs the last block of P into the counter; the other residues push or edit blocks, often by a
smaller phase of the same kind run on a block of P: the word is a stack of nested counters.

Exploring the word dynamics breadth first for every sequence of residues (600 words, the longest 43 cells): no transition halts, and every one returns to a phase start (the same word graph as its relabelled twin).

From the first phase start (step 17, P empty, n = 6), computed exactly: no halt in 2,000 phases (n then has 2,833 bits); 32 distinct words, the longest 20 cells.

No halting word is known, so there is no coin-flip argument for a halt (unlike Antihydra-type machines); nonhalting is
plausible but needs an invariant on all reachable words, more than this pass could do.

## Remainder classes (family survey)

- **Rounds between end events, by remainder class** (trusted). Sample the run whenever the head is in state D reading 0 with only 0s to its right. Read leftwards from the head, the tape is then `A U^m B`: one long periodic block between two short context words. For each class (A, U, B, m mod 3) the next sample is simulated for six values of m and extended as an affine map of m (with a cubic step count). Along the direct run from blank tape to 3·10^9 steps (10 events) the class map predicts the next event in all 6 rounds it applies to. This is an extrapolation checked by computation, not a proof.
