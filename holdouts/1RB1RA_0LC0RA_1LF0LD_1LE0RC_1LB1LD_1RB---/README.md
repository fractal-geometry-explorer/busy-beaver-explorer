# 1RB1RA_0LC0RA_1LF0LD_1LE0RC_1LB1LD_1RB---

Growing periodic regions with resets: next to the left end a periodic word grows by about one copy per left turn and is wiped out at intervals that grow roughly tenfold; the middle is long periodic stretches. Halting is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RA |
| B | 0LC | 0RA |
| C | 1LF | 0LD |
| D | 1LE | 0RC |
| E | 1LB | 1LD |
| F | 1RB | --- |

## What it does

**The tape.** At a left turn: blocks of ones of lengths 1, 3, 5 (and a few 4, 7, 9) separated by single 0s, in long
periodic stretches, e.g. `1 4 (1 3 1 5 5)^87 1 3 1 3 3 1 3 1 3 5 5 3 5 5 3 …` at 1.8·10^7 steps.

**The sweeps (proved, `lean/Rules.lean`).**

| rule | from | to | what it does |
|---|---|---|---|
| `a_1101` | `L A> (1101)^n R` | `L (1110)^n A> R` | Rightward: A turns each 1101 into 1110. |
| `d_1101` | `L (1101)^n D> 0 R` | `L D> 0 (0111)^n R` | Leftward: D turns each 1101 into 0111. |
| `a_110111` | `L A> (110111)^n R` | `L (111011)^n A> R` | Rightward: A turns each 110111 into 111011. |
| `d_110111` | `L (110111)^n D> 0 R` | `L D> 0 (011101)^n R` | Leftward: D turns each 110111 into 011101. |
| `d_11` | `L (11)^n D> 0 R` | `L D> 0 (01)^n R` | Leftward: D turns each 11 into 01. |

**Emergent behaviour (observed, `py/observe.py blocks 30000000 L`).** Copies of `1 3 1 5 5` after the left end `1 4`
at successive left turns: 1, 2, 0, 1, 0, 3, 1, 3, 0, 0, 1, 1, 4, 5, 7, 11, 15, 13, 16, 16, 9, 11, … 28 (at
6.96·10^5 steps), 0 (1.08·10^6), 1, 2, … 82 (9.1·10^6), 0 (1.17·10^7), 4, 5, 25, … 87 (1.8·10^7), 69, 78, … 106
(2.6·10^7). So the stretch grows by about one copy per left turn and is reset at intervals growing about tenfold.
The right end grows by about 2 cells per round trip; left turns are not every round trip (107 in 3·10^7 steps).

**Halting.** F1 halts; F is entered only from `1 C>0`. C reads a 0 only 10,252 times in 10^9 steps; in the first
3·10^7 steps 1,959 of 2,053 are at an end of the tape (next to a blank cell). The other ~5% are the places to look.

## For later

Find the phase structure: what grows, what triggers a reset, and the rule from one phase to the next. The growth of the
reset intervals suggests a counter.
