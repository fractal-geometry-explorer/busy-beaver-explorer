# 1RB1LF_1LC0RD_---1LD_1RB1RE_1LA0LB_0LA0LE

bbchallenge id 34042. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LF |
| B | 1LC | 0RD |
| C | --- | 1LD |
| D | 1RB | 1RE |
| E | 1LA | 0LB |
| F | 0LA | 0LE |

## What it does

Family: **Collatz-like (4n/3) + counter list.**

Write `a` for `10` and `c` for `100`. The right end of the tape holds one long block that changes its encoding
from round to round, `1^N` -> `c^(N/3)` -> `a^(2N/3)` -> ones again, while a list of counters on the left (runs
`a^x` separated by runs of ones whose lengths are multiples of 6) is updated once per round.

* **The transfer (computed, see the legs printed by the scratch tools).** In the main phase the head zigzags between
  the right end and the frontier of a `c`-block: each trip turns one `100` into two `10`s at the right end, so
  `... c^k 1 a^j A> 11` becomes `... c^(k-1) 1^2 B> a^(j+2) 11` and the tape grows by one cell on the right per
  trip (the square-root side). Example from the run: `c^47 1 a^409` at step 1,133,048 becomes `c^9 1^2 a^484`
  at step 1,200,211.
* **Rounds.** When a block is used up the head works through the counters on the left (the cells next to the left
  end change, which is the only time the tape grows on the left: the logarithmic side), and the long block is
  re-encoded. The long block grows by about 4/3 from round to round, as for 1RB1LF_1LC0RD_---1LA_0LA0RE_1LA1RA_1LB0LD
  (a related machine with the same first two states), but here the left part is not a short tail: its blocks
  (`a^174`, `a^354`, `a^750`, ...) grow too.

Round starts seen at the left end, `A> 0 0 P 1^N` (blank on both sides):

**Halting.** The machine stops on C reading 0; C is entered only from B on a 0 (`1LC`), so a halt needs the head in
B on a 0 with a 0 on its left. In the run B meets 0s only next to a run of ones (`1^2 B> ...`).

No rule for a whole round is known yet, so the halting question has not been reduced to a map.

## Status

Open. Lean, all by the kernel:

* `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`); no halt in 10,000 steps by the
  kernel, in 10,000,000 by `native_decide`.
* `lean/Rules.lean` (generated by `py/rules.py`): the six shift rules over `(10)^n` and `(01)^n` that make the
  sweeps (`cross_B_r_10`: B runs right over `(10)^n` leaving `(01)^n`, and so on), for all `n` and any tapes around.

Computed: C runs to 5·10^9 steps (no halt; the round starts above are from them). C (`tools/c/triage.c`): no halt in 10^9 steps.
