## What it does

A two-sided bouncer on blocks of four cells, running in phases.

**Where it can halt.** Only in B reading a 1. B is entered from `A>0` (write 1, move right) and from `D>1` (write 0,
move right), so the machine halts exactly when one of these happens with a 1 just right of the head. In the first
10^8 steps B is entered 13,163,946 times, always onto a 0.

**The main regime.** At the left end in state F the tape is

    P a b  =  F>0^6 (1000)^a 1 0 1 1 1 (0001)^b T

with the tail T cycling through `0100010100001`, `010110100001`, `0111011`. A round trip: moving right, D carries a
pair `0 0` and turns each block into `1111` (`0 0 D>1000 -> 1111 0 0 D>`, 28 steps a block); at the right end the tail
moves to its next shape and, on two shapes of three, swallows one `0001`; moving left, A turns `1111 A>1` into
`A>1 0001` (10 steps a block), which is `1000` again re-bracketed; at the left end a short dance adds two `1000`.
Three trips: `P a (b+3) -> P (a+6) (b+1)` in `114a + 114b + 1115` steps.

**Phases.** When the 0001s run out the tape is rebuilt: the ~3b left blocks become the next reservoir and the left
part restarts at `(1000)^3`. Phase starts (`py/phases.py`): b = 0, 2, 6, 32, 94, 287, 862 at steps 613 ... 10,800,216.
The offsets depend on the tail shape when the reservoir empties (Collatz-like). After b = 862 the rebuild is
incomplete: a segment `(1000)^859` remains on the right and is eaten slowly by the following phases
(b = 8, 36, 290, 1156; segment 859, 850, 742, 454). At 3·10^11 steps the tape has three long segments: a nest of
counters.

## What is proved (Lean, kernel only)

- `lean/Blank.lean` (generated): the halting configurations, 10^4 steps from blank (10^7 with `native_decide`).
- `lean/Rules.lean` (`phase3`, generated by `py/gen_rules.py` with `tools/py/bbtools/symtm.py`): the three-trip cycle
  for all a, b.
- `lean/Phase.lean`: `P_step : steps (114a+114b+1115) (P a (b+3)) = some (P (a+6) (b+1))` (re-bracketing of the
  generated rule) and `P_iter`: `P a (b+2k+1)` reaches `P (a+6k) (b+1)`.
- `lean/Reach.lean`: `reach_P : steps 30224 init = some (P 13 27)` and `reach_P_end`: the run reaches `P 91 1`.

## Computed / observed

- No halt in 10^9 steps (`tools/c/triage.c`), in 3·10^11 with a block-4 macro simulator (C, written for this study,
  not in the repo; `tools/py/bbtools/cycles.py MACHINE 4 ...` reproduces the early part).
- The phase sequence above (`py/phases.py`).

## Open, and next steps

- Prove the phase end for each tail shape: `P a 1`, `P a 2` (and the other two tails) run to the next phase start
  `F>0^6 (1000)^3 1 0 1 1 1 (0001)^b' ...` with b' an explicit function of a. symtm can do this if the reorganising
  sweeps are crossed by shift rules (try `rotate=True` and splitting a by its residue).
- Then the nested case: describe a segment `(1000)^m` to the right of a phase and how a phase end consumes it, and
  find the induction (on the list of segment sizes) that would close the argument, or the residue class that halts.
