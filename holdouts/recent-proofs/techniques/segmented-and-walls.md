# Techniques: segmented-and-walls (busycoq PRs 81, 83, 107, 88, 91, 89; Alex Havrilla, DeepMind)

## 1RB---_1RC0LE_1RD1RF_1LB0LB_0RD0LD_0RC0RA (PR 81, halts, ~10^98,832 steps)
- Invariant: hub config `C` with `1^11` on the left, right tape `00000 ++ encStack st`, where `st : list (BigUint * Delim)` and each entry is `R9^n ++ bitsDelim d`, `R9 = 100001000`, 7 delimiters (pass P1..P3, wall W1..W4).
- Macro step `stackStep` = `scanStep` (outward: P-entries pushed onto a reversed list, converting R9 to R6 runs) + `backStep` (return: each passed count is halved via `div2`, parity selects the next delimiter, halves summed into a new front count). Simplest case: `(n,W1)` with n even -> `(n+n/2+3, W1), (n/2, P1)`, next entry -1. Halt: first wall met is W4 with next count >= 2 (31-step local witness to A1).
- Lemmas: R6/L6 sweeps for all lengths, `roundTrip`, three bounce families (`bounce1_pow`, `bounce2_pow`, B3); `stackStep_spec` soundness; `truncate_sound` (deep suffix irrelevant: halting of a prefix stack implies halting for any suffix/tail).
- vm_compute: 11,243-step bootstrap via a reflective window evaluator `runLocal`, ~30 local lemmas, and `run_blocks 3008 cp0 = Halted` (192,575 stack steps, 64 per block, truncating to 24 entries) with `BigUint` (63-bit limbs; uses PrimInt63 axioms). Counters reach ~164,000 bits. I re-ran the stack map in Python: halts at step 192,575 from hit8 as claimed.
- Generality: needs a "hub" config whose far side is a list of (unary run of one fixed word, delimiter from a finite set), and a macro step that only reads a bounded-length prefix of the list and acts affinely on counts (halving with parity). Fits machines whose repo summary says "stack of counters", "frozen stack", runs with ratio ~3/2 or ~2 between consecutive frozen runs (Collatz-like tower of runs). The frozen runs 908/302/200/133/88 seen in this repo were exactly stack entries.

## 1RB1RE_0RC0RF_1LC1RD_1RA0LE_0RA0LD_0RA--- (PR 83, halts, ~10^20 steps)
- Encoding: left tape `list (d,b)` with `lWord = 1^(d+1) 0` or `1^(d+1) 00`; right tape `list (z,o)` with `rWord = 0^z 1^(o+1) 0`; 8 head modes (`mAR, mAR0, mAR00, mCL, mDL, mEL, mDR, mER`). `stepMacro` is a total table of list moves (each a few raw steps, `start_progress`). RLE layer (`LRun`/`RRun` with binary-N run counts of 1- and 2-element periods) + 11 bulk rules.
- Odometer: near the hub (A at right end, right side blank) the left list reads `(100)^p (10)^(2m) encW(w) 10 rest` with `encW: 0 -> 10, 1 -> 1110`. `odom_master`/`odom_carryW_jump`: for all m, the rest advances `pre(m-1)+post(m-1)+extra = (4^(m+1)-4)/3 + extra` P2-steps while `w` is carried (`carryWFuel`), via recurrence `(pre,post) -> (2pre+post+2, 2pre+3post+2)`. A second symbolic RLE checker (`SymCnt` = const, +t, -t) verifies the jump body once for symbolic t.
- vm_compute: one `check_all_ops` over 3,939 ops (1,650 OpRun + 2,289 OpJump, m <= 14) + 251 final steps to `A> 0 1 1` (A0 -> B1 -> F1 = ---). No axioms.
- Generality: needs a block-of-1s grammar (left blocks separated by one or two 0s) with a bounded mode set, and a self-similar binary odometer region adjacent to the hub whose sweep count obeys a linear recurrence; the rest of the tape must advance "one tick per pass". Good fit for bouncers whose irregular part is a counter right next to the turning point ("zone rewritten like a counter", "counter in a fixed wall").

## 1RB0LA_0RC0LE_0RD1RC_1LD1RE_1LA1RF_---0RB (PR 107, never halts)
- Invariant `invCfg t m = C at right end, blank right; left = (110)^(t+2) ++ frozenAtoms ++ (110)^2 ++ cycState m`, `cycState m = 10 (110)^(m+2) cycIn_0` (cycIn_0: ~108 RLE elements). Left words `1^(d+1)` + `0/00/000` (Sep3), runs of `110` binary-N.
- Repeated step: `TailBounce` = one round trip from the right end to the far-left tail and back; `topWrap_bounces`: n tail bounces add 2n to the top run. `tailBounces_frame_atoms`: any TailBounces certificate lifts across arbitrary passive prefixes built from 3 atoms (`pa_r n`, `pa_z2`, `pa_zr2 a`) — passive blocks are crossed and restored by the out/in sweep transducers for every length.
- Cycle: `sym_cycle : TailBounces (2^37-3) (cycState m) (cycState (m+1))` for all m, composed from `rule_1323` (2^36-4 bounces), `rule_1279` (2^36-7) and 8 single symbolic bounces. Gives `invCfg t m ->+ invCfg (t+2(2^37-3)) (m+1)`; `progress_nonhalt_simple`. Entry: 51-op prefix + wrap to `invCfg 1549833076750 0`.
- vm_compute: 2,579 MINI1 base rules (130,137 miniStep ticks) + 1,334 DAG rules (bit-packed binary-N prefix ops) checked by `vm_compute`, lifted by strong induction (`rules_all_sound`). No axioms.
- Generality: a "growing cycler" proof. Needs: (i) a bouncer whose sweeps pass long periodic blocks unchanged (passive framing transducer), (ii) a bounded-size active tail that eventually returns to the same RLE shape with one counter incremented (m -> m+1) while the top run grows linearly, (iii) the return time can be huge (2^37) as long as it is composed from a DAG of reusable bounce rules (binary-counter-like tail). Candidates: bouncers with a bounded irregular region feeding a growing periodic block.

## 1RB0RD_1RC0LF_0LA0RB_1RE---_1LB1RA_0LE0LF (PR 88, halts, ~8.86e27 steps)
- Base: crystal `crysTape ph c = crysHead ph ++ (0011111)^c ++ 001 ++ 0^inf`, 8 phases with parametric `crystal_bounce`; `LeftWallInv sL := exists w in 13 edges, c, sL = pref35At w ++ crysTape P4 c`; `leftWall_step`: `sL <F sR ->* sL' A> sR` with `LeftWallInv sL'` (each of the 13 edges checked by a parametric crystal simulator `simCrysWall`). So the wall is an autonomous reflector, `RuleSound 0`.
- Byte layer: `theB8Table` (2 sides x 6 states x 256 bytes = 3,072 entries, `vm_check_eq` against raw simulation). `NodeTape d id sL`: node of layer d = parent node at layer d-1 + `nrev` bytes. Each node stores exit slots for entry states {A,B,E,F}: `(idOut, qOut)`. `RuleSound d` proved from `RuleSound (d-1)` by `checkLayersUpTo` (simulate bytes with the table, delegate left exits to layer d-1 rules). 20 layers, 32,053 nodes.
- Top: `simTopLoop` (fuel 450, 20 pushes of fresh zero slices) to `SliceHalt` at D1. No axioms.
- Generality: "closed left-context DAG" (memoised half-tape summaries). Needs a reflecting periodic wall (parametric in its length) plus a data region whose reachable left-contexts per layer are few (here 32k total). Best for "Bouncer + Chaotic Edge" machines where a counting wall is proved separately and the chaotic edge is an odometer of non-identical wheels.

## 1RB1LD_1LC0RF_0RD0LB_1LB0LE_1LA---_0RA0RF (PR 91, halts, ~2.15e114 steps)
- Same machinery mirrored (nodes describe the right side, rules `sL q> sR ->* sL <qOut sR'`), right crystal `(1111100)^c ++ 1`, 12 phases, `crystal_bounce` for every c; 303-step bootstrap.
- New ingredient: wall tower. Stage s has `stageDepth s` byte layers; `checkStageWall` verifies that a finite set of `stageWallCnt s` (5..27) top-layer nodes is closed under the exit rules, and `wallClosure_sound : RuleSound s (stageDepth s) -> RuleSound (s+1) 0`: the closed set becomes the base wall of the next stage. 14 stages, 56 byte layers (70 layer ids), 13 bridges (`stageBridge_step`), final `simTailHalt` at E1. Also closes 2 equivalent TNF holdouts via `Eqv_Misc` TM46 and `Eqv_v2` TM1664. No axioms.
- Generality: extends PR 88 to counters whose low digits form closed finite systems at several scales (a carry hierarchy); needs that at each stage the reachable set of top nodes is small and closed. Applies to "counter next to a conveyor" machines where the carry depth grows like log(time).

## 1RB1RD_0LC0LB_0RE0LD_1LB0RB_1RF---_0RA0RC (PR 89, halts, ~4.9e601 steps)
- Tokens `b0 | b1 | w001 d` (`(001)^(d+1)`), 4 head modes + HALT (`E> 1`); `encode` + fueled `stepFastK`.
- Macro ops from `CL` with empty left (left end): `towerK k` (for every k: first block +7^k, deeper blocks pay `2*7^i+1`, i.e. 7^k odometer increments), `carryUntilAbsK` (base-6 phase carry sweep across w001 blocks until absorbed), `upChainK`/`downChainK` (batched Horner-style waves: costs accumulated as `c + S*7^len`).
- vm_compute: 40,462 ops in 203 chunks in one `vm_cast_no_check` over an optimised executor proved equal (`execChunksF_eq`, `Pos.sub_mask`); counts ~2,000 bits. Also closes the TNF holdout `1RB0LB_0RC0RB_0LD0RA_1LE---_0LF0LC_1LB1LA` via `Eqv_v2` TM2552. No axioms.
- Generality: base-b odometer whose digits are markers between unary blocks that pay per digit change ("paying blocks"); needs a closed-form k-level drain (b^k increments) and a carry sweep grammar. Direct fit for the "marker counter" (base-5 markers between 0010-blocks) and "binary/base-4/base-5 counter with paying blocks" holdouts, where halting depends on block lengths and must be followed exactly.

## Candidates (all decision "open" in holdouts/*/status.json)
- `1RB0LC_0RC0RB_1LD0RE_0LE1LF_1LA0LB_0RE---` (PR 89 technique; and its ~13 "marker counter" siblings, Skelet 1-like Class 1): base-5 counter of markers between 0010-blocks; halting needs two merges close together, i.e. a length-dependent misaligned carry exactly like PR 89.
- `1RB1LF_1RC0RA_0RD1RA_1RE1LA_0LA---_1RF0LD` (PR 89): binary counter with bits between blocks of 10s, each block paying one copy per cleared bit; halt needs neighbouring blocks to run out together.
- `1RB1LF_1LC0RD_0LD0LC_1RE0LA_0RA0RC_0RE---` (PR 89): base-5 counter of five-phase gadgets between blocks of 1000s, each tick paid by moving 1000s between blocks.
- `1RB---_0RC0RD_1LD0RF_0LE0LC_1RA0LC_1RC0RA` (PR 81, same tracker class Chaotic Bell Class 2): "stack of counters at the right end ... each pop starts a top about 2.5 times larger while deeper blocks tick slowly".
- `1RB1LF_1RC1LD_1LB1LE_1LE0LD_0LA0RE_1RD---` (PR 81): each round pushes a new run of 10010s ~6x or 4/3x the previous top onto an otherwise frozen stack; no halt in 1.12e37 accelerated steps, so a BigUint stack evaluator is the natural tool.
- `1RB0RC_1RC1RA_1LD0RA_0LE1RA_---1LF_1RB0LF` (PR 88/91, Bouncer + Chaotic Edge): a middle of identical blocks 1010^8 gaining one block per cycle (a counting wall), a left end cycling through ~10 prefixes, and an irregular right end that decides halting.
- `1RB1RA_0LC0RF_1LD1LC_1RE1LB_---0RA_1RF0RD` (PR 88/91, Bouncer + Chaotic Edge): irregular word W next to a run of 1s that counts visits (Lean); halts iff W eats the run between two visits, W changes at most 14 cells per visit: a reflecting counter wall plus a small data word.
- `1RB---_1LC0RF_1LD0LC_0RE0LF_0RD1LA_1RB0LE` (PR 83/91): bouncer between a growing block and a wall of exactly 1,573 cells that changes every sweep like a counter, carries reaching further about every 3x as many sweeps; the 83 odometer-jump or 91 wall-tower scheme fits.
- `1RB0LF_1LC0LA_---1RD_1RF1RE_1LF1RD_1LB0RE` (PR 107, non-halting side): periodic left part (1011011011)^n grows by one copy every few round trips while an irregular right part of 300-430 cells keeps roughly constant size: the bounded-active-region + passive-growing-block shape of the 107 growing cycler.
