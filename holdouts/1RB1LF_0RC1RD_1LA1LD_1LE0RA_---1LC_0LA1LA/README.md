# 1RB1LF_0RC1RD_1LA1LD_1LE0RA_---1LC_0LA1LA

bbchallenge id 35366. One of the six-state holdouts whose halting from blank tape is open.  It is a
**two-variable piecewise-linear map in disguise**: the tape is two blocks of ones, `1^a 0 1^c`, and one "round"
of the machine (thousands to billions of steps) replaces `(a, c)` by a new pair in which `c` is roughly tripled.
Lean's kernel proves that the machine halts **if and only if** the orbit of this map reaches one of four exact
differences between `c` and `a`.  The orbit has been followed for 10^6 rounds without reaching them; nothing
seems to stop it from doing so except chance, which shrinks geometrically.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LF |
| B | 0RC | 1RD |
| C | 1LA | 1LD |
| D | 1LE | 0RA |
| E | --- | 1LC |
| F | 0LA | 1LA |

## What it does

### The tape

Between rounds the tape is a few blocks of ones separated by single 0s, with the head in state A on the blank cell
just left of them.  Write `K[x1, x2, ..., xk]` for that configuration (`A>0 1^x1 0 1^x2 0 ... 0 1^xk`, blank on
both sides).  The machine sweeps right across all the blocks and back, and each sweep changes only two or three
blocks by a few ones.  Which blocks change is decided by parity (this is what `py/rules.py` and
`lean/Rules.lean` prove for all values of the counts):

| round start | next round start | rule in Lean |
|---|---|---|
| `K[2x+6, 2y+8]` (both even) | `K[2x+6, 2y+4, 9]` | `e0` |
| `K[f, 2m+5, z]` (f even >= 4) | `K[f-2, 2m+3, z+6]` | `loop_e`, `loop_o`, `loop4_*`, `loop3_*`, `loop43_*` |
| `K[f, 1, z]` (f >= 6) | `K[f-2, z+9]` | `end1_*` |
| `K[2, 2m+3, z]` | `K[2m+4, z+6]` | `end2_*` |
| `K[4, 1, z]`, `K[2, 1, z]` | **halt** | `halt4_*`, `halt2_*` |

plus five rules that shrink a block `9` to `1` (`e9`, `e7`, `e5`, `e3`, `e1`) and one for an odd right block
(`o0`).  So a round with three blocks `(f, m, z)` (`f` even, `m` odd) moves two ones out of each of the first two
blocks and six into the last; this repeats until the first block is down to 2 or the middle one to 1, and then the
three blocks become two again.  That whole *phase* is one step of the map below.

### The map

With two blocks `(a, c)` (`a` always even) one phase gives (`lean/Map.lean`, `mapc`):

| case | condition | next `(a, c)` |
|---|---|---|
| `c` even | `c <= a + 8` | `(a - c + 12, 3c - 6)` |
| `c` even | `c = a + 10` or `c = a + 12` | **halt** |
| `c` even | `c >= a + 14` | `(c - a - 10, 3a + 27)` |
| `c` odd | `c <= a - 5` | `(a - c - 1, 3c + 6)` |
| `c` odd | `c = a - 1` or `c = a - 3` | **halt** |
| `c` odd | `c > a` | `(c - a + 3, 3a)` |

The first block is a *difference* of the two old blocks and the second is three times one of them, so the pair
behaves like a subtractive Euclid algorithm with a factor 3 thrown in: `c` grows by a factor of about 1.236 per
round on average.  From blank tape the machine reaches `K[74, 30]` at step 6,998 and then follows the map:

    (74, 30) -> (56, 84) -> (18, 195) -> (180, 54) -> (138, 156) -> (8, 441) -> (436, 24) -> (424, 66)
             -> (370, 192) -> (190, 570) -> (370, 597) -> (230, 1110) -> (870, 717) -> (152, 2157) -> ...

(`py/orbit.py --check` compares these with the machine's own round starts.)

### Why it might halt, and why it probably does not

The machine halts exactly when, in some round, `c - a` is 10 or 12 (`c` even) or `a - c` is 1 or 3 (`c` odd):
then the first block runs out while the middle one is still there and the head walks off the left end into state E
on a blank cell.  In the orbit, `c - a` is always about as large as `c` itself (after round 40 it never had
fewer bits than `c` minus 26), and `c` has 306,184 bits after 10^6 rounds.  If `c - a` behaved like a random
number of that size, the chance of ever hitting one of the four values after round `n` would be about
`sum 4/c_k`, which is astronomically small already after a few dozen rounds.  So the machine is very probably a
non-halter, but a proof would need to control the exact value of `c - a` along an orbit of a map like
Collatz's, which nobody knows how to do.

### The growth shape

The blocks are left of the start cell; the right end of the tape hardly moves (the "exp" side of the triage).  A
round sweeps the whole tape about `m/2` times, so it takes on the order of `(a + c)^2` steps while the tape grows
by a constant factor: the tape length grows like the square root of the step count (the "sqrt" side).

## Status

Open, reduced to the map.  Lean, all by the kernel (axioms `propext`, `Quot.sound`, `Classical.choice`):

- `lean/Rules.lean` (generated by `py/rules.py` with `tools/py/bbtools/symtm.py`): the 28 rounds above, each for
  all values of its counts;
- `lean/Rounds.lean`: the rules on blocks (`Blk`), the loop by induction (`loopN`), the phases (`phase_lt`,
  `phase_ge`, `phase_halt`);
- `lean/Map.lean`: `round_ok` and `round_halt` (the map `mapc`), `init_reach` (step 6,998 is `K[74, 30]`) and
  **`halts_iff`: if the orbit of `mapc` from `(74, 30)` never meets a `.small` case, the machine halts from blank
  tape iff the orbit reaches `.halt`**.  The `.small` cases (blocks too short for the rules, such as `c < 18`) are
  not met in the first 10^6 rounds (`py/orbit.py`, computed).

Also `lean/Blank.lean`: the halting configurations (`step_none_iff`), no halt in 10,000 steps by the kernel, in
10,000,000 by `native_decide`. C (`tools/c/triage.c`): no halt in 1,000,000,000 steps.

## For later

- The `.small` cases could be removed from `halts_iff` by proving that the orbit stays in the large region
  (`a >= 6` with `c >= 18` when `c` is even), which holds after round 1 in every computed step but needs an
  argument about the map, or by proving rules for the small blocks too.
- The map itself: any invariant of the orbit that keeps `|c - a|` away from the four values would prove
  non-halting.  Residues modulo small numbers do not: for every modulus `N = 2^k 3^j` up to 1458 tried, the
  residues of `(a, c)` reachable from `(10, 6)` when either branch of each case may be taken include halting ones.
