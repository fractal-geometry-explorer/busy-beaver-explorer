# 1RB1LD_1RC0RA_1LA1RE_0LA0LB_0RB1RF_---1RD

bbchallenge id 28830. One of the six-state holdouts whose halting from blank tape is open. Lean reduces it exactly to a
machine with three counters; whether that halts is a Collatz-like question.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LD |
| B | 1RC | 0RA |
| C | 1LA | 1RE |
| D | 0LA | 0LB |
| E | 0RB | 1RF |
| F | --- | 1RD |

## What it does

Every time the head turns left into state D, the tape is one of three shapes (read left to right):

```
X(a,b,c) = 0^inf 1^a 0  (10)^b 1 D> 0 1^c 0^inf
Y(a,b,c) = 0^inf 1^a 00 (10)^b 1 D> 0 1^c 0^inf
Z(a,c)   = 0^inf 1^a 0 D> 0 1^c 0^inf
```

so the machine is a three-counter machine: a block of ones on the left, a block of `10`s in the middle, a block of
ones on the right, with the head at the boundary of the last two. Between two such moments the head makes one trip
over the `10` block (or over the right block, when that is down to one cell). The rules, proved in Lean for all
values (`lean/Rules.lean`):

```
X(a+4,b,c+2) -> X(a+1,b+2,c+1)     X(3,b,c+2) -> X(1,b+1,c+1)     X(2,b,c+2) -> X(2,b+2,c+1)
X(1,b,c+2)   -> Y(3,b,c+1)         X(0,0,c+2) -> Z(3,c+1)
X(a+5,b,1)   -> X(a,0,2b+9)        X(4,b,1) -> X(4,0,2b+7)        X(3,b,1) -> X(4,0,2b+5)
X(2,b,1)     -> X(0,0,2b+9)        X(1,b,1) -> X(1,0,2b+5)        (X(0,b+1,c) is the tape X(1,b,c))
Y(a,b+1,c+2) -> Y(a+3,b,c+1)       Y(a,0,c+2) -> Z(a+3,c+1)       Y(a,b,1) -> X(a,1,2b+3)
Z(a,c+6)     -> X(a+4,0,c+1)       Z(a,1) -> X(a,1,1)             Z(a,3) -> X(a,0,5)
Z(a,4)       -> X(a+2,0,3)         Z(a,5) -> X(a+2,0,5)           Z(a,2): halts 5 steps later
```

(for Y and Z, a >= 3). In words: in X the left block gives 3 ones and the middle block gains 2 `10`s for each one taken
from the right block; in Y it is the other way round (left +3, middle -1, right -1). From blank tape the machine is at
X(2,0,3) after 29 steps. Lean (`halts_iff`, `lean/Model.lean`): **the machine halts if and only if the orbit of
X(2,0,3) reaches Z(a,2)**, i.e. a Y run whose middle block empties exactly when the right block has 3 ones.

## Rounds

A round starts at `X(0,0,N)` (the whole tape is ones, N odd). It opens with a doubling stage:
`X(A,0,C) -> X(1,..) -> Y(3,..) -> Y(..,0,..) -> Z -> X(2A+8, 0, C-A-6)` from A = 7, C = N-6, so A+8 = 15·2^i,
eating the right block until it is too short. The rest of the round is a short, Euclid-like stretch (sometimes with a
second doubling stage) that ends at `X(2,b,1) -> X(0,0,2b+9)`. N goes 17, 57, 185, 601, 2265, 5913, 16121, 35177, ...,
growing about 2.4 times a round, and a round costs about N^2 steps; that is the triage shape (left side like the
square root of the step count).

## Does it halt?

Halting needs a Y run `Y(a,b,c)` with c - b = 3 exactly. In the doubling stage this is impossible by parity (there c
is always even and b is even; checked by hand from the formulas above, not in Lean). Elsewhere nothing rules it out,
but the coincidence has a chance of about 1/N. `py/orbit.py` iterates the map for 2,000 rounds (about 10^1511 steps,
N about 10^756) without halting; the closest approach after round 3 is |c-b-3| about 10^-5.5 N (2.5 million Y runs
checked). **Open**; heuristically it almost surely never halts.

## For later

The reduction is complete and proved; what is left is the arithmetic of the map. The doubling stage is understood
in closed form; the endgame of a round (what happens when the right block runs short of the doubling sequence) is
not. A closed form of the round map N -> N' (it depends on where N falls among the values 15·2^i and on residues mod
3 of the left block) would turn the question into a statement about one integer sequence.

## Status

Open, reduced to the three-counter map. Lean, kernel only: `lean/Rules.lean` (20 symbolic runs, generated by
`py/gen_rules.py`), `lean/Model.lean` (`nxt`, `rule_some`, `rule_none`, `blank_to_X`, `halts_iff`).
`lean/Blank.lean`: the halting configurations, no halt in 10,000 steps by the kernel, in 10,000,000 by
`native_decide`. C (`c/canon.c`) + `py/orbit.py validate`: every transition of the direct run up to 1.1·10^10 steps
is the map's, with the map's step count. `py/orbit.py run 2000`: no halt in 2,000 rounds (about 10^1511 steps).
