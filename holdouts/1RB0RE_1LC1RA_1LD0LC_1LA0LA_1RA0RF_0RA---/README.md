# 1RB0RE_1LC1RA_1LD0LC_1LA0LA_1RA0RF_0RA---

bbchallenge id 37401, group G12. Whether it halts from blank tape is **open**. Family: two-level counter on odd blocks (fast tail, leftward carry, full rewrites).

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1LC | 1RA |
| C | 1LD | 0LC |
| D | 1LA | 0LA |
| E | 1RA | 0RF |
| F | 0RA | --- |


## The picture

At the moments the head is in A on the first blank cell right of everything written: Read the tape as words `a = 01`, `b = 0111`, `c = 011111`, `d = 0 1^7`, `e = 0 1^9` (a 0 followed by an odd run of 1s) and `z = 00`; `a^4` is four a's. The fast counter is the run `1^(2k)` at the right end: it grows by 2 per round (by 4 between the samples shown), and each round takes twice as long as the one before plus about 2 steps.

| step | tape | |
|---|---|---|
| 31,891,522 | `1^2 b^3 a^2 c a^2 c a^2 b c^2 b a b^2 a^2 b a c b^5 a^2 b^2 c a^6 d b a^2 c^2 a c d a b` | after a rewrite |
| 32,133,214 | `… a^2 b a b a b^6 a^2 b^2 a^7 d b a^2 c^2 a c d a e 1^10` | carries move left |
| 94,026,078 | `1^2 b a^2 b a^2 c a^2 c a^2 b c^2 … e 1^26` |  |
| 280,432,778 | `a b^3 a^2 c a^2 c … d a e 1^30` | the carry at the left end |

Left of the fast counter is a slow list, a word in a, b, c, d, e: blocks of odd length separated by single 0s. In each round one local change happens in it, a little further left each time (a carry: for example `c a^3` → `b a b a^2`, `b^3` → `a^2 b^2`), so the list behaves like the low digits of a slow counter whose digits are the odd block lengths. When the change reaches the left end, the head sweeps the whole tape: going left, state C erases runs of 1s and the tape is rewritten into words `1^2 0^k`, and going right it is rewritten back, a rebuild that makes the list longer. This pair shares the first rows `1RB0RE_1LC1RA_1LD0LC` and differs in D0 and E1; both behave in the same way.

Rebuilds seen at about 1.4·10^7 and 5.2·10^8 steps (the head reaches the left end of the tape).

**Proved in Lean, kernel only** — Three rounds of the run, for any tape further left: Three consecutive rounds of the run from blank tape (between moments the head is in A on the first 0 right of everything written), each proved for every tape left of the cells it visits, with its exact step count. (`lean/Rounds.lean` (generated by `py/gen_rounds.py`))

**Proved in Lean with `native_decide`** — No halt in the first 10^7 steps: The same run, evaluated by compiled code. (`blank_runs_native`, `lean/Blank.lean`)

**Computed (trusted C/Python)** — No halt in the first 10^9 steps: The C simulator `tools/c/triage.c` runs 10^9 steps without a halt; at the end 227 cells have been visited and 121 of them hold a 1. (`holdouts/triage.json`)

**Computed (trusted C/Python)** — No halt in 10^9 steps; rebuilds: Direct simulation. The fast counter is the run `1^(2k)` at the right end: it grows by 2 per round (by 4 between the samples shown), and each round takes twice as long as the one before plus about 2 steps. The slow list was rebuilt at about 1.4·10^7 and 5.2·10^8 steps (the head reaches the left end of the tape); between rebuilds each round makes one local change in it. (`tools/c/tmrun.c` (`at A R`))

**Heuristic / observed** — Two-level counter: Left of the fast counter is a slow list, a word in a, b, c, d, e: blocks of odd length separated by single 0s. In each round one local change happens in it, a little further left each time (a carry: for example `c a^3` → `b a b a^2`, `b^3` → `a^2 b^2`), so the list behaves like the low digits of a slow counter whose digits are the odd block lengths. When the change reaches the left end, the head sweeps the whole tape: going left, state C erases runs of 1s and the tape is rewritten into words `1^2 0^k`, and going right it is rewritten back, a rebuild that makes the list longer. This pair shares the first rows `1RB0RE_1LC1RA_1LD0LC` and differs in D0 and E1; both behave in the same way. Not shown for all sizes. (`README.md`)

**Open** — Does it halt from blank tape?: Not known. See the heuristic claims above for what a halt would need.
