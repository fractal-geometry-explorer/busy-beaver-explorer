# 1RB1LD_0LC1RC_1RA1RD_1LE0RB_---1LF_0LC0LA

bbchallenge id 176216. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LD |
| B | 0LC | 1RC |
| C | 1RA | 1RD |
| D | 1LE | 0RB |
| E | --- | 1LF |
| F | 0LC | 0LA |

Three zones, and phases that grow by about 4/3. Seven sweeps over the left zone are proved in Lean for all sizes; the
phase structure is read off simulation.

## What it does

Read from the left end, the tape is `0 0 (0 1^5)^a [gadget] 0 1^15 (0 1^11)^b [tail]`. The gadget is a few blocks of
length 5…17 and the tail a few odd blocks.

- **Visits.** The head walks from the left end to the gadget and back. On each walk it crosses the run of short
  blocks several times and re-encodes it: pairs `011111011111` become `101011011011`, then other 12-cell words, and
  finally pairs again. These crossings are the seven shift rules in `lean/Rules.lean`.
- **One period.** Every 12 visits (counted when the head is in state C at the left end) the gadget is back in the same
  shape, a has grown by 16 and b has shrunk by 6: three long blocks become eight short ones. `bbtools.cycles` (block
  size 12) proves these cycles symbolically, but each needs about 1 MB of Lean, so they are not kept.
- **Phase change.** When the long run is used up, the short run is folded into about half as many long blocks and a
  new tail is written. A new phase then starts with a = 9. The values of b at the start of each phase are 24, 33, 53,
  78, 111, 143, 196, 269, 374, 500, 661, 900, 1197, 1604, 2147, 2868, 3834 and 5113, the last at step 2,251,904,944. A
  phase ends with about 8b/3 short blocks and the next one starts with about half of that, a ratio of about 4/3; the
  offsets and the tail differ from phase to phase.

A phase costs about the square of the tape length, which gives the sqrt growth on the left; the right end hardly moves.

## Does it halt?

The halting transition is E0. E is entered only from D0 (`1LE`), so a halt needs D to read a 0 with a 0 to its left.
Inside a phase the 12 shapes repeat (by the computed period rule), so a halt could only come at a phase change.
Whether one ever produces that pattern is open.

## For later

- Work out the phase change exactly: how the tail and the residue of b mod 3 give the next tail and the next b. Prove
  it with symtm, at least for the tails seen so far, and iterate the map.
- Prove the 12-visit period in Lean in a compact form, as a composition of the shift rules, instead of one
  `bbtools.cycles` proof of about 1 MB.

## Files

- `lean/Rules.lean`: the seven shift rules, generated by `py/gen_rules.py` (`bbtools.symtm`).
- `c/tok.c`: prints the tape at events (here: state C at the left end). `py/blocks.py` turns that output into lists
  of block lengths.

## Status

Open. Lean: `step_none_iff`, no halt in 10,000 steps by the kernel and in 10^7 by `native_decide` (`lean/Blank.lean`),
and the shift rules (`lean/Rules.lean`, kernel). C (`tools/c/triage.c`): no halt in 10^9 steps.
