# 1RB0RE_1LC0RE_1LA1LD_0LB1LF_1RC1RA_1LB---

bbchallenge id 59536. A six-state holdout of BB(6). **Open.** It is a list of blocks of ones that behaves like a binary counter: between two visits of the head to the left end, block i loses about 2^(i+2) ones.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1LC | 0RE |
| C | 1LA | 1LD |
| D | 0LB | 1LF |
| E | 1RC | 1RA |
| F | 1LB | --- |

## What it does

At the left end the tape is `1^x0 0 1^x1 0 ... 0 1^xr`. Write it as [x0, ..., xr]. On the way right, A and E
rewrite each block of ones as copies of `10` (`a_right`, `e_right`). On the way left, F (with D, B and C) turns
each `1010` back into `1111` (`f_left`). As in `1RB0RE_1LC1LF_1RA1LD_0LB---_1RF1LE_0LB0RA`, which does the same in
base 4, most sweeps turn at block boundaries before they reach the left end.

Lists at the left end (C simulator, `edges` + `rl.py`):

    659,177        [132, 94, 22, 18, 398, 86, 1142]
    36,766,110     [112, 374, 834, 586, 222, 942, 546, 1998, 8978, 614]
    69,844,480     [110, 366, 822, 558, 166, 834, 330, 1562, 8102, 2550, 6782]
    267,430,903    [110, 358, 806, 526, 102, 706, 74, 1050, 7078, 502, 2686, 24566]
    837,409,267    [107, 350, 790, 490, 30, 554, 682, 6330, 698, 20582, 8114, 12454, 25118]
    2,015,765,149  [98, 342, 770, 450, 446, 466, 5890, 19010, 4966, 6158, 44270, 16662, 16886]

From 69,844,480 to 267,430,903 the differences are 0, -8, -16, -32, -64, -128, -256, -512, ...: block i loses
2^(i+2). A block that runs low (here 30, then 74) is refilled by an amount that depends on the list.

## Rules proved in Lean

`lean/Rules.lean` is generated by `lean/rules.py` (symbolic runs, `tools/py/bbtools/symtm.py`). Every rule holds for all values of its variables and all tapes L, R:

| theorem | from | to | meaning |
|---|---|---|---|
| `f_left` | `L 1 (1010)^n F> 0 1 R` | `L 1 F> 0 (1111)^n 1 R` | Going left, F (with D, B, C) turns each `1010` into `1111`, eight steps per word: copies of `10` become ones. |
| `e_right` | `L 0 E> (1111)^n 1 R` | `L 0 (1010)^n E> 1 R` | Going right, E and A turn each `1111` back into `1010`, four steps per word. |
| `a_right` | `L 0 A> (11)^n 0 R` | `L 0 (01)^n 1 B> R` | A runs right over a block of 2n ones, turning it into `(01)^n`; at the 0 after it B turns back. |

## Second round

Over the visits to the left end up to step 1.5*10^10, the clean pairs (no refill, no leading block `1`) follow
the base-4 machine's law in base 2. The first block loses 1, block i >= 1 loses 2^(i+2), and a new last block
appears. For example [146,126,22,102,182] -> [145,118,6,70,118,374] (steps 49,832 -> 105,098). The other pairs
involve a block running out or a leading block of length 1, which shifts the indexing. These have not been decoded
yet.

## Status

Open. Lean: the halting configurations and no halt in 10^7 steps (`lean/Blank.lean`), and the three sweep rules
(`lean/Rules.lean`). C: no halt in 4*10^9 steps. The binary-counter picture is a heuristic read off the run.
