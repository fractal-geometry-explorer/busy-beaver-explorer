Using these passes, Lean proves 27 rules. Each rule says: from form X with numbers like (a, b + 6, c + 2), the machine reaches form Y with numbers that are simple formulas of a, b, c, in an exact number of steps that is also a formula. The rule holds for every value of the variables. Kernel This is the theorem that ties level 2 to level 1: a rule is a statement steps N (X …) = some (Y …) about the machine itself, so a chain of rules is a stretch of the real run, step count included.

The central example is the 4-visit cycle cycle: S1 a (b+2) (c+2) reaches S1 (a+3) (b+14) c in exactly 80a + 72b + 1356 steps. Each turn uses up two of the 14-cell words (c drops by 2), and the runs of 1000 and 10 grow by 3 and 12. The head visits the left end four times on the way.

Each rule's proof is a symbolic run: Lean steps the machine on a tape whose runs have lengths like b + 2, uses a pass to cross a whole run at once, and at the end shows the tape it got is the target form (by regrouping, e.g. (0010)^a 0 = 0 (0100)^a). Lean also proves the k-fold repeats such as cycle_iter, by induction on k. The rules are in lean/Cycle.lean, lean/Phase.lean, lean/Branch.lean and lean/Ends.lean.

Try any rule: choose small numbers for its variables, and the browser runs the real machine for exactly the stated number of steps. The picture shows the tape over time (rows are moments, time going down; dark = 1) and the path of the head (orange line). The check compares the result with the target form, cell for cell.
