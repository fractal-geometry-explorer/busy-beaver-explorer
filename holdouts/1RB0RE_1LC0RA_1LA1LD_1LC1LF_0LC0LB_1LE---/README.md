# 1RB0RE_1LC0RA_1LA1LD_1LC1LF_0LC0LB_1LE---

bbchallenge id 103424, one of the six-state holdouts (group G06: one side of the tape stops growing, the other grows
like a square root). Whether it halts from blank tape is open. It runs a Collatz-like map M -> about 8M/3 on the
length of a block of ones, with a small stack of blocks (the *tail*) beside it that the residue M mod 3 pushes,
pops and edits; it halts only if the tail ever takes one of a few shapes containing two adjacent blocks `0 1 1`.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1LC | 0RA |
| C | 1LA | 1LD |
| D | 1LC | 1LF |
| E | 0LC | 0LB |
| F | 1LE | --- |

## What it does

A *phase* starts at

```
PS(M, T) = 0^inf  F> 0 1^M  T  0^inf          T = 0 1^t1 0 1^t2 ... (the tail, written [t1, t2, ...])
```

From blank tape the phases start at steps 36, 226, 1,430, 9,562, ... with M = 9, 27, 75, 203, 545, 1457, 3889,
10365 (tail [6]), 27659, 73761 (step 1.19·10^9).

Within a phase (all proved in `lean/Rules.lean`):

- `start`: five ones become a wall `(10)^5` at the left end;
- `round`: each round trip of the head eats three more ones and adds four pairs to the wall (6k + 39 steps for a
  wall of k pairs; inside it the gap `00` runs left through the wall, `gap_left`). So the wall grows to about 4M/3
  pairs and the phase costs about 4M²/3 steps: the square-root growth on the left;
- at the end (0, 1 or 2 ones left, M mod 3) the head meets the tail, does something to it, and state C runs left
  turning every `10` of the wall into `11` (`unwall`): the next phase has M' = 8M/3 + c ones.

On the empty tail and the tail [6] this is proved for whole phases, for every M (`lean/Phase.lean`):

| M mod 3 | tail [] | tail [6] |
|---|---|---|
| 2 | M' = (8M + 11)/3, tail [] (`phase_e0`) | M' = (8M + 29)/3, tail [] (`phase_s0`) |
| 0 | M' = (8M + 9)/3, tail [] (`phase_e1`) | M' = (8M + 57)/3, tail [] (`phase_s1`) |
| 1 | M' = (8M − 17)/3, tail [6] (`phase_e2`) | M' = (8M − 5)/3, tail [1, 1, 3] (`phase_s2`) |

For other tails `py/phases.py` gets the phase by running the machine on three small M of the same residue and
extrapolating linearly (checked: slope 8/3, same tail). The tail changes by simple rules, with r = M mod 3 and the
tail written as some 1s, then a first longer block t, then the rest:

- r = 2: pop: the first block is removed ([1, 3] -> [3], [5, 2] -> [2], [] -> []);
- r = 1: the first block t >= 3 after the leading 1s becomes 1, 1, t − 3 (so it is counted down by threes, pushing
  pairs of 1s); an all-ones tail of length L becomes [2L + 6]; a first block 2 makes a new block in front
  ([1^j, 2] -> [2j + 4, 6]);
- r = 0: by the first block t mod 3: t = 1 (also a leading 1) clears the tail to [] or [6]; t = 0 pops two blocks;
  t = 2 pops it and counts the next block down like r = 1 ([2, 6] -> [1, 1, 3]).

It halts exactly in a few of these tail cases: (tail, r) = ([2, 2], 1), ([1, 2, 2], 1), ([2, 2, 1], 1),
([2, 2, 2], 0 or 1), ([5, 2, 2], 0), ([8, 2, 2], 0) among the tails of up to three blocks of 1 to 8.

## Status

**Open.** It halts if and only if the phase map, iterated from PS(9, []), reaches a halting (tail, residue). That
needs the tail to build a stack with two adjacent blocks 2, which takes a long run of specific residues M mod 3:

- iterated from blank tape, 30,000 phases have no halt (`py/phases.py 30000`, a few minutes; M then has about
  12,800 digits, so this is far beyond 10^25000 steps). The tail stays small: at most 26 cells, at most 9 blocks.
- with the residues free (any sequence), a halting tail is reachable: a best-first search (`py/tails.py`) finds a
  path of 108 phases from [] to ([1, 2, 2], 1). So no invariant of the tail alone excludes halting.
- with the residues taken as independent and uniform (a heuristic model), 3·10^6 random phases (300 runs of
  10,000 from [], `py/tails.py`) had no halt.

So the question is Collatz-like: whether the residues of M mod 3 along the orbit of M -> 8M/3 + c ever line up in
the pattern that builds a halting tail. No method is known for this kind of question.

## Proved in Lean

- `lean/Rules.lean` (generated by `lean/rules.py`): `start`, `round`, `gap_left`, `unwall`, and the ends of a phase
  `end_e0`, `end_e1`, `end_e2` (empty tail) and `end_s0`, `end_s1`, `end_s2` (tail [6]).
- `lean/Phase.lean` (by hand): `rounds` (j rounds, by induction), and the whole phases `phase_e0`, `phase_e1`,
  `phase_e2`, `phase_s0`, `phase_s1`, `phase_s2` for every j (M = 3j + 5, 3j + 6, 3j + 7).
- `lean/Blank.lean` (generated): the halting configurations (`step_none_iff`, F reading 1) and no halt in the first
  10^7 steps.

The end with tail [6] and M = 0 mod 3 runs three passes over the wall; its generated proof needs a higher
heartbeat limit, which `rules.py` sets for `Rules.lean`.

## Computed (not proved)

- `py/tails.py` (about ten minutes): the free-residue search and the random-residue runs above.
- `py/phases.py [PHASES]` (half a minute for 3000): checks `phase` against the real machine on the first nine phases
  from blank tape, lists the halting tails, iterates the phase map from PS(9, []) and prints the largest tails.

## For later

- Prove the tail rules in Lean for general tails (the end of a phase is a bounded interaction with the first few
  blocks, then `unwall`), so that the phase map itself is a theorem.
- Bound how long a run of residues the halting tails need from any reachable tail, and test those residue patterns
  along the orbit with arithmetic modulo 3^k instead of the full numbers.
