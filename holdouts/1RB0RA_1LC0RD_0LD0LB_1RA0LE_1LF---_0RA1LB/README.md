# 1RB0RA_1LC0RD_0LD0LB_1RA0LE_1LF---_0RA1LB

bbchallenge id 65987, a six-state holdout of group G05 (growth class fixed/sqrt). **Open.** A fixed gadget at the
left end pumps a marker `111 0` through a block of `10`s, 12 pairs per trip, leaving 15 new pairs each time. Lean
proves that pump exactly (every block length, every rest of the tape) and that the run reaches it. The pump runs in
phases whose block lengths follow a Collatz-like map (about x5/4 per phase) until a remainder case ends it near step
435,764; after that the tape is a row of a dozen or so units that change irregularly. No halt in 10^11 steps.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RA |
| B | 1LC | 0RD |
| C | 0LD | 0LB |
| D | 1RA | 0LE |
| E | 1LF | --- |
| F | 0RA | 1LB |

## What it does

**The gadget and the cycle.** From step 16,718 on, whenever the head is at the left end (state C on the first cell,
blank tape to the left) the tape starts with the 17-cell gadget

    G = 0 1 0 1 0 111 0 1 00 1 0 11 0

In the first regime the rest is `(10)^X 111 0 R` with X even. One trip of the head carries the marker `111 0` twelve
pairs to the left and leaves fifteen pairs behind it:

    C> G (10)^(2x+12) 111 0 R   ->   C> G (10)^(2x) 111 0 (10)^15 R      in 120x + 878 steps

The trip never reads R, so this holds for every tape R.

**Phases (first regime).** The cycles run until fewer than 12 pairs are left (X mod 12 = r). Then the head
reorganizes the short blocks right of the new pairs and a new phase starts with the shape
`G (10)^X 111 0 (10)^Y 0 (10)^t`:

| step | X | Y | t |
|---|---|---|---|
| 16,718 | 64 | 15 | 4 |
| 33,824 | 90 | 8 | 3 |
| 61,598 | 118 | 5 | 2 |
| 102,230 | 152 | 0 | 5 |
| 169,786 | 190 | 2 | 4 |
| 283,966 | 230 | 14 | 3 |

so X' = Y + 15 floor(X/12) + a(r, t) with a small correction a: about 5X/4, a Collatz-like map. The symbolic prover
writes the phase ends for r in {0, 4, 6, 8, 10} without trouble; for r = 2 (first met at X = 230) the head makes long
trips into the right part (`NeedSplit` in `bbtools.symtm`), and that phase ends the first regime.

**Second regime.** From step 435,764 on, right of the gadget the tape is a row of *units* `(10)^a 111 0 (10)^b`
separated by extra 0s (in the block notation of the group, `1^a 3 1^b` separated by `0`). At step 3·10^9 there are 13
units after a short irregular stretch next to the gadget, (a, b) = (51, 16), (2512, 22), (374, 34), (284, 107),
(125, 1), (204, 947), (456, 40), (3559, 1), (17222, 29), (130, 28), (413, 1), (40, 100), (6, 1), followed by
`(10)^116`. Each return of the head to the left end changes a few units; no rule for these changes has been found.

**Halting.** The only missing transition is E reading 1. E is entered only from D reading 1 (`0LE`), so the machine
halts exactly when D erases a 1 that has another 1 just to its left. The cycle never does this.

## Status

Open.

**Lean (kernel)**:
- `cycle_cells` (`lean/Rules.lean`, written by `py/gen_rules.py` with `bbtools.symtm.prove`): the cycle with the
  cells written out.
- `cycle` (`lean/Cycle.lean`): `steps (120*x+878) (cyc (x+6) R) = some (cyc x (rep 15 [true,false] R))`, where
  `cyc x R` is `C> G (10)^(2x) 111 0 R`.
- `cycles` (`lean/Cycle.lean`): k cycles at once, `steps (ccost x k) (cyc (x+6k) R) = some (cyc x (rep (15k) [true,false] R))`,
  with `ccost` recursive (it equals k(120x+878) + 360k(k-1); the closed form is not proved, there is no Mathlib).

**Lean (native_decide)** (`lean/Reach.lean`, written by `py/gen_reach.py`):
- `reach_16718`: blank tape reaches `cyc 32 R0` (X = 64) after 16,718 steps.
- `phase_end_29508`: five cycles later, at step 29,508, it is `cyc 2 ((10)^75 R0)`.

The bounded runs of `lean/Blank.lean` (no halt in 10^7 steps) are as generated.

**Computed (trusted)**: `tmrun` runs 10^11 steps without a halt. At the end 176,677 cells hold a 1.

**Heuristic**: the phase table and the description of the second regime come from the list of configurations with
C at the left end (25,758 of them up to 3·10^9 steps).

## Deciders tried (F11, 13 November 2026)

None closes. Each reaches a halting configuration in its abstraction, which says nothing about halting.

- n-gram CPS (`tools/c/ngramcps.c`), equal widths on both sides: a halting local configuration is reached with plain up to width 24, history 1 up to width 24, history 2 up to width 24, history 3 up to width 24, LRU history up to width 13 (larger widths ran out of the 150 s or 60 million configuration budget).
- n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 20, p = 3 up to width 20, p = 4 up to width 20, p = 6 up to width 20.
- n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets.
- Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4).
- Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..8; n = 9 not finished in 150 s.

## Where a halt can come from

`lean/Route.lean` (kernel, written by `py/route.py`): `halt_route`, two steps before any halt the machine is in one
of: C with 1 two left, 1 left, 0 under the head.
