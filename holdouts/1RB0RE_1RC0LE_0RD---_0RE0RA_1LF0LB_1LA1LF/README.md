# 1RB0RE_1RC0LE_0RD---_0RE0RA_1LF0LB_1LA1LF

bbchallenge id 96519. A six-state holdout of BB(6). **Open.** It is a string of digit words `(10)^d 0 1` rewritten by a head that moves only in short zigzags. A prefix of the tape has frozen.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 0RE |
| B | 1RC | 0LE |
| C | 0RD | --- |
| D | 0RE | 0RA |
| E | 1LF | 0LB |
| F | 1LA | 1LF |

## What it does

Cut the tape after every `0 1`: it becomes a string of words `(10)^d 0 1` (digits d, mostly 1 to 4, with a few
variants like `10 0 10 0 1`). The head does not sweep:

- after step 2,791,354 the head never again crosses the whole tape (checked to 3*10^9 steps);
- in the first 10^9 steps there are only 24 straight runs of 10 or more cells, the last at step 211,281,720;
- from step 3,401,999 on, successive snapshots of the tape agree on their first 1,850 to 2,000 cells.

So the run is a zigzagging rewriter that works on the right part of a digit string, while the left part stays
fixed. The shift rules `e_right` and `d_right` are the only long straight moves.

## Rules proved in Lean

`lean/Rules.lean` is generated by `lean/rules.py` (symbolic runs, `tools/py/bbtools/symtm.py`). Every rule holds for all values of its variables and all tapes L, R:

| theorem | from | to | meaning |
|---|---|---|---|
| `e_right` | `L 0 E> (10)^n 0 R` | `L (10)^n 0 E> 0 R` | E runs right over a block of `10` words, moving the 0 in front of it to its far side. |
| `d_right` | `L 0 D> (110)^n 0 R` | `L (101)^n 0 D> 0 R` | D runs right over a block of `110` words, shifting it by one cell. |

## Status

Open. Lean: the halting configurations and no halt in 10^7 steps (`lean/Blank.lean`), and two shift rules
(`lean/Rules.lean`). C: no halt in 3*10^9 steps.

## For later

- Treat the zigzag as a transducer: record the digit string before and after each pass of the active zone and look
  for a rule that rewrites a few digits at a time (a sliding window). Then prove it.
- Check whether the frozen prefix grows. If it does, and the active zone has bounded "state", the run may be a
  translated pattern of a known kind.
