# 1RB1RF_1RC0RE_1LD0RB_1RE0LC_1RA0LE_0RC---

bbchallenge id 75404. One of the six-state holdouts whose halting from blank tape is open. Like
1RB1RF_0RC0RE_0RD1RA_1LE0LA_1LB0LD_0RD--- (a different machine with the same kind of run), its tape is a **queue of
blocks (01)^k that a cursor eats one copy at a time while the block at the right end grows by two per copy**; the
block sizes that persist are 4^j - 2 (14, 62, 254, 1022, 4094). The feeding rules are proved in Lean, the global
schedule is not understood, halting is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1RF |
| B | 1RC | 0RE |
| C | 1LD | 0RB |
| D | 1RE | 0LC |
| E | 1RA | 0LE |
| F | 0RC | --- |


## What it does

Write `a` for `01` and `b` for `00110`. After a fixed prefix `(101001100)^128 (10)^10 0110` (the left end has not
moved since early in the run), the tape is a list of blocks a^k separated by b, and near the right end a *cursor*
cell (0 or 1) stands where a b would be:

    ... b a^(k+1) c a^m 0 B> 0^inf

**The feeding rules.** Each time the head comes to the right end in state B, one copy of 01 leaves the block before
the cursor, two join the block at the end, and the cursor flips:

    L a^(k+1) 0 a^m 0 B> 0^inf  ->  L a^k 1 a^(m+2) 0 B> 0^inf     in 4m+18 steps   (feed0)
    L a^(k+1) 1 a^m 0 B> 0^inf  ->  L a^k 0 a^(m+2) 0 B> 0^inf     in 4m+10 steps   (feed1)

(lean/Rules.lean, generated by py/rules.py with bbtools.symtm; restated in lean/Phase.lean as `feed0'`, `feed1'`;
two visits `feed2`: k+2 -> k, m -> m+4 in 8m+36 steps; `feeds` iterates it j times). A block of k copies thus
becomes 2k copies at the end; with a second pass (blocks are fed again later) and the separators this gives the
sizes 2 -> 14 -> 62 -> 254 -> 1022 -> 4094, each 4k + 6, which is what persists on the tape. Runs of equal blocks
(`(b a^62)^313`, `(b a^254)^61` at 10^9 steps) are digits of a counter-like structure: the queue is consumed from
the left of the active region and rebuilt, larger, at the right end, so the head's round trips grow and the right
end grows like the square root of the step count.

## Where it could halt

The machine halts only on F reading 1, and F is entered from A reading 1 (A moves right): a halt needs A to read a
1 followed by another 1. The CTL search of `bbtools.ctl` (K = 6) allows it only where the six
cells left of the head read `111011`; the words of the queue (`01`, `00110`, a cursor 0 or 1, the prefix) never
contain `111`, so a halt needs the machine to leave the block language.

## Status

Open. Proved in Lean: the halting configurations, no halt in 10^7 steps (`lean/Blank.lean`), the two feeding rules
and their iteration (`lean/Rules.lean`, `lean/Phase.lean`). Observed (not proved): the block sizes 4^j - 2, the
queue structure. Not understood: the order in which blocks are fed (the global schedule), so there is no macro map.

### Next steps

- Prove the transitions when a block is used up (the cursor moves to the next b), and write the whole queue as a
  counter with an exact update rule; compare with 1RB1RF_0RC0RE_0RD1RA_1LE0LA_1LB0LD_0RD---, whose queue has
  sizes 4^j.
- With the exact rule, a CTL certificate on the block language with cursors.
