The same node with other counts is not safe. With 61 words instead of 59 in the left block,

E> 0 (1011001)^61 1011 0^5 1101100110110 (011)^16 001101100110 (011)^r, r odd ≥ 65,

halts after 1,772,276 + 5,220 (r − 65) steps (computed by py/closure/classes.py, confirmed by plain simulation for r = 65, 67, 71). C(r) itself with r even halts too, much later, at event 21,362,421. So there is no simple description of "safe tapes" that contains the run: it is safe because it sits on one exact orbit. That is why the automatic deciders, which look for such descriptions, left this machine open, and why the proof follows the orbit itself.

The browser can run the halting neighbour: pick r and the number of seven-cell words, and the real machine runs from that tape.

With 59 words the browser stops after 2·107 steps; that the run from C(r) never halts for odd r ≥ 65 is the Lean theorem grow_cyc, not something a bounded run can show.
