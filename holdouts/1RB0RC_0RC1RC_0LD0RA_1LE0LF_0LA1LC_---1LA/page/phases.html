Three regular phases take almost all the time. p counts the seven-cell words, q or m the three-cell words of the middle block, r those of the last block.

Collecting turns three-cell words into seven-cell words one for one; expanding gives seven three-cell words back for each seven-cell word. So each round the blocks are about seven times longer: about 600, 4,370, 30,750, 215,000, 1,506,000 words. Between the phases there are short irregular stretches where the separators collide, and trains of cars (011)^4 0 are built and taken apart. Usually the next round starts. Sometimes the stretch ends in the drain pattern: then the whole left block is poured into the last block (414 words of three for 52 words of seven), and the left part starts again from a small state, in front of a much longer last block.

At level 3 a whole cycle of a phase is one statement. A cycle rule is a template of the whole tape whose counts are b + 2x before and b' + 2x after, one x for each block that changes. It is proved for all values of the x by one run of the executor itself, without cycle rules, from the template before to the template after (ruleOK_of_run, kernel; the run is evaluated by native_decide: rule0_ok … rule11_ok in lean/ExecData.lean). The executor then applies a rule N times in one move, N as large as the shrinking counts allow; the induction over N is in Lean (rule_instN, kernel), so the choice of N is not trusted. Twelve rules were enough: eleven are collect or expand, plain or with inert trains in between, and one, rule 8, is the drain. Separately, lean/Phases.lean proves the plain collect and expand cycles by hand for any number of cycles, with the kernel only (collect2, collect_n, expand4, expand_n); the replay does not need them.

Every block that has a variable gets the same x here. The browser writes the template on a blank tape, puts the head on its first cell in state E, runs the real machine until state E has reached the left end the rule's number of times, and compares the tape with the template after. The drain (rule 8) takes about five million steps. lean/Phases.lean writes the blocks of three-cell words with the six-cell word 110110 and allows any count b + x, not only b + 2x.
