# 1RB1LD_0LC0RA_1RA1LC_1RE0LC_---1RF_0RD0RB

bbchallenge id 726. One of the six-state holdouts whose halting from blank tape is open.

| state | read 0 | read 1 |
|---|---|---|
| A | 1RB | 1LD |
| B | 0LC | 0RA |
| C | 1RA | 1LC |
| D | 1RE | 0LC |
| E | --- | 1RF |
| F | 0RD | 0RB |

## What it does

**An irregular region beside a tail of 10s.** In the first 10^9 steps the left end of the tape is last extended at
step 43,506. Whenever the head turns at the right end, the tape reads `[irregular region] (10)^n`. A tick is a round
trip across the tail: the head zigzags left in states C and A, two cells every four steps (`zig`), turns near the
tail's left end (sometimes after rewriting the region), and runs back right in state B (`run_right`). Each tick adds
one cell.

The irregular region is a sequence of runs of ones separated by single 0s. At step 10^8, of its 1,191 runs, 679 have
length 6, 246 length 2, 193 length 10, and the rest are rare defects. Unlike a counter it grows linearly in the number
of ticks:

| step | region (cells) | tail (copies of 10) |
|---|---|---|
| 98,902 | 280 | 49 |
| 2,840,976 | 1,528 | 374 |
| 24,502,522 | 4,060 | 1,006 |
| 99,931,972 | 7,904 | 1,931 |

How far back a tick rewrites the region is heavy-tailed. Over 11,392 ticks, about half touch only the last 20 cells,
563 reach 20-39 cells, 109 reach 80-99, and 30 still reach 720-739.

## Rules proved in Lean (`lean/Rules.lean`, generated by `lean/rules.py`)

- `zig`: `L (10)^n 1 0 C> 1 R` reaches `L C> (10)^n 1 0 1 R` in 4n + 4 steps.
- `run_right`: `L B> (10)^n R` reaches `L (01)^n B> R` in 2n steps.

## Status

**Open.** Proved: the halting configurations, no halt in 10^7 steps (`lean/Blank.lean`), and the two sweeps. The
machine halts only when D reads 0 with a 0 to its right (E reading 0). No rule for the irregular region is known.

## For later

## Deciders tried (F11, 13 November 2026)

None closes. Each reaches a halting configuration in its abstraction, which says nothing about halting.

- n-gram CPS (`tools/c/ngramcps.c`), equal widths on both sides: a halting local configuration is reached with plain up to width 24, history 1 up to width 24, history 2 up to width 24, history 3 up to width 24, LRU history up to width 22 (larger widths ran out of the 150 s or 60 million configuration budget).
- n-gram CPS with every cell tagged by its position mod p: fails for p = 2 up to width 20, p = 3 up to width 20, p = 4 up to width 20, p = 6 up to width 20.
- n-gram CPS where each side also carries the state of a small automaton that has read that side from the far end (every automaton with up to 3 states on both sides, or 4 states on one side), with position mod 1..4 and widths 4, 6, 8: no closed set without a halt in all 120 parameter sets.
- Run-length windows (the K nearest runs of equal macro cells on each side, run lengths kept exactly below T and mod M above): fails for all 72 parameter sets (cells of 1 to 4 bits, K = 2, 4, 6, T = 2, 4, M = 1, 2, 4).
- Two-automaton closed tape language by SAT (a deterministic automaton reading each side inward, n states each, CaDiCaL): no solution for n = 2..9; n = 10 not finished in 150 s.

## Where a halt can come from

`lean/Route.lean` (kernel, written by `py/route.py`): `halt_route`, two steps before any halt the machine is in one
of: F with 0 under the head, 0 right, 0 two right.
