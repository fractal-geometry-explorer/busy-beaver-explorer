# Lab notes: 1RB1RA_1LC1LD_1LD0LB_1RE0RF_---1RD_1RA1RB

## 30 October 2026: setup and first look

Set up on the shared tools (`../../tools`): `lean/Machine.lean` generated by `bbtools.leangen` (namespace `BB6c`),
bounded runs in `lean/Blank.lean`, the reference simulator wrapped in `py/blank.py`.

The table, with the halting transition E0:

| state | on 0 | on 1 |
|---|---|---|
| A | 1RB | 1RA |
| B | 1LC | 1LD |
| C | 1LD | 0LB |
| D | 1RE | 0RF |
| E | halt | 1RD |
| F | 1RA | 1RB |

**Where a halt comes from.** E is entered only by D0 (write 1, move right), so the machine halts exactly when D reads
a 0 whose right neighbour is 0 (`halt_shape`, kernel). A sweeps right over 1s (A1 = 1RA) and turns at the first 0.

**Bounded runs.** No halt in 20,000 steps (kernel), 10⁷ (`native_decide`), 10¹⁰ (C `tmrun`, 5,580 ones, 6,278
cells visited).

**No linear invariant.** `bbtools.invariants` finds no conserved a·ones + b·pos + W[state] modulo 2 to 12.

**First records** (`python3 py/blank.py records 100000 60`): the head reaches new cells mostly on the right, as
`1^a 0 1^b A>0` and then `1^a 0 1^(b+1) B>0` one step later (steps 46, 155, 183, 444, 855, 1408, 1600, 2311, 3234,
...). The left part of the tape becomes a run of `1^2 0` blocks with an occasional `1 0`; D reaches the left end on a
0 or a 1, and in the first 3·10⁹ steps the cell to its right is always a 1 (655 times `D>0 1^2`, 193 times
`D>0 1 0`, 534 times `D>1`).

**Growth.** After t steps the width w is roughly √(t/250): t/w² is 207 at w = 5,080 (5.3·10⁹ steps) and 254 at
w = 6,277 (10¹⁰), so a little worse than quadratic time per cell, so a pass over the tape is likely the unit of the macro structure.
