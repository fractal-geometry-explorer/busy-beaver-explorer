# The six-state machine 1RB1RA_1RC1LB_1LD0RA_---0LE_1LC0LF_1RE0LB

Whether this machine halts from blank tape is open. This folder holds its work; the shared tools are in
[`../tools`](../tools), the proof-status page is [`../pages/1RB1RA_1RC1LB/proof-status.html`](../pages/1RB1RA_1RC1LB/proof-status.html)
(built from [`status.json`](status.json)), and the log is [`notes/LAB_NOTES.md`](notes/LAB_NOTES.md).

## What is established

**Proved in Lean, kernel only** (`lean/`): no halt in the first 20,000 steps (`blank_runs_20000`); the shift rules
`a_sweep` (A runs right over 1^n) and `b_sweep` (B runs left over 1^n to the 0 before it).

**Proved in Lean with `native_decide`**: no halt in the first 10,000,000 steps (`blank_runs_10M`).

**Computed** (trusted C/Python, tested): no halt in the first 10¹⁰ steps (`tools/c/tmrun`); no conserved quantity
a·ones + b·pos + W[state] modulo 2 to 12 (`tools/py/bbtools/invariants.py`).

**Observed only**: the tape is a list of blocks of ones; the head returns to the left end rarely, the last time at step
2,047,931 up to 10¹⁰ (see the notes).

## Layout

| path | contents |
|---|---|
| `lean/Machine.lean` | the machine, generated by `tools/py/bbtools/leangen.py` |
| `lean/rules.py` → `lean/Rules.lean` | rules proved along the symbolic run (generated; do not edit the `.lean`) |
| `lean/Blank.lean` | bounded runs from blank tape |
| `lean/Axioms.lean` | prints what each theorem rests on |
| `tests/test_machine.py` | the generated files are current, early facts of the run |
| `runs/` | outputs of long runs |
