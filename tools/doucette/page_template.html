Five machines, one question

Does a Doucette sequence ever hit a power of two?

Five of the six-state holdouts, Space Needle among them, halt exactly when a simple one-number sequence lands on a power of 2 (one of them: a power of 3). Lean proves those equivalences. This page collects what has been learned about the sequences themselves: which values could step onto a power (proved), how far the sequences have been followed (computed, now terms of each), and why every piece of evidence points the same way while a proof stays out of reach.

Still open, for all five. Nothing found here decides any of them. What is new:

  • kernel For each machine, the exact set of values that can step onto a power, and so a list of exponents that can never be hit (for example, the 1RB1LA_0LC0RC_1LE1RD_1RE1RC_1LF0LA_---1LE sequence never reaches 2n with n ≡ 1 mod 4, and 1RB0RF_1RC1RF_1LD0LE_---1LC_1RA1LE_1LC1RB's misses 17 exponents in every 24).
  • kernel The shift identity that makes the sequences computable a hundred times faster: the next valuations depend only on the low digits, so the low digits can be run alone.
  • computed No power reached in the first terms of each sequence.
  • evidence The valuations are independent and geometric to within sampling noise, the backward tree of every power is tiny, and a halt would need a backward chain hundreds of millions of steps long.

The five maps

One rule, five sets of constants

Write D = bv(b·a + ρ) with ρ ≠ 0, so v counts the factors b of D. Then each sequence goes D → D + α·a + v + (a constant), except at a few exceptional values that the orbits never visit; the machine halts when D is a pure power of b. Each D stands for a configuration of the machine; the Lean theorem named in the last column proves that the machine halts from blank tape exactly when its sequence reaches a power.

Proved in Lean

The last step before a halt

Which values step onto a power? For the four maps with α = 1, the equation D' = bn becomes (b·a + ρ)(bv+1 + 1) + w = bn+1 + … with w small, and modulo q = bv+1 + 1 the powers of b are only ±bi (because bv+1 ≡ −1). So w must be one of a handful of numbers, which pins v to one or two values and n to one class. This is the "dangerous families" argument of the bbchallenge wiki (credited to Aristotle), made exact for all five machines and checked by Lean's kernel. Space Needle (α = 3, q = 2v+1 + 3) has no such symmetry: there the condition only puts n in one class modulo the order of 2, for each possible v, and some v are impossible outright.

Backward trees

Everything that leads to a power is a tiny tree

Run the map backwards from bn: find every D that steps onto it, then everything that steps onto those, and so on. A random number has on average fewer than one predecessor (about 0.7 for Space Needle), so these trees die out quickly. Below n = 400 the deepest tree is 9 levels for Space Needle and 33 for the deepest of the others; a halt at bn needs a chain from the start that is hundreds of levels deep already at n = 400 (the sequence gains only about one bit per step), and hundreds of millions deep for the n that are still possible after the computations.

Computed

A billion terms of each sequence

The shift identity (tools/doucette/lean/Shift.lean): if D = bmX + L and the valuation v of L satisfies v + 2 ≤ m, then D has the same v as L and F(D) = bm−v−1(bv+1 + α)X + F(L). So the next valuations depend only on the low digits, and many steps can be taken on the low half of the number alone, with the high half folded back in by one multiplication. Applied recursively (as for fast Collatz trajectories), N terms cost about as much as a few multiplications of the final number. In Python with GMP, 108 terms of Space Needle take about a minute on one core, and the run reproduces the community's 108-term computation exactly: 94,125,050 bits at term 108, the first v = 25 at term 23,145,881. No exceptional value can occur inside a jump (its odd part is at least b2), so every possible halt is checked by the exact rule.

Records: the step at which each new largest valuation first appears. Hashes are SHA-256 of the final term's big-endian bytes; tools/doucette/results/ has them at every checkpoint.

Evidence

The valuations behave like coin flips

If the low digits were random, v would be geometric: P(v = k) = (b−1)/bk+1. This is exact for a uniformly random b-adic starting value: the valuations depend only on the low digits (the shift identity), and each run of valuations v1, …, vk is taken by exactly one residue class modulo bΣ(vi+1), because the multiplier bv+1 + α is prime to b (the standard argument for the Collatz map; not in Lean here). What a proof would need

Why this is hard

A non-halting proof has to show that one specific orbit never has v equal to its own length, that is, it must control the low digits of every term forever. Every known technique stops short:

  • Residues. Each condition found here (a class of n, a set of v) leaves infinitely many exponents open, and the 2-adic picture is exactly uniform: no congruence on D can be invariant, because every finite run of valuations is taken by some residue class.
  • Backward trees. They are finite for each n, but proving a bound on their depth for every n is the same problem again.
  • Baker-type bounds (used for 1RB1LA_1RC1RE_1LD0RB_1LA0LC_0RF0RD_0RB---) need the orbit in closed form, like 2·3i close to a power of 2. Here the orbit has no closed form; its growth factor changes every step with v.

So these five stay probviously non-halting: the heuristic chance that any of them ever halts is below 2−108.
